Reference ledger: claims to verify by hand¶

State on 2026-11-12: 43 rows are open, i.e. not yet checked by hand against the original (row 35 was checked against the arXiv PDF on 2026-11-12). This is a separate check from the page proofs of the assumption ledger (tngxmm ledger proofs, which locate each quoted text on its arXiv PDF page). Until a row is checked, the value it carries is as read, with the reading mode stated below.

Every claim that a decision, a line of code or a sentence of the paper rests on, with the source we took it from and how we read it. The author checks each row against the original (PDF or journal page, not a summary) and fills in the last two columns. This ledger is about CONTENT; the bibliographic metadata of each key (authors, journal, DOI) is tracked separately by verify: in citations/*.yml.

How we read the sources: primary = the paper’s own text (journal or arXiv); rendered = an HTML rendering of the arXiv source (ar5iv / arxiv.org/html), read through an automatic summariser, so equations and numbers can be garbled; secondary = another paper or a search result quoting it; code = read in the installed source; internal = our own reports.

Every numeric literature value the code uses (the published cluster masses of reference_masses.csv and the constants: cosmology, c(M), abundances, truth definitions, priors, instrument facts) is tabulated, with its table/equation, arXiv page and code location, in the public inputs/literature_values.csv (see inputs/README.md); its verified column follows the verdicts of this ledger. The paper sources themselves live in the private references area, outside git.

Status: open (not checked), ok (checked, as stated), fix (checked, wrong: correct the text/code), drop (do not use).

μ ≈ 0.6 for the ICM: “μ … ≈ (2X + 3/4 Y + 1/2 Z)⁻¹ ∼ 0.6” and μ_e = 1.155 for a cosmic H/He mix with 0.3 solar metals (Ettori et al. 2013, §2, §3.2); “μ = ρ_gas/(m_u n_gas) ≈ (2X + 0.75Y + 0.56Z)⁻¹ ≈ 0.6” (Ettori et al. 2019, X-COP, A&A 621, A39, §3); “μ = 0.59 … assuming a primordial, fully ionized plasma” (Pearce et al. 2020, eq. 5). 6

“True” hydrostatic mass from simulation profiles: 3D density and MASS-WEIGHTED temperature in 50 linearly spaced radial bins over 0–1.5 r500 (§2.1.5, eq. 1); M_tot(<r) = r kT/(G μ m_p)[dlogρ_g/dlogr + dlogT/dlogr] with μ = 0.59 (§2.4, eq. 12; thermal only, implicit). The slopes are NOT finite differences: §2.4 fits the 3D density (as n_e n_H) with the Vikhlinin (2006) modified β model (eq. 8, γ = 3, ξ < 5) and the 3D temperature with the Vikhlinin T model (eq. 10, T0 t_cool t) and uses the ANALYTIC derivatives of the fits. Our headline is the Barnes-faithful barnes21_nosf_fit_mu (single Vikhlinin component, analytic slopes, star-forming gas excluded, each cell’s own thermal pressure instead of mu = 0.59). The finite-difference variant barnes21_nosf (numpy.gradient of the binned profiles, mu = 0.59: noisier, non-monotonic M(<r)) is a diagnostic column; the mu = 0.59 fit is not emitted. The M500 crossing rule (innermost downward crossing of 500 ρ_c beyond 0.4 R500c) is OUR choice: Barnes gives none (§2.4 only says r500,est is found by interpolating the profile to where it crosses 500). Barnes removes substructure only for the images (§2.2.3), not for these profiles. NO gas cut is stated for these profiles. The cuts T < 10⁶ K / star-forming / net-cooling belong to the synthetic X-ray images (§2.2.3)

Barnes et al. 2021, MNRAS 506, 2533; doi:10.1093/mnras/stab1276; arXiv:2001.11508
