Figures¶

The figures of this site, made from results that exist on disk by python -m tngxmm.viz.doc_figures (module tngxmm.viz.doc_figures). No figure runs a simulation or a fit. Each input file is recorded in docs/figures/manifest.json with its root variable, relative path, size and sha256 (the tables under each figure), and python -m tngxmm.viz.doc_figures --check tells whether an input has changed since. Files under $TNGXMM_DEV are in the development area, not in the data package; they have to move into the data package before a reader can remake those figures.

Paper candidates are written as PDF as well. “Paper candidate” means the figure type is proposed for the paper; most of them need to be remade on the final configuration first (the caveat of each says so).

pipeline_overview¶

The stages of the pipeline and the products between them. The mock branch (simulation, instrument) and the real branch (PPS products of the reference observations) meet in the same photometry, the same source detection rules and the same hydrostatic fit; the comparison uses three masses per mock (M_X, M_HSE, M_true; Science definitions). The node-level graph is in the README and in Kedro-Viz.

No input files (a diagram drawn by the function).

mock_vs_real¶

Left: the 0.5-2 keV mock of TNG-Cluster halo 19542651 at snapshot 67 (z = 0.503, M500c = 1.5e14 Msun from the group catalogue), view 0, observed at z_obs = 0.496 as XMM observation 0656201501 (the golden fixture products of release 1.1.1, the current configuration). Right: the PPS mosaic of that observation (PSZ2 G308.33-20.21, z = 0.48, catalogue M500 = 1.06e15 Msun). Same 4 arcsec pixels, Gaussian smoothing of 2 pixels and the stretch rule of the image bank on each panel. Caveats: the halo is the fixture halo, chosen to be small enough to ship, not a mass match to this cluster (the catalogue M500 of the cluster is seven times the halo’s); the detector orientation differs because the mock is observed with a jittered roll angle; the mock field is the donor’s exposure-map footprint. A pair from the production replica list needs production trees of the current configuration, which do not exist yet.

Function: tngxmm.viz.doc_figures.fig_mock_vs_real(); commit 05ad75c505b7; paper candidate: yes.

lx_mass¶

Rest-frame 0.5-2 keV luminosity inside R500, scaled by E(z)^-2 (self-similar for a band emissivity independent of temperature), against mass. Orange: 6,634 TNG-Cluster views of the v1.0.1 trees with a valid measurement, measured on the mock images with the campaign estimator (point sources masked, annulus background); orange line: running median; red line: the intrinsic luminosity of the same views. In the median the measurement reads the mocks low: log10(measured / intrinsic) over these 6,634 views has a median of -0.077 dex (16-84 per cent -0.141 to -0.045; -0.096 dex at 1-2e14 Msun, -0.066 dex above 7e14 Msun). In the 1 Mpc aperture the median is -0.071 dex over 6,967 views (LXGAP_INVESTIGATION/REPORT.md, section 2), within 0.015 dex of that below z_obs = 0.8 and -0.112 dex above (851 views). This is the net ratio of the measurement chain, mostly the vignetting, chip gaps and inactive CCDs that the on-axis live time and ECF leave out and the PSF; the background annulus is a small part (Validation status, “The L_X estimator against the intrinsic luminosity”; internal/ledger_tests/lx_truth_ratio.py). Blue: 615 real observations measured with the same estimator on their PPS mosaics. At 4-7e14 Msun the mocks are +0.31 dex brighter. Caveats: the mass axes are different quantities (true M500c(z_obs) for the mocks, the catalogue M500 for the real clusters, mostly SZ masses, which are biased low), so the offset is not the luminosity excess at fixed true mass (+0.28 dex, Validation status); the v1.0.1 mocks emit from the FoF gas within 2 R200c, not the cube of release 1.1 (a median +0.001 dex difference in L on 30 halos); the truth ratio is that of the v1.0.1 configuration, an earlier one (on the views of the L_X gap test, release 1.1.3 instrument and full emission, L_X(1 Mpc) reads 0.052 dex low); the ratio is not known for the real clusters, whose aperture is the catalogue R500, so whether it cancels in the offset between the two sides is not measured.
