Source code for tngxmm.analysis.pilot_report

"""The report of the pilot run (``docs/dev/PILOT.md``): the fit against published hydrostatic masses on real
clusters, and against the true and the hydrostatic mass of the simulation on mocks.

    python -m tngxmm.analysis.pilot_report --real-fits <work_real>/fits --real-targets <targets_real.csv> \\
        --references <references_realfit_v4.csv> --mock-fits <work_mock>/fits --truth-root <campaign tree> \\
        --sim flamingo_l1m8 --out <dir>

It reads finished fits only and can be run while the job is going: the numbers are then those of the fits
finished so far, and the report says how many of each list that is.

Tables: :func:`tngxmm.analysis.tables.real_table` (one row per fit and reference; the rows of the hydrostatic
reference :data:`REFERENCE_KEY` are kept) and :func:`tngxmm.analysis.tables.mock_table` (the estimands at z_obs:
``ln_bt_so`` fit / true, ``ln_br_so`` fit / hydrostatic truth, ``ln_rt_so`` hydrostatic truth / true).  The
reference masses are already in the analysis cosmology (``m500_ref_1e14`` of the references table).

Samples.  A fit is inside the domain of the measurement when it carries none of the flags that are known before
it runs (:data:`DOMAIN_FLAGS`: the centre, a cluster that fills the field so that no image has a region beyond
2 R500, a first guess limited by the field or missing).  They come from the target row and the geometry of the
images, the same for mocks and real data, so the domain does not depend on what the fit returns.  The flags a fit
earns from its own result (:data:`FIT_FLAGS`) do: cutting on them can remove the fits that disagree.  Every
statistic is therefore given three times: inside the domain without a fit flag (the usable fits of
:data:`tngxmm.massfit.fit_qc.QC_EXCLUDING`), inside the domain with every ok fit, and outside the domain (a
known limit of the method, reported apart).

Statistics: the median of the ln ratio with a bootstrap 95 per cent interval of the median, the scatter
(1.4826 times the median absolute deviation) and the slope of the ln ratio with log10 mass and with redshift
(least squares, bootstrap interval over the fits).  The bootstrap resamples fits; the pilot has one view per halo
and one observation per cluster.

Tension, per real fit (:func:`tension`): the fit's 68 per cent interval (``m500_lo``, ``m500_hi`` of its
result.json) against the published one (the errors of ``reference_masses.csv``, carried to the analysis cosmology
with the mass).  ``overlap`` says whether the two intervals overlap, ``pull``
is the ln ratio over the two facing errors added in quadrature.  The report counts the fits whose intervals do
not overlap and those beyond 2 and 3 sigma and names them; it draws no line through these counts.

The mocks are read from two numbers.  Fit / hydrostatic mass of the simulation is the test of the measurement: the
same gas, the same assumption, so the median should be 1 and the reading says whether its interval includes 1.
No pull per view is formed against it: the simulation's value is a point and the fit's interval is statistical
only, so such a pull measures the scatter between the two, not an error.  Hydrostatic mass of the simulation /
true mass involves no fit and is set against the literature; fit / true is their product and keeps the range
written in ``docs/dev/PILOT.md`` (:data:`READINGS`), which on its own cannot tell a biased fit from the
simulation's bias.

Written: ``pilot_report.md``, ``pilot_real.csv``, ``pilot_mock.csv``, ``pilot_report.png``.

References
----------
lovisari2020 : the published hydrostatic masses (Table A1).
wicker2023 : the copy of that table, kept for comparison.
pratt2019 : the range of the hydrostatic bias in simulations the mock reading uses.
barnes2021 : the hydrostatic mass of the truth stage.
"""
from __future__ import annotations

import json
import math
from pathlib import Path
from typing import Any

#: the hydrostatic reference of the real list (Lovisari et al. 2020, their Table A1)
REFERENCE_KEY = "hse_lovisari2020_xmm"
#: the same masses as Wicker et al. 2023 copied them (20 of 120 rows differ), for comparison only
COMPARISON_KEY = "hse_wicker2023_xmm"
#: bootstrap resamples and seed of every interval
NBOOT = 4000
BOOT_SEED = 20261110
#: the comparisons: column of the ln ratio -> question
QUESTIONS: dict[str, str] = {
    "ln_fit_ref": "real, fit / published hydrostatic mass",
    "ln_br_so": "mock, fit / hydrostatic mass of the simulation",
    "ln_rt_so": "mock, hydrostatic mass of the simulation / true mass (no fit)",
    "ln_bt_so": "mock, fit / true mass",
}
#: flags known before the fit runs (target row, image geometry): they set the domain of the measurement
DOMAIN_FLAGS = ("centre", "bg_fallback", "field_edge", "no_seed")
#: flags a fit earns from its own result
FIT_FLAGS = ("prior_edge_c200", "prior_edge_Z", "pout_runaway")
#: the three samples of every statistic
USABLE, IN_DOMAIN, OUTSIDE = "in domain, no fit flag", "in domain, every ok fit", "outside the domain"
#: the reading by range of docs/dev/PILOT.md: column -> lowest and highest median ratio at which it holds (the
#: range of the hydrostatic bias in simulations, Pratt et al. 2019).
READINGS: dict[str, tuple[float, float]] = {"ln_bt_so": (0.70, 1.00)}


def _finite(x: Any) -> Any:
    import numpy as np

    x = np.asarray(x, float)
    return x[np.isfinite(x)]

def ratio_summary(ln: Any, nboot: int = NBOOT, seed: int = BOOT_SEED) -> dict[str, float]:
    """Of the ln ratios ``ln`` (NaNs dropped): ``n``, the ``median`` ratio, the bootstrap 95 per cent interval of
    the median (``lo``, ``hi``; NaN below three fits) and ``scatter``, 1.4826 times the median absolute deviation
    of the ln ratio."""
    import numpy as np

    x = _finite(ln)
    out = dict(n=int(len(x)), median=math.nan, lo=math.nan, hi=math.nan, scatter=math.nan)
    if not len(x):
        return out
    med = float(np.median(x))
    out.update(median=math.exp(med), scatter=float(1.4826 * np.median(np.abs(x - med))))
    if len(x) >= 3:
        rng = np.random.default_rng(seed)
        b = np.median(rng.choice(x, size=(nboot, len(x)), replace=True), axis=1)
        lo, hi = np.percentile(b, [2.5, 97.5])
        out.update(lo=math.exp(lo), hi=math.exp(hi))
    return out

def trend(x: Any, ln: Any, nboot: int = NBOOT, seed: int = BOOT_SEED) -> dict[str, float]:
    """Least-squares slope of the ln ratio ``ln`` with ``x`` over the rows where both are finite, with the
    bootstrap 95 per cent interval over the rows (NaN below five rows or when ``x`` does not vary)."""
    import numpy as np

    x, y = np.asarray(x, float), np.asarray(ln, float)
    ok = np.isfinite(x) & np.isfinite(y)
    x, y = x[ok], y[ok]
    out = dict(n=int(len(x)), slope=math.nan, lo=math.nan, hi=math.nan)
    if len(x) < 5 or np.ptp(x) == 0:
        return out
    out["slope"] = float(np.polyfit(x, y, 1)[0])
    rng = np.random.default_rng(seed)
    idx = rng.integers(0, len(x), size=(nboot, len(x)))
    b = [np.polyfit(x[i], y[i], 1)[0] for i in idx if np.ptp(x[i]) > 0]
    out["lo"], out["hi"] = (float(v) for v in np.percentile(b, [2.5, 97.5]))
    return out

def reading(column: str, summary: dict[str, float]) -> str:
    """The reading of ``column`` for a :func:`ratio_summary`: ``no fits`` without a median; for a column of
    :data:`READINGS`, ``holds`` when the median ratio lies in the range and ``does not hold`` otherwise; for the
    real clusters ``by tension`` (the counts of :func:`tension_summary`); for fit / hydrostatic mass of the
    simulation whether the interval of the median includes 1 (``too few fits`` without an interval); for the
    simulation's own ratio ``against the literature``."""
    m = summary["median"]
    if not m == m:
        return "no fits"
    if column == "ln_fit_ref":
        return "by tension"
    if column == "ln_rt_so":
        return "against the literature"
    if column == "ln_br_so":
        lo, hi = summary.get("lo", math.nan), summary.get("hi", math.nan)
        if not lo == lo:
            return "too few fits"
        return "interval includes 1" if lo <= 1.0 <= hi else "interval excludes 1"
    lo, hi = READINGS[column]
    return "holds" if lo <= m <= hi else "does not hold"

def tension(m_fit: Any, fit_lo: Any, fit_hi: Any, m_ref: Any, ref_lo: Any = None, ref_hi: Any = None) -> Any:
    """Per fit: ``overlap`` (the fit's interval [fit_lo, fit_hi] and the reference's [ref_lo, ref_hi] overlap) and
    ``pull`` = ln(m_fit / m_ref) over the quadrature sum of the two errors that face each other, in ln (the fit's
    lower and the reference's upper error when the fit lies above, the opposite ones below).  A reference without
    errors (``ref_lo``, ``ref_hi`` None) is a point.  NaN where an input is missing."""
    import numpy as np
    import pandas as pd

    f, flo, fhi, r = (np.asarray(x, float) for x in (m_fit, fit_lo, fit_hi, m_ref))
    rlo = r if ref_lo is None else np.asarray(ref_lo, float)
    rhi = r if ref_hi is None else np.asarray(ref_hi, float)
    with np.errstate(divide="ignore", invalid="ignore"):
        d = np.log(f / r)
        above = d >= 0
        sf = np.where(above, np.log(f / flo), np.log(fhi / f))
        sr = np.where(above, np.log(rhi / r), np.log(r / rlo))
        sig = np.hypot(sf, sr)
        pull = np.where(sig > 0, d / sig, np.nan)
    ok = np.isfinite(pull)
    overlap = np.where(ok, (flo <= rhi) & (rlo <= fhi), False)
    return pd.DataFrame(dict(pull=pull, overlap=pd.array(np.where(ok, overlap, None), dtype="boolean")))

def tension_summary(pull: Any, overlap: Any) -> dict[str, float]:
    """Of the fits with a pull: ``n``, ``n_overlap``, ``n_gt2`` and ``n_gt3`` (|pull| above 2 and 3), the
    ``median_pull`` and ``rms_pull`` (1 for Gaussian errors of the right size and no offset)."""
    import numpy as np

    p = np.asarray(pull, float)
    ok = np.isfinite(p)
    p, ov = p[ok], np.asarray(overlap)[ok]
    n = int(len(p))
    return dict(n=n, n_overlap=int(sum(bool(x) for x in ov)), n_gt2=int((np.abs(p) > 2).sum()),
                n_gt3=int((np.abs(p) > 3).sum()), median_pull=float(np.median(p)) if n else math.nan,
                rms_pull=float(np.sqrt(np.mean(p ** 2))) if n else math.nan)




def _fit_intervals(table: Any) -> Any:
    """``table`` with ``m500_lo_1e14`` and ``m500_hi_1e14``, the 16th and 84th percentiles of each fit's M500
    (``m500_lo``, ``m500_hi`` of the result.json in ``fit_dir``)."""
    lo, hi = [], []
    for d in table.fit_dir:
        try:
            res = json.loads((Path(d) / "result.json").read_text())
        except (OSError, ValueError):
            res = {}
        lo.append(res.get("m500_lo"))
        hi.append(res.get("m500_hi"))
    out = table.copy()
    out["m500_lo_1e14"], out["m500_hi_1e14"] = lo, hi
    return out

@cites("lovisari2020", "wicker2023")
def real_rows(fits_root: str | Path, targets_csv: str | Path, references_csv: str | Path,
              catalogue_csv: str | Path | None = None, reference_key: str = REFERENCE_KEY) -> Any:
    """The real fits against the hydrostatic reference: the rows of
    :func:`~tngxmm.analysis.tables.real_table` with ``ref_key`` ``reference_key`` (default
    :data:`REFERENCE_KEY`; :data:`COMPARISON_KEY` gives the Wicker+23 copy), the fit's interval, the
    reference's interval (``m500_ref_lo_1e14``, ``m500_ref_hi_1e14``: the published errors of the row ``ref_id``
    of ``catalogue_csv``, default the packaged ``reference_masses.csv``, times the factor that carried the
    published mass to the analysis cosmology) and their :func:`tension`."""
    import pandas as pd

    from tngxmm.analysis.tables import real_table
    from tngxmm.obs.build_observations import REFERENCE_MASSES_CSV

    t = real_table(fits_root, targets_csv, references_csv)
    t = _fit_intervals(t[t.ref_key == reference_key].reset_index(drop=True))
    ref = pd.read_csv(references_csv, dtype={"obsid": str})
    ref = ref[ref.ref_key == reference_key].set_index("obsid")
    if not len(ref):
        raise ValueError(f"{references_csv}: no row of reference key {reference_key!r}")
    cat = pd.read_csv(catalogue_csv or REFERENCE_MASSES_CSV).drop_duplicates("ref_id").set_index("ref_id")
    lo, hi = [], []
    for ob, m in zip(t.obsid, t.m500_ref_1e14):
        r = ref.loc[ob]
        c = cat.loc[r.ref_id]
        k = float(m) / float(r.m500_published_1e14)
        lo.append(k * (float(c.value_1e14msun) - float(c.err_lo_1e14msun)))
        hi.append(k * (float(c.value_1e14msun) + float(c.err_hi_1e14msun)))
    t["m500_ref_lo_1e14"], t["m500_ref_hi_1e14"] = lo, hi
    tn = tension(t.m500_fit_1e14, t.m500_lo_1e14, t.m500_hi_1e14, t.m500_ref_1e14, lo, hi) if len(t) else \
        tension([], [], [], [])
    return pd.concat([t, tn.rename(columns={"pull": "pull_ref", "overlap": "overlap_ref"})], axis=1)

def _samples(table: Any) -> dict[str, Any]:
    """The ok rows of a fit table by sample: :data:`USABLE` (no excluding flag), :data:`IN_DOMAIN` (no flag of
    :data:`DOMAIN_FLAGS`, whatever the fit's own flags) and :data:`OUTSIDE` (a flag of :data:`DOMAIN_FLAGS`)."""
    import numpy as np

    ok = table[table.status.astype(str) == "ok"]
    out = np.zeros(len(ok), bool)
    for k in DOMAIN_FLAGS:
        if k in ok:
            out |= np.asarray(ok[k].astype(bool))
    return {USABLE: ok[~ok.qc_excluded.astype(bool)], IN_DOMAIN: ok[~out], OUTSIDE: ok[out]}


def _fmt(v: float, nd: int = 3) -> str:
    return "n/a" if not v == v else f"{v:.{nd}f}"


def _summary_lines(table: Any, column: str, mass_col: str, z_col: str) -> list[str]:
    import numpy as np

    out = ["| sample | fits | median ratio | 95 % interval | scatter (ln) | slope per dex of mass | slope per unit z |",
           "|---|---|---|---|---|---|---|"]
    for label, t in _samples(table).items():
        s = ratio_summary(t[column])
        with np.errstate(divide="ignore", invalid="ignore"):
            tm = trend(np.log10(np.asarray(t[mass_col], float)), t[column])
        tz = trend(t[z_col], t[column])
        out.append(f"| {label} | {s['n']} | {_fmt(s['median'])} | {_fmt(s['lo'])} to {_fmt(s['hi'])} | "
                   f"{_fmt(s['scatter'])} | {_fmt(tm['slope'], 2)} ({_fmt(tm['lo'], 2)} to {_fmt(tm['hi'], 2)}) | "
                   f"{_fmt(tz['slope'], 2)} ({_fmt(tz['lo'], 2)} to {_fmt(tz['hi'], 2)}) |")
    return out


def _qc_lines(table: Any, n_listed: int | None) -> list[str]:
    from tngxmm.massfit.fit_qc import QC_EXCLUDING

    ok = table[table.status.astype(str) == "ok"]
    failed = table[table.status.astype(str) != "ok"]
    of = "" if n_listed is None else f" of {n_listed} listed"
    sam = _samples(table)
    out = [f"Fits finished: {len(table)}{of}; ok {len(ok)}, failed {len(failed)}; inside the domain "
           f"{len(sam[IN_DOMAIN])}, of them without a fit flag {len(sam[USABLE])}."]
    assert set(QC_EXCLUDING) == set(DOMAIN_FLAGS) | set(FIT_FLAGS), "a flag of fit_qc is in neither group"
    for label, group, rows in (("Outside the domain, by flag known before the fit", DOMAIN_FLAGS, ok),
                               ("Fit flags inside the domain", FIT_FLAGS, sam[IN_DOMAIN])):
        lost = {k: int(rows[k].astype(bool).sum()) for k in group if k in rows}
        out.append(f"{label} (a fit can carry several): "
                   + (", ".join(f"{k} {v}" for k, v in lost.items() if v) or "none") + ".")
    if "chain_lp_rising" in ok:
        out.append(f"Chains still climbing (reported, not a cut): {int(ok.chain_lp_rising.astype(bool).sum())}.")
    for _, r in failed.iterrows():
        out.append(f"- failed: {r.get('name') or r.get('fit_dir')}: {r.status}")
    return out


def _tension_lines(table: Any, pull: str, overlap: str, name: str) -> list[str]:
    out = ["| sample | fits | intervals overlap | beyond 2 sigma | beyond 3 sigma | median pull | rms pull |",
           "|---|---|---|---|---|---|---|"]
    for label, t in _samples(table).items():
        s = tension_summary(t[pull], t[overlap])
        out.append(f"| {label} | {s['n']} | {s['n_overlap']} | {s['n_gt2']} | {s['n_gt3']} | "
                   f"{_fmt(s['median_pull'], 2)} | {_fmt(s['rms_pull'], 2)} |")
    use = _samples(table)[IN_DOMAIN]
    far = use[use[pull].abs() > 2].sort_values(pull, key=abs, ascending=False)
    for _, r in far.iterrows():
        flags = [k for k in FIT_FLAGS if k in r and bool(r[k])]
        out.append(f"- beyond 2 sigma: {r[name]}: pull {r[pull]:+.1f}" + (f" ({', '.join(flags)})" if flags else ""))
    return out


def _runtime_lines(label: str, facts: Any) -> list[str]:
    import numpy as np

    rt = _finite(facts.runtime_s[facts.status == "ok"]) / 3600.0
    if not len(rt):
        return [f"{label}: no finished fit."]
    top = facts[facts.status == "ok"].sort_values("runtime_s", ascending=False).head(3)
    longest = ", ".join(f"{r['name']} {float(r.runtime_s) / 3600:.1f} h" for _, r in top.iterrows())
    return [f"{label}: {len(rt)} ok fits, {rt.sum():.0f} core-hours; per fit median {np.median(rt):.1f} h, "
            f"90th percentile {np.percentile(rt, 90):.1f} h, longest {rt.max():.1f} h ({longest})."]

def write_figure(real: Any, mock: Any, out_png: str | Path) -> Path:
    """Three panels: the fit against the published mass (real), fit / true and fit / hydrostatic truth against the
    true mass (mocks).  Fits inside the domain without a fit flag filled, with the fit's 68 per cent interval (and
    the published one across), fits with an excluding flag open; the dashed line is the limit of the reading (:data:`READINGS`)."""
    import matplotlib

    matplotlib.use("Agg")
    import matplotlib.pyplot as plt
    import numpy as np

    ink, muted, mark = "#1f2328", "#8b949e", "#2f6fb0"
    fig, axes = plt.subplots(1, 3, figsize=(13.5, 4.2), constrained_layout=True)
    panels = ((real, "m500_ref_1e14", 1.0, "ln_fit_ref", "published hydrostatic $M_{500}$ [$10^{14}$ M$_\\odot$]",
               "fit / published"),
              (mock, "m500c_zobs_msun", 1e-14, "ln_bt_so", "true $M_{500c}$ [$10^{14}$ M$_\\odot$]", "fit / true"),
              (mock, "m500c_zobs_msun", 1e-14, "ln_br_so", "true $M_{500c}$ [$10^{14}$ M$_\\odot$]",
               "fit / hydrostatic mass of the simulation"))
    for ax, (t, xc, xs, yc, xl, yl) in zip(axes, panels):
        ok = t[t.status.astype(str) == "ok"] if len(t) else t
        if len(ok) and xc in ok and yc in ok:
            x = np.asarray(ok[xc], float) * xs
            y = np.exp(np.asarray(ok[yc], float))
            use = ~np.asarray(ok.qc_excluded, bool)
            ax.scatter(x[~use], y[~use], s=26, facecolors="none", edgecolors=muted, linewidths=1.0,
                       label=f"excluding flag ({int((~use).sum())})")
            if "m500_lo_1e14" in ok:
                f = np.asarray(ok[xc], float) * xs * y            # the fitted mass, from the ratio
                with np.errstate(invalid="ignore"):
                    yerr = np.abs(np.array([y - y * np.asarray(ok.m500_lo_1e14, float) / f,
                                            y * np.asarray(ok.m500_hi_1e14, float) / f - y]))
                xerr = (np.abs(np.array([x - np.asarray(ok.m500_ref_lo_1e14, float),
                                         np.asarray(ok.m500_ref_hi_1e14, float) - x]))[:, use]
                        if "m500_ref_lo_1e14" in ok else None)
                ax.errorbar(x[use], y[use], yerr=np.nan_to_num(yerr[:, use]), xerr=xerr, fmt="none", ecolor=mark,
                            elinewidth=0.7, alpha=0.5)
            ax.scatter(x[use], y[use], s=26, color=mark, edgecolors="white", linewidths=0.6, zorder=3,
                       label=f"in domain, no fit flag ({int(use.sum())})")
            s = ratio_summary(np.asarray(ok[yc], float)[use])
            if s["median"] == s["median"]:
                ax.axhline(s["median"], color=mark, lw=1.6)
                if s["lo"] == s["lo"]:
                    ax.axhspan(s["lo"], s["hi"], color=mark, alpha=0.15, lw=0)
                ax.set_title(f"median {s['median']:.2f}" + (f" ({s['lo']:.2f} to {s['hi']:.2f})"
                                                            if s["lo"] == s["lo"] else ""),
                             fontsize=10, color=ink, loc="left")
            ax.legend(frameon=False, fontsize=8, loc="upper right")
        ax.axhline(1.0, color=ink, lw=0.8)
        for lim in READINGS.get(yc, ()):
            if lim != 1.0:
                ax.axhline(lim, color=muted, lw=0.8, ls="--")
        ax.set_xscale("log")
        ax.set_yscale("log")
        ax.set_ylim(0.4, 2.5)
        ax.set_yticks([0.5, 0.7, 1.0, 1.5, 2.0], labels=["0.5", "0.7", "1", "1.5", "2"])
        ax.minorticks_off()
        ax.set_xlabel(xl, color=ink)
        ax.set_ylabel(yl, color=ink)
        ax.grid(True, color="#d0d7de", lw=0.5, alpha=0.6)
        for side in ("top", "right"):
            ax.spines[side].set_visible(False)
    out_png = Path(out_png)
    fig.savefig(out_png, dpi=150)
    plt.close(fig)
    return out_png

def pilot_report(real_fits: str | Path, real_targets: str | Path, references: str | Path, mock_fits: str | Path,
                 truth_root: str | Path, sim: str, out: str | Path, *, mock_targets: str | Path | None = None,
                 figure: bool = True, catalogue: str | Path | None = None,
                 reference_key: str = REFERENCE_KEY) -> dict[str, Any]:
    """Build the tables, the statistics and the report under ``out``; returns ``{column: {sample: summary with
    its reading}}`` for the two samples inside the domain (the real column with its tension counts).  ``mock_targets``: the mock fit-target list, only for the number of listed views;
    ``catalogue``: the reference catalogue with the published errors (default the packaged one);
    ``reference_key``: the hydrostatic reference of the real list (default :data:`REFERENCE_KEY`)."""
    import pandas as pd

    from tngxmm.core.provenance import git_hash

    out = Path(out)
    out.mkdir(parents=True, exist_ok=True)
    real = real_rows(real_fits, real_targets, references, catalogue, reference_key)
    mock = mock_rows(mock_fits, truth_root, sim)
    real.to_csv(out / "pilot_real.csv", index=False)
    mock.to_csv(out / "pilot_mock.csv", index=False)
    n_real = len(pd.read_csv(real_targets))
    n_mock = len(pd.read_csv(mock_targets)) if mock_targets else None

    verdict: dict[str, Any] = {}
    for col, table in (("ln_fit_ref", real), ("ln_br_so", mock), ("ln_rt_so", mock), ("ln_bt_so", mock)):
        verdict[col] = {}
        for label in (USABLE, IN_DOMAIN):
            use = _samples(table)[label]
            s = ratio_summary(use[col] if col in use else [])
            verdict[col][label] = dict(s, reading=reading(col, s))
            if col == "ln_fit_ref":
                verdict[col][label]["tension"] = tension_summary(use.pull_ref, use.overlap_ref)

    lines = ["# Pilot report", "",
             f"Code {git_hash()}. Real fits `{real_fits}`, mock fits `{mock_fits}`, truth `{truth_root}` ({sim}).",
             f"Hydrostatic reference of the real list: `{reference_key}`.",
             "", "## Reading (docs/dev/PILOT.md)", "",
             "Inside the domain: no flag known before the fit (centre, cluster filling the field, first guess).  "
             "The second row of each question keeps the fits that carry a flag from their own result.", "",
             "| question | sample | fits | median ratio | 95 % interval | intervals overlap | beyond 2 sigma | "
             "reading |", "|---|---|---|---|---|---|---|---|"]
    for col, by in verdict.items():
        for label, v in by.items():
            t = v.get("tension")
            rng = (f" (range {READINGS[col][0]:.2f} to {READINGS[col][1]:.2f})" if col in READINGS else "")
            lines.append(f"| {QUESTIONS[col]} | {label} | {v['n']} | {_fmt(v['median'])} | "
                         f"{_fmt(v['lo'])} to {_fmt(v['hi'])} | "
                         + (f"{t['n_overlap']} of {t['n']} | {t['n_gt2']}" if t else "n/a | n/a")
                         + f" | {v['reading']}{rng} |")
    lines += ["", "## Real clusters: fit / published hydrostatic mass", "", *_qc_lines(real, n_real), "",
              *_summary_lines(real, "ln_fit_ref", "m500_ref_1e14", "z"), "",
              "Tension of each fit with its published mass (68 per cent intervals of both):", "",
              *_tension_lines(real, "pull_ref", "overlap_ref", "name"),
              "", "## Mocks: fit / hydrostatic mass of the simulation", "", *_qc_lines(mock, n_mock), ""]
    have = "ln_bt_so" in mock and mock.ln_bt_so.notna().any()
    if have:
        lines += [*_summary_lines(mock, "ln_br_so", "m500c_zobs_msun", "z_obs"),
                  "", "## Mocks: hydrostatic mass of the simulation / true mass (no fit involved)", "",
                  *_summary_lines(mock, "ln_rt_so", "m500c_zobs_msun", "z_obs"),
                  "", "## Mocks: fit / true mass", "",
                  *_summary_lines(mock, "ln_bt_so", "m500c_zobs_msun", "z_obs")]
        missing = mock[(mock.status.astype(str) == "ok") & (mock.get("estimands") != "ok")]
        if len(missing):
            lines += ["", f"{len(missing)} ok fits have no estimands (truth file or saved profiles missing)."]
    else:
        lines.append("No finished mock fit with estimands yet.")
    lines += ["", "## Run facts", "", *_runtime_lines("Real", run_facts(real_fits)),
              *_runtime_lines("Mock", run_facts(mock_fits)), ""]
    if figure:
        write_figure(real, mock, out / "pilot_report.png")
        lines += ["![fit against the references](pilot_report.png)", ""]
    (out / "pilot_report.md").write_text("\n".join(lines))
    (out / "pilot_report.json").write_text(json.dumps(verdict, indent=1))
    return verdict

def main(argv: list[str] | None = None) -> int:
    """Command-line entry of :func:`pilot_report`."""
    ap = argparse.ArgumentParser(prog="python -m tngxmm.analysis.pilot_report", description=__doc__.split("\n")[0])
    ap.add_argument("--real-fits", required=True)
    ap.add_argument("--real-targets", required=True)
    ap.add_argument("--references", required=True)
    ap.add_argument("--mock-fits", required=True)
    ap.add_argument("--mock-targets", default=None)
    ap.add_argument("--truth-root", required=True)
    ap.add_argument("--sim", required=True, help="the folder of the truth profiles under the tree (sim.sim_name)")
    ap.add_argument("--out", required=True)
    ap.add_argument("--no-figure", action="store_true")
    ap.add_argument("--catalogue", default=None,
                    help="reference catalogue with the published errors (default: the packaged reference_masses.csv)")

                    help=f"hydrostatic reference of the real list (default {REFERENCE_KEY}; {COMPARISON_KEY} "
                         "for the Wicker+23 copy)")

                  f"({_fmt(s['lo'])} to {_fmt(s['hi'])}): {s['reading']}")
