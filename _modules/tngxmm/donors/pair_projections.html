Source code for tngxmm.donors.pair_projections

"""Release 1.2 pairing: the projections of a halo-snapshot and their physics donors.

Release 1.2 observes every halo-snapshot along ``n_projections`` lines of sight (the six icosahedral axes of
``sim.projection = 'icosahedral6'``) and pairs the HALO-SNAPSHOT with real observations, not each view on its own: a
one-to-many assignment of up to ``n_projections`` distinct physics donors (DECISIONS, "Release 1.2 (planned,
2026-10-26)" and "Release 1.2: six projections per halo, each under a different donor" of the design note of
2026-10-27).

Window (fixed, never widened).  An observation is a candidate of a halo-snapshot when |z_snap - z_ref| <= ``dz_max``
and |log M_halo - log M_ref| <= ``mass_window_dex``.  ``dz_max`` = 0.25 is the redshift window of the matched draw
(``params:donors.matched.dz_max``, ledger ``method.matched_draw``).  The mass window is a caliper (decision of
2026-11-04, ledger ``method.pairing_caliper``): by default (``mass_window_dex`` None) 0.25 standard deviations of the
log10 matching mass of the reference observations with a finite mass and redshift (:data:`CALIPER_SD`,
:func:`caliper_dex`), the caliper Rosenbaum & Rubin (1985) suggest for nearest-neighbour matching (as summarised by
Stuart 2010, Sect. 2.2); it is computed from the reference table alone, before any halo is paired, recorded in the
report (``mass_window_dex``, ``mass_window_rule``) and never widened.  A number in ``mass_window_dex`` fixes the window
instead (a sensitivity arm).  The masses are columns the
caller names (``halo_mass_col``, ``ref_mass_col``, log10 Msun, no default): the plan of 2026-10-27 pairs the
hydrostatic fit mass M_fit on both sides, with no catalogue mass and no bias factor.  The candidates are ranked by the
combined distance of the matched draw, d^2 = (dlog M / ``sigma_logm_dex``)^2 + (dz / ``sigma_z``)^2 with both widths
0.05 (``params:donors.matched.sigma_logm_dex`` and ``sigma_z``, ledger ``method.matched_kernel_widths``), ties by
obsid.

Assignment.  With k candidates the halo-snapshot has k_eff = min(k, ``n_projections``) distinct physics donors, its
k_eff nearest; projection p (0-based) takes the (p mod k_eff)-th nearest, so a shortfall is filled by repeating the
nearest matches in turn, never by widening the window.  The rank of a view's physics donor is therefore tied to its
projection index: view 0 has the nearest, and a subset of views chosen by index (the two fitted views of pass 2,
say) is not a random subset of the pairs.  The number of distinct physics donors is recorded per halo-snapshot
(``n_physics_donors``, ``shortfall``) and reported by mass and redshift (:func:`shortfall_by_mass_z`).

Assignment ``least_used`` (``PairingSpec.assignment``; the default ``nearest`` is the rule above).  With more
candidates than projections the nearest ``n_projections`` are not the only choice, and taking them for every
halo-snapshot leaves the observations that are never among anyone's nearest without a mock, and loads a few
observations with hundreds of views.  Under ``least_used`` the window and the distance are the same, and a
halo-snapshot takes, among its candidates, the ``n_projections`` that serve the fewest views so far (ties to the
nearer, then to the lower obsid); its projections take them in order of distance, so view 0 still has the nearest of
the chosen.  The halo-snapshots are assigned in order of their number of candidates, fewest first (ties by ``sim``,
``snap``, ``halo_id``), so that those with little choice do not find their few candidates already loaded.  A
halo-snapshot with at most ``n_projections`` candidates gets the same donors as under ``nearest``.  ``donor_rank`` is
then the rank of the donor among the candidates, which is no longer the projection index.

Unpaired halo-snapshots.  A halo-snapshot with no observation in the window is UNPAIRED (``paired`` False,
``donor_id`` empty).  The design keeps such halo-snapshots for training, observed under conditions donors only, and
leaves them out of every mock-against-real statistic (:func:`drop_unpaired`).  Generating their views is not supported
yet (release 1.2, E1): :func:`tngxmm.core.pool.replica_package` refuses a row with ``paired`` False.  The pairing
records ``conditions_anchor_id`` for them, the nearest observation by the same distance without the window; it would
place the views in the condition space (:func:`tngxmm.instrument.conditions_donor.draw_projection_conditions`) and
lends no mass, redshift or count target.  For a paired projection the anchor is its physics donor.

Every row also carries ``conditions_anchors``, the anchors of all projections of its halo-snapshot
(``"0:<obsid>;1:<obsid>;..."``, :func:`format_anchor_map`): the per-projection conditions draw reads them from any one
row, so a target list cut to some views, or a donor excluded at run time, leaves the draw of every other view as it is.

Donor folds.  With ``folds`` (obsid -> donor fold) the report counts the paired halo-snapshots whose physics donors lie
in more than one fold.  A ``donor_fold`` column in the halo table restricts the candidates and the anchor of each
halo-snapshot to the observations of that fold, so all its projections stay in one fold.

No random number enters: the pairing is a deterministic function of the two tables and the settings.

References
----------
stuart2010 (the caliper of nearest-neighbour matching); the redshift window and the distance are those of
:mod:`tngxmm.donors.sample_matched` with the parameters of ``params:donors.matched``.
"""

@cites("stuart2010")
def caliper_dex(ref_log_mass: Any, k: float = CALIPER_SD) -> float:
    """The mass window of the pairing [dex]: ``k`` times the sample standard deviation (ddof 1) of the finite values of
    ``ref_log_mass`` (log10 matching mass of the reference observations).  Needs two finite values."""
    import numpy as np

    x = np.asarray(ref_log_mass, float)
    x = x[np.isfinite(x)]
    if len(x) < 2:
        raise ValueError("caliper: the reference table needs at least two finite matching masses")
    return float(k) * float(np.std(x, ddof=1))

@dataclass(frozen=True)
class PairingSpec:
    """Settings of the release 1.2 pairing.  ``halo_mass_col`` and ``ref_mass_col`` have no default: the caller says
    which matching mass is paired (the fit mass on both sides in the release).  The other numbers are design parameters
    (docs/assumptions/OPEN_ITEMS.md, section P): the redshift window and the distance widths of the matched draw
    (``params:donors.matched``).  ``mass_window_dex`` None (the default) is the caliper rule (:func:`caliper_dex` of
    the reference table); a number fixes the window.  Neither is widened."""

    #: log10 matching mass [Msun] of a halo-snapshot (a column of the halo table)
    halo_mass_col: str
    #: log10 matching mass [Msun] of an observation (a column of the reference table)
    ref_mass_col: str
    n_projections: int = 6
    dz_max: float = 0.25
    mass_window_dex: float | None = None
    sigma_logm_dex: float = 0.05
    sigma_z: float = 0.05
    halo_z_col: str = "z_snap"
    ref_z_col: str = "z"
    #: which candidates a halo-snapshot with more than ``n_projections`` of them takes: 'nearest' or 'least_used'
    assignment: str = "nearest"

    def to_dict(self) -> dict[str, Any]:

def _variance_ratio(halo_logm: Any, ref_logm: Any) -> float:
    """Sample variance (ddof 1) of the paired halo-snapshots' log mass over that of the reference observations: the
    ratio under which Cochran and Rubin's caliper result holds (two; Stuart 2010, Sect. 2.2).  NaN below two each."""
    import numpy as np

    a, b = np.asarray(halo_logm, float), np.asarray(ref_logm, float)
    if len(a) < 2 or len(b) < 2 or not np.var(b, ddof=1) > 0:
        return float("nan")
    return float(np.var(a, ddof=1) / np.var(b, ddof=1))

    return normalise_obsid(v)

def format_anchor_map(anchors: dict[int, str]) -> str:
    """``"0:<obsid>;1:<obsid>;..."``: the anchors of a halo-snapshot's projections as one CSV-safe string, in view
    order (obsids as 10 digits)."""
    return ";".join(f"{int(v)}:{_obsid(o)}" for v, o in sorted((int(k), o) for k, o in anchors.items()))

def parse_anchor_map(text: Any) -> dict[int, str]:
    """The inverse of :func:`format_anchor_map`: ``{view: obsid}``; ``ValueError`` on an empty or malformed string."""
    if not isinstance(text, str) or not text.strip():
        raise ValueError(f"{ANCHORS_COLUMN}: {text!r} is not a list of view:obsid pairs")
    out: dict[int, str] = {}
    for part in text.strip().split(";"):
        v, sep, o = part.partition(":")
        if not sep or not v.strip().isdigit():
            raise ValueError(f"{ANCHORS_COLUMN}: {part!r} of {text!r} is not view:obsid")
        if int(v) in out:
            raise ValueError(f"{ANCHORS_COLUMN}: view {int(v)} appears twice in {text!r}")
        out[int(v)] = _obsid(o)
    return out

def pair_projections(halos: Any, reference: Any, spec: PairingSpec, *,
                     folds: dict[str, int] | None = None) -> tuple[Any, dict[str, Any]]:
    """Pair every halo-snapshot of ``halos`` with real observations of ``reference`` (module docstring).

    ``halos``: one row per halo-snapshot (``sim``, ``snap``, ``halo_id``, ``spec.halo_z_col``, ``spec.halo_mass_col``;
    every other column is carried to the output; an optional ``donor_fold`` restricts the halo-snapshot to the
    observations of that fold and needs ``folds``).  ``reference``: one row per real observation (``obsid``,
    ``spec.ref_z_col``, ``spec.ref_mass_col``); rows without a finite mass or redshift are left out and counted.
    ``spec``: the settings, with the two mass columns named.  ``folds``: obsid -> donor fold.

    Returns ``(pairs, report)``: ``pairs`` one row per (halo-snapshot, projection ``view`` = 0 .. n_projections - 1)
    with the halo columns and ``log_m_match``, ``z_match`` (the halo's matching mass and redshift), ``paired``,
    ``donor_id`` (the physics donor, empty when unpaired), ``conditions_anchor_id``, ``conditions_anchors`` (the anchors
    of all projections of the halo-snapshot), ``donor_rank`` (rank of the donor among the halo-snapshot's candidates,
    from 0), ``donor_repeat`` (the donor already serves an earlier projection), ``donor_dz`` (z_snap - z_ref),
    ``donor_dlogm_dex`` (log M_halo - log M_ref), ``donor_distance`` (d of the donor, or of the anchor when unpaired),
    ``n_candidates``, ``n_physics_donors``, ``shortfall`` (n_projections - n_physics_donors), ``donor_fold`` (the
    anchor's fold, with ``folds``) and ``pairing_spec_hash`` (of the settings with the mass window as applied);
    ``report`` the counts (:func:`pairing_summary`), the window applied (``mass_window_dex``,
    ``mass_window_rule``) and ``variance_ratio_logm`` (:func:`_variance_ratio`)."""
    import numpy as np
    import pandas as pd

    if not isinstance(spec, PairingSpec):
        raise TypeError("spec: a PairingSpec naming the mass columns of both tables")
    P = int(spec.n_projections)
    if P < 1:
        raise ValueError("n_projections must be >= 1")
    if spec.assignment not in ASSIGNMENTS:
        raise ValueError(f"assignment: {spec.assignment!r} is not one of {ASSIGNMENTS}")
    for c in (*HALO_KEY, spec.halo_z_col, spec.halo_mass_col):
        if c not in halos.columns:
            raise KeyError(f"halo table: no column {c!r}")
    for c in ("obsid", spec.ref_z_col, spec.ref_mass_col):
        if c not in reference.columns:
            raise KeyError(f"reference table: no column {c!r}")
    h = halos.reset_index(drop=True)
    if h.duplicated(list(HALO_KEY)).any():
        raise ValueError("halo table: a halo-snapshot appears twice")
    r = reference.assign(obsid=reference["obsid"].map(_obsid)).reset_index(drop=True)
    if r.obsid.duplicated().any():
        raise ValueError("reference table: an observation appears twice")
    zr = r[spec.ref_z_col].to_numpy(float)
    mr = r[spec.ref_mass_col].to_numpy(float)
    good = np.isfinite(zr) & np.isfinite(mr)
    n_bad_ref = int((~good).sum())
    r, zr, mr = r[good].reset_index(drop=True), zr[good], mr[good]
    if not len(r):
        raise ValueError("reference table: no observation with a finite mass and redshift")
    import dataclasses

    window_rule = "fixed"
    if spec.mass_window_dex is None:          # the caliper, from the reference table alone
        spec = dataclasses.replace(spec, mass_window_dex=caliper_dex(mr))
        window_rule = f"caliper {CALIPER_SD:g} sd of the reference log mass ({len(mr)} observations)"
    oid = r.obsid.to_numpy(object)
    tie = np.argsort(np.argsort(oid, kind="stable"), kind="stable")      # obsid order breaks distance ties
    zh = h[spec.halo_z_col].to_numpy(float)
    mh = h[spec.halo_mass_col].to_numpy(float)
    if not (np.isfinite(zh).all() and np.isfinite(mh).all()):
        raise ValueError("halo table: every halo-snapshot needs a finite matching mass and redshift")

    restrict = "donor_fold" in h.columns and h["donor_fold"].notna().any()
    if restrict and folds is None:
        raise ValueError("halo table has donor_fold: give folds (obsid -> donor fold) to restrict the pairing")
    fold_of = None
    if folds is not None:
        fmap = {_obsid(k): int(v) for k, v in folds.items()}
        missing = sorted(set(oid) - set(fmap))
        if missing:
            raise KeyError(f"{len(missing)} observations have no donor fold, e.g. {missing[:3]}")
        fold_of = np.array([fmap[o] for o in oid], int)

    rows_dz, rows_dm, rows_d = (np.full((len(h), P), np.nan) for _ in range(3))
    donor = np.full((len(h), P), None, object)
    anchor = np.full((len(h), P), None, object)
    rank = np.full((len(h), P), -1, int)
    repeat = np.zeros((len(h), P), bool)
    anc_fold = np.full((len(h), P), -1, int)
    n_cand = np.zeros(len(h), int)
    cands: list[Any] = [None] * len(h)
    nearest: list[int] = [0] * len(h)
    for i in range(len(h)):
        dz = zh[i] - zr
        dm = mh[i] - mr
        d2 = (dm / spec.sigma_logm_dex) ** 2 + (dz / spec.sigma_z) ** 2
        allowed = np.ones(len(r), bool)
        if restrict and pd.notna(h.at[i, "donor_fold"]):
            allowed = fold_of == int(h.at[i, "donor_fold"])
            if not allowed.any():
                raise ValueError(f"halo-snapshot {tuple(h.loc[i, list(HALO_KEY)])}: no observation in donor fold "
                                 f"{int(h.at[i, 'donor_fold'])}")
        order = np.lexsort((tie, d2))
        order = order[allowed[order]]
        inwin = (np.abs(dz[order]) <= spec.dz_max + 1e-12) & (np.abs(dm[order]) <= spec.mass_window_dex + 1e-12)
        cands[i], nearest[i], n_cand[i] = order[inwin], int(order[0]), int(inwin.sum())

    # which of its candidates each halo-snapshot takes (positions in its distance-ordered candidate list)
    hkey = [tuple(str(h.at[i, c]) if c == "sim" else int(h.at[i, c]) for c in HALO_KEY) for i in range(len(h))]
    served = np.zeros(len(r), int)                    # views an observation serves so far ('least_used')
    turn = sorted(range(len(h)), key=lambda i: (n_cand[i], hkey[i])) if spec.assignment == "least_used" \
        else range(len(h))
    for i in turn:
        cand = cands[i]
        k = min(len(cand), P)
        pos = np.arange(k)
        if spec.assignment == "least_used" and len(cand) > P:
            pos = np.sort(np.lexsort((np.arange(len(cand)), served[cand]))[:P])
        dz = zh[i] - zr
        dm = mh[i] - mr
        for p in range(P):
            j = int(cand[pos[p % k]]) if k else nearest[i]
            if k:
                donor[i, p] = oid[j]
                rank[i, p] = int(pos[p % k])
                repeat[i, p] = p >= k
                served[j] += 1
            anchor[i, p] = oid[j]
            rows_dz[i, p], rows_dm[i, p] = dz[j], dm[j]
            rows_d[i, p] = float(np.sqrt((dm[j] / spec.sigma_logm_dex) ** 2 + (dz[j] / spec.sigma_z) ** 2))
            if fold_of is not None:
                anc_fold[i, p] = fold_of[j]

    out = h.loc[h.index.repeat(P)].reset_index(drop=True)
    out["view"] = np.tile(np.arange(P), len(h))
    out["log_m_match"] = np.repeat(mh, P)
    out["z_match"] = np.repeat(zh, P)
    n_phys = np.minimum(n_cand, P)
    out["paired"] = np.repeat(n_phys > 0, P)
    out["donor_id"] = donor.ravel()
    out[ANCHOR_COLUMN] = anchor.ravel()
    out[ANCHORS_COLUMN] = np.repeat([format_anchor_map(dict(enumerate(a))) for a in anchor], P)
    out["donor_rank"] = pd.array([int(x) if x >= 0 else pd.NA for x in rank.ravel()], dtype="Int64")
    out["donor_repeat"] = repeat.ravel()
    out["donor_dz"] = rows_dz.ravel()
    out["donor_dlogm_dex"] = rows_dm.ravel()
    out["donor_distance"] = rows_d.ravel()
    out["n_candidates"] = np.repeat(n_cand, P)
    out["n_physics_donors"] = np.repeat(n_phys, P)
    out["shortfall"] = P - out["n_physics_donors"]
    if fold_of is not None:
        out["donor_fold"] = pd.array(anc_fold.ravel(), dtype="Int64")
    out["pairing_spec_hash"] = spec.spec_hash()
    report = pairing_summary(out, P, folds=folds)
    report.update(spec=spec.to_dict(), spec_hash=spec.spec_hash(), reference_rows=int(len(r)),
                  mass_window_dex=float(spec.mass_window_dex), mass_window_rule=window_rule,
                  variance_ratio_logm=_variance_ratio(mh[n_phys > 0], mr),
                  reference_rows_without_mass_or_z=n_bad_ref, fold_restricted=bool(restrict))
    return out, report

def pairing_summary(pairs: Any, n_projections: int | None = None, folds: dict[str, int] | None = None
                    ) -> dict[str, Any]:
    """Counts of a pairing table (one row per halo-snapshot and projection): halo-snapshots, views, ``paired``,
    ``unpaired``, ``full`` (as many distinct physics donors as projections), ``short`` (paired with fewer),
    ``physics_donors_histogram`` (halo-snapshots by their number of distinct physics donors), views that repeat a
    donor, observations used and the most views one observation serves; with ``folds``, the paired halo-snapshots whose
    physics donors lie in more than one donor fold (``halo_snaps_spanning_folds``)."""
    hs = pairs.drop_duplicates(list(HALO_KEY))
    P = int(n_projections or pairs.groupby(list(HALO_KEY)).size().max())
    k = hs["n_physics_donors"].astype(int)
    used = pairs.loc[paired_mask(pairs), "donor_id"].map(_obsid)
    out: dict[str, Any] = {
        "n_projections": P, "halo_snaps": int(len(hs)), "views": int(len(pairs)),
        "paired": int((k > 0).sum()), "unpaired": int((k == 0).sum()), "full": int((k >= P).sum()),
        "short": int(((k > 0) & (k < P)).sum()),
        "physics_donors_histogram": {int(a): int(b) for a, b in k.value_counts().sort_index().items()},
        "views_repeating_a_donor": int(pairs["donor_repeat"].astype(bool).sum()),
        "observations_used": int(used.nunique()),
        "max_views_per_observation": int(used.value_counts().max()) if len(used) else 0,
    }
    if folds is not None:
        fmap = {_obsid(a): int(b) for a, b in folds.items()}
        p = pairs.loc[paired_mask(pairs)].assign(_f=used.map(fmap))
        span = p.groupby(list(HALO_KEY))["_f"].nunique()
        out["halo_snaps_spanning_folds"] = int((span > 1).sum())
    return out

def shortfall_by_mass_z(pairs: Any, mass_edges_msun: tuple[float, ...] = SHORTFALL_MASS_EDGES_MSUN,
                        n_projections: int | None = None) -> Any:
    """The distribution of the number of distinct physics donors by halo mass and redshift: one row per (``sim``,
    mass bin of ``log_m_match`` with edges ``mass_edges_msun``, redshift ``z`` = ``z_match`` of the pairing, a snapshot
    redshift) with ``halo_snaps``, ``unpaired``,
    ``short`` (paired, fewer distinct donors than projections), ``full``, ``mean_physics_donors`` (over the paired
    halo-snapshots of the cell; NaN without one) and ``n_donors_<k>`` (halo-snapshots with k distinct physics donors,
    k = 0 .. n_projections).  ``m_lo_msun`` / ``m_hi_msun`` bound the bin (0 and inf at the ends)."""
    import numpy as np
    import pandas as pd

    hs = pairs.drop_duplicates(list(HALO_KEY)).copy()
    P = int(n_projections or pairs.groupby(list(HALO_KEY)).size().max())
    edges = np.array([0.0, *sorted(float(e) for e in mass_edges_msun), np.inf])
    m = 10.0 ** hs["log_m_match"].to_numpy(float)
    b = np.clip(np.searchsorted(edges, m, side="right") - 1, 0, len(edges) - 2)
    hs["m_lo_msun"], hs["m_hi_msun"] = edges[b], edges[b + 1]
    hs["z"] = hs["z_match"].astype(float).round(4)          # a snapshot redshift (2.2e-16 is 0)
    hs["_k"] = hs["n_physics_donors"].astype(int)
    keys = [c for c in ("sim",) if c in hs.columns] + ["m_lo_msun", "m_hi_msun", "z"]
    rows = []
    for key, g in hs.groupby(keys, sort=True):
        k = g["_k"]
        row = dict(zip(keys, key if isinstance(key, tuple) else (key,)))
        row.update(halo_snaps=int(len(g)), unpaired=int((k == 0).sum()), short=int(((k > 0) & (k < P)).sum()),
                   full=int((k >= P).sum()),
                   mean_physics_donors=float(k[k > 0].mean()) if (k > 0).any() else float("nan"))
        for j in range(P + 1):
            row[f"n_donors_{j}"] = int((k == j).sum())
        rows.append(row)
    return pd.DataFrame(rows)

def paired_value(v: Any) -> bool:
    """One ``paired`` flag: True or False as a bool (numpy's too), the strings 'true' / 'false' of a CSV in any case,
    or 1 / 0; anything else (an empty cell, NaN, another string) raises ``ValueError``.  The one rule of the view
    tables (:func:`paired_mask`), the donor packages (:func:`tngxmm.core.pool.replica_package`) and the conditions draw
    (:func:`tngxmm.instrument.conditions_donor.draw_projection_conditions`)."""
    import numpy as np

    if isinstance(v, (bool, np.bool_)):
        return bool(v)
    if isinstance(v, str) and v.strip().lower() in ("true", "false"):
        return v.strip().lower() == "true"
    if isinstance(v, (int, np.integer, float, np.floating)) and float(v) in (0.0, 1.0):
        return bool(v)
    raise ValueError(f"{PAIRED_COLUMN}: {v!r} is not a flag (true / false)")

def pairing_changes(previous: Any, current: Any) -> dict[str, Any]:
    """How a pairing moved between two iterations (tables of :func:`pair_projections`): the halo-snapshots paired in
    either, those whose physics donors (by projection, empty when unpaired) differ, their share
    (``frac_changed``) and the median |change| of the halo-snapshot's matching mass ``log_m_match`` [dex]."""
    import numpy as np

    def donors(t):
        t = t.sort_values([*HALO_KEY, "view"])
        ids = [_obsid(v) if paired_value(p) else "" for v, p in zip(t["donor_id"], t[PAIRED_COLUMN])]
        t = t.assign(_d=ids)
        g = t.groupby(list(HALO_KEY), sort=False)
        return g["_d"].apply(tuple).to_dict(), g["log_m_match"].first().to_dict()

    da, ma = donors(previous)
    db, mb = donors(current)
    keys = [k for k in set(da) | set(db) if any(da.get(k, ("",))) or any(db.get(k, ("",)))]
    changed = [k for k in keys if da.get(k) != db.get(k)]
    dm = [abs(float(mb[k]) - float(ma[k])) for k in keys if k in ma and k in mb
          and np.isfinite(float(mb[k])) and np.isfinite(float(ma[k]))]
    return dict(n_paired=len(keys), n_changed=len(changed),
                frac_changed=len(changed) / len(keys) if keys else float("nan"),
                median_abs_dlogm_dex=float(np.median(dm)) if dm else float("nan"))

def convergence_state(frac_changed_history: list[float]) -> str:
    """The convergence rule of the fit-mass pairing on the shares of changed halo-snapshots, one per iteration of pass
    2 (the first compares its pairing with pass 1's): CONVERGED when the last is below
    :data:`CONVERGENCE_MAX_CHANGED_FRAC`; NOT_CONVERGED when :data:`CONVERGENCE_MAX_ITERATIONS` iterations ran without
    it (reported as such, never extended); else CONTINUE."""
    h = [float(v) for v in frac_changed_history]
    if h and h[-1] < CONVERGENCE_MAX_CHANGED_FRAC:
        return "CONVERGED"
    if len(h) >= CONVERGENCE_MAX_ITERATIONS:
        return "NOT_CONVERGED"
    return "CONTINUE"

def window_edge_share(values: Any, lo: Any, hi: Any, tenth: float = EDGE_TENTH) -> dict[str, Any]:
    """The edge test: for each paired halo-snapshot its position u = (value - lo) / (hi - lo) in its own streaming
    window; the shares with u < ``tenth`` (``low``) and u > 1 - ``tenth`` (``high``), and whether each is at most
    :data:`EDGE_MAX_SHARE` (``low_ok``, ``high_ok``).  ``values``, ``lo``, ``hi``: arrays of log10 M."""
    import numpy as np

    v, a, b = (np.asarray(x, float) for x in (values, lo, hi))
    ok = np.isfinite(v) & np.isfinite(a) & np.isfinite(b) & (b > a)
    u = (v[ok] - a[ok]) / (b[ok] - a[ok])
    n = int(len(u))
    low = float((u < tenth).mean()) if n else float("nan")
    high = float((u > 1.0 - tenth).mean()) if n else float("nan")
    return dict(n=n, low=low, high=high, low_ok=bool(n and low <= EDGE_MAX_SHARE),
                high_ok=bool(n and high <= EDGE_MAX_SHARE))

def pass1_reference(observations: Any, columns: tuple[str, ...], eligible: Any = None) -> tuple[str, Any]:
    """The one reference observation of pass 1 (design note of 2026-10-27, step 2): among the ``eligible`` rows
    (boolean, the observations with all three cameras in full-frame modes; every row when None), the one with the
    smallest sum over ``columns`` (effective exposure per camera, HI4PI column, N_H,tot / N_HI, flare-filtered
    particle background) of |p - 0.5|, p the row's percentile rank in the donor pool (all rows of ``observations``,
    ranks of ties averaged); ties by obsid.  Returns (obsid, the eligible rows with their ``rank_distance``, sorted).
    No number is fitted: the rule only orders the pool."""
    import numpy as np

    t = observations.copy()
    t["obsid"] = t["obsid"].map(_obsid)
    d = np.zeros(len(t))
    for c in columns:
        x = t[c].astype(float)
        if not np.isfinite(x).all():
            raise ValueError(f"pass1_reference: column {c!r} has non-finite values")
        d += np.abs((x.rank(method="average").to_numpy() - 0.5) / len(t) - 0.5)
    t["rank_distance"] = d
    if eligible is not None:
        t = t[np.asarray(eligible, bool)]
    if not len(t):
        raise ValueError("pass1_reference: no eligible observation")
    t = t.sort_values(["rank_distance", "obsid"])
    return str(t["obsid"].iloc[0]), t
