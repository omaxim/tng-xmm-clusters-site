Source code for tngxmm.validation.closure_grid

"""Closure grid: idealised hydrostatic clusters through the package chain.

The grid measures the error of the production fit: an idealised cluster in exact hydrostatic
equilibrium in the fitter's own conventions
(:mod:`tngxmm.validation.ideal_cluster`) is generated and fitted through the
production chain, and M500_fit / M500_true of the gate arm is judged by the rule given
below ("Acceptance").  Since 2026-11-11 the result is reported and does not gate the freeze
of the configuration.  The stages are driven by a CampaignSpec preset.

Chain per view (exactly the calls of :func:`tngxmm.sim.generate_view.generate_halo_views`
with the preset's options):

1. gas cells of the ideal cluster (:func:`~tngxmm.validation.ideal_cluster.sample_cells`,
   metals of the fit's composition in the generator's abundance table);
2. :func:`tngxmm.sim.generate_photons.generate_photons` (20 keV rest, APEC
   3.1.3, lodd, T interpolation) for the
   donor's longest camera time, then :func:`tngxmm.sim.apply_absorption.apply_absorption`
   at the donor's N_H;
3. the instrument stage, :func:`tngxmm.instrument.run_xmm_simulator.run_xmm_simulator`
   with :meth:`InstrumentOptions.from_spec` and the per-view keywords of
   :func:`tngxmm.sim.generate_view.instrument_view_kwargs` (per-donor
   filters and PN mode, inverse-mapped exposure maps, count-weighted
   vignetting energy, full-column OoT, ARF to 15 keV, half-pixel WCS fix,
   headers, and the cluster PLACED AT THE DONOR'S CORE OFFSET from the
   aim point, ``placement = donor-offset``).  ``clean`` cells switch the sky background, the particle
   background and the AGN off (the only point sources the chain injects);
   ``real`` cells keep them, with the donor's live times;
4. the hydrostatic fit, :func:`tngxmm.massfit.fit_hydrostatic.run_fit`, with
   the preset's switches (:func:`~tngxmm.massfit.fit_hydrostatic.fit_switches_from_spec`:
   free Z, lodd, full-ionisation mu, optical axis from the header,
   block-centre rebin, the on-axis King PSF and the pn out-of-time template
   in the model, ``massfit.psf`` / ``massfit.pn_oot``).  Point sources:
   every cell gets the SAS edetect_chain detection of every campaign view and real
   observation (:func:`detect_cell`; an empty list is a valid result), and its first
   guess and centre come from that list by the procedure of the real targets
   (:func:`cell_seed`).  The gate arm's fit masks that list in every cell, as a campaign view's.  A cell's
   catalogue position and fit redshift are those its donor's catalogue entry gives it, as for a campaign view
   (:mod:`tngxmm.sim.catalogue_centre`, :func:`tngxmm.massfit.build_fit_targets.mock_entry`: the true z unless
   the donor's redshift is photometric); its closure record keeps the entry, ``z_fit`` and the offsets.

Grid: true total M500 {2, 4, 8} x 1e14 Msun x z {0.06, 0.2,
0.5} x profile {ncc, cc} x data mode x seed {0, 1, 2} =
54 clusters per data mode (108 with the default data modes clean and real).  Data modes (:data:`DATA_MODES`): ``clean`` (no sky
or particle background, no AGN), ``real`` (both), ``bgonly`` (backgrounds, no AGN) and
``agnonly`` (AGN, no backgrounds).  Donor conditions per (z, seed): the
replica's views (``campaigns/v4/targets_v4.csv``) with z_obs nearest the
cell's z, one distinct donor per seed (all three cameras, a usable core
offset), shared by every mass, profile, data mode and arm at that (z, seed).

Fit arms (:data:`FIT_ARMS`): ``v1sas`` (the gate arm, :data:`GATE_ARM`: the production preset, masked with the
cell's own SAS edetect_chain list, as a campaign view and a real observation), ``v1`` (masked with the simulated
source table, a diagnostic) and the study arms.  Each ``closure.json`` records its
:func:`fit_config`; a finished fit is resumed only if that matches the arm's
current configuration and the record carries ``z_fit`` and the current catalogue-position rule version (a generated
cell is likewise kept only when its ``truth.json`` was made under the current rule, :func:`generation_done`).  It
also records the seed hash of the code and preset that seeded the cell
(:func:`tngxmm.photometry.build_obs_seed_lx.seed_hash`), which the certification compares with the real fits'.  Fits are QUICK (150 + 300 steps) unless ``--long`` / ``quick=False`` (500 + 1500 steps): quick and long
medians agree to 0.002 dex.

Layout under ``out_root``: ``grid.csv`` (the plan), ``gen/<arm>/<cell>/``
(products, ``truth.json``; the fitter's image root is ``gen/<arm>``),
``fits/<arm>/mock_ideal_<cell>_<arm>/`` (``result.json``, ``closure.json``),
``caches/`` (mbproj2d rate caches: ``seed``, ``warm/<group>``, one per fit
slot ``w<NN>``), ``logs/``, and the analysis outputs ``closure_fits.csv``,
``closure_cells.csv``, ``closure_summary.md``, ``closure_verdict.json``.

Acceptance (:func:`analyse`), the rule of :data:`CLOSURE_RULE`, written on 2026-11-04 before any fit of the grid
(DESIGN v4, ``docs/dev/PREREGISTRATION.md``; :func:`gate_verdict`).  A fit is usable when its status is ok and it
carries no QC flag that excludes a fit from the science sample (:data:`tngxmm.massfit.fit_qc.QC_EXCLUDING`, the
same flags as for every mock and real fit, among them a first guess limited by the field or none at all).  Per data
mode of the gate arm the statistic is the median of ln(M500_fit / M500_true) over the usable fits, pooled over mass,
profile, redshift and seed, with a bootstrap 95 per cent interval over the fits.  The clean cells (the fitter on its
own) pass when that interval lies inside [0.95, 1.05] and the median of every redshift in the domain lies in
[0.90, 1.10]; the real cells pass the tail rule when at most 5 per cent of their ok fits lie outside [0.67, 1.5].
These two make the gate (exit 0 PASS, 1 FAIL, 2 INCOMPLETE).  The real-cell median is judged separately, for the
hydrostatic-bias claim only: |median - 1| <= 0.08 and every redshift median in the domain in [0.85, 1.15] (DESIGN v2,
R4).  A mode with more than 10 per cent failed fits fails; one with a missing or stale fit, or with more than 10 per
cent fits started from the pivot, is INCOMPLETE; a redshift with fewer than half of its fits usable is out of the
domain and enters no median, and a mode needs two redshifts in the domain.  The earlier per-cell rule (geometric mean
over the seeds within 1.00 +/- 0.03, :func:`summarise`, :func:`verdict`) is kept as a report.

Study arms (:func:`arm_verdicts`, :data:`ARM_RULE`): the paired difference ln M500(arm) - ln M500(base) of the same
cell and seed (:data:`ARM_BASE`), over the pairs whose two fits are both usable, on the real-background cells (the
clean cells reported); its median with a bootstrap 95 per cent interval is NEGLIGIBLE inside +/- 0.03, SYSTEMATIC
when the interval reaches beyond +/- 0.03 and excludes 0 (MATERIAL as well when |median| > 0.03), INCONCLUSIVE when it
reaches beyond and includes 0.  What a verdict does to the budget depends on the arm's role (:data:`ARM_ROLE`).  The
re-seed arms (``v1sas_r2``, ``v1sas_r3``: the gate arm with another chain seed) are the power check: if one is not
NEGLIGIBLE the grid has too few cells for the arm rule, and seeds are added; the threshold does not move.

References
----------
mbproj2d (fitter), pyxsim / apec (photons), xmm_simulator (instrument),
vikhlinin2006 and nfw (the ideal cluster).
"""

            "v1_vighi": "v1", "v1_viglo": "v1", "v1_psfell": "v1"}
#: study arms that differ from their base arm in one thing; they draw the base arm's random streams, so a cell of a study
#: arm is the base arm's cell with that one change (paired):
#: ``v1_psfon`` generates the cluster photons with the on-axis King PSF at every energy and position
#: (``instrument.psf_model = 'king-onaxis'``, the fit's own model; production draws the King PSF interpolated in energy
#: and off-axis angle and fits, like real data, with the on-axis King); ``v1_spflat`` draws the soft protons flat over
#: the field and keeps the flare-map template in the fit (``instrument.soft_proton_template``), a wrong shape of the
#: kind a real fit has;
#: ``v1_half`` halves every camera time of the donor package (cluster, background and AGN counts all x 0.5; with
#: ``v1_deep`` at x 10 the S/N dependence of the closure at three exposures, without thinning the cluster to a
#: measured count ratio);
#: ``v1_vigcw`` writes the exposure maps with the vignetting at the count-weighted energy of the band (the rule before
#: release 1.1) instead of the band centre (the SAS rule of the PPS maps), a diagnostic of the closure at large theta500;
#: the other diagnostic arms each set one release 1.1 instrument switch back to its earlier value: ``v1_fpmask`` the packaged
#: detector mask instead of the donor's PPS footprint, ``v1_axpt`` the vignetting centred on the pointing instead of the
#: calibrated telescope axis, ``v1_vigzero`` no effective area beyond the tabulated
#: vignetting (instead of the last tabulated value held);
#: the calibration-error arms (``instrument.area_perturbation``) generate the cells with the effective area of every
#: camera times a published energy-dependent difference and keep the nominal response in the fit, the error a real
#: fit meets and a mock fit does not: ``v1_xcalhi`` / ``v1_xcallo`` the ACIS/PN spline of Schellenberger et al. (2015,
#: Table A.3) and its inverse (``v1_xcallo`` is the case of a correct ACIS calibration: EPIC then reads low, as the
#: paper finds), ``v1_nustarhi`` / ``v1_nustarlo`` the EPIC-to-NuSTAR correction of the CCF (ABSCORRAREA, 6-8 per cent
#: at 3-12 keV) and its inverse.  The presets generate with the conditions donor's own RMF and on-axis ARF shape
#: (``instrument.responses = 'donor'``) and fit with the per-observation responses, so ``v1`` is that pair; the fit
#: arm ``v1_obsresp_shared`` fits the v1 cells with the shared responses (their error on real data);
#: ``v1_vighi`` / ``v1_viglo`` generate with the vignetting of every camera times 1 + 0.05 theta / 10' or its inverse,
#: the published flux accuracy of off-axis sources (XMM-SOC-CAL-TN-0018, Sect. 4.5), and fit with the nominal
#: vignetting (since B11 the fit's vignetting is the generator's own function, so a mock fit meets no vignetting
#: error); ``v1_psfell`` draws the cluster photons with the ELLBETA envelope the AGN are drawn with (Read et al.
#: 2011, the SAS default PSF) instead of the King table, fitted with the nominal on-axis King: the King model's own
#: error against a second calibration of the same PSF, which ``v1_psfon`` (the King off-axis dependence) does not see;
#: reported per band (the ELLBETA rows above 10 keV are the least secure).  These three arms share the base cell's

def gen_spec(gen_arm: str) -> Any:
    """The CampaignSpec of a generator arm: its preset with the arm's overrides (:data:`GEN_ARM_OVERRIDES`)."""
    import dataclasses

    from tngxmm.config import get_preset

    from tngxmm.core import site

    spec = get_preset(GEN_ARMS[gen_arm])
    for section, fields in GEN_ARM_OVERRIDES.get(gen_arm, {}).items():
        # ("site", VAR, part, ...): a path under a site directory, resolved here (tngxmm.core.site)
        fields = {k: (str(site.path_or_placeholder(*v[1:])) if isinstance(v, tuple) and v[:1] == ("site",) else v)
                  for k, v in fields.items()}
        spec = dataclasses.replace(spec, **{section: dataclasses.replace(getattr(spec, section), **fields)})
    return spec

#: the level error d of a QPB template fixed by the observation's corners, per fitted image (ledger
#: fit.particle_background_esas): the intrinsic scatter of the in-field counts over the corner-scaled template across
#: the filter-wheel-closed exposures of the CCF, each predicted with the FWC reference of its own epoch in the normal
#: CCD state as the fit's template is (tools/fwc_qpb_level.py, rule 'state'), root mean square over the fit regions of
#: the real targets (the circle inside each crop; the circle holding the crop gives up to 0.010 less).  The pn values
#: have the 2.3 per cent bound on the soft protons in the pn corners (Marelli et al. 2021) added in quadrature (FWC
#: data cannot show them; 0.029, 0.004, 0.022, 0.010 without).  A lower bound: closed exposures do not show the
#: cluster's own photons in the pn corners, the pn out-of-time events left after their model, or the photons and
#: low-energy particles reaching part of the MOS corners of CCDs 2 and 7; and a crop much smaller than the median
#: (high z) sees up to 1.7 times these values (MOS1 2-4.5 keV: 0.051 within 5 arcmin of the axis, 0.022 over the
#: whole field).
QPB_LEVEL_ERROR = {
    "MOS1_2000": 0.080, "MOS1_3000": 0.020, "MOS1_4000": 0.030, "MOS1_5000": 0.017,
    "MOS2_2000": 0.027, "MOS2_3000": 0.022, "MOS2_4000": 0.026, "MOS2_5000": 0.010,
    "PN_2000": 0.037, "PN_3000": 0.023, "PN_4000": 0.032, "PN_5000": 0.025,
}
#: the PPS bands at or below 2 keV (0.5-1, 1-2 keV); 4000 and 5000 lie above
QPB_SOFT_BANDS = ("2000", "3000")

def sp_tie_decision(fits: Any, arm_verdict: dict | None, real_shift: dict | None = None) -> str:
    """The rule of STATUS Q7 (docs/dev/PREREGISTRATION.md, section 4), written before B1.  Mock side: the arm v1_sptie
    must be SYSTEMATIC and bring the median of the real-background cells nearer the truth than its base v1, by a gain
    g = |median ln(M_fit/M_true)| of v1 minus that of v1_sptie; otherwise the free level per image stays ('free').
    Real side, before adoption: ``real_shift``, the arm rule (:func:`arm_shift`) on the paired real refits, tied
    minus free, measures what the tie does where its spectral shape is an assumption (Leccardi & Molendi 2008
    measured it on the MOS; the pn takes the same shape).  The tie is adopted ('tied') only if that shift is NEGLIGIBLE
    or its size (|median|, the far end of the interval when INCONCLUSIVE) is smaller than g; then a non-NEGLIGIBLE
    shift enters the budget as a real-side error term.  'undecided' without a mock verdict, 'pending-real' while the
    mock side says tie and the real refits have not run."""
    import numpy as np

    v = (arm_verdict or {}).get("verdict")
    if v in (None, "INCOMPLETE"):
        return "undecided"
    if v != "SYSTEMATIC":
        return "free"

    def med(arm):
        g = fits[(fits.arm == arm) & (fits.background == ARM_RULE["background"])]
        g = g[usable(g)]
        return abs(float(np.median(np.log(g.ratio.to_numpy(float))))) if len(g) else float("nan")

    gain = med("v1") - med("v1_sptie")
    if not gain > 0:
        return "free"
    rv = (real_shift or {}).get("verdict")
    if rv in (None, "INCOMPLETE"):
        return "pending-real"
    if rv == "NEGLIGIBLE":
        return "tied"
    size = (max(abs(real_shift["ci95"][0]), abs(real_shift["ci95"][1])) if rv == "INCONCLUSIVE"
            else abs(real_shift["median"]))
    return "tied" if size < gain else "free"

def sp_band_ratio_check(levels: dict, gaps: dict | None = None, n_boot: int = 2000, seed: int = 20261104) -> dict:
    """The per-band check of the soft-proton shape on real free-level fits (docs/dev/PREREGISTRATION.md, section 4),
    a report beside the tie rule: ``levels`` maps an image id (``<camera>_<band>``) to the fitted ln level
    (``sp_<image>``) of each real target, in target order, the targets the same for every image of a camera.  Per
    image other than its camera's 0.5-1 keV image, the median over targets of the band ratio, ln level - ln level of
    the camera's 2000 image, minus the Leccardi & Molendi ratio ln K_b / K_2000
    (:func:`tngxmm.massfit.esas_background.sp_band_factor`), with a bootstrap 95 per cent interval: 0 when the real
    bands follow the spectrum the tie assumes.  The pn rows are the extrapolation of a MOS spectrum."""
    import numpy as np

    from tngxmm.massfit.esas_background import sp_band_factor

    out = {}
    rng = np.random.default_rng(seed)
    for img, lv in sorted(levels.items()):
        cam, _, band = img.rpartition("_")
        ref = f"{cam}_2000"
        if band == "2000" or ref not in levels:
            continue
        d = np.asarray(lv, float) - np.asarray(levels[ref], float)
        d -= np.log(sp_band_factor(img, gaps) / sp_band_factor(ref, gaps))
        d = d[np.isfinite(d)]
        if not len(d):
            continue
        b = np.median(d[rng.integers(0, len(d), (n_boot, len(d)))], axis=1)
        out[img] = dict(n=int(len(d)), median=float(np.median(d)),
                        ci95=tuple(float(x) for x in np.percentile(b, [2.5, 97.5])))
    return out

def qpb_level_error_from_fits(real: Any, mock: Any) -> dict[str, tuple[float, float]]:
    """The two-sided level error (d_up, d_down) per fitted image of a QPB template fixed by the corners, from fits with
    the level free (fit-fix ``qpb_level = 'free'``): ``real`` and ``mock`` map an image id to the fitted level over the
    corner level of each fit (``exp(qpbl_<image>)``), the real refits and the closure arm v1_qpbfree on the real
    cells.  On a mock the corners predict the in-field QPB exactly, so the mock distribution is the free fit's own
    offset and noise; d_up = q84(real) - median(mock) and d_down = median(mock) - q16(real), each at least 0.  The
    noise of the real free fits is not removed (no deconvolution), so the size is an upper estimate.  The arms then fix
    each template at (1 + d_up) and (1 - d_down) times its corner level."""
    import numpy as np

    lo_q, hi_q = QPB_LEVEL_RULE["quantiles"]
    out = {}
    for img in sorted(set(real) & set(mock)):
        r = np.asarray(real[img], float)
        m = np.asarray(mock[img], float)
        r, m = r[np.isfinite(r) & (r > 0)], m[np.isfinite(m) & (m > 0)]
        if not len(r) or not len(m):
            continue
        c = float(np.median(m))
        out[img] = (max(0.0, float(np.percentile(r, hi_q)) - c), max(0.0, c - float(np.percentile(r, lo_q))))
    return out

def pick_donors(targets_csv: str | Path, z_values=GRID_Z, n_seeds: int = len(GRID_SEEDS),
                core_table: Any = None) -> dict:
    """{(z, seed): donor package}: per z, the replica rows with z_obs nearest z, one
    distinct donor per seed, all three cameras with live time and filter, a usable
    core offset (``donor_core_offsets.csv``).  Deterministic."""
    import pandas as pd

    from tngxmm.core.pool import replica_package
    from tngxmm.donors.build_core_offsets import attach_core_offset, read_core_offsets

    tg = pd.read_csv(targets_csv, dtype={"donor_id": str, "ref_obsid": str})
    ok = tg[[c for c in ("exposure_pn_s", "exposure_mos1_s", "exposure_mos2_s")]].gt(0).all(axis=1)
    ok &= tg[["filter_pn", "filter_mos1", "filter_mos2"]].notna().all(axis=1)
    tg = tg[ok].copy()
    core = core_table if core_table is not None else read_core_offsets()
    usable = set(core[core.usable.astype(str).str.lower() == "true"].obsid.astype(str).str.zfill(10))
    tg = tg[tg.donor_id.astype(str).str.zfill(10).isin(usable)]
    out = {}
    for z in z_values:
        c = tg.assign(dz=(tg.z_obs - z).abs()).sort_values(["dz", "view_id"], kind="stable")
        c = c.drop_duplicates("donor_id")
        if len(c) < n_seeds:
            raise ValueError(f"z = {z}: only {len(c)} usable replica donors")
        for s in range(n_seeds):
            r = c.iloc[s]
            pkg = attach_core_offset(replica_package(r), core)
            pkg["replica_z_obs"] = float(r.z_obs)
            out[(float(z), s)] = pkg
    return out

class instrument_components:
    """Context: the instrument stage with or without the sky + particle background (``sky_qpb``) and the
    AGN (``agn``) (the module-level callables of ``simulate_instrument`` are swapped and restored; nothing
    else changes; every other random draw is made as usual)."""

    def __init__(self, sky_qpb: bool = True, agn: bool = True):
        """``sky_qpb``: keep the sky and particle background of the instrument stage; ``agn``: keep the AGN sources.  A
        False value is applied while the context is open."""
        self.sky_qpb, self.agn = bool(sky_qpb), bool(agn)

    def __enter__(self):
        import functools

        import numpy as np

        from tngxmm.instrument import simulate_instrument as si

        self._orig = (si.camera_events, si.generate_agn_sources)
        if not self.sky_qpb:
            si.camera_events = functools.partial(self._orig[0], with_skybkg=False, with_qpb=False)
        if not self.agn:
            si.generate_agn_sources = lambda *a, **k: np.zeros((0, 9))
        return self

    def __exit__(self, *exc):
        from tngxmm.instrument import simulate_instrument as si

        si.camera_events, si.generate_agn_sources = self._orig
        return False

def thin_events(src: Path, dst: Path, keep: float, rng) -> Path:
    """Copy the photon list ``src`` to ``dst`` keeping each photon with probability ``keep`` (``data/*`` columns
    subset, every other group and attribute copied); ``src`` is removed.  Returns ``dst``."""
    import h5py

    with h5py.File(str(src), "r") as a, h5py.File(str(dst), "w") as b:
        n = int(a["data"]["eobs"].shape[0])
        sel = rng.random(n) < float(keep)
        for k, v in a.attrs.items():
            b.attrs[k] = v
        for name in a:
            if name == "data":
                g = b.create_group("data")
                for col in a["data"]:
                    g.create_dataset(col, data=a["data"][col][()][sel])
            else:
                a.copy(name, b)
    Path(src).unlink(missing_ok=True)
    return Path(dst)

def generation_done(out_root, gen_arm: str, cell: str, row: dict | None = None, need_sas: bool = True) -> bool:
    """True when the view has its ``truth.json`` (written last) made under the current catalogue-position rule
    (:func:`catalogue_position_current`, the full rule of the row's donor when ``row`` is given; a cell of an earlier
    rule is made again) from the current files of the data package and of AtomDB (``data_inputs``,
    :func:`tngxmm.sim.data_inputs.view_record`), the band-5000 exposure-map product and, ``row`` given and
    ``need_sas``, its SAS source list."""
    vd = view_dir(out_root, gen_arm, cell)
    if not ((vd / "truth.json").exists() and any((vd / "percam").glob("P*EXPMAP5000.FTZ"))):
        return False
    try:
        truth = json.loads((vd / "truth.json").read_text())
    except Exception:  # noqa: BLE001 - an unreadable record is not a finished view
        return False
    if not catalogue_position_current(truth, gen_arm, row):
        return False
    from tngxmm.sim.data_inputs import view_record

    if truth.get("data_inputs") != view_record(gen_spec(gen_arm)):   # made from other files: made again
        return False
    rs = (truth.get("sim_switches") or {}).get("response_set")
    donor_resp = str(getattr(gen_spec(gen_arm).instrument, "responses", None) or "packaged") != "packaged"
    if donor_resp and rs is None:              # made with the packaged responses before the arm took the donors'
        return False
    if rs is not None:
        # made with the donors' responses: of the set there is now (its manifest digest), else made again
        from tngxmm.instrument.obs_responses import set_digest

        try:
            if rs.get("digest") != set_digest(rs.get("root") or None):
                return False
        except (FileNotFoundError, RuntimeError):     # no manifest, or no set configured
            return False
    if row is not None and need_sas and needs_sas_list(row):
        return (vd / "sas_detect" / "sources.csv").exists()
    return True

def cell_seed(vd: Path, truth: dict, spec: Any, donor_id: str) -> dict:
    """The first guess of a cell's fit from the cell's own image, as for a campaign view
    (:func:`tngxmm.massfit.build_fit_targets.measure_seed`: centre found from the cell's simulated catalogue position,
    the catalogue error of its donor ``donor_id``, and the published L-M relation iterated on the image, at the
    redshift the donor's entry gives the cell); the cell's true luminosity, mass and centre never seed the fit.  With
    the seed columns it returns the cell's offsets (:data:`tngxmm.massfit.build_fit_targets.MOCK_OFFSET_COLUMNS`),
    which the closure record keeps.  A cell without its SAS list is an error (every cell is detected at generation).
    Empty (the fitter then starts at the relation's pivot mass, ``seed_source = 'pivot'``, which the fit record keeps)
    when the image cannot be measured."""
    from tngxmm.massfit.build_fit_targets import MOCK_OFFSET_COLUMNS, SEED_COLUMNS, measure_seed
    from tngxmm.photometry._settings import photometry_settings
    from tngxmm.photometry.measure_lx import emsce_mean_exposure

    if not (Path(vd) / "sas_detect" / "sources.csv").exists():
        raise FileNotFoundError(f"{vd}: no SAS source list (tngxmm instrument sas-detect --view-dir {vd})")
    try:
        texp = emsce_mean_exposure(Path(vd) / "image_merged.fits", settings=photometry_settings(spec))
        s = measure_seed(Path(vd), float(truth["z"]), texp, float(truth["nh_1e22"]), spec, donor_id=donor_id)
    except (OSError, KeyError, ValueError) as e:
        print(f"  ! seed of {Path(vd).name}: {type(e).__name__}: {e}; the fit starts at the pivot mass")
        return {}
    return {**{k: s[k] for k in ("lx_0p35mpc", "lx_r500", "lx_1mpc")}, **{k: s[k] for k in SEED_COLUMNS},
            **{k: s[k] for k in MOCK_OFFSET_COLUMNS}}




def _fit_kwargs(out_root, row: dict, arm: str, *, quick: bool, cache_dir, timeout_s: int) -> tuple:
    """(target row, run_fit keyword arguments, truth.json record) of one fit."""
    from tngxmm.config import get_preset
    from tngxmm.massfit.build_fit_targets import MOCK_ENTRY_COLUMNS, mock_entry
    from tngxmm.massfit.fit_hydrostatic import fit_switches_from_spec, resp_dir

    a = FIT_ARMS[arm]
    spec = get_preset(a["preset"])
    sw = fit_switches_from_spec(spec)
    for k in ("psf", "pn_oot", "pixels_per_r500"):
        if k in a:
            sw[k] = a[k]
    pixsize = float(a.get("pixsize_as", sw.pop("target_pixsize_as")))
    # the gate arm (v1sas) masks with the cell's SAS edetect_chain list, exactly as a campaign view (source_list = sas
    # of the preset); the plain v1 arm with the simulated source table (a diagnostic)
    src_list = a.get("source_list", "default")
    sw["fitfix"] = {**sw["fitfix"], "source_list": src_list, **a.get("fitfix", {})}
    has_bg, has_agn = DATA_MODES[row["background"]]["sky_qpb"], DATA_MODES[row["background"]]["agn"]
    if spec.massfit.closure_clean_bg_zero and not has_bg and not has_agn and a.get("clean_bg", "zero") == "zero":
        # a clean mock has no sky, no particle background and no AGN: the fit's background is frozen at zero
        # (otherwise it fits cluster light beyond 2 R500 and the scattered wings as "background").  An AGN-only cell
        # keeps a free background: the unresolved AGN below the mask threshold are one (release 1.1.3; before, it was
        # frozen at zero too)
        sw["fitfix"] = {**sw["fitfix"], "bg_fixed": "zero"}
    vd = view_dir(out_root, a["gen"], row["cell"])
    truth = json.loads((vd / "truth.json").read_text())
    # the redshift the donor's catalogue entry gives the cell (its true z plus the drawn error of a photometric
    # catalogue redshift), as for a campaign view; a cell made before its entry's catalogue-position rule is refused
    ent = mock_entry(vd, float(truth["z"]), str(row["donor_id"]).zfill(10), spec=spec)
    target = dict(name=fit_name(row["cell"]), obsid=row["obsid"], z=float(ent["z_fit"]), ra=truth["ra"],
                  dec=truth["dec"], nh_1e22=truth["nh_1e22"], **{k: ent[k] for k in MOCK_ENTRY_COLUMNS})
    target.update(cell_seed(vd, truth, spec, str(row["donor_id"]).zfill(10)))
    f = seed_scale(arm)
    if f != 1.0 and math.isfinite(float(target.get("m500_seed_msun", float("nan")))):
        # the first-guess arms (B4, S6): the seed mass scaled, its R500 with it (R500 ~ M^(1/3) at fixed z); the
        # centre found stays.  A cell without a seed starts from the pivot whatever the arm
        target["m500_seed_msun"] = float(target["m500_seed_msun"]) * f
        if math.isfinite(float(target.get("r500_seed_kpc", float("nan")))):
            target["r500_seed_kpc"] = float(target["r500_seed_kpc"]) * f ** (1.0 / 3.0)
    # point sources: the preset's rule, exactly as for any campaign view and real observation: the gate arm masks
    # the cell's own SAS list (whatever it detected: AGN, spurious background sources, point-like cluster structure);
    # the plain v1 arm masks the simulated sources, which only the cells with AGN have
    masking = bool(sw.pop("source_masking")) and (has_agn or src_list == "sas")
    if masking:
        target["donor_id"] = str(row["donor_id"]).zfill(10)
    sas = None
    if masking and src_list == "sas":
        sas = vd / "sas_detect" / "sources.csv"
        if not sas.exists():
            raise FileNotFoundError(f"{sas}: arm {arm} masks with the cell's SAS list "
                                    f"(tngxmm instrument sas-detect --view-dir {vd})")
    kw = dict(quick=quick, seed=_seed("fit", row["cell"], arm), nprocesses=1,
              workdir=Path(out_root) / "fits" / arm, tag=arm,
              crop_r500=float(a.get("crop_r500", spec.massfit.crop_r500)), crop_cap_arcmin=a["crop_cap_arcmin"],
              target_pixsize_as=pixsize,
              fallback_bg_prior_dex=float(spec.massfit.fallback_bg_prior_dex),
              img_root=vd.parent, resp=str(resp_dir(None)), cache_dir=str(cache_parent(cache_dir)),
              per_fit_timeout_s=int(timeout_s), catalogue_csv=None, lx_csv=None,
              source_masking=masking, sources=None,
              mock_sources=str(vd / "pts_sources.fits") if masking else None, preset=spec.name, **sw)
    if sas is not None:
        kw["sas_sources"] = str(sas)
    return target, kw, truth

    ff = fitfix_from_spec(SimpleNamespace(massfit=m))

            ff.pop(k)
    return json.loads(json.dumps(without_late_defaults(ff)))

def fit_done(out_root, arm: str, cell: str) -> bool:
    """A finished fit (status ok) of ``arm``'s CURRENT configuration: EVERY key of :func:`fit_config` (preset, PSF, pn
    out-of-time switches, pixels per R500, fit-fix switches, clean background, crop cap, pixel size and the keys only
    some arms set) equals the record's, and the record has no other key; a record without one counts as not done.
    The record must also carry the current version of the catalogue-position rule (``catalogue_position_version``)
    and the fit's redshift ``z_fit`` equal to the one the donor's catalogue entry gives the cell now
    (:func:`tngxmm.photometry.catalogue_positions.mock_redshift` of the record's grid z, physics donor and the cell's
    ``VIEW_ID``): a fit of a cell made under an earlier rule, fitted at the grid's z before the catalogue redshift, or
    at a draw of a catalogue table since rebuilt, is made again."""
    from tngxmm.photometry.catalogue_positions import POSITION_RULE_VERSION, mock_redshift

    p = fit_dir(out_root, arm, cell) / "closure.json"
    if not p.exists():
        return False
    try:
        rec = json.loads(p.read_text())
    except Exception:  # noqa: BLE001
        return False
    if rec.get("status") != "ok":
        return False
    if rec.get("z_fit") is None or rec.get("catalogue_position_version") != POSITION_RULE_VERSION:
        return False
    try:
        want_z = mock_redshift(float(rec["z"]), str(rec["physics_donor_id"]).zfill(10), cell_view_id(cell))["z_fit"]
    except (KeyError, TypeError, ValueError):
        return False                                       # no entry to compare with: not a current fit
    if not math.isclose(float(rec["z_fit"]), float(want_z), rel_tol=0.0, abs_tol=1e-9):
        return False
    have = rec.get("fit_config")
    if not have:
        return False
    if "_agnonly_" in cell and rec.get("agn_bg") != AGN_BG_RULE:
        return False                                       # an AGN-only fit with its background frozen at zero
    want = json.loads(json.dumps(fit_config(arm)))        # JSON-normalised like the stored record
    return have == want

def _child(fn, args: tuple, log: Path) -> None:
    """Forked child: stdout/stderr to ``log``, run ``fn(*args)``, exit 0/1."""
    import traceback

    log.parent.mkdir(parents=True, exist_ok=True)
    fd = os.open(str(log), os.O_WRONLY | os.O_CREAT | os.O_APPEND, 0o644)
    os.dup2(fd, 1)
    os.dup2(fd, 2)
    sys.stdout = os.fdopen(1, "w", buffering=1)
    sys.stderr = os.fdopen(2, "w", buffering=1)
    code = 0
    try:
        fn(*args)
    except BaseException:  # noqa: BLE001
        traceback.print_exc()
        code = 1
    sys.stdout.flush()
    sys.stderr.flush()
    os._exit(code)

def run_forked(jobs: list[tuple], workers: int, *, timeout_s: float = 0, poll_s: float = 2.0,
               echo=print) -> dict:
    """Run ``jobs`` = [(label, fn, args_fn, log)] in at most ``workers`` forked children;
    ``args_fn(slot)`` gives the arguments (the slot number selects per-slot
    resources such as a rate cache: one child per slot at a time).  A child that
    exceeds ``timeout_s`` (> 0) is killed.  Returns {label: exit code or 'timeout'}."""
    import multiprocessing as mp

    ctx = mp.get_context("fork")
    pending = list(jobs)
    free = list(range(workers))
    running: dict[int, tuple] = {}
    out: dict = {}
    t_start = time.time()
    n = len(jobs)
    while pending or running:
        while pending and free:
            slot = free.pop(0)
            label, fn, args_fn, log = pending.pop(0)
            p = ctx.Process(target=_child, args=(fn, args_fn(slot), Path(log)), daemon=False)
            p.start()
            running[slot] = (p, label, time.time())
        time.sleep(poll_s)
        for slot, (p, label, t0) in list(running.items()):
            if p.exitcode is not None:
                p.join()
                out[label] = p.exitcode
            elif timeout_s and time.time() - t0 > timeout_s:
                p.kill()
                p.join()
                out[label] = "timeout"
            else:
                continue
            del running[slot]
            free.append(slot)
            echo(f"[{len(out)}/{n}] {label}: exit {out[label]}  "
                 f"({(time.time() - t0) / 60:.1f} min; elapsed {(time.time() - t_start) / 60:.1f} min)")
    return out

def response_coverage(plan: Any, arms) -> dict[str, dict[str, str]]:
    """``{generator arm: {donor: reason}}`` for the generator arms of ``arms`` made with the conditions donors' own
    responses (``instrument.responses`` other than 'packaged', every arm of the presets): the cells' donors and, under the
    conditions rule 'nn', every donor of the conditions pool, checked against the per-observation set
    (:func:`tngxmm.instrument.obs_responses.missing_responses`).  Empty when every donor is covered."""
    from tngxmm.instrument.conditions_donor import conditions_of
    from tngxmm.instrument.donor_tables import read_table
    from tngxmm.instrument.obs_responses import missing_responses
    from tngxmm.instrument.simulate_instrument import InstrumentOptions

    out: dict[str, dict[str, str]] = {}
    for g in gen_arms_of(arms):
        spec = gen_spec(g)
        opt = InstrumentOptions.from_spec(spec, "")
        if opt.responses == "packaged":
            continue
        donors = set(plan.donor_id.astype(str).str.zfill(10))
        cond = conditions_of(spec) or {}
        if cond.get("rule") == "nn":
            t = read_table("conditions", cond.get("table") or None)
            donors |= set((t[t["pool"].astype(bool)] if "pool" in t else t).obsid.astype(str).str.zfill(10))
        from tngxmm.instrument.obs_responses import check_set

        check_set(opt.response_set or None)   # a manifest and the current centre table, before any photon
        gone = missing_responses(donors, opt.response_set or None)
        if gone:
            out[g] = gone
    return out

def run_generation(out_root, workers: int, *, arms=tuple(GEN_ARMS), cells=None, resume=True,
                   ncell: int = NCELL, echo=print) -> dict:
    """Generate the views of the plan for ``arms`` (all cells, or ``cells``) on ``workers`` forked processes, brightest
    (low z, high mass) first; with ``resume`` finished views are skipped.  Returns the exit status of each job.
    An arm made with the donors' own responses stops here, before any view, when a donor it may draw has no complete
    entry in the per-observation set (:func:`response_coverage`), and every arm when a file its cells are made from is
    not current (:func:`tngxmm.sim.data_inputs.check_stage_inputs`)."""
    plan = read_plan(out_root)
    if cells:
        plan = plan[plan.cell.isin(cells)]
    cov = response_coverage(plan, arms)
    if cov:
        raise SystemExit("per-observation responses missing for donors the arms may draw (build the set: tngxmm "
                         "instrument obs-responses):\n" + _coverage_lines(cov))
    from tngxmm.sim.data_inputs import check_stage_inputs

    for arm in arms:                     # every file a cell is made from, current, before any view
        try:
            check_stage_inputs(gen_spec(arm))
        except (ValueError, FileNotFoundError) as e:
            raise SystemExit(f"generator arm {arm}: {e}") from e
    rows = plan.to_dict("records")
    # brightest first (low z, high mass): they take longest
    rows.sort(key=lambda r: (r["z"], -r["m500_1e14"]))
    jobs = []
    for arm in arms:
        for r in rows:
            if resume and generation_done(out_root, arm, r["cell"], r):
                continue
            if resume and generation_done(out_root, arm, r["cell"], r, need_sas=False):   # current, no SAS list yet
                log = Path(out_root) / "logs" / "sas" / arm / f"{r['cell']}.log"
                jobs.append((f"sas {arm} {r['cell']}", detect_cell,
                             (lambda slot, r=r, arm=arm: (out_root, r, arm)), log))
                continue
            log = Path(out_root) / "logs" / "gen" / arm / f"{r['cell']}.log"
            jobs.append((f"gen {arm} {r['cell']}", generate_view,
                         (lambda slot, r=r, arm=arm: (out_root, r, arm)), log))
    echo(f"generation: {len(jobs)} views to make on {workers} workers")
    if not jobs:
        return {}
    warm_generation_tables()
    return run_forked(jobs, workers, timeout_s=3 * 3600, echo=echo)




def _warm_groups(plan, arms) -> list[tuple[str, dict]]:
    """One representative (fit arm, row) per distinct rate-table key set: generator arm (header filters) x the fit's
    responses (:func:`tngxmm.massfit.fit_hydrostatic.response_options`: the shared set or the donor's own, the CCF
    selection; ``v1`` and ``v1_obsresp_shared`` fit the same cells through other RMFs and ARFs) x the redshift of the
    fit x donor.  The fit's redshift is the one the donor's catalogue entry gives the cell
    (:func:`tngxmm.photometry.catalogue_positions.mock_redshift`, keyed by the cell's ``VIEW_ID``), the redshift
    :func:`warm_rate_cache` builds the tables at; it differs from the grid's z for a photometric catalogue redshift."""
    from tngxmm.massfit.fit_hydrostatic import response_options
    from tngxmm.photometry.catalogue_positions import mock_redshift

    seen = set()
    out = []
    for arm in arms:
        g = FIT_ARMS[arm]["gen"]
        ro = response_options(fit_config(arm).get("fitfix") or {})
        resp_key = (ro["pn_arf"], ro["responses"], ro["ccf_selection"])
        for r in plan.to_dict("records"):
            donor = str(r["donor_id"]).zfill(10)
            z_fit = mock_redshift(float(r["z"]), donor, cell_view_id(r["cell"]))["z_fit"]
            key = (g, resp_key, round(float(z_fit), 9), donor)
            if key in seen:
                continue
            seen.add(key)
            out.append((arm, r))
    return out

def run_warm(out_root, seed_cache, workers: int, *, arms=DEFAULT_FIT_ARMS, echo=print) -> Path:
    """Fill ``caches/seed`` (a copy of ``seed_cache``'s settled entries) with every
    rate table of the grid: one forked child per key group, each in its own cache
    ``caches/warm/<n>``, merged afterwards (entries are content-addressed)."""
    from tngxmm.massfit.check_preflight import check_preflight

    root = Path(out_root) / "caches"
    seed = root / "seed"
    n = copy_settled_cache(seed_cache, seed) if seed_cache else 0
    (seed / "mbproj2d_cache").mkdir(parents=True, exist_ok=True)
    echo(f"seed cache {seed}: {n} entries copied from {seed_cache}")

    jobs = []
    for i, (arm, r) in enumerate(groups):
        wd = root / "warm" / f"{i:03d}"
        copy_settled_cache(seed, wd)
        check_preflight(wd / "mbproj2d_cache", minutes=0, log=echo)
        jobs.append((f"warm {arm} z={r['z']} donor={r['donor_id']}", warm_rate_cache,
                     (lambda slot, arm=arm, r=r, wd=wd: (out_root, r, arm, wd)),

def make_slot_caches(out_root, workers: int, echo=print) -> list[Path]:
    """One private rate cache per fit slot, ``caches/w<NN>``, copied from ``caches/seed``

def run_fits(out_root, workers: int, *, arms=DEFAULT_FIT_ARMS, cells=None, quick: bool = True,
             resume: bool = True, timeout_s: int = FIT_TIMEOUT_S, echo=print) -> dict:
    """Fit the generated views for each of ``arms``: skips finished fits (``resume``) and cells not generated, runs the
    rest longest first (PSF arms, low z, high mass) on ``workers`` processes with a private rate cache per slot, ``timeout_s`` per fit. Returns
    the exit status of each job."""
    plan = read_plan(out_root)
    if cells:
        plan = plan[plan.cell.isin(cells)]
    todo = []
    for arm in arms:
        for r in plan.to_dict("records"):
            if resume and fit_done(out_root, arm, r["cell"]):
                continue
            sas_arm = FIT_ARMS[arm].get("source_list") == "sas"
            if not generation_done(out_root, FIT_ARMS[arm]["gen"], r["cell"], r, need_sas=sas_arm):
                echo(f"skip {arm} {r['cell']}: not generated")
                continue
            todo.append((arm, r))
    todo.sort(key=lambda t: _fit_cost(t[1], t[0]))
    echo(f"fits: {len(todo)} to run on {workers} workers (quick={quick})")
    if not todo:
        return {}
    slots = make_slot_caches(out_root, min(workers, len(todo)), echo=echo)
    jobs = [(f"fit {arm} {r['cell']}", fit_view,
             (lambda slot, arm=arm, r=r: (out_root, r, arm)),
             Path(out_root) / "logs" / "fits" / arm / f"{r['cell']}.log") for arm, r in todo]
    # fit_view(out_root, row, arm, cache_dir=..., quick=...): bind the slot's cache
    jobs = [(lab, _fit_slot, (lambda slot, a=args, q=quick, t=timeout_s: (a(slot), slots[slot], q, t)),
             log) for lab, _f, args, log in jobs]
    return run_forked(jobs, len(slots), timeout_s=timeout_s + 900, echo=echo)

def collect(out_root, arms=DEFAULT_FIT_ARMS) -> Any:
    """One row per (cell, arm) of the plan: the closure record, or status 'missing'; a record with status ok that
    fails :func:`fit_done` (another rule version, fit configuration or catalogue redshift), or whose result.json (its
    QC flags) cannot be read, gets status 'stale', so the cell counts as INCOMPLETE and never enters a ratio."""
    import pandas as pd

    plan = read_plan(out_root)
    rows = []
    for arm in arms:
        for r in plan.to_dict("records"):
            p = fit_dir(out_root, arm, r["cell"]) / "closure.json"
            rec = None
            if p.exists():
                try:
                    rec = json.loads(p.read_text())
                except Exception:  # noqa: BLE001
                    rec = None
            if rec is not None and rec.get("status") == "ok" and not fit_done(out_root, arm, r["cell"]):
                rec = dict(rec, status="stale")
            if rec is None:
                rec = dict(cell=r["cell"], arm=arm, gen_arm=FIT_ARMS[arm]["gen"],
                           m500_1e14=r["m500_1e14"], z=r["z"], profile=r["profile"],

                           ratio=float("nan"))
            else:

                    # an ok fit whose QC cannot be read (no result.json) is not judged: it counts as stale, so the
                    # background is INCOMPLETE, as for a missing fit
                    rec["status"] = "stale"
            rows.append(rec)
    return pd.DataFrame(rows)

    def num(v):

        except (TypeError, ValueError):
            return float("nan")
        return v if math.isfinite(v) else float("nan")

    out["rhat_lnm500"], out["ess_bulk_lnm500"] = num(d.get("rhat")), num(d.get("ess_bulk"))
    return out

def usable(fits: Any) -> Any:
    """Boolean Series: the fits that enter a closure statistic: status ok, a finite positive ratio, and no QC flag of
    :data:`tngxmm.massfit.fit_qc.QC_EXCLUDING` (a fit whose QC is unknown is not usable)."""
    import numpy as np
    import pandas as pd

    ratio = np.asarray(fits["ratio"], float) if "ratio" in fits.columns else np.full(len(fits), np.nan)
    ok = (fits["status"].astype(str) == "ok").to_numpy() & np.isfinite(ratio) & (ratio > 0)
    qc = fits["qc_excluded"] if "qc_excluded" in fits.columns else None
    # False (or 0) only: a fit whose QC is unknown (None, NaN) is not usable
    clean = np.zeros(len(fits), bool) if qc is None else np.asarray([v is not None and v == 0 for v in qc], bool)
    return pd.Series(ok & clean, index=fits.index)

def mode_verdict(fits: Any, background: str, gate_arm: str = GATE_ARM, rule: dict | None = None) -> dict:
    """The DESIGN v4 rule (:data:`CLOSURE_RULE`) on one data mode of the gate arm: the counts (fits planned, ok,
    failed, missing or stale, pivot, QC-excluded, usable), the redshifts in and out of the domain with their medians,
    the pooled median of the ratio and its bootstrap 95 per cent interval, the catastrophic fraction of the ok fits,
    and the verdicts ``clean`` (the fitter gate, clean cells), ``tail`` (real cells) and ``hse_claim`` (real cells:
    the window of the hydrostatic-bias claim), each PASS, FAIL, INCOMPLETE or None where it does not apply."""
    import numpy as np

    R = dict(CLOSURE_RULE, **(rule or {}))
    g = fits[(fits.arm == gate_arm) & (fits.background == background)]
    n = len(g)
    st = g["status"].astype(str)
    use = usable(g)
    piv = is_pivot(g)
    out: dict[str, Any] = dict(background=background, n_fits=int(n), n_ok=int((st == "ok").sum()),
                               n_failed=int((~st.isin(["ok", "missing", "stale"])).sum()),
                               n_missing=int(st.isin(["missing", "stale"]).sum()), n_pivot=int(piv.sum()),
                               n_qc_excluded=int(((st == "ok") & ~use).sum()), n_usable=int(use.sum()))
    verdicts: dict[str, Any] = dict(clean=None, tail=None, hse_claim=None)
    if n == 0 or out["n_missing"]:
        out["reason"] = "no fits" if n == 0 else f"{out['n_missing']} fits missing or stale"
        if background == "clean":
            verdicts["clean"] = "INCOMPLETE"
        elif background == "real":
            verdicts["tail"] = verdicts["hse_claim"] = "INCOMPLETE"
        out.update(verdicts)
        return out
    fail = out["n_failed"] / n > R["max_fail_frac"]
    pivot_inc = out["n_pivot"] / n > R["max_pivot_frac"]
    z_med, z_out = {}, []
    for z, gz in g.groupby("z", sort=True):
        u = use.loc[gz.index]
        if u.sum() < R["min_usable_frac_z"] * len(gz):
            z_out.append(float(z))
            continue
        z_med[float(z)] = float(np.exp(np.median(np.log(gz.loc[u, "ratio"].to_numpy(float)))))
    out.update(z_medians=z_med, z_out_of_domain=z_out)
    dom = g[use & g.z.astype(float).isin(list(z_med))]
    lr = np.log(dom["ratio"].to_numpy(float))
    med, lo, hi = _median_ci(lr, int(R["n_boot"]), int(R["boot_seed"])) if len(lr) else (np.nan,) * 3
    out.update(median=float(np.exp(med)), ci95=(float(np.exp(lo)), float(np.exp(hi))), n_domain=int(len(lr)))
    okr = np.asarray(g.loc[st == "ok", "ratio"], float)
    okr = okr[np.isfinite(okr) & (okr > 0)]

    out["catastrophic_frac"] = float(((okr < c_lo) | (okr > c_hi)).mean()) if len(okr) else float("nan")
    few_z = len(z_med) < R["min_z_in_domain"]

    def decide(passed: bool) -> str:
        if fail:
            return "FAIL"
        if pivot_inc or few_z:
            return "INCOMPLETE"
        return "PASS" if passed else "FAIL"

        a, b = R["clean_pass_inside"]
        zl, zh = R["clean_z_window"]
        verdicts["clean"] = decide(a <= out["ci95"][0] and out["ci95"][1] <= b
                                   and all(zl <= v <= zh for v in z_med.values()))
    elif background == "real":
        verdicts["tail"] = decide(out["catastrophic_frac"] <= R["max_catastrophic_frac"])
        a, b = R["real_window"]
        zl, zh = R["real_z_window"]
        verdicts["hse_claim"] = decide(a <= out["median"] <= b and all(zl <= v <= zh for v in z_med.values()))
    out.update(verdicts)
    return out

def arm_shift(d, delta: float, n_boot: int, seed: int, min_pairs: int) -> dict:
    """The arm rule on paired differences ``d`` (ln M500, arm minus base): median, bootstrap 95 per cent interval,
    verdict NEGLIGIBLE (interval inside +/- delta), SYSTEMATIC (reaches beyond and excludes 0), INCONCLUSIVE (reaches
    beyond and includes 0) or INCOMPLETE (fewer than ``min_pairs``), and MATERIAL (SYSTEMATIC with |median| > delta)."""
    import numpy as np

    d = np.asarray(d, float)
    d = d[np.isfinite(d)]
    if len(d) < max(int(min_pairs), 1):
        return dict(n_pairs=int(len(d)), median=float(np.median(d)) if len(d) else float("nan"),
                    ci95=(float("nan"), float("nan")), verdict="INCOMPLETE", material=False)
    med, lo, hi = _median_ci(d, n_boot, seed)
    if -delta <= lo and hi <= delta:
        v = "NEGLIGIBLE"
    elif lo > 0 or hi < 0:
        v = "SYSTEMATIC"
    else:
        v = "INCONCLUSIVE"
    return dict(n_pairs=int(len(d)), median=float(med), ci95=(float(lo), float(hi)), verdict=v,
                material=bool(v == "SYSTEMATIC" and abs(med) > delta))

def paired_differences(fits: Any, arm: str, base: str, background: str | None = None,
                       require_usable: bool = True) -> Any:
    """ln M500(arm) - ln M500(base) per cell (the cell name holds the seed), over the cells where both fits are usable
    (:func:`usable`), or only status ok with ``require_usable`` False; ``background`` restricts the data mode."""
    import numpy as np

    def side(a):
        s = fits[fits.arm == a]
        if background is not None:
            s = s[s.background == background]
        keep = usable(s) if require_usable else (s.status.astype(str) == "ok") & (s.ratio.astype(float) > 0)
        s = s[keep]
        return s.set_index("cell")["ratio"].astype(float)

    a, b = side(arm), side(base)
    j = a.index.intersection(b.index)
    return np.log(a.loc[j].to_numpy()) - np.log(b.loc[j].to_numpy())

def arm_verdicts(fits: Any, arms, rule: dict | None = None) -> dict:
    """The arm rule (:data:`ARM_RULE`) for every study arm in ``arms`` whose base (:data:`ARM_BASE`) is fitted too: the
    verdict on the real-background cells (``ARM_RULE['background']``) and, reported, on the clean cells and on all ok
    pairs without the QC exclusion; the arm's role (:data:`ARM_ROLE`).  ``power`` says whether every re-seed arm in
    ``arms`` is NEGLIGIBLE: if one is not, the cells are too few for the rule (add seeds; the threshold stays)."""
    R = dict(ARM_RULE, **(rule or {}))
    kw = dict(delta=float(R["delta"]), n_boot=int(R["n_boot"]), seed=int(R["boot_seed"]),
              min_pairs=int(R["min_pairs"]))

                        **arm_shift(paired_differences(fits, arm, base, R["background"]), **kw),

                        all_ok=arm_shift(paired_differences(fits, arm, base, R["background"], False), **kw))

    return dict(rule=R, arms=out, power=power)

def budget(arm_rule: dict) -> dict:
    """The systematic budget of the study arms (docs/dev/PREREGISTRATION.md, section 2) from :func:`arm_verdicts`:
    per arm that is not NEGLIGIBLE (or INCOMPLETE) its contribution (down, up) in ln M500 by its role: ``error`` two-
    sided at |median| (INCONCLUSIVE: the far end of the interval); ``pair`` the asymmetric interval [min(0, a, b),
    max(0, a, b)] of the medians of the two arms that are not NEGLIGIBLE, once per pair; ``range`` one-sided at the
    median.  ``up`` and ``down`` add the terms in quadrature.  ``bound`` arms are listed apart (``bounds``, two-sided
    at |median|): stated sensitivities, not summed; the other roles enter nothing."""
    import math as _m

    arms = arm_rule.get("arms", {})
    terms: dict[str, tuple[float, float]] = {}
    bounds: dict[str, float] = {}

    def size(v):
        if v["verdict"] == "INCONCLUSIVE":
            return max(abs(v["ci95"][0]), abs(v["ci95"][1]))
        return abs(v["median"])

    for a, v in arms.items():
        if v["verdict"] in ("NEGLIGIBLE", "INCOMPLETE"):
            continue
        role = v["role"]
        if role == "error":
            terms[a] = (size(v), size(v))
        elif role == "range":
            m = v["median"]
            terms[a] = (max(0.0, -m), max(0.0, m))
        elif role == "bound":
            bounds[a] = size(v)
        elif role.startswith("pair:"):
            partner = role.split(":", 1)[1]
            key = "/".join(sorted((a, partner)))
            if key in terms:
                continue
            ms = [v["median"]]
            if partner in arms and arms[partner]["verdict"] not in ("NEGLIGIBLE", "INCOMPLETE"):
                ms.append(arms[partner]["median"])
            terms[key] = (max(0.0, -min(ms)), max(0.0, max(ms)))
    down = _m.sqrt(sum(d * d for d, _ in terms.values()))
    up = _m.sqrt(sum(u * u for _, u in terms.values()))
    return dict(terms={k: dict(down=d, up=u) for k, (d, u) in terms.items()}, down=down, up=up, bounds=bounds)

def jitter_bias(arm_rule: dict) -> dict | None:
    """The second-order bias of a zero-mean exposure jitter (docs/dev/PREREGISTRATION.md, section 9): the quadratic
    y = p x + q x^2 through the paired medians of ``v1_half`` (x = ln 0.5) and ``v1_deep`` (x = ln 10) about ``v1``
    (x = 0), the curvature c = 2 q, and bias = c sigma^2 / 2 with sigma^2 the sum of the squares of
    :data:`JITTER_SIGMA_LN`; ``enters`` when |bias| > :data:`JITTER_MAX_BIAS`.  None without both arms."""
    import math as _m

    arms = arm_rule.get("arms", {})
    if not all(a in arms and arms[a]["verdict"] != "INCOMPLETE" for a in ("v1_half", "v1_deep")):
        return None
    xa, xb = _m.log(GEN_ARM_EXPOSURE["v1_half"]), _m.log(GEN_ARM_EXPOSURE["v1_deep"])
    ya, yb = arms["v1_half"]["median"], arms["v1_deep"]["median"]
    q = (yb / xb - ya / xa) / (xb - xa)
    s2 = sum(s * s for s in JITTER_SIGMA_LN)
    bias = q * s2
    return dict(curvature=2.0 * q, bias=bias, enters=bool(abs(bias) > JITTER_MAX_BIAS))

def sampler_verdict(fits: Any, rule: dict | None = None) -> dict:
    """The rule of STATUS Q18 (:data:`SAMPLER_RULE`) on the fits of the Q18 job (both backgrounds pooled): per
    candidate, the agreement with the reference (the arm rule on the usable pairs, ``delta``), its Monte-Carlo scatter
    (1.4826 MAD of the candidate minus its re-seed, over sqrt 2), the median R-hat and bulk ESS of ln M500 and whether
    it is converged in the sense of Vehtari et al. (2021) (every fit R-hat < ``rhat_max`` and ESS > ``ess_min``);
    ``eligible`` = agrees and scatter <= ``max_mc_scatter``.  ``choice``: the cheapest converged eligible candidate
    (``cost_core_h``) first, then, among the eligible candidates whose scatter is within ``tie_scatter`` of the
    smallest, the cheapest, equal costs going to the smaller scatter; if
    none is eligible, the reference, if its own re-seed scatter is within the limit; else None (the author decides,
    and the Monte-Carlo term is carried from the repeats)."""
    import numpy as np

    S = dict(SAMPLER_RULE, **(rule or {}))
    present = set(fits.arm.unique()) if len(fits) else set()

    def mc(a):
        r = S["repeats"].get(a)
        if r is None or a not in present or r not in present:
            return float("nan")
        d = paired_differences(fits, r, a)
        return float(1.4826 * np.median(np.abs(d - np.median(d))) / math.sqrt(2.0)) if len(d) else float("nan")

    def conv(a):
        g = fits[(fits.arm == a) & usable(fits)]
        rh = np.asarray(g.get("rhat_lnm500", []), float)
        es = np.asarray(g.get("ess_bulk_lnm500", []), float)
        ok = len(rh) > 0 and bool(np.all(rh < S["rhat_max"]) and np.all(es > S["ess_min"]))
        return ok, float(np.nanmedian(rh)) if len(rh) and np.isfinite(rh).any() else float("nan"), \
            float(np.nanmedian(es)) if len(es) and np.isfinite(es).any() else float("nan")

    ref = S["reference"]
    out: dict[str, Any] = {}
    for a in S["candidates"]:
        if a not in present or ref not in present:
            continue
        agree = arm_shift(paired_differences(fits, a, ref), float(S["delta"]), int(ARM_RULE["n_boot"]),
                          int(ARM_RULE["boot_seed"]), int(ARM_RULE["min_pairs"]))
        c, rh, es = conv(a)
        s = mc(a)
        out[a] = dict(agreement=agree, mc_scatter=s, converged=c, rhat_median=rh, ess_median=es,
                      eligible=bool(agree["verdict"] == "NEGLIGIBLE" and math.isfinite(s) and s <= S["max_mc_scatter"]))
    elig = [a for a in S["candidates"] if out.get(a, {}).get("eligible")]
    cost = S["cost_core_h"]
    conv = sorted((a for a in elig if out[a]["converged"]), key=lambda a: (cost[a], out[a]["mc_scatter"]))
    choice = conv[0] if conv else None
    if choice is None and elig:
        # the cheapest of the candidates within tie_scatter of the smallest scatter; equal cost: the smaller scatter
        best = min(out[a]["mc_scatter"] for a in elig)
        near = [a for a in elig if out[a]["mc_scatter"] <= best + S["tie_scatter"]]
        choice = min(near, key=lambda a: (cost[a], out[a]["mc_scatter"]))
    ref_s = mc(ref) if ref in present else float("nan")
    if choice is None and math.isfinite(ref_s) and ref_s <= S["max_mc_scatter"]:
        choice = ref
    return dict(rule=S, candidates=out, reference_mc_scatter=ref_s, choice=choice)

def summarise(fits: Any, n_seeds: int = len(GRID_SEEDS), tol: float = TOLERANCE) -> Any:
    """Per (arm, cell): seeds fitted, geometric-mean ratio, scatter, standard error,
    verdict (|mean - 1| <= tol), the looser 'consistent' flag (within tol + 2 s.e.) and ``n_pivot``, the fits that
    started from the relation's pivot mass because the cell's image gave no first guess (``mass_seed_source``
    ``pivot``, or ``pivot (<status>)`` when the seed failed with that status)."""
    import numpy as np
    import pandas as pd

    out = []
    for key, g in fits.groupby(["arm", *CELL_KEYS], sort=True):
        ok = g[(g.status == "ok") & np.isfinite(g.ratio) & (g.ratio > 0)]
        lr = np.log(ok.ratio.to_numpy(float))
        n = len(lr)
        mean = float(np.exp(lr.mean())) if n else float("nan")
        sd = float(lr.std(ddof=1)) if n > 1 else float("nan")
        se = sd / math.sqrt(n) if n > 1 else float("nan")
        complete = n == n_seeds
        within = bool(n and abs(mean - 1.0) <= tol)
        consistent = bool(n > 1 and abs(math.log(mean)) <= math.log(1 + tol) + 2 * se)
        out.append(dict(zip(("arm", *CELL_KEYS), key), n_ok=n, ratio_gmean=mean,
                        ratio_min=float(ok.ratio.min()) if n else float("nan"),
                        ratio_max=float(ok.ratio.max()) if n else float("nan"),
                        sd_ln=sd, se_ln=se, complete=complete,
                        verdict=("INCOMPLETE" if not complete else "PASS" if within else "FAIL"),
                        consistent_2se=consistent,
                        n_pivot=int(g.get("mass_seed_source", pd.Series(dtype=object)).astype(str)
                                    .str.startswith("pivot").sum())))
    return pd.DataFrame(out)

def verdict(cells: Any, gate_arm: str = GATE_ARM) -> tuple[int, str]:
    """(exit code, word) of the gate arm: 0 PASS, 1 FAIL, 2 INCOMPLETE."""
    g = cells[cells.arm == gate_arm]

        return 2, "INCOMPLETE"

def _md_table(cells: Any, arms) -> str:
    lines = ["| M500 [1e14] | z | profile | background | " + " | ".join(arms) + " |",
             "|---|---|---|---|" + "---|" * len(arms)]
    for key, g in cells.groupby(list(CELL_KEYS), sort=True):
        vals = []
        for arm in arms:
            r = g[g.arm == arm]
            if not len(r) or not r.n_ok.iloc[0]:
                vals.append("missing")
                continue
            r = r.iloc[0]
            mark = {"PASS": "", "FAIL": " **FAIL**", "INCOMPLETE": f" ({r.n_ok} seeds)"}[r.verdict]
            vals.append(f"{r.ratio_gmean:.3f} [{r.ratio_min:.2f}-{r.ratio_max:.2f}]{mark}")
        lines.append(f"| {key[0]:g} | {key[1]:g} | {key[2]} | {key[3]} | " + " | ".join(vals) + " |")
    return "\n".join(lines)

    common(p, workers=False)
    p.add_argument("--cell", required=True)
    p.add_argument("--arm", required=True, choices=list(FIT_ARMS))
    p.add_argument("--cache-dir", required=True, help="directory containing mbproj2d_cache")
    p.add_argument("--long", action="store_true")
    p.add_argument("--timeout-s", type=int, default=FIT_TIMEOUT_S)
    a = ap.parse_args(argv)

    def lst(s):
        return [x for x in str(s).split(",") if x]

    def cells_of(a):
        return cells_from(getattr(a, "cells", ""), getattr(a, "cells_file", ""))

    if a.cmd == "plan":
        bgs = tuple(lst(a.backgrounds))
        unknown = sorted(set(bgs) - set(DATA_MODES))
        if unknown:
            ap.error(f"unknown data modes {unknown}; known: {sorted(DATA_MODES)}")
        print(write_plan(a.out_root, a.targets, force=a.force, backgrounds=bgs))
        # the arms made with the donors' own responses need the per-observation set (checked again by 'generate')
        from tngxmm.core.site import SiteNotConfigured

        try:
            cov = response_coverage(read_plan(a.out_root), list(GEN_ARMS))
        except (SiteNotConfigured, OSError, ValueError) as exc:
            print(f"note: per-observation response coverage not checked ({exc})")
        else:
            if cov:
                print("note: these arms cannot be generated until the per-observation set covers their donors:\n"
                      + _coverage_lines(cov))
        return 0
    if a.cmd == "generate" and a.check_only:
        stale = stale_views(a.out_root, arms=gen_arms_of(lst(a.arms)), cells=cells_of(a))
        for arm, cell in stale:
            print(f"not current: {arm} {cell}")
        print(f"{len(stale)} views not current")
        return 3 if stale else 0
    if a.cmd == "generate":
        res = run_generation(a.out_root, a.workers, arms=gen_arms_of(lst(a.arms)), cells=cells_of(a),
                             resume=not a.no_resume, ncell=a.ncell)
        bad = {k: v for k, v in res.items() if v != 0}
        print(f"generation finished: {len(res) - len(bad)}/{len(res)} ok" + (f"; failed {bad}" if bad else ""))
        return 0 if not bad else 1
    if a.cmd == "warm":
        run_warm(a.out_root, _cache_from_env(a.seed_cache), a.workers, arms=lst(a.arms))
        return 0
    if a.cmd == "fit":
        res = run_fits(a.out_root, a.workers, arms=lst(a.arms), cells=cells_of(a),
                       quick=not a.long, resume=not a.no_resume, timeout_s=a.timeout_s)
        bad = {k: v for k, v in res.items() if v != 0}
        print(f"fits finished: {len(res) - len(bad)}/{len(res)} ok" + (f"; failed {bad}" if bad else ""))
        return 0 if not bad else 1
    if a.cmd == "analyse":
        return analyse(a.out_root, lst(a.arms), a.gate_arm)
    if a.cmd == "generate-one":
        generate_view(a.out_root, _row(a.out_root, a.cell), a.arm, ncell=a.ncell,
                      keep_events=a.keep_events)
        return 0
    if a.cmd == "warm-one":
        warm_rate_cache(a.out_root, _row(a.out_root, a.cell), a.arm, a.cache_dir)
        return 0
    if a.cmd == "fit-one":
        fit_view(a.out_root, _row(a.out_root, a.cell), a.arm, cache_dir=a.cache_dir,
                 quick=not a.long, timeout_s=a.timeout_s)
        return 0
    return 2
