Source code for tngxmm.massfit.fit_hydrostatic

"""Hydrostatic M500 from XMM per-camera images with mbproj2d (2-D forward fit).

The fit has switches for seeding (``seed``: deterministic sampler), point-source
masking, the optical axis from the header, the rebin-centre convention, per-fit
provenance, the metallicity (fixed 0.3 / per population / free), the XSPEC
abundance table (lodd / angr), the mean molecular weight (mbproj2d's / full
ionisation, ``set_molecular_weight``), the PSF in the model (none / the
on-axis King profile, ``fit_psf``) and the pn out-of-time events (none / a fixed
template per pn image, ``pn_oot``).  CampaignSpec ``massfit`` carries the
switches; :func:`fit_switches_from_spec` maps them, and the ``fitfix`` bundle of
sub-switches (:data:`FITFIX_DEFAULTS`, ``--fitfix k=v``) holds the priors, the
background seeding and the optimiser stages.

For one cluster every per-camera image in four bands

    2000 = 0.5-1.0    3000 = 1.0-2.0    4000 = 2.0-4.5    5000 = 4.5-12  [keV]

is loaded as a separate mbproj2d ``Image`` with its own (rmf, arf) chosen from
the camera (EPN/EMOS1/EMOS2) and filter (Thin1/Medium/Thick) of the image
header (fit-fix ``responses = 'per-observation'``: the RMF and on-axis ARF SAS made
for the image's own exposure, :mod:`tngxmm.instrument.obs_responses`), and its own
exposure map.  The soft bands fix the gas density; the hard
bands fix the temperature (and hence the mass) through the band ratios.  Band 5
(4.5-12 keV) is the thermometer (an upstream log(0) typo is worked around in
``patch_apec``); band 1 (0.2-0.5 keV) is dropped (no temperature leverage, most
exposed to N_H errors, flares and SWCX).

Model: NFW dark-matter halo parameterised directly by M500
(``ProfileMassNFWfnM``, overdensity 500) + hydrostatic equilibrium + a
Vikhlinin density profile (``mode='single'``, keeping the outer steepening
term) + a flat metallicity (Lodders 2003 units, the ``abund lodd`` of
mbproj2d's rate tables): free with a flat prior by default, or fixed at a given
value; c200 free with the flat prior in ln c over 1-10 of Sanders et al. (2018), or
(``cm_prior = 'dutton14'``) with the log-normal prior about the c200(M200, z) relation
of Dutton & Maccio (2014) evaluated at the sampled mass (:mod:`tngxmm.massfit.cm_prior`).
R500 is not fitted: it follows from M500 and the redshift through the critical
density.  Reported M500/R500 are TOTAL enclosed values from ``mbproj2d.Phys``.
Background (``massfit.qpb_model = 'esas-fwc-corners'``, XMM-ESAS and X-COP;
:func:`build_esas_background`): per image a fixed particle-background template
whose level the observation's corners set, a vignetted sky and the residual soft
protons on the CCF flare maps, both with free levels and no prior, and the pn
out-of-time template.  The alternative ``'mixture'`` is mbproj2d's
``BackModelVigNoVig`` per image, seeded from the outer annulus with a 0.05 dex
Gaussian prior (Sanders et al. 2018), widened to ``fallback_bg_prior_dex`` where
the seed did not come from a clean annulus beyond 2 R500.  Optimiser: two nlopt stages (backgrounds seeded from
the data frozen or not in stage 1, then all released); sampler: emcee via
mbproj2d (its moves, the walker start and the convergence diagnostics of every
``result.json``: :mod:`tngxmm.massfit.sample_posterior`).

Randomness: every draw of a single-target fit comes from numpy's GLOBAL RNG
(mbproj2d walker starts, emcee 3.1.6 copying the global state, the
``randsamples`` shuffle); the nlopt optimisers used are deterministic.
``seed`` calls ``numpy.random.seed(seed)`` at the start of each target, so a
single-target fit with ``nprocesses=1`` is reproducible exactly.

Rate cache: mbproj2d caches XSPEC rate tables in ``./mbproj2d_cache``
(cwd-relative, one lock directory per key).  ``cache_dir`` (or
``$TNGXMM_MBPROJ_CACHE_DIR``) points it at a PRIVATE directory; never share a
cache with production or another agent (a killed lock holder hangs every other
reader; ``check_preflight`` removes stale locks).

References
----------
mbproj2d, sanders2018 and sanders2018_bgprior (method, priors), vikhlinin2006
(density profile), nfw (mass profile), emcee (sampler), nlopt (optimiser),
heasoft_xspec, apec and atomdb (rate tables), xmm_ccf_sas (responses and
vignetting), cosmology_planck2015 (pipeline cosmology).

def resolve_fitfix(fitfix=None) -> dict[str, Any]:
    """:data:`FITFIX_DEFAULTS` with the entries of ``fitfix`` (a dict, or None) applied; validated."""
    ff = dict(FITFIX_DEFAULTS)
    for k, v in (fitfix or {}).items():
        if k not in FITFIX_DEFAULTS:
            raise ValueError(f"unknown fitfix entry {k!r} (known: {sorted(FITFIX_DEFAULTS)})")
        if k in _FITFIX_CHOICES and v not in _FITFIX_CHOICES[k]:
            raise ValueError(f"fitfix {k} = {v!r} (one of {_FITFIX_CHOICES[k]})")
        ff[k] = tuple(v) if k == "z_gauss" else v
    ff["qpb_scale"] = _qpb_scale_value(ff["qpb_scale"])
    from tngxmm.massfit.model_shells import pixel_average, shells_per_pixel

    ff["shells_per_pixel"] = shells_per_pixel(ff["shells_per_pixel"])
    ff["pixel_average"] = pixel_average(ff["pixel_average"])
    if ff["qpb_level"] == "free" and ff["qpb_scale"] != 1.0:
        # the scale multiplies the fixed template; a free level is fitted from the template as it is
        raise ValueError(f"fitfix qpb_scale = {ff['qpb_scale']} applies to qpb_level 'fixed' only")
    return ff




#: what a fit-fix ``qpb_scale`` mapping may name: a fitted PPS band (every camera's image of it) or one image
#: (``<camera>_<band>``, the image ids of prepare_images)
QPB_SCALE_BANDS = ("2000", "3000", "4000", "5000")
QPB_SCALE_CAMERAS = ("MOS1", "MOS2", "PN")


def _qpb_scale_value(v: Any) -> Any:
    """The fit-fix ``qpb_scale`` validated: a positive number (every image), or a mapping band or image -> positive
    number (an image named neither by its id nor by its band keeps its template); a mapping with every factor 1 is 1."""
    what = "a positive number, or a mapping band or <camera>_<band> -> positive number"

    def number(x: Any) -> float:
        try:
            f = float(x)
        except (TypeError, ValueError):
            raise ValueError(f"fitfix qpb_scale = {v!r} ({what})") from None
        if not (math.isfinite(f) and f > 0):
            raise ValueError(f"fitfix qpb_scale = {v!r} ({what})")
        return f

    if isinstance(v, dict):
        out = {}
        for key, x in v.items():
            cam, _, band = str(key).rpartition("_")
            if band not in QPB_SCALE_BANDS or cam not in ("",) + QPB_SCALE_CAMERAS:
                raise ValueError(f"fitfix qpb_scale: {key!r} is neither a band {QPB_SCALE_BANDS} nor an image "
                                 f"<camera>_<band> with a camera of {QPB_SCALE_CAMERAS}")
            out[str(key)] = number(x)
        return dict(sorted(out.items())) if any(x != 1.0 for x in out.values()) else 1.0
    return number(v)

def mock_peak_centre(img_path, ra, dec, pix_arcsec=4.0, theta500_arcsec=None, spec=None):
    """(ra, dec, offset [arcmin], info) of the X-ray peak of a mock view, found as for the real clusters: the peak of
    the merged count image smoothed with 16 arcsec, its listed point sources masked outside the catalogue's error
    circle (:func:`tngxmm.massfit.guess_mass.peak_search_image`), within max(theta500, r90) of the nominal position
    (:func:`~tngxmm.photometry.find_centre.find_peak_centre_guarded`).  The nominal position is the view's catalogue
    position before its error (``SZCENX/SZCENY`` of ``image_merged.fits``, its SZ position by the filter of the
    replicated cluster's catalogue; ``XRCENX/XRCENY`` for an entry of neither SZ catalogue) moved by an error drawn
    from the published positional error of that entry, r90 the entry's 90 per cent radius
    (:func:`tngxmm.photometry.find_centre.mock_nominal`); the angular offset peak - true centre is measured in the
    merged image's WCS and applied to (ra, dec), the true position in the frame of the per-camera files the fit reads
    (:func:`~tngxmm.photometry.find_centre.transfer_offset`).  The fallback for a target without the centre of
    :func:`tngxmm.massfit.guess_mass.centre_and_seed`; ``theta500_arcsec`` its first-guess theta500 (None, fit-fix
    ``mock_centre = 'xray-peak-unguarded'``, a diagnostic: the plain 4 arcmin search), ``spec`` the preset of the
    source-list rule (None: the production preset)."""
    from astropy.io import fits
    from astropy.wcs import WCS

    from tngxmm.config import PRODUCTION_PRESET, get_preset
    from tngxmm.massfit.build_fit_targets import physics_donor
    from tngxmm.massfit.guess_mass import peak_search_image
    from tngxmm.massfit.mask_point_sources import PSF_HEW_ARCSEC, view_source_table
    from tngxmm.photometry.find_centre import (find_peak_centre, find_peak_centre_guarded, mock_nominal,
                                               transfer_offset)

    tab = view_source_table(img_path)
    if tab is None or not (tab.parent / "image_merged.fits").exists():
        raise FileNotFoundError(f"mock_centre = xray-peak: no image_merged.fits next to the view of {img_path}")
    merged = tab.parent / "image_merged.fits"
    with fits.open(merged) as h:
        data, hdr = h[0].data, h[0].header
        w = WCS(hdr)
    from tngxmm.photometry._settings import photometry_settings

    cx, cy = float(hdr["CLUSTX"]), float(hdr["CLUSTY"])
    spec = spec or get_preset(PRODUCTION_PRESET)
    nom, r90 = mock_nominal(hdr, physics_donor(tab.parent), spec=spec)
    search = peak_search_image(merged, data, nom, max(r90, PSF_HEW_ARCSEC), spec=spec, pix_arcsec=pix_arcsec,
                               kind="mock")
    st = photometry_settings(spec)
    if theta500_arcsec is None:
        px, py = find_peak_centre(search, nom, pix_arcsec=pix_arcsec, settings=st)
        info = dict(flag="unguarded")
    else:
        px, py, info = find_peak_centre_guarded(search, nom, max(float(theta500_arcsec), r90), pix_arcsec=pix_arcsec,
                                                settings=st)
    ra_p, dec_p = transfer_offset(w, (cx, cy), (px, py), ra, dec)
    return ra_p, dec_p, math.hypot(px - cx, py - cy) * pix_arcsec / 60.0, info

def apply_mock_centre(job, kind, root, fitfix, spec=None) -> dict:
    """``mock_centre = xray-peak``: move the (ra, dec) of a MOCK job from the known cluster centre to the
    X-ray peak, as the real fits are centred; returns what to record ({} when the switch is off, the target is real,
    or it has no images).  The peak is the target's ``centre_xy`` (pixels of ``image_merged.fits``, found from the
    simulated catalogue position by :func:`tngxmm.massfit.guess_mass.centre_and_seed`, the procedure of the real
    observations) and ``mock_centre_flag`` that search's flag (``unknown`` for a target row without one, which
    :func:`tngxmm.massfit.fit_qc.qc_flags` excludes); a target without it is searched from the view's catalogue position here
    (:func:`mock_peak_centre`, under the preset ``spec``; None: the production preset)."""
    mode = resolve_fitfix(fitfix)["mock_centre"]
    if kind != "mock" or mode == "true":
        return {}
    found = find_images(job["obsid"], root)
    if not found:
        return {}
    if mode == "xray-peak" and job.get("centre_xy") is not None:
        from astropy.io import fits
        from astropy.wcs import WCS

        from tngxmm.massfit.mask_point_sources import view_source_table
        from tngxmm.photometry.find_centre import transfer_offset

        tab = view_source_table(found[0]["img"])
        with fits.open(tab.parent / "image_merged.fits") as h:
            hdr = h[0].header
        cx, cy = float(hdr["CLUSTX"]), float(hdr["CLUSTY"])
        ra_p, dec_p = transfer_offset(WCS(hdr, naxis=2), (cx, cy), job["centre_xy"], job["ra"], job["dec"])
        info = {"mock_centre": mode, "ra_true": job["ra"], "dec_true": job["dec"],
                "mock_centre_flag": job.get("centre_flag") or "unknown",
                "mock_centre_offset_arcmin": round(math.hypot(job["centre_xy"][0] - cx, job["centre_xy"][1] - cy)
                                                   * 4.0 / 60.0, 4)}
        job["ra"], job["dec"] = ra_p, dec_p
        return info
    theta = None
    if mode == "xray-peak":        # guarded: the search radius is the theta500 of the target's first-guess mass
        kpc_per_arcsec, r500_guess = crop_r500_guess(job["z"], job.get("m500_guess"))
        theta = r500_guess / kpc_per_arcsec
    ra_p, dec_p, off, pk = mock_peak_centre(found[0]["img"], job["ra"], job["dec"], theta500_arcsec=theta,
                                            spec=spec)
    info = {"mock_centre": mode, "ra_true": job["ra"], "dec_true": job["dec"],
            "mock_centre_offset_arcmin": round(off, 4), "mock_centre_flag": pk["flag"]}
    if theta is not None:
        info["mock_centre_search_arcsec"] = round(pk["search_arcsec"], 1)
    job["ra"], job["dec"] = ra_p, dec_p
    return info

def stage1_frozen_keys(bg_keys, bg_srcs, fitfix=None, image_ids=None) -> list:
    """Background parameters frozen in optimiser stage 1: all (``frozen``) or, with
    ``bg_stage1 = free-unseeded``, only the sky levels seeded from the data (the r > 2 R500 annulus).

    ``bg_srcs`` has one entry per image, in the order of ``image_ids``; the sky level of image ``i`` is the
    parameter ``bg_<image id>``.  ``bg_keys`` may hold other levels beside the sky levels (the soft-proton levels
    ``sp_*`` of the ESAS background, interleaved with them): those are never seeded from the annulus and stay free.
    Without ``image_ids`` the keys are taken to be the sky levels of the images, one each and in their order.

    Until 2026-11-26 the keys were paired with the sources by position whatever the keys were.  With the 24
    interleaved ``bg_*`` and ``sp_*`` keys of the ESAS background and 12 sources, the levels frozen in stage 1 were
    those at the positions of the annulus-seeded images among the first 12 keys, not the sky levels of those images.
    Stage 2 frees every level, so the model and the posterior were the same; the start of stage 2 was not the
    intended one."""
    ff = resolve_fitfix(fitfix)
    if ff["bg_stage1"] == "frozen":
        return list(bg_keys)
    if image_ids is None:
        if len(bg_keys) != len(bg_srcs):
            raise ValueError(f"{len(bg_keys)} background keys for {len(bg_srcs)} images: give the image ids")
        return [k for k, src in zip(bg_keys, bg_srcs) if src == "annulus"]
    seeded = {f"bg_{i}" for i, src in zip(image_ids, bg_srcs) if src == "annulus"}
    return [k for k in bg_keys if k in seeded]

def parse_fitfix(text, base=None) -> dict[str, Any]:
    """``--fitfix`` text ``key=value,key=value`` (numbers, ``none``, names; ``z_gauss=0.3:0.1``)
    applied to ``base`` (default: :data:`FITFIX_DEFAULTS`)."""
    ff = dict(resolve_fitfix(base))
    for part in [t for t in str(text).split(",") if t.strip()]:
        k, _, v = part.partition("=")
        k, v = k.strip(), v.strip()
        if k not in FITFIX_DEFAULTS:
            raise ValueError(f"unknown fitfix entry {k!r} (known: {sorted(FITFIX_DEFAULTS)})")
        if v.lower() == "none":
            val: Any = None
        elif k == "z_gauss":
            val = tuple(float(x) for x in v.split(":"))
        elif k == "qpb_scale" and ":" in v:
            # per band or image: qpb_scale=2000:1.04/3000:1.04/4000:0.96/5000:0.96 or MOS1_2000:1.08/PN_4000:0.97
            try:
                val = {b.strip(): float(x) for b, x in (p.split(":") for p in v.split("/") if p.strip())}
            except ValueError:
                raise ValueError(f"fitfix qpb_scale={v!r} (key:factor/key:factor)") from None
        elif k in ("pout_fixed", "protect_core_as", "cm_scatter_dex", "qpb_scale", "vignetting_tolerance"):
            val = float(v)
        elif k in ("stage2_maxloops", "shells_per_pixel", "pixel_average"):
            val = int(v)
        else:
            val = v
        ff[k] = val
    return resolve_fitfix(ff)

def resolve_metallicity(metallicity, kind: str):
    """The metallicity of one target: a number, ``"free"``, or the ``kind`` entry
    ('mock'/'obs') of a per-population mapping."""
    if isinstance(metallicity, dict):
        if kind not in metallicity:
            raise ValueError(f"per-population metallicity has no entry for {kind!r}: {metallicity}")
        metallicity = metallicity[kind]
    if isinstance(metallicity, str) and metallicity.strip() == "free":
        return "free"
    try:
        z = float(metallicity)
    except (TypeError, ValueError):
        raise ValueError(f"metallicity must be a number, 'free' or a per-population mapping, "
                         f"got {metallicity!r}") from None
    if not (math.isfinite(z) and z >= 0):
        raise ValueError(f"metallicity must be finite and >= 0, got {metallicity!r}")
    return z

def check_mock_response(header, responses: str = "shared", ccf_selection: str = "highest-issue") -> None:
    """Refuse a mock (header ``MOCK`` = T) made with another response than the fit's: 'per-observation' fits need
    ``RESPSRC`` 'donor' (the photons saw the conditions donor's RMF and ARF), 'shared' fits need no ``RESPSRC`` (the
    packaged responses) and the ``CCFSEL`` of the fit's ``ccf_selection`` (absent for 'highest-issue').  Real
    images pass.  Raises :class:`MockResponseMismatch`."""
    if not bool(header.get("MOCK", False)):
        return
    src = str(header.get("RESPSRC") or "packaged").strip()
    want = "donor" if responses == "per-observation" else "packaged"
    if src != want:
        raise MockResponseMismatch(
            f"mock made with responses {src!r} (RESPSRC) fitted with responses {responses!r}: instrument.responses "
            f"{'donor' if want == 'donor' else 'None'} pairs with massfit.responses {responses!r} (fit-fix "
            "mock_response_check 'off' fits it anyway, as the closure arm v1_obsresp_shared does)")
    if responses == "shared":
        sel = str(header.get("CCFSEL") or "highest-issue").strip()
        if sel != ccf_selection:
            raise MockResponseMismatch(f"mock made with ccf_selection {sel!r} (CCFSEL) fitted with the shared ARFs of "
                                       f"ccf_selection {ccf_selection!r}")

@cites("xmm_ccf_sas", "sas_cifbuild")
def response_for(header, resp=None, pn_arf: str = "all-pattern", responses: str = "shared",
                 obs_resp=None, ccf_selection: str = "highest-issue", mock_check: bool = True) -> tuple[Path, Path]:
    """(rmf, arf) of a per-camera image header.  ``responses`` 'shared': the camera's RMF and the on-axis ARF of its
    filter in the response directory ``resp`` (:func:`resp_dir`); ``pn_arf`` 'pattern' takes the PATTERN<=4 pn ARF
    (``PN_<filter>_pat4.arf``) for every pn image, mock or real; ``ccf_selection`` 'valid-at-date' takes the ARF of
    the image's epoch (DATE-OBS; the ``ccf_<start>/`` sets of :func:`tngxmm.massfit.build_responses.ccf_epoch_dir`).
    'per-observation': the RMF and on-axis ARF of the image's own exposure in the per-observation set ``obs_resp``
    (:mod:`tngxmm.instrument.obs_responses`; the observation is the header's DONORID for a mock, its conditions donor,
    else OBS_ID; the exposure EXPIDSTR); its pn ARF is arfgen's PATTERN<=4 ARF, so ``pn_arf`` must be 'pattern'.
    ``mock_check``: :func:`check_mock_response` first."""
    from tngxmm.massfit.patch_apec import xspec_safe_path

    camera = INSTR[header["INSTRUME"]]
    if ccf_selection not in _FITFIX_CHOICES["ccf_selection"]:
        raise ValueError(f"unknown ccf_selection {ccf_selection!r}; known: {_FITFIX_CHOICES['ccf_selection']}")
    if mock_check:
        check_mock_response(header, responses, ccf_selection)
    if responses == "per-observation":
        from tngxmm.instrument import obs_responses as OR

        if pn_arf != "pattern":
            raise ValueError("responses 'per-observation' need pn_arf 'pattern': the pn ARF of the set is the "
                             "PATTERN<=4 ARF of arfgen")
        rmf, arf = OR.response_pair(obs_resp, OR.header_obsid(header), camera, header.get("EXPIDSTR"))
        if mock_check and bool(header.get("MOCK", False)):
            # the mock's photons saw the donor's responses of one set: the fit must read the same set
            got, want = str(header.get("RESPSET") or "").strip(), OR.set_digest(obs_resp)
            if got != want:
                raise MockResponseMismatch(f"mock made with the response set {got or 'unrecorded'!r} (RESPSET) "
                                           f"fitted with the set {want!r} ({OR.response_root(obs_resp)})")
    elif responses == "shared":
        filt = filter_key(header)
        rd = resp_dir(resp)
        rmf = rd / f"{camera}.rmf"
        ad = rd
        if ccf_selection == "valid-at-date":
            from tngxmm.massfit.build_responses import ccf_epoch

            iv = ccf_epoch(rd, header.get("DATE-OBS"))
            ad = rd / iv["dir"]
            if mock_check and bool(header.get("MOCK", False)):
                # the mock's photons saw the quantum efficiency the stage chose for its donor's date: the same file
                want = (iv.get("files", {}).get(camera) or {}).get("qe")
                got = str(header.get("QEFILE") or "").strip()
                if got != want:
                    raise MockResponseMismatch(f"mock made with the quantum efficiency {got or 'unrecorded'!r} "
                                               f"(QEFILE) fitted with the ARF set {iv['dir']} of {want!r}")
        arf = ad / (f"{camera}_{filt}_pat4.arf" if camera == "PN" and pn_arf == "pattern" else f"{camera}_{filt}.arf")
        if not arf.exists():
            raise FileNotFoundError(f"{arf} missing (run build_responses)")
    else:
        raise ValueError(f"unknown responses {responses!r}; known: {_FITFIX_CHOICES['responses']}")
    xspec_safe_path(rmf, "RMF"); xspec_safe_path(arf, "ARF")      # both reach XSPEC's fakeit command
    return rmf, arf

def response_record(images, obs_resp=None) -> dict:
    """The per-observation responses of a fit, for its provenance: the set (root and manifest digest) and image ->
    [rmf, arf] file names.  The set is checked (:func:`tngxmm.instrument.obs_responses.check_set`): a set without a

    from tngxmm.instrument import obs_responses as OR

    root = OR.response_root(obs_resp)
    digest = OR.check_set(obs_resp)
    return dict(mode="per-observation", set=str(root), manifest_digest=digest,
                files={im.img_id: [Path(str(im.rmf)).name, Path(str(im.arf)).name] for im in images})

def apply_pn_band_gap(cluster, images, nh_1022: float, z: float) -> list[str]:
    """Give the pn 4.5-12 keV image of ``cluster`` (mbproj2d ClusterHydro) the count rate without 7.8-8.2 keV
    (``massfit.pn_hard_band = 'pps'``, the selection of the PPS pn images); returns the image ids changed."""
    from mbproj2d.ratecalc import ApecRateCalc

    done = []
    for img in images:
        if img.img_id != PN_GAP_IMAGE or img not in cluster.image_RateCalc:
            continue
        gap = ApecRateCalc(img.rmf, img.arf, PN_BAND_GAP_KEV[0], PN_BAND_GAP_KEV[1], nh_1022, z)
        cluster.image_RateCalc[img] = GapRateCalc(cluster.image_RateCalc[img], gap)
        done.append(img.img_id)
    return done




#: per process: image root -> (modification times it was listed at, its band images)
_IMAGE_INDEX: dict[str, tuple[tuple, dict]] = {}


def _image_index(root: str, refresh: bool = False) -> dict:
    """Band images under ``root`` (``<root>/*/*/P*IMAGE_*.FTZ``) as {file name: [paths]}, listed once a process.

    :func:`find_images` used to glob the tree for every band of every call.  Under a campaign's image root that is
    a listing of each view's directory, and a fit asks several times: with 5,001 views and the workers of two nodes
    at it together the file system answered in minutes, not seconds.  The listing is kept for as long as the root
    and its first-level directories keep their modification times, so a new view directory is seen; images added to
    a directory already listed are seen when the observation asked for has none (``refresh``)."""
    try:
        stamp = tuple(sorted((e.name, e.stat().st_mtime_ns) for e in os.scandir(root)
                             if e.is_dir() and not e.name.startswith(".")))
        stamp = (os.stat(root).st_mtime_ns, stamp)
    except OSError:
        return {}
    kept = _IMAGE_INDEX.get(root)
    if kept is not None and kept[0] == stamp and not refresh:
        return kept[1]
    index: dict[str, list[Path]] = {}
    for family, _ in stamp[1]:
        for view in os.scandir(os.path.join(root, family)):
            if not view.is_dir() or view.name.startswith("."):
                continue
            for f in os.scandir(view.path):
                n = f.name
                if n.startswith("P") and n.endswith(".FTZ") and "IMAGE_" in n:
                    index.setdefault(n, []).append(Path(f.path))
    _IMAGE_INDEX[root] = (stamp, index)
    return index

def find_images(obsid: str, img_root=None) -> list[dict]:
    """Every per-camera band image on disk for this obsid, with its exposure map."""
    from astropy.io import fits

    root = Path(img_root) if img_root is not None else image_root()
    index = _image_index(str(root))
    if not any(fnmatch.fnmatchcase(n, f"P{obsid}*") for n in index):
        index = _image_index(str(root), refresh=True)      # images written since the tree was listed
    out = []
    for band, (elo, ehi) in BANDS_EV.items():
        for img in sorted(q for n in fnmatch.filter(index, f"P{obsid}*IMAGE_{band}.FTZ") for q in index[n]):
            expmap = img.parent / img.name.replace(f"IMAGE_{band}", f"EXPMAP{band}")
            if not expmap.exists():
                print(f"  ! no expmap for {img.name}; skipping")
                continue
            hdr = fits.getheader(img)
            out.append(dict(img=img, expmap=expmap, band=band,
                            emin_keV=elo / 1000, emax_keV=ehi / 1000,
                            camera=INSTR[hdr["INSTRUME"]],
                            filter=filter_key(hdr),
                            header=hdr))
    return out

def _build_model(pars, images, z, nh_1022, bg_inits=None, free_centre=False,
                 m500_guess_1e14=6.35, c200_fixed=None, maxradius_kpc=3000.0,
                 bg_srcs=None, fallback_prior_dex=0.3, mb=None, metallicity=0.3,
                 metallicity_prior=METALLICITY_FREE_PRIOR, fitfix=None):
    """mbproj2d TotalModel (hydrostatic cluster + per-image VigNoVig backgrounds).

    ``metallicity``: a number (fixed Z in solar units of the abundance table,
    0.3 by default) or ``"free"`` (one extra parameter ``Z``, start 0.3, flat prior
    ``metallicity_prior``).  Returns (totmod, cluster, bg_keys); see the module
    docstring for the choices.  ``fitfix``: :data:`FITFIX_DEFAULTS` entries (None = the defaults):
    the frozen outer pressure, the c200 and Z priors and the zero background of a clean closure cell act
    here."""
    from tngxmm.massfit import guess_mass

    ff = resolve_fitfix(fitfix)

    if mb is None:
        mb = import_mbproj2d()
    cosmo = mb.Cosmology(z, H0=H0, WM=OM, WV=1 - OM)

    if metallicity == "free":
        Z_prof = mb.ProfileFlat("Z", pars, defval=METALLICITY_FREE_START)
        pars["Z"].frozen = False
        pars["Z"].prior = mb.PriorFlat(float(metallicity_prior[0]), float(metallicity_prior[1]))
        if ff["z_prior"] == "gaussian":
            # outskirts metallicity ~ 0.3 Z_sun with a small scatter (Mernier et al. 2017), truncated
            # to the flat prior's range
            pars["Z"].prior = mb.PriorBoundedGaussian(float(ff["z_gauss"][0]), float(ff["z_gauss"][1]),
                                                      float(metallicity_prior[0]), float(metallicity_prior[1]))
    else:
        Z_prof = mb.ProfileFlat("Z", pars, defval=float(metallicity))
        pars["Z"].frozen = True                # metallicity poorly constrained by imaging

    # mode='single' (NOT 'betacore', which deletes the outer steepening term):
    # n_e at large r is the denominator of T = P/(X n_e), so over-predicting it
    # at R500 propagates 1:1 into T and M500 (Vikhlinin+06; Sanders+2018 eqn 14).
    ne_prof = mb.ProfileVikhDensity("ne", pars, mode="single")
    # flat priors as Sanders+2018 (the package defaults are informative)
    for key, lo, hi in (("ne_beta_1", 0.0, 4.0),
                        ("ne_logrc_1", math.log(0.1), math.log(5000.0)),
                        ("ne_alpha", 0.0, 4.0),
                        ("ne_epsilon", 0.0, 5.0),
                        ("ne_logr_s", math.log(10.0), math.log(5000.0))):
        if key in pars:
            pars[key].prior = mb.PriorFlat(lo, hi)
    pars["ne_logrc_1"].val = math.log(100.0)

    mass_prof = mb.ProfileMassNFWfnM("mass", cosmo, pars, overdensity=500)

    if ff.get("vignetting", "expmap") == "sub-band":
        # the vignetting at the energies of the photons, before the PSF (band_response; the pn PI gap is in the
        # band's channel set)
        from tngxmm.massfit.band_response import subband_cluster
        from tngxmm.massfit.prepare_images import ccf_dir

        gaps = {PN_GAP_IMAGE: PN_BAND_GAP_KEV} if ff.get("pn_hard_band", "contiguous") == "pps" else {}
        cluster = subband_cluster(mb, "cl", pars, images, cosmo=cosmo, nh_1022=nh_1022, ne_prof=ne_prof,
                                  mass_prof=mass_prof, Z_prof=Z_prof, maxradius_kpc=maxradius_kpc,
                                  ccf_dir=ccf_dir(), tolerance=float(ff["vignetting_tolerance"]),
                                  rule=ff.get("band_channels", "xspec-energy"), gap_images=gaps)
    else:
        cluster = mb.ClusterHydro(
            "cl", pars, images, cosmo=cosmo, NH_1022pcm2=nh_1022,
            ne_prof=ne_prof, mass_prof=mass_prof, Z_prof=Z_prof,
            # bound the model to the measured region (an outer shell beyond the data
            # enters the projection of every annulus)
            maxradius_kpc=maxradius_kpc,
        )
        if ff.get("pn_hard_band", "contiguous") == "pps":
            apply_pn_band_gap(cluster, images, nh_1022, z)
    # model shells finer than the fit pixel (massfit.model_shells_per_pixel; 1 = mbproj2d's one-pixel shells)
    from tngxmm.massfit.model_shells import refine_shells

    refine_shells(cluster, ff["shells_per_pixel"], mb, ff["pixel_average"])
    if ff["projection"] != "groups":
        cluster.projection = ff["projection"]
    if ff["pout_fixed"] is not None:
        # the model is bounded at maxradius_kpc, where the true pressure is ~0 (the floor of the
        # parameter is -37); a free P_out ran away to -26 at z = 0.06 and absorbed the background
        pars["cl_Pout_logergpcm3"].val = float(ff["pout_fixed"])
        pars["cl_Pout_logergpcm3"].frozen = True

    # start M500 near the first guess so the gradient-free optimiser starts in
    # the right basin (from M = 1e14, c = 4 it finds a worse local optimum)
    pars["mass_M_logMsun"].val = math.log(max(m500_guess_1e14, 0.5) * 1e14)
    # c200 (mbproj2d logconc) is FIT and marginalised with the flat log prior of
    # Sanders+2018 (c = 1-10); the Dutton & Maccio (2014) median at the first guess is the start.
    c200 = c200_fixed if c200_fixed is not None else guess_mass.c200_guess(m500_guess_1e14, z)
    import numpy as np

    pars["mass_logconc"].val = math.log(float(np.clip(c200, 1.5, 10.0)))
    c_lo, c_hi = c200_prior_range(ff)
    pars["mass_logconc"].prior = mb.PriorFlat(math.log(c_lo), math.log(c_hi))
    if ff["cm_prior"] == "dutton14":
        # log-normal about the Dutton & Maccio (2014) c200(M200, z) relation (0.11 dex scatter) at the M200 of the
        # sampled halo: a term of the mass profile's prior, which the cluster model adds at every evaluation.  The
        # parameter itself keeps a flat prior over the wide range, which cuts nothing of the log-normal
        from tngxmm.massfit.cm_prior import ConcentrationMassPrior

        mass_prof.prior = ConcentrationMassPrior(z, float(ff["cm_scatter_dex"]), name=mass_prof.name)
    pars["mass_logconc"].frozen = False
    for ax in ("cx", "cy"):
        p = pars[f"cl_{ax}"]
        p.val = 0.0
        p.frozen = not free_centre
        if free_centre:
            p.minval, p.maxval = -60.0, 60.0   # arcsec

    # vignetted (sky + CXB) and unvignetted (particle) background components per
    # image, with a fitted vignetted fraction (BackModelFlat gave the hard-band
    # particle background the wrong radial shape)
    if ff.get("qpb_model", "mixture") == "esas-fwc-corners":
        return source_exposure(build_esas_background(pars, images, cluster, bg_inits, bg_srcs, mb, ff), ff)
    back = mb.BackModelVigNoVig("bg", pars, images, defval=-15,
                                expmap="expmap", expmap_novig="expmap_novig")
    # each normalisation seeded from its outer annulus, Gaussian prior; frozen
    # during the first optimiser stage only
    bg_keys = []
    if bg_inits is not None:
        srcs = bg_srcs if bg_srcs is not None else ["annulus"] * len(images)
        for image, b, src in zip(images, bg_inits, srcs):
            key = "bg_%s" % image.img_id
            pars[key].val = float(b)
            # 0.05 dex only for a clean annulus beyond 2 R500; otherwise widened
            sig = (BG_PRIOR_DEX if src == "annulus" else fallback_prior_dex) * math.log(10)
            vf0 = getattr(image, "bg_vf_init", None)
            if vf0 is not None and ff.get("annulus_seed") == "split":
                pars[key + "_vf"].val = float(vf0)
                # fitfix bg_vf = seed: the split between vignetted and flat background stays the seed's
                pars[key + "_vf"].frozen = ff.get("bg_vf", "free") == "seed"
            pars[key].prior = mb.PriorGaussian(float(b), sig)
            if ff["bg_fixed"] == "truth" and hasattr(image, "bg_truth"):
                # closure diagnostic: the background frozen at its truth (attach_background_truth)
                lv, vf = image.bg_truth
                pars[key].val, pars[key + "_vf"].val = float(lv), float(vf)
                pars[key].frozen = pars[key + "_vf"].frozen = True
                continue
            if ff["bg_fixed"] == "zero":
                # clean mock cell: no sky and no particle background in the data
                pars[key].val = -30.0                  # the parameter's floor: exp(-30) counts
                pars[key].frozen = True
                pars[key + "_vf"].frozen = True
                continue
            bg_keys.append(key)

    back_models = [back]
    if any(getattr(im, "oot_template", None) is not None for im in images):
        # pn out-of-time events: a fixed template per pn image (prepare_images pn_oot)
        from tngxmm.massfit.pn_oot import FixedTemplateBackModel

        back_models.append(FixedTemplateBackModel("oot", images))
    totmod = mb.TotalModel(pars, images, src_expmap="expmap",
                           src_models=[cluster], back_models=back_models)
    return source_exposure((totmod, cluster, bg_keys), ff)

def image_tree_digest(specs: list[dict]) -> str:

    h = hashlib.sha256()
    names = sorted({(Path(s[k]).name, str(s[k])) for s in specs for k in ("img", "expmap")})

def resume_matches(prev: dict, fit_dir: Path, job: dict) -> bool:
    """True when the finished fit ``prev`` (its result.json; ``fit_dir`` holds its provenance.json) is the fit ``job``
    would make: a fit that ran to its end (:func:`fit_ran_to_its_end`: status ok, or unconstrained, which another run
    of the same fit would give again), the same fit redshift ``z`` and ``z_obs`` (a mock's catalogue redshift and its photons'),
    and the same images, by the ``image_tree_sha256`` of its provenance against the job's images now.  A fit of views
    since regenerated, or at another catalogue redshift, is made again, and so is one whose chain or mass-profile
    file is cut (:func:`fit_files_complete`).  ``provenance.json`` is the done-marker of a fit: :func:`run_one`
    removes it before the chain is started and writes it last."""
    if not fit_ran_to_its_end(prev.get("status")):
        return False
    if not fit_files_complete(fit_dir):
        return False
    if not math.isclose(float(prev.get("z", float("nan"))), float(job["z"]), rel_tol=0.0, abs_tol=1e-9):
        return False
    a, b = prev.get("z_obs"), job.get("z_obs")
    if (a is None) != (b is None) or (a is not None and not math.isclose(float(a), float(b), abs_tol=1e-9)):
        return False
    pj = Path(fit_dir) / "provenance.json"
    if not pj.exists():
        return False
    try:
        rec = json.loads(pj.read_text()).get("image_tree_sha256")
    except Exception:  # noqa: BLE001 - an unreadable record is not a match
        return False
    specs = find_images(job["obsid"], job["img_root"])
    return bool(specs) and rec == image_tree_digest(specs)

@cites("cosmology_planck2015", "astropy")
def crop_r500_guess(z, m500_guess=None, published=None) -> tuple[float, float]:
    """(kpc per arcsec, R500 guess [kpc]) from the first-guess mass (crop size only)."""
    cosmo = flat_lcdm(H0, OM)
    kpc_per_arcsec = cosmo.kpc_proper_per_arcmin(z).value / 60.0
    # the published mass never seeds the fit (reference only): Lx guess, else the default
    m_guess = (m500_guess or 6.35) * 1e14         # no seed: the pivot of the L-M relation (guess_mass)
    rho_c = cosmo.critical_density(z).to("Msun/kpc^3").value
    r500_guess = (3 * m_guess / (4 * math.pi * 500 * rho_c)) ** (1 / 3)
    return kpc_per_arcsec, r500_guess

def net_counts_r500(images, r500_guess_kpc, kpc_per_arcsec) -> dict[str, float]:
    """Signal of a fit: net source counts within the first-guess R500 of the prepared fit images.

    Summed over every image (camera and band): the counts inside R500 of the centre minus the background
    expected there, the exposed-pixel count rate of the ring r > 2 R500 (the outer 40 per cent of the
    exposed field when that ring has fewer than 50 pixels, as the background seed) scaled by the
    exposure inside; the pn out-of-time template is removed from both.  Point-source masks and gaps
    are exposure zero and drop out (a diagnostic of the signal; no fit setting depends on it).  Returns ``net``,
    ``inner`` (all counts inside) and ``snr`` = net / sqrt(inner)."""
    import numpy as np

    r500_as = r500_guess_kpc / kpc_per_arcsec
    net = inner = 0.0
    for im in images:
        cts = np.asarray(im.imagearr, float)
        oot = getattr(im, "oot_template", None)
        if oot is not None:
            cts = cts - np.asarray(oot, float)
        exp = np.asarray(im.expmaps["expmap"], float)
        oy, ox = im.origin
        yy, xx = np.mgrid[0:cts.shape[0], 0:cts.shape[1]]
        r = np.hypot(xx - ox, yy - oy) * im.pixsize_as
        ok = exp > 0
        ins = ok & (r < r500_as)
        ring = ok & (r > 2.0 * r500_as)
        if ring.sum() < 50 and ok.any():
            ring = ok & (r > 0.6 * r[ok].max())
        rate = cts[ring].sum() / exp[ring].sum() if ring.sum() >= 10 and exp[ring].sum() > 0 else 0.0
        inner += cts[ins].sum()
        net += cts[ins].sum() - rate * exp[ins].sum()
    return dict(net=float(net), inner=float(inner), snr=float(net / math.sqrt(inner)) if inner > 0 else 0.0)

def effective_pixsize(target_pixsize_as, r500_guess_kpc, kpc_per_arcsec, pixels_per_r500=None) -> float:
    """Target fit pixel [arcsec]: ``target_pixsize_as``, coarsened for large clusters so that
    R500 (of the first-guess mass) spans about ``pixels_per_r500`` pixels (None: no rule).

    The one rule of the fit pixel, both from the preset: ``massfit.target_pixsize_arcsec``
    (8") and ``massfit.fit_pixels_per_r500`` (40; None switches the rule off), i.e.
    max(8", R500_guess / 40): 8" down to z ~ 0.1, coarser only below.  The native
    image pixel is then rebinned by the integer factor closest to this target
    (``prepare_images.preprocess_one``), so the fitted pixel is a multiple of 4".

    Why: at z ~ 0.06 an 8" pixel samples R500 with ~80 pixels per radius over a 43' frame,
    which makes the fit (model and PSF convolution of 12 images per likelihood call) several
    times slower than needed; R500/40 is still finer in kpc than 8" at z = 0.5."""
    if not pixels_per_r500:
        return float(target_pixsize_as)
    return max(float(target_pixsize_as), r500_guess_kpc / kpc_per_arcsec / float(pixels_per_r500))

@cites("esas_mosback", "esas_pnback", "esas_proton", "ghirardini2019")
def build_esas_background(pars, images, cluster, bg_inits, bg_srcs, mb, ff):
    """(totmod, cluster, bg_keys) with the background of XMM-ESAS / X-COP (``massfit.qpb_model = 'esas-fwc-corners'``,
    :mod:`tngxmm.massfit.esas_background`): the QPB a fixed template per image (its level set by the observation's
    corners), the sky vignetted with a free level (``bg_<image>``), the residual soft protons the ESAS detector map with
    a free level (``sp_<image>``), the pn out-of-time events their fixed template.  The sky level starts at half the
    mean level of the unmasked crop with the particle and out-of-time counts of the model removed (ln -20 when nothing
    is left); the soft protons at 5 per cent of it.  No prior on either level (X-COP leaves them free).  ``bg_inits``,
    the starts the other background models take from the outer region, is not used.

    Fit-fix ``qpb_level = 'free'`` (closure arm v1_qpbfree) gives each image's template a free factor (``qpbl_<image>``,
    start 1); fit-fix ``qpb_scale`` fixes the template at a multiple of the corner level, one factor for every image
    or one per band or image (closure arms v1_qpbhi, v1_qpblo, v1_qpbsoft, v1_qpbhard).  The sky start removes the
    template the fit uses: the scaled one, or the free one at its start."""
    import numpy as np

    from tngxmm.massfit import esas_background as EB
    from tngxmm.massfit.pn_oot import FixedTemplateBackModel

    clean = ff.get("bg_fixed") == "zero"
    if clean:
        # clean mock cell (closure grid): no sky, no particle background in the data; the QPB template is zero and
        # the sky and soft-proton levels sit at their floor, frozen, as the mixture model does
        for im in images:
            im.qpb_template = np.zeros(im.shape, dtype=np.float32)
    missing = [im.img_id for im in images if getattr(im, "qpb_template", None) is None]
    if missing:
        raise ValueError(f"qpb_model esas-fwc-corners: no particle-background template for {missing}")
    free_level = ff.get("qpb_level", "fixed") == "free" and not clean
    scales = {im.img_id: (1.0 if (free_level or clean) else qpb_scale_of(ff, im.img_id)) for im in images}
    qpb_attr = "qpb_template"
    if any(s != 1.0 for s in scales.values()):
        # a level-error study arm: the fixed template wrong by a known factor, one for every image or one per band or
        # image (a copy; the template stays)
        for im in images:
            im.qpb_template_scaled = (im.qpb_template * scales[im.img_id]).astype(im.qpb_template.dtype)
        qpb_attr = "qpb_template_scaled"
    sky = EB.SkyBackModel("bg", pars, images)
    tied = ff.get("sp_bands", "free") == "tied"
    if tied:
        # one soft-proton level per camera, the band ratios of the spectrum the mocks draw (massfit.sp_band_tie)
        gaps = {PN_GAP_IMAGE: PN_BAND_GAP_KEV} if ff.get("pn_hard_band", "contiguous") == "pps" else {}
        sp = EB.TiedTemplateBackModel("sp", pars, images, attr="sp_template", gaps=gaps)
    else:
        sp = EB.ScaledTemplateBackModel("sp", pars, images, attr="sp_template")
    bg_keys = []
    if clean:
        for k in [k for k in pars if k.startswith(("bg_", "sp_"))]:
            pars[k].val, pars[k].frozen = EB.LOG_FLOOR, True
        images_to_seed = []
    else:
        images_to_seed = images
    for image, b in zip(images_to_seed, bg_inits if bg_inits is not None else [None] * len(images_to_seed)):
        key = "bg_%s" % image.img_id
        e, m = image.expmaps["expmap"], image.mask != 0
        # the particle counts the model starts with: the template as the fit uses it (scaled by qpb_scale)
        resid = image.imagearr[m].sum() - getattr(image, qpb_attr)[m].sum() - (
            getattr(image, "oot_template", None)[m].sum() if getattr(image, "oot_template", None) is not None else 0.0)
        lvl = resid / max(float((e[m]).sum()) * image.pixsize_as ** 2, 1e-30)
        # the whole crop holds the cluster too: the start is an upper bound of the sky, not a prior
        pars[key].val = math.log(max(0.5 * lvl, 1e-12)) if lvl > 0 else -20.0
        bg_keys.append(key)
        if tied and image.img_id in sp.factor and sp.key(image) not in bg_keys:
            # the camera's level from its first image: 5 per cent of that image's sky start, in the band's share
            pars[sp.key(image)].val = pars[key].val + math.log(0.05) - math.log(sp.factor[image.img_id])
            bg_keys.append(sp.key(image))
        elif not tied and f"sp_{image.img_id}" in pars:
            pars[f"sp_{image.img_id}"].val = pars[key].val + math.log(0.05)
            bg_keys.append(f"sp_{image.img_id}")
    if free_level:
        # the closure arm v1_qpbfree: the template's shape with a free level per image (no knowledge of the level)
        qpb = EB.ScaledCountsTemplateBackModel("qpbl", pars, images, attr="qpb_template")
        bg_keys += [f"qpbl_{im.img_id}" for im in images]
    else:
        qpb = FixedTemplateBackModel("qpb", images, attr=qpb_attr)
    back_models = [sky, sp, qpb]
    if any(getattr(im, "oot_template", None) is not None for im in images):
        back_models.append(FixedTemplateBackModel("oot", images))
    totmod = mb.TotalModel(pars, images, src_expmap="expmap", src_models=[cluster], back_models=back_models)
    return totmod, cluster, bg_keys

def attach_background_truth(images, specs, obsid, ra, dec, r500_guess, kpc_per_arcsec, **kw) -> None:
    """Closure diagnostic (fitfix ``bg_fixed = 'truth'``): each image gets ``bg_truth`` = (ln SB, vf logit) of the
    model's background (mbproj2d ``BackModelVigNoVig``: counts = e^p pix^2 (f E + (1 - f) rho F), rho =
    median(E / F) over the image's mask) fitted by Poisson maximum likelihood to the background-truth view of the cell,
    cut and rebinned like the image.  The truth view's tree: ``$TNGXMM_BG_TRUTH_IMG_ROOT`` (a closure generation
    arm with the cluster removed, ``closure_grid`` arm ``v1_bgcell``)."""

def cm_prior_offset_sd(chain, keys, z, sigma_dex) -> float | None:
    """Median over the chain samples of (ln c200 - ln c(M200, z)) / sigma, c(M200, z) the Dutton & Maccio (2014)
    relation at each sample's own NFW M200 and sigma = ``sigma_dex`` ln 10: how far the posterior sits from the
    centre of the concentration-mass prior.  A reported number; nothing is cut on it.  None when the chain has no
    free concentration or mass."""
    import numpy as np

    from tngxmm.massfit import cm_prior
    from tngxmm.massfit.guess_mass import m500_over_m200_nfw

    keys = list(keys)
    if "mass_logconc" not in keys or "mass_M_logMsun" not in keys:
        return None
    ch = np.asarray(chain, float)
    lc, lm = ch[:, keys.index("mass_logconc")], ch[:, keys.index("mass_M_logMsun")]
    s = float(sigma_dex) * math.log(10.0)
    d = [(c - math.log(cm_prior.c200c_dutton14(math.exp(m) / m500_over_m200_nfw(math.exp(c)), z))) / s
         for c, m in zip(lc, lm)]
    return round(float(np.median(d)), 3) if d else None

@cites("willingale2013")
def fit_column(nh_1022, specs, obsid, mode="hi4pi", table=None):
    """(N_H of the fit model [1e22 cm^-2], record) for fitfix ``galactic_nh``.

    ``hi4pi``: ``nh_1022`` unchanged.  ``willingale13``: ``nh_1022`` times N_H,tot / N_HI of the field
    (:func:`tngxmm.instrument.galactic_column.donor_ratio`, table ``nh_total``), the field named by the
    image header DONORID (a mock: its donor) or OBS_ID, else ``obsid``.  A mock absorbed with
    instrument.galactic_nh = 'willingale13' then has exactly the column of its generation (view column x
    donor ratio).  Raises KeyError when the field is not in the table."""
    if mode == "hi4pi":
        return float(nh_1022), {}
    if mode != "willingale13":
        raise ValueError(f"galactic_nh {mode!r} (hi4pi | willingale13)")
    from tngxmm.instrument import donor_tables as DT
    from tngxmm.instrument.galactic_column import donor_ratio

    hdr = next((s.get("header") for s in specs or () if s.get("header") is not None), None)
    field = (hdr.get("DONORID") or hdr.get("OBS_ID")) if hdr is not None else None
    field = str(field or obsid).strip()
    ratio = donor_ratio(table if table is not None else DT.read_table("nh_total"), field)
    return float(nh_1022) * ratio, dict(nh_hi_1022=float(nh_1022), nh_total_ratio=ratio, nh_field=field)

def run_one(name, obsid, z, nh_1022, ra, dec, published=None, m500_guess=None,
            c200_fixed=None, quick=False, free_centre=False, nprocesses=8,

            metallicity_prior=METALLICITY_FREE_PRIOR, abund_table="lodd",

    error of a photometric catalogue redshift and the entry's redshift type,
    :func:`tngxmm.photometry.catalogue_positions.mock_redshift`) are recorded in result.json when given; the truth
    tables compare a mock's fit with its truth at ``z_obs``.

    ``reference`` (:func:`reference_from_row`) and ``published`` are RECORDED only:
    they never seed the crop, the model radius or the first-guess mass (``m500_guess``, else the pivot of the
    L-M relation).  result.json gets ``reference_mass_1e14``, ``reference_quantity``,
    ``reference_radius_kpc``, ``reference_source``; ``published_m500_1e14`` and
    ``ratio_fit_over_pub`` are written only when the reference IS an M500c (like for like).

    The keyword-only arguments are the roots and the fit switches; their defaults
    are the plain fit (:func:`fit_switches_from_spec` gives a preset's values).  ``metallicity``: number, ``"free"`` or
    {"mock": Z, "obs": Z}; ``abund_table``: XSPEC abundance table of the rate
    tables (``patch_apec.apply_abundance_table``); ``mu_convention`` /
    ``mu_composition``: ``set_molecular_weight.apply_mu_convention``; ``psf``: ``None``
    (no PSF in the model), ``"king-onaxis"`` or ``"king-angle"`` (``fit_psf``); ``pn_oot``: ``None``
    (no out-of-time events) or ``"data-template"`` (pn out-of-time template, ``pn_oot``);
    ``pn_oot_energy``: ``"ccf-cti"`` moves the template's counts between the bands with the CTI
    correction of the assigned row (:mod:`tngxmm.instrument.pn_oot_energy`), None or ``"none"`` keeps them;
    ``xspec_tmpdir``: :func:`xspec_scratch_dir`; ``masking_info``: what
    ``sources`` is (recorded in result.json and provenance.json).

    ``fitfix``: the fit-fix sub-switches (:data:`FITFIX_DEFAULTS`; None = the defaults): background seed rule, frozen outer pressure, optimiser stages, chain
    burn, core protection of the point-source mask, c200 and Z priors."""
    import numpy as np

    check_catalogue_redshift(name, z_obs, z_offset, z_type)
    ff = resolve_fitfix(fitfix)
    if seed is not None:
        # the ONLY entry of randomness: numpy's global stream
        np.random.seed(int(seed))
    mb = import_mbproj2d()
    # XSPEC's scratch spectrum (rate-cache miss) under the run's scratch, never /tmp
    xspec_dir = set_xspec_scratch(xspec_tmpdir, workdir)
    # the fit switches, set (or reset to the package values) before any model is built
    zfit, mu_consts = apply_fit_switches(name, metallicity, abund_table, mu_convention, mu_composition)
    t0 = time.time()
    root = Path(img_root) if img_root is not None else image_root()
    specs = find_images(obsid, root)
    if not specs:
        return dict(name=name, obsid=obsid, status="no images")

    nh_1022, nh_rec = fit_column(nh_1022, specs, obsid, ff["galactic_nh"])

    print(f"{name}: {len(specs)} images "
          f'({sorted({s["camera"] for s in specs})} x {sorted(set(BANDS_EV))}), '
          f"z={z}, NH={nh_1022:.3f}e22, R500guess={r500_guess:.0f}kpc")

    outdir = fits_root(workdir) / outdir_name(name, tag)
    outdir.mkdir(parents=True, exist_ok=True)
    chainfname = str(outdir / "chain.hdf5")

    image_info: list = []
    images, bg_inits, bg_srcs = build_fit_images(
        specs, ra, dec, r500_guess, kpc_per_arcsec, resp=resp, crop_r500=crop_r500,
        target_pixsize_as=target_pixsize_as, crop_cap_arcmin=crop_cap_arcmin, sources=sources,
        optical_axis=optical_axis, rebin_centre=rebin_centre, mb=mb, psf=psf, pn_oot=pn_oot,
        info=image_info, pixels_per_r500=pixels_per_r500, pn_oot_energy=pn_oot_energy, fitfix=ff,
        psf_kt_keV=guess_kt_keV(z, m500_guess))
    if not images:
        return dict(name=name, obsid=obsid, status="no usable images after crop")
    if ff["bg_fixed"] == "truth":
        attach_background_truth(images, specs, obsid, ra, dec, r500_guess, kpc_per_arcsec, resp=resp,
                                crop_r500=crop_r500, target_pixsize_as=target_pixsize_as,
                                crop_cap_arcmin=crop_cap_arcmin, optical_axis=optical_axis,
                                rebin_centre=rebin_centre, mb=mb, pixels_per_r500=pixels_per_r500,
                                pn_oot_energy=pn_oot_energy, fitfix=ff, psf=psf, pn_oot=pn_oot, sources=sources,
                                psf_kt_keV=guess_kt_keV(z, m500_guess))
    print(f"  cropped/rebinned: {images[0].shape} px @ {images[0].pixsize_as:.1f}\"/px "
          f"({images[0].shape[0]*images[0].shape[1]} px/img)")
    prior_rec: dict = {}
    pars = mb.Pars()
    rmax_model, totmod, cluster, bg_keys = build_fit_model(
        pars, images, bg_inits, bg_srcs, z=z, nh_1022=nh_1022, r500_guess=r500_guess,
        crop_r500=crop_r500, free_centre=free_centre, m500_guess=m500_guess, published=published,
        c200_fixed=c200_fixed, fallback_bg_prior_dex=fallback_bg_prior_dex, mb=mb,
        zfit=zfit, metallicity_prior=metallicity_prior, fitfix=ff)
    print(f'  background seeds: {",".join(bg_srcs)}')
    print(f'  c200 start = {math.exp(pars["mass_logconc"].v):.2f} '
          f'(fit, {"flat prior 1-10" if ff["cm_prior"] == "flat" else "prior " + ff["cm_prior"] + " at the sampled M200"})'
          f"  rmax_model = {rmax_model:.0f} kpc")
    print(f"  fitfix: { {k: v for k, v in ff.items() if v != _FITFIX_RECORD_BASE[k]} }")

    fit = mb.Fit(images, totmod, pars)
    stage1_frozen = stage1_frozen_keys(bg_keys, bg_srcs, ff, image_ids=[im.img_id for im in images])
    image_psfs = [im.psf for im in images]
    psf_objs = list(image_psfs)
    if ff["psf_eval"] == "window" and psf is not None:
        # fitfix psf_eval = window: the optimiser's second stage and the sampler convolve on the mask's bounding box
        # (psf_window); an image whose mask comes too close to the grid's edge keeps its PSF
        from tngxmm.massfit import psf_window

        psf_objs = [psf_window.windowed(im) or im.psf for im in images]
        for im, p in zip(images, psf_objs):
            im.psf = p
        print(f"  psf_eval window: {sum(p is not q for p, q in zip(psf_objs, image_psfs))} of {len(images)} images",
              flush=True)

    # fitfix like_cache = image: the optimiser's evaluations keep what an unchanged image needs (like_cache; the value
    # of every evaluation is mbproj2d's).  The sampler below gets the fit with mbproj2d's own evaluation back
    from tngxmm.massfit import like_cache

    cache = like_cache.attach(fit) if ff["like_cache"] == "image" else None

    # nlopt's BOBYQA can return a point one unit in the last place outside a bound, which the next call refuses
    # (optimiser_bounds): every call starts inside its bounds, and the optimum is put inside the priors' bounds
    from tngxmm.massfit.optimiser_bounds import clip_free_parameters, clipped_starts

    optimiser_rec: dict = {}

    def optimise():
        # Stage 1: backgrounds frozen at their data seeds, optimise the ~7 source
        # parameters (nlopt is fast in 7-d, crawls in 16-d)
        # fitfix bg_stage1 = free-unseeded: only the backgrounds seeded from the data (annulus) stay frozen
        for k in stage1_frozen:
            pars[k].frozen = True
        # with the PSF in the model, stage 1 runs without it: each evaluation is ~2x cheaper
        # and the PSF-free optimum is a close start for stage 2, which has the PSF (the result
        # is the optimum of the full model; this only saves optimiser time)
        if psf is not None:
            for im in images:
                im.psf = None
        with clipped_starts(optimiser_rec):
            fit.run(verbose=False, maxloops=4)
        for im, p in zip(images, psf_objs):
            im.psf = p
        # Stage 2: release backgrounds (Gaussian priors) and refine
        for k in bg_keys:
            pars[k].frozen = False
        with clipped_starts(optimiser_rec):
            fit.run(verbose=False, maxloops=ff["stage2_maxloops"])
        clip_free_parameters(pars, optimiser_rec)
        # mbproj2d's Likelihood.total is prior + image likelihoods already (fit.py), so this is the log posterior
        return float(fit.like().total)

    # fitfix starts = grid: the same two stages from every start of OPTIMISER_START_GRID (each from the same
    # initial state), the highest log posterior wins; starts = single: the default start only
    start_rec = []
    if ff["starts"] == "grid":
        init = {k: (p.val, p.frozen) for k, p in pars.items()}
        lm0, lc0 = pars["mass_M_logMsun"].val, pars["mass_logconc"].val
        grid = [(1.0, None)] + [(fm, c) for fm, c in OPTIMISER_START_GRID]
        best = None
        for fm, c in grid:
            for k, (v, fr) in init.items():
                pars[k].val, pars[k].frozen = v, fr
            pars["mass_M_logMsun"].val = lm0 + math.log(fm)
            pars["mass_logconc"].val = lc0 if c is None else math.log(c)
            lp = optimise()
            start_rec.append(dict(m500_seed_factor=fm, c200_start=None if c is None else c, log_post=round(lp, 3),
                                  ln_m500_nfw=round(pars["mass_M_logMsun"].val, 5),
                                  c200=round(math.exp(pars["mass_logconc"].val), 4)))
            print(f"  start M x{fm} c {'default' if c is None else c}: log posterior {lp:.2f} "
                  f"c200 {math.exp(pars['mass_logconc'].val):.2f}", flush=True)
            if best is None or lp > best[0]:
                best = (lp, {k: p.val for k, p in pars.items()}, len(start_rec) - 1)
        for k, v in best[1].items():
            pars[k].val = v
        for k in bg_keys:
            pars[k].frozen = False
        start_rec[best[2]]["chosen"] = True
    else:
        optimise()
    pars.write()
    t_opt = time.time() - t0
    like_cache.detach(fit)
    kept = "" if cache is None else (" {evaluations} evaluations, {source} of the cluster model, "
                                     "{image_terms} image terms".format(**cache.counts))
    print(f"  optimiser done [{t_opt:.0f} s]{kept}", flush=True)

    nburn, nrun = (150, 300) if quick else (500, 1500)
    nwalkers = max(2 * pars.numFree() + 2, 4 * pars.numFree())
    if nwalkers % 2:
        nwalkers += 1

#: the private rate cache of a pool worker under ``--worker-caches`` (set by
#: :func:`_init_worker_cache` in the worker; None = the batch's cache)
_WORKER_CACHE: str | None = None


def _init_worker_cache(slots, root, seed_cache) -> None:
    """Pool-worker initialiser of ``--worker-caches``: one PRIVATE mbproj2d rate cache per worker.

    Takes a free slot number from ``slots`` (a pool worker that replaces a dead
    one, if any, gets ``p<pid>``), copies the settled entries of ``seed_cache``
    (never its lock directories) into ``<root>/w<NN>/mbproj2d_cache``, removes
    every lock left there (a slot belongs to one worker of one job; a lock in
    it is a leftover of a killed job) and points mbproj2d at it.  No two
    concurrent processes ever share a cache this way; a re-submission reuses
    the slot caches with the tables computed before."""
    global _WORKER_CACHE
    import queue

    from tngxmm.massfit.check_preflight import check_preflight
    from tngxmm.validation.closure_grid import copy_settled_cache

    try:
        slot = f"w{int(slots.get(timeout=10)):02d}"
    except queue.Empty:
        slot = f"p{os.getpid()}"
    d = Path(root) / slot
    n = copy_settled_cache(seed_cache, d) if seed_cache and Path(seed_cache).is_dir() else 0
    cache = d / "mbproj2d_cache"
    cache.mkdir(parents=True, exist_ok=True)
    if any(cache.iterdir()):
        check_preflight(cache, minutes=0, log=lambda *a: None)
    _WORKER_CACHE = set_rate_cache(d)
    print(f"worker {os.getpid()}: rate cache {_WORKER_CACHE} ({n} entries copied from {seed_cache})",
          flush=True)


def _row_flag(r, key: str, default: bool = True) -> bool:
    """A boolean column of a targets row (absent / empty -> ``default``)."""
    v = _row_str(r, key)

def _task(job):
    """One target in its own process (nprocesses=1: no nested MCMC forking).

    ``per_fit_timeout_s`` > 0 arms a REPEATING interval timer (first at tmo, then
    every 60 s) so a pathological fit raises instead of holding a pool slot;
    repeating, because a single SIGALRM can be swallowed by an ``except OSError``
    on the call path.  (A hang here is usually a stale cache lock, not the MCMC:
    see ``check_preflight``.)

    A fit that fails because the disk is full (the exception says so, or a probe write in the fit root fails:
    :func:`tngxmm.core.diskguard.failure_status`) returns the status ``interrupted: disk``, not ``error``; a fit
    that would start after the batch was stopped for it is not started and returns the same."""
    import signal

    job = dict(job)
    if diskguard.stop_requested():
        return dict(name=job.get("name"), obsid=job.get("obsid"), status=diskguard.interrupted_status("not started"))
    tmo = int(job.pop("per_fit_timeout_s", 0) or 0)
    job.pop("centre_xy", None)             # consumed by apply_mock_centre before the fit; not an input of run_one
    job.pop("centre_flag", None)
    if _WORKER_CACHE is not None:          # --worker-caches: this worker's private rate cache
        job["cache_path"] = _WORKER_CACHE

    def _alarm(signum, frame):
        raise FitTimeout(f"per-fit timeout after {tmo} s")
    if tmo > 0:
        signal.signal(signal.SIGALRM, _alarm)
        signal.setitimer(signal.ITIMER_REAL, tmo, 60)
    try:
        return run_one(**job)
    except Exception as e:
        import traceback
        traceback.print_exc()
        disk = diskguard.failure_status(e, fits_root(job.get("workdir")))
        if disk is not None:
            diskguard.request_stop()
        return dict(name=job.get("name"), obsid=job.get("obsid"),
                    status=disk or f"error: {type(e).__name__}: {e}")
    finally:
        if tmo > 0:
            signal.setitimer(signal.ITIMER_REAL, 0)

def reference_from_row(r, ref_by_obsid=None) -> dict[str, Any] | None:
    """The reference mass of a target row WITH its quantity (recorded, never used by the fit).

    Order: the row's own ``m_ref_value_msun`` / ``m_ref_quantity`` (observations.csv columns);
    for a mock row, ``hse`` = the true M500c; for a real row, the ``observations.csv`` reference
    of its obsid (``ref_by_obsid``; the targets ``hse`` is kept as ``legacy_hse_1e14``); else the
    targets ``hse`` with quantity :data:`REF_UNSPECIFIED`.  None when there is none."""
    import numpy as np

    def fin(c):
        try:
            return c in r and np.isfinite(float(r.get(c, np.nan)))
        except (TypeError, ValueError):
            return False
    if fin("m_ref_value_msun") and isinstance(r.get("m_ref_quantity"), str):
        return dict(value_1e14=float(r["m_ref_value_msun"]) / 1e14, quantity=str(r["m_ref_quantity"]),
                    radius_kpc=float(r["m_ref_radius_kpc"]) if fin("m_ref_radius_kpc") else None,
                    source=str(r.get("m_ref_source", "targets row")))
    hse = float(r["hse"]) if fin("hse") else None
    if target_kind(r) == "mock":
        return None if hse is None else dict(value_1e14=hse, quantity="M500c (simulation truth)",
                                             radius_kpc=None, source="targets column hse (true M500c)")
    hit = (ref_by_obsid or {}).get(str(r.get("obsid", "")).zfill(10))
    if hit is not None:
        return dict(hit, legacy_hse_1e14=hse)
    if hse is None:
        return None
    return dict(value_1e14=hse, quantity=REF_UNSPECIFIED, radius_kpc=None, source="targets column hse")

def job_from_row(r, *, mc_by_name=None, nh_by_obsid=None, nh_fallback=0.03, quick=False, free_centre=False,

    ``r`` is a pandas Series (:func:`_row_as_series`).

    First guess (crop radius, optimiser start, model extent): the row's ``m500_seed_msun``, iterated on the target's
    own image through the published L-M relation (:func:`tngxmm.massfit.guess_mass.seed_lx_iterated`; mocks:

    :func:`tngxmm.validation.closure_grid.summarise`).  The c200 start is the Dutton &

    only) is :func:`reference_from_row`.  ``_legacy``: keyword arguments of the earlier seed rules, ignored."""

    nh_by_obsid = nh_by_obsid or {}
    if "ra" in r and np.isfinite(r.get("ra", np.nan)):

    else:

        ra = float(mcr["ra"]) if mcr is not None else np.nan
        dec = float(mcr["dec"]) if mcr is not None else np.nan
    if not (np.isfinite(ra) and np.isfinite(dec)):
        print(f'{r["name"]}: no RA/Dec; skipping')
        return None

def job_cost(j) -> tuple[float, float]:
    """Longest-first key: capped angular crop radius [arcmin], then the mass guess."""
    cosmo = flat_lcdm(H0, OM)
    m = (j["m500_guess"] or 6.35) * 1e14
    rho_c = cosmo.critical_density(j["z"]).to("Msun/kpc^3").value
    r500 = (3 * m / (4 * math.pi * 500 * rho_c)) ** (1 / 3)
    theta = r500 / cosmo.kpc_proper_per_arcmin(j["z"]).value
    crop = j["crop_r500"] * theta
    if j["crop_cap_arcmin"]:
        crop = min(crop, j["crop_cap_arcmin"])
    return (crop, m)

def _row_as_series(target_row):
    """A targets-CSV row as pandas parses it (obsid as a zero-filled string)."""
    import io

    import pandas as pd

    if isinstance(target_row, pd.Series):
        r = target_row.copy()
    else:
        d = dict(target_row)
        if all(isinstance(v, str) for v in d.values()):
            # strings straight from csv.DictReader: re-parse with pandas' own parser,
            # so floats are bit-identical to pd.read_csv
            buf = io.StringIO()
            pd.DataFrame([d]).to_csv(buf, index=False)
            buf.seek(0)
            r = pd.read_csv(buf, dtype={"obsid": str}).iloc[0]
        else:
            r = pd.Series(d)
    r["obsid"] = str(r["obsid"]).zfill(10)
    return r


def _row_str(r, key):
    """``r[key]`` as a string, or None when absent / empty / NaN."""
    v = r.get(key) if hasattr(r, "get") else None
    if v is None or (isinstance(v, float) and v != v) or str(v).strip() in ("", "nan"):
        return None
    if isinstance(v, float) and v.is_integer():
        v = int(v)                      # an obsid parsed as a number
    return str(v).strip()

def _same(a, b) -> bool:
    if isinstance(a, (list, tuple)) and isinstance(b, (list, tuple)):
        return len(a) == len(b) and all(_same(x, y) for x, y in zip(a, b))
    try:
        return float(a) == float(b)

        return a == b

def switches_with_overrides(preset: str, given: dict[str, Any]) -> tuple[dict, dict]:
    """(switches, overrides): ``fit_switches_from_spec`` of ``preset`` with every entry of
    ``given`` that is not ``"preset"`` applied; ``overrides`` = {name: {preset, used}} of
    those that differ from the preset's value."""
    from tngxmm.config import get_preset

    sw = fit_switches_from_spec(get_preset(preset))
    overrides = {}
    for k, v in given.items():
        if isinstance(v, str) and v == PRESET:
            continue
        if k == "fitfix":
            v = resolve_fitfix({**sw["fitfix"], **dict(v)})      # a partial dict overrides single entries
        if not _same(v, sw[k]):
            overrides[k] = dict(preset=sw[k], used=v)
        sw[k] = v
    return sw, overrides

def resolve_preset_switches(a) -> dict[str, Any]:
    """Fill every fit switch of the parsed CLI ``a`` that was not given with the value of
    ``a.preset`` (:func:`fit_switches_from_spec`), in the CLI's own form; returns
    {destination: value} of the filled ones (printed by the batch driver)."""
    from tngxmm.config import get_preset

    sw = fit_switches_from_spec(get_preset(a.preset))
    filled = {}
    for dest, key in _CLI_SWITCHES.items():
        cur = getattr(a, dest)
        given = (cur is not None) if dest == "mask_sources" else not (isinstance(cur, str) and cur == PRESET)
        if given:
            continue
        v = sw[key]
        if dest == "metallicity":
            v = (",".join(f"{k}={z}" for k, z in v.items()) if isinstance(v, dict) else str(v))
        elif dest in ("psf", "pn_oot"):
            v = "none" if v is None else v
        elif dest == "pixels_per_r500":
            v = 0.0 if v is None else float(v)
        elif dest == "mask_sources":
            v = bool(v)
        setattr(a, dest, v)
        filled[dest] = v
    if not isinstance(a.fitfix, dict):               # --fitfix text over the preset's entries
        txt = str(a.fitfix).strip()
        a.fitfix = parse_fitfix(txt, base=sw["fitfix"])
    # explicit values that differ from the preset: recorded with every fit (switch_overrides)
    over = {}
    for dest, key in _CLI_SWITCHES.items():
        if dest in filled:
            continue
        v = getattr(a, dest)
        used = (parse_metallicity(v) if dest == "metallicity" else
                (None if v == "none" else v) if dest in ("psf", "pn_oot") else
                (v or None) if dest == "pixels_per_r500" else v)
        if dest == "fitfix":
            used = a.fitfix
        if not _same(used, sw[key]):
            over[key] = dict(preset=sw[key], used=used)

def parse_metallicity(text: str):
    """``--metallicity``: a number, ``free``, or ``mock=Z1,obs=Z2``."""
    text = str(text).strip()
    if text == "free":
        return "free"
    if "=" in text:
        out = {}
        for part in text.split(","):
            k, v = part.split("=")
            out[k.strip()] = "free" if v.strip() == "free" else float(v)
        return out
    return float(text)

def _prepare_row(r):
    """The job of one target row with its source list and fit centre: ``(job, None, None)``; ``(None, failed row,
    None)`` when the masking asked for is impossible; ``(None, None, result)`` under ``--resume`` for a fit that is
    finished (:func:`_finished_fit`); None for a row that gives no job.  It reads files and writes none, so
    :func:`fit_targets` runs it on all workers; the outcome does not depend on where it ran."""
    c = _PREP
    a, spec, cache_path = c["a"], c["spec"], c["cache_path"]
    mc_by_name, nh_by_obsid, lx_by_obsid = c["mc_by_name"], c["nh_by_obsid"], c["lx_by_obsid"]
    core_by_obsid, ref_by_obsid = c["core_by_obsid"], c["ref_by_obsid"]
    j = job_from_row(r, mc_by_name=mc_by_name, nh_by_obsid=nh_by_obsid, lx_by_obsid=lx_by_obsid,
                     core_by_obsid=core_by_obsid, nh_fallback=a.nh, quick=a.quick,
                     free_centre=a.free_centre, nprocesses=a.nprocesses, crop_r500=a.crop_r500,
                     target_pixsize_as=a.pixsize, tag=a.tag, crop_cap_arcmin=a.crop_cap_arcmin,
                     per_fit_timeout_s=a.per_fit_timeout_s,
                     fallback_bg_prior_dex=a.fallback_bg_prior_dex, ref_by_obsid=ref_by_obsid)
    if j is None:
        return None
    kind = target_kind(r)
    j.update(workdir=a.workdir, img_root=image_root(kind, r.get("campaign") if kind == "mock" else None,
                                                    a.img_root),
             resp=a.resp, seed=a.seed, preset=a.preset, optical_axis=a.optical_axis,
             rebin_centre=a.rebin_centre, write_provenance=not a.no_provenance, cache_path=cache_path,
             metallicity=parse_metallicity(a.metallicity), abund_table=a.abund_table,
             mu_convention=a.mu_convention, mu_composition=a.mu_composition,
             psf=None if a.psf == "none" else a.psf, xspec_tmpdir=a.xspec_tmpdir,
             pn_oot=None if a.pn_oot == "none" else a.pn_oot, pn_oot_energy=a.pn_oot_energy,
             switch_overrides=a.switch_overrides or None, pixels_per_r500=a.pixels_per_r500 or None,
             fitfix=a.fitfix)
    if a.resume:                # a finished fit is kept as it is: no source list, no centre
        prev = _finished_fit(j, a.workdir)
        if prev is not None:
            return None, None, prev
    if a.mask_sources and not _row_flag(r, "mask_sources", True):
        # per-row switch: this target has no source list to mask with (recorded, not hidden)
        note = _row_str(r, "mask_note") or "targets row: mask_sources = False"
        j["sources"], j["masking_info"] = None, dict(source_masking=False, n_sources_masked=0,
                                                     mask_threshold_rule=f"off: {note}",
                                                     **apply_mock_centre(j, kind, j["img_root"], a.fitfix, spec))
        return j, None, None
    centre_info = apply_mock_centre(j, kind, j["img_root"], a.fitfix, spec)
    try:
        j["sources"], j["masking_info"] = _sources_for(j, a, r)
        if centre_info:
            j["masking_info"] = {**(j["masking_info"] or {}), **centre_info}
    except Exception as e:      # masking asked for but impossible: this target fails, not the batch
        return None, dict(name=j["name"], obsid=j["obsid"],
                          status=f"error: source masking: {type(e).__name__}: {e}"), None
    return j, None, None

def batch_argv(options: dict[str, Any]) -> list[str]:
    """The command line of :func:`fit_targets` for a mapping of run options (the Kedro parameters of a fit node).

    A key is the flag's name with underscores (``worker_caches`` -> ``--worker-caches``; ``fit_tag`` is ``--tag``
    and ``target_pixsize_as`` is ``--pixsize``).  ``None`` leaves the flag out, so the driver's default or the
    preset's value holds; a true switch gives the bare flag, a false one nothing (``mask_sources: false`` gives
    ``--no-mask-sources``).  A key the driver does not have raises ``ValueError``."""
    acts = {a.dest: a for a in build_parser()._actions if a.option_strings}
    argv: list[str] = []
    for key, value in options.items():
        dest = _OPTION_DEST.get(key, key)
        if dest not in acts or dest == "help":
            raise ValueError(f"fit option {key!r}: massfit fit-hydrostatic has no --{dest.replace('_', '-')}")
        act, flag = acts[dest], acts[dest].option_strings[0]
        if value is None:
            continue
        if isinstance(act, argparse.BooleanOptionalAction):
            argv.append(flag if value else flag.replace("--", "--no-", 1))
        elif act.nargs == 0:                           # a store_true switch
            if value:
                argv.append(flag)
        else:
            argv += [flag, str(value)]
    return argv

def fit_targets(argv: list[str] | None = None) -> list[dict]:
    """Batch driver: job list, --resume, longest-first, pool, incremental table.

    Options: ``--order as-listed`` (dispatch in the CSV's
    order), ``--worker-caches DIR`` (one private rate cache per pool worker,
    :func:`_init_worker_cache`) and, with ``--mask-sources``, a targets column
    ``mask_sources`` whose false rows are fitted unmasked and recorded as such
    (``mask_threshold_rule = "off: <mask_note>"``).

    The results table (``results_all.csv``) is rebuilt from the results of the fits, kept and new, every time a
    fit ends, and written atomically; it is never read back.  A full disk stops the batch
    (:mod:`tngxmm.core.diskguard`): the fit root is probed before the first fit and every few minutes; at the first
    fit with status ``interrupted: disk`` the fits not yet started are cancelled and the running ones end.  The
    interrupted fits are in no table and have no ``result.json``, so the same command with ``--resume`` makes them.
    :class:`~tngxmm.core.diskguard.DiskFull` is then raised; :func:`main` turns it into exit code 28."""
    from concurrent.futures import ProcessPoolExecutor

    import pandas as pd

    a = build_parser().parse_args(argv)
    filled = resolve_preset_switches(a)
    if filled:
        print(f"fit switches from preset {a.preset}: {filled}", flush=True)
    if a.switch_overrides:
        print(f"fit switches OVERRIDING preset {a.preset} (recorded per fit): {a.switch_overrides}", flush=True)
    vt = pd.read_csv(a.targets, dtype={"obsid": str})
    vt["obsid"] = vt["obsid"].str.zfill(10)
    mc_by_name, nh_by_obsid, lx_by_obsid, core_by_obsid = load_fallback_tables(
        a.catalogue_csv or None, a.lx_csv or None)

    rows = vt if a.all else vt[vt["name"] == a.name]
    if len(rows) == 0:
        sys.exit(f'no target matching --name {a.name!r}; choices: {", ".join(vt["name"].head(10))} ...')

    cache_path = set_rate_cache(a.cache_dir)
    if a.preflight:
        from tngxmm.massfit.check_preflight import check_preflight
        check_preflight(cache_path)

    from tngxmm.config import get_preset

    spec = get_preset(a.preset)                  # the preset of a mock's catalogue-position rule
    ref_by_obsid = load_reference_by_obsid()     # reference masses with their quantity (recorded only)
    _PREP.update(a=a, spec=spec, cache_path=cache_path, mc_by_name=mc_by_name, nh_by_obsid=nh_by_obsid,
                 lx_by_obsid=lx_by_obsid, core_by_obsid=core_by_obsid, ref_by_obsid=ref_by_obsid)
    row_list = [r for _, r in rows.iterrows()]
    cap = int(os.environ.get("TNGXMM_MAX_CORES", "0") or 0)
    nprep = a.workers or max((os.cpu_count() or 3) - 2, 1)
    if cap > 0:
        nprep = min(nprep, cap)
    nprep = max(min(nprep, len(row_list) // 4), 1)
    if nprep > 1:
        # a few seconds a target (source list, centre): one core would hold the other workers back for hours
        import multiprocessing as mp

        print(f"preparing {len(row_list)} targets on {nprep} workers", flush=True)
        with ProcessPoolExecutor(max_workers=nprep, mp_context=mp.get_context("fork")) as ex:
            prepared = list(ex.map(_prepare_row, row_list, chunksize=max(1, len(row_list) // (8 * nprep))))
    else:
        prepared = [_prepare_row(r) for r in row_list]
    jobs, failed, kept = [], [], []
    for got in prepared:                         # in the order of the table, wherever a row was prepared
        if got is None:
            continue
        j, bad, prev = got
        if bad is not None:
            print(f'{bad["name"]}: {bad["status"].removeprefix("error: ")}', flush=True)
            failed.append(bad)
        elif prev is not None:
            kept.append(prev)
        else:
            jobs.append(j)

    # --resume: the finished fits were set aside as the rows were prepared (_finished_fit)
    done = list(failed) + kept
    if a.resume:
        print(f"--resume: {len(done)} finished fits kept, {len(jobs)} to run", flush=True)

    # longest-first: the cost scales with the fitted area and the counts
    # (--order as-listed keeps the order of the targets CSV, e.g. a priority order)
    if a.order == "longest-first":
        jobs.sort(key=job_cost, reverse=True)

    out = fits_root(a.workdir) / ("results_all.csv" if a.all else f"result_{a.name}.csv")
    if a.dry_run:
        print(f"dry run: {len(done)} kept, {len(jobs)} to fit, results -> {out}")
        for j in _dry_run_sample(jobs):
            print("  ", j if isinstance(j, str) else
                  f"{j['name']:28s} z={j['z']:.3f} seed={j['seed_source']} crop_cost={job_cost(j)[0]:.1f}' "
                  f"n_img={len(find_images(j['obsid'], j['img_root']))}")
        return []
    out.parent.mkdir(parents=True, exist_ok=True)
    diskguard.remove_stale_tmp(out.parent, older_than_s=3600.0)
    guard = diskguard.SpaceGuard(out.parent, cache_path if Path(cache_path).is_dir() else None)
    try:
        guard.check(force=True)                  # before any fit starts
    except diskguard.DiskFull as e:
        raise diskguard.DiskFull(diskguard.disk_message("fit batch", 0, out.parent, e)) from e
    diskguard.install_stop()
    interrupted, why = [], []

    def write_table(rows) -> None:
        try:
            with diskguard.atomic_path(out) as tmp:
                pd.DataFrame(rows).to_csv(tmp, index=False)
        except OSError as e:                     # the table is rebuilt by the next run; the fits are on disk
            if not diskguard.is_disk_error(e):
                raise
            why.append(f"results table {out}: {e}")
            diskguard.request_stop()

    def check_disk() -> None:
        if not why:
            try:
                guard.check()
            except diskguard.DiskFull as e:
                why.append(str(e))
                diskguard.request_stop()

    def stopped(res) -> bool:
        """Count a fit a full disk interrupted (True) and stop the batch at the first."""
        if not diskguard.is_interrupted(res.get("status")):
            return False
        interrupted.append(res.get("name"))
        why.append(res["status"])
        diskguard.request_stop()
        return True

    if len(jobs) == 1:
        if a.worker_caches:
            import queue

            q = queue.Queue()
            q.put(0)
            _init_worker_cache(q, str(a.worker_caches), cache_path)
        res = _task(jobs[0])
        results = [] if stopped(res) else [res]
    else:
        cap = int(os.environ.get("TNGXMM_MAX_CORES", "0") or 0)
        nw = a.workers or max((os.cpu_count() or 3) - 2, 1)
        if cap > 0:
            nw = min(nw, cap)
        nw = max(min(nw, len(jobs)), 1)
        print(f"fitting {len(jobs)} targets on {nw} parallel workers ({a.nprocesses} MCMC proc each)\n",
              flush=True)
        results = []
        pool_kw = {}
        if a.worker_caches:
            import multiprocessing as mp

            slots = mp.Queue()
            for i in range(nw):
                slots.put(i)
            pool_kw = dict(initializer=_init_worker_cache,
                           initargs=(slots, str(a.worker_caches), cache_path))
            print(f"--worker-caches: {nw} private rate caches under {a.worker_caches}, "
                  f"seeded from {cache_path}", flush=True)
        # incremental write: a wall-clock timeout must never lose finished work
        with ProcessPoolExecutor(max_workers=nw, **pool_kw) as ex:
            futs = {ex.submit(_task, j): j["name"] for j in jobs}
            i = 0
            for fut in diskguard.completed_or_tick(futs, guard.interval_s):
                if fut is None:                  # no fit ended for a while: look at the disk all the same
                    check_disk()
                    if why:
                        for f in futs:
                            f.cancel()
                    continue
                i += 1
                if fut.cancelled():
                    interrupted.append(futs[fut])
                    continue
                try:
                    res = fut.result()
                except Exception as e:           # a worker that died (the pool is broken): the disk's doing?
                    disk = diskguard.failure_status(e, out.parent)
                    if disk is None:
                        raise
                    res = dict(name=futs[fut], status=disk)
                print(f'[{i}/{len(jobs)}] {res.get("name")}: '
                      + (f'M500={res.get("m500_1e14"):.2f}e14' if res.get("status") == "ok"
                         else res.get("status", "?")), flush=True)
                if not stopped(res):
                    results.append(res)
                    write_table(done + results)
                    check_disk()
                if why:                          # no new fit; the running ones end by themselves
                    for f in futs:
                        f.cancel()

    diskguard.clear_stop()
    results = done + results
    write_table(results)
    if why:
        raise diskguard.DiskFull(diskguard.disk_message("fit batch", len(interrupted), out.parent, why[0]))
    print(f'\nwrote {out}  ({sum(r.get("status") == "ok" for r in results)}/{len(results)} ok)')
    return results

def to_fit_results(results, targets=None, *, fit_tag: str, preset: str = PRODUCTION_PRESET, seed=None,
                   spec_hash: str | None = None):
    """Result dicts (list of dicts or DataFrame) -> the ``fit_results`` table (INTERFACES 4.3).

    ``targets`` (DataFrame of the targets CSV) supplies the mock view ids
    (snap, halo_id, view, campaign); real targets use the 10-digit obsid."""
    import numpy as np
    import pandas as pd

    from tngxmm import __version__
    from tngxmm.config import get_preset
    from tngxmm.core.provenance import git_hash
    from tngxmm.schemas import FIT_RESULTS_TABLE
    from tngxmm.schemas.ids import make_view_id

    df = pd.DataFrame(results).copy() if not isinstance(results, pd.DataFrame) else results.copy()
    df = FIT_RESULTS_TABLE.rename_legacy(df)
    if "nh_1022" in df.columns and "nh_1e22cm2" not in df.columns:
        df = df.rename(columns={"nh_1022": "nh_1e22cm2"})
    tmap = {}
    if targets is not None:
        tmap = {str(r["name"]): r for _, r in targets.iterrows()}
    kinds, tids = [], []
    for _, r in df.iterrows():
        name = str(r["name"])
        if name.startswith("mock_"):
            kinds.append("mock")
            t = tmap.get(name)
            if t is not None and "snap" in t:
                camp = str(t.get("campaign", preset)).replace("campaign_", "")
                tids.append(make_view_id(camp, int(t["snap"]), int(t["halo_id"]), int(t["view"])))
            else:
                _, snap, halo, v = name.split("_")
                tids.append(make_view_id(preset, int(snap), int(halo), int(v.lstrip("v"))))
        else:
            kinds.append("obs")
            tids.append(str(r["obsid"]).zfill(10))
    df.insert(0, "target_id", tids)
    df.insert(1, "kind", kinds)
    df["obsid"] = df["obsid"].astype(str)
    if "cluster_id" not in df.columns:
        df["cluster_id"] = np.nan
    df["fit_tag"] = fit_tag
    if "crop_cap_arcmin" in df.columns:
        df["crop_cap_arcmin"] = pd.to_numeric(df["crop_cap_arcmin"], errors="coerce")
    if "seed" not in df.columns:
        df["seed"] = -1 if seed is None else int(seed)
    df["spec_hash"] = spec_hash or get_preset(preset).spec_hash()
    df["package_version"] = __version__
    df["git_hash"] = git_hash()
    return df
