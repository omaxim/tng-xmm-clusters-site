Source code for tngxmm.sim.compute_hse_stream

"""Streamed intrinsic hydrostatic truth: :func:`compute_hse_truth` from chunked reads.

Built for the spherical truth of TNG50 on a normal 250 GB node.
:func:`tngxmm.sim.compute_hse_mass.compute_hse_truth` (the REFERENCE, unchanged) holds every
particle of the halo in memory and ~40 derived per-cell arrays beside them: ~0.25-0.4 GB per
million particles, i.e. ~450 GB for a TNG50-1 halo-0 sphere (1.1e9 particles in 3 R200c).
The truth needs no per-particle state beyond the cells' own arithmetic: every estimator is a
function of per-shell sums on fixed radial grids, and a sum is additive over chunks of cells.
:func:`compute_hse_truth_streamed` therefore reads the particles of a halo chunk by chunk
(``source.iter_particles``), does the per-cell arithmetic of the reference on the chunk,
adds the chunk's shell sums (``numpy.bincount``) to the running totals and drops the chunk;
the estimators (finite differences, Vikhlinin fits, M500 and R500 crossings, the truth-profile
arrays) are then computed from the totals with the reference's own functions.  The result
dictionary has the keys and the layout of the reference's (``summary``, ``profiles``,
``mass_profile``, ``truth_profile``), so the file writer and everything downstream are shared.

What is accumulated, per type of particle
-----------------------------------------
* dark matter, stars, black holes (the bulk of the particles; one pass each, coordinates and
  masses only): the shell mass sums of the total-mass profile (``mtot_shell``), the mass inside
  the first shell edge, and the cumulative mass at the radii of the particle mass profile
  (``n_grid`` log radii, M500c(z) crossing) and of the truth profile (shell centres and
  edges): ``M(<r_j)`` is the cumulative sum of a per-gap histogram of the masses, which equals
  the reference's sorted cumulative sum up to the order of the float64 additions;
* gas, main pass (non-SF and hot phases): the shell sums of every mass-, volume-, ``n_e``-,
  ``T``-, ``P``-, ``wsl``-, ``wew``-weighted and kinetic moment of the reference, on the
  48-shell HSE grid, the 60-shell truth-profile grid (``truth_profile.N_SHELLS``), the Barnes (50 linear) and Pearce (50
  log) grids, the R500c temperatures and the emission-weighted metallicities;
* gas, mock pass (``mock_selection``: the mock's cells inside the sphere, the FoF members with loader fof, every gas cell with loader cutout):
  the same for the mock phase.

Shell MEDIANS (``th_med``: P and rho of the non-SF gas; ``X_*_nemed``: n_e of the hot gas;
the ``ne_med`` of the truth profile: the non-SF, hot and mock phases) are not additive.
They are EXACT here: the per-cell values (float64 P, rho, n_e, the two shell indices and the
hot flag; 29 bytes per non-SF cell, 12 per mock cell) of the gas cells inside the HSE grid
are kept, concatenated after the pass and reduced with ``numpy.median`` per shell, so the
medians are bit-identical to the reference's.  That buffer and the pieces kept for the
sums the reference takes with numpy's pairwise ``sum`` over the cells inside R500c (kept in
sphere order and summed once: the same bits) are the only per-particle state; they grow
with the number of GAS CELLS in 3.15 R500c, not with the dark matter (~60 % of a sphere):
measured ~100 B per selected gas cell in all (TNG100 halo, 1.9e7 cells: 2.3 GB), i.e. ~35 GB
for a TNG50 halo 0.

Equality with the reference
---------------------------
Every per-cell value is the same IEEE operation on the same dtype, so the cells' arrays are
bit-identical; the medians are bit-identical; the shell sums are bit-identical too
(:class:`_Idx` ``acc``: ``numpy.bincount`` with the running total of every bin in front of the
chunk's weights continues the reference's single sequential float64 sum, whatever the
chunking), and so are the sums over the cells inside R500c and the float32 pairwise sums of
the reference (the inner mass ``m_in``, the gas mass inside R500c), which are summed once from
the kept pieces.  Hence every estimator, the Vikhlinin fits and the whole truth-profile
structure equal the reference's to the bit.  The only difference is the cumulative particle
mass (``mass_profile``, ``truth_profile/mass/*``, ``m500c_particles_msun`` and the
``*_avg0.8-1.2`` ratios built on it): the reference sums over the radius-sorted particles
(``cumsum``), here per-gap mass histograms are cumulated; the same numbers in another order,
equal to ~5e-11 (measured on TNG-Cluster and TNG300 halos), the reference being the less
accurate (a sequential float64 ``cumsum`` of 3e6 equal masses is off by 2e-11, of 3e7 by
5e-10; the histogram sum by 1e-14).  tests/unit/test_sim_hse_stream.py, DECISIONS "Streamed
spherical truth".

References
----------
sarazin1988, rasia2006, mazzotta2004, barnes2021, pearce2020, chatzigiannakis2025 :
    the estimators, as in :mod:`tngxmm.sim.compute_hse_mass`.
illustristng, tngcluster : the simulations whose spheres are streamed.
"""

import time

# ------------------------------------------------------------------ helpers --
class _Idx:
    """Shell index of a set of radii on one grid (``edges``) and the binned sum of the
    reference (``compute_hse_mass._shell_tools.bs``: the cells whose shell is inside).

    :meth:`acc` adds a chunk to a running total WITHOUT changing the order of the float64
    additions: ``numpy.bincount`` adds the weights to their bins one after the other in
    input order, so putting the running total of every bin in front of the chunk's weights
    continues the reference's single sequential sum over all the cells (``((a1 + a2) + a3)
    + ...``) exactly: the shell sums are bit-identical to the reference's, whatever the
    chunking."""

    def __init__(self, r: Any, edges: Any, nb: int) -> None:
        import numpy as np

        self.idx = np.digitize(r, edges) - 1
        self.nb = nb
        self.inb = (self.idx >= 0) & (self.idx < nb)

    def acc(self, d: dict, key: str, w: Any, s: Any = None) -> None:
        import numpy as np

        s = self.inb if s is None else (s & self.inb)
        carry = d.get(key)
        if carry is None:
            carry = np.zeros(self.nb)
        d[key] = np.bincount(np.concatenate([np.arange(self.nb), self.idx[s]]),
                             weights=np.concatenate([carry, w[s]]), minlength=self.nb)


class _CumMass:
    """Cumulative mass M(<=r_j) at fixed radii from chunks of (r, m): the per-gap mass
    histogram of the chunks, cumulated at the end (the reference sorts all radii and takes
    ``cumsum`` at ``searchsorted(r_sorted, radii, 'right')``: the same sets, summed in a
    different order)."""

    def __init__(self, radii: Any) -> None:
        import numpy as np

        self.radii = np.asarray(radii, float)
        self.order = np.argsort(self.radii, kind="stable")
        self.sorted = self.radii[self.order]
        self.hist = np.zeros(len(self.radii) + 1)

    def add(self, r: Any, m: Any) -> None:
        import numpy as np

        # a particle at r belongs to every radius >= r: the first such radius
        b = np.searchsorted(self.sorted, r, side="left")
        self.hist += np.bincount(b, weights=np.asarray(m, np.float64),
                                 minlength=len(self.radii) + 1)

    def result(self) -> Any:
        import numpy as np

        out = np.empty(len(self.radii))
        out[self.order] = np.cumsum(self.hist[:-1])
        return out


def _first_available(has: Any, ptype: int, candidates: list[list[str]]) -> list[str]:
    """The first field list of ``candidates`` whose fields the source has (the order in
    which :func:`~tngxmm.sim.load_halo_gas.gas_optional` drops the optional fields)."""
    for fl in candidates:
        if all(has(ptype, f) for f in fl):
            return fl
    raise KeyError(f"fields of PartType{ptype} absent from the snapshot: {candidates[-1]}")


def _gas_fields(has: Any) -> list[str]:
    """The main gas pass's fields, as the reference's ``gas_optional`` chain: the
    composition fields (``GFM_Metals``, ``GFM_Metallicity``) with ``GFM_CoolingRate`` and
    ``GFM_Metals`` dropped in turn, else the plain fields with ``GFM_CoolingRate`` optional."""
    cr, me = "GFM_CoolingRate", "GFM_Metals"
    comp = [[f for f in H.GAS_FIELDS_COMPOSITION if f not in drop]
            for drop in ((), (cr,), (cr, me))]
    plain = [[f for f in H.GAS_FIELDS if f not in drop] for drop in ((), (cr,))]
    try:
        return _first_available(has, 0, comp)
    except KeyError:
        return _first_available(has, 0, plain)


def _mock_fields(has: Any) -> list[str]:
    """The mock pass's fields (``_mock_phase_profiles``: with ``GFM_Metallicity`` first)."""
    cr, me = "GFM_CoolingRate", "GFM_Metals"
    drops = ((), (me,), (me, cr))
    withz = [[f for f in H.MOCK_FIELDS + ["GFM_Metallicity"] if f not in d] for d in drops]
    plain = [[f for f in H.MOCK_FIELDS if f not in d] for d in drops]
    try:
        return _first_available(has, 0, withz)
    except KeyError:
        return _first_available(has, 0, plain)


def _shell_median(x: Any, idx: Any, nb: int) -> Any:
    """Median of ``x`` per shell of ``idx`` (cells outside [0, nb) ignored), NaN with <= 10
    cells: the reference's ``bmed`` / ``truth_profile.shell_median`` on the same cells (the
    median does not depend on the order of the cells)."""
    import numpy as np

    out = np.full(nb, np.nan)
    ok = (idx >= 0) & (idx < nb)
    ii, xx = idx[ok], x[ok]
    o = np.argsort(ii, kind="stable")
    ii, xx = ii[o], xx[o]
    cuts = np.searchsorted(ii, np.arange(nb + 1))
    for k in range(nb):
        if cuts[k + 1] - cuts[k] > 10:
            out[k] = np.median(xx[cuts[k]:cuts[k + 1]])
    return out


def _pairwise(parts: list) -> Any:
    """``concatenate(parts).sum()`` in the dtype of the parts: numpy's pairwise sum of the
    whole array, i.e. the reference's ``x[mask].sum()`` for the masses it keeps here."""
    import numpy as np

    if not parts:
        return np.float64(0.0)
    return np.concatenate(parts).sum()


def _metal_summary(pw: dict) -> dict:
    """``metallicity_summary`` from the kept cells: ``{'z_ew', 'z_fe_ew'}`` (NaN without
    weight or for an absent field)."""
    out = {"z_ew": math.nan, "z_fe_ew": math.nan}
    ws = float(_pairwise(pw["w_em"])) if pw["w_em"] else 0.0
    if ws > 0:
        for k in ("z_ew", "z_fe_ew"):
            if pw[k]:
                out[k] = float(_pairwise(pw[k]) / ws)
    return out


def _cat(parts: list) -> Any:
    import numpy as np

    return np.concatenate(parts) if parts else np.zeros(0)


def _profile_from_sums(msum: Any, vsum: Any, twsum: Any, wsum: Any, vol: Any, density: str,
                       min_filling: float | None, has_v: bool) -> tuple:
    """``(rho, T)`` of :func:`~tngxmm.sim.compute_hse_mass._bin_profile` from the shell sums
    (mass, cell volume, sum of T x weight, sum of weight)."""
    import numpy as np

    with np.errstate(invalid="ignore", divide="ignore"):
        if density == "geometric" and min_filling is None:
            rho, omit = msum / vol, None
        else:
            if not has_v:
                raise ValueError("the filling-consistent density needs the cell volumes V")
            rho, _, omit = H.shell_gas_density(msum, vsum, vol, density, min_filling)
        T = twsum / wsum
    rho[rho <= 0] = np.nan
    if omit is not None:
        rho[omit] = np.nan
        T[omit] = np.nan
    return rho, T

            for k, M in mock_est.items():

        res.update({k: mp[k] for k in ("t_ew_r500c_kev", "t_sl_r500c_kev", "t_mw_r500c_kev",
                                       "mgas_mock_lt_r500c_msun")})
        res["z_ew_r500c_mock"] = mp["metal_mock"]["z_ew"]
        res["z_fe_ew_r500c_mock"] = mp["metal_mock"]["z_fe_ew"]
        res["mock_selection"] = mock_selection
        res["mock_t_min_k"] = float(mock_t_min_k)
        res["mock_clip_radius_kpc"] = clip
        c, M = mp["barnes21_mock"]
        with np.errstate(invalid="ignore", divide="ignore"):
            res.update(H._summaries("barnes21_mock", M, c, R500, M500, rho_c, mtrue_at(c)))
        profiles["M_barnes21_mock"] = M
        profiles.update({"ne_med_mock": mp["ne_med"], "T_sl_mock": mp["T_sl"],
                         "T_mw_mock": mp["T_mw"], **{f"M_{k}": M for k, M in mock_est.items()}})
    res["m500c_particles_msun"] = H.m500_at_z((r_grid, m_grid), z, h, om0)[0]
    for k, (c, M) in lit.items():
        profiles[f"M_{k}"] = M
        profiles[f"r_{k}"] = c
    out = {"summary": res, "profiles": profiles, "mass_profile": (r_grid, m_grid),
           "h": h, "om0": om0}
    res["truth_selection"] = str(selection)
    res["hse_shell_density"] = str(shell_density)
    res["hse_min_filling"] = float("nan") if min_filling is None else float(min_filling)
    if tp is not None:
        for k, cm in cum_prof.items():
            if k != "gas_mock" or mock_selection is not None:
                macc.m[k] = cm.result()
        native = {k: (cent, M) for k, M in est.items()}
        native.update({k: v for k, v in lit.items()
                       if k not in (H.MU059_FIT_ESTIMATOR, H.NOSF_FD_ESTIMATOR)})
        if mock_selection is not None:
            native.update({k: (cent, profiles[f"M_{k}"]) for k in H.MOCK_ESTIMATORS})
            native["barnes21_mock"] = mp["barnes21_mock"]
        out["truth_profile"] = H._truth_profile_finish(
            tp, macc, mp.get("tp_mock") if mock_selection is not None else None, native,
            metal_mock=mp.get("tp_metal_mock") if mock_selection is not None else None,
            abund_table=abund_table, source=source, fr=fr, box=box,
            mock_selection=mock_selection, selection=selection, mock_t_min_k=mock_t_min_k,
            mock_clip=res.get("mock_clip_radius_kpc", float("nan")), **dens_kw)
        # the file records the same source type whichever way the particles were read
        out["truth_profile"]["attrs"]["source_type"] = "SphereSource"
    st["seconds"]["total"] = time.time() - t_start
    return out

def _phase_sums(Sq: dict, ph: str, Q: _Idx, m, T, ne, V, mask, P) -> None:
    """The additive part of :func:`tngxmm.sim.truth_profile.phase_profiles`."""
    import numpy as np

    wsl = ne ** 2 * V * T ** -0.75
    wew = ne ** 2 * V * np.sqrt(T)
    for name, w in (("V", V), ("m", m), ("neV", ne * V), ("ne2V", ne ** 2 * V), ("Tm", T * m),
                    ("wsl", wsl), ("Twsl", T * wsl), ("wew", wew), ("Twew", T * wew),
                    ("PV", P * V), ("n", np.ones(len(m)))):
        Q.acc(Sq, f"{ph}_{name}", w, mask)


def _phase_from_sums(Sq: dict, ph: str, ne_med: Any, pe: Any, density: str) -> dict:
    """``truth_profile.phase_profiles`` from the shell sums of the phase ``ph``."""
    import numpy as np

    from tngxmm.sim import truth_profile as tpm

    vol = 4.0 / 3.0 * np.pi * np.diff(pe ** 3)
    g = lambda n: Sq[f"{ph}_{n}"]       # noqa: E731
    with np.errstate(invalid="ignore", divide="ignore"):
        Vs, Ms = g("V"), g("m")
        rho, fill, _ = H.shell_gas_density(Ms, Vs, vol, density)
        out = dict(rho_gas=rho, fill=fill, ne_vw=g("neV") / Vs, ne_med=ne_med,
                   ne_rms=np.sqrt(g("ne2V") / Vs), T_mw=g("Tm") / Ms / H.KEV_K,
                   T_sl=g("Twsl") / g("wsl") / H.KEV_K, T_ew=g("Twew") / g("wew") / H.KEV_K,
                   P_th=g("PV") / Vs * tpm.P_TO_KEV_CM3, n_cells=g("n"))
        out["K_mw"] = out["T_mw"] * out["ne_vw"] ** (-2.0 / 3.0)
        out["K_sl"] = out["T_sl"] * out["ne_vw"] ** (-2.0 / 3.0)
    out["rho_gas"][out["rho_gas"] <= 0] = np.nan
    return out


def _truth_profile_gas_from_sums(Sq: dict, med: dict, pe: Any, pc: Any, vol: Any,
                                 dens_kw: dict, present: dict) -> dict:
    """:func:`~tngxmm.sim.compute_hse_mass._truth_profile_gas` from the shell sums
    (``present``: which metallicity fields the cells carry)."""
    import numpy as np

    density, min_filling = dens_kw["density"], dens_kw["min_filling"]
    gas = {"nonsf": _phase_from_sums(Sq, "nonsf", med["tp_ne_nonsf"], pe, density),
           "hot": _phase_from_sums(Sq, "hot", med["tp_ne_hot"], pe, density)}
    with np.errstate(invalid="ignore", divide="ignore"):
        Mg = Sq["kMg"]
        rho_gas, _, omit = H.shell_gas_density(Mg, Sq["kVn"], vol, density, min_filling)
        vr_mean = Sq["kmvr"] / Mg
        sr2 = Sq["kmvr2"] / Mg - vr_mean ** 2
        st2 = Sq["kmvt2"] / Mg
        beta = 1 - st2 / (2 * sr2)
        P_vw = Sq["kPV"] / Sq["kVn"]
        rho_h = np.where(omit, np.nan, rho_gas)
        P_h = np.where(omit, np.nan, P_vw)
        M_th = -pc * P_h * H._dln(P_h, pc) / (H.GK * rho_h)
        Ptot = P_h + rho_h * sr2
        M_thkin = -pc * Ptot * H._dln(Ptot, pc) / (H.GK * rho_h) - 2 * beta * sr2 * pc / H.GK
    from tngxmm.sim import truth_profile as tpm

    kin = dict(sigma_r2=sr2, sigma_t2=st2, beta=beta, vr_mean=vr_mean,
               P_kin=rho_gas * sr2 * tpm.P_TO_KEV_CM3)
    out = dict(gas=gas, kinetic=kin, hse={"M_th_nonsf": M_th, "M_thkin_nonsf": M_thkin})
    out["metallicity"] = _metal_from_sums(Sq, present)
    return out


def _metal_from_sums(Sq: dict, present: dict) -> dict:
    """``truth_profile.metallicity_profiles`` from the shell sums of w, w Z, w Z_Fe."""
    import numpy as np

    ws = Sq["zw"]
    with np.errstate(invalid="ignore", divide="ignore"):
        return {name: (np.where(ws > 0, Sq[key] / ws, np.nan) if present[pk]
                       else np.full(len(ws), np.nan))
                for name, key, pk in (("Z_ew", "zz", "z_ew"), ("Z_fe_ew", "zf", "z_fe_ew"))}


def _literature_from_sums(Sb: dict, Sp: dict, sc: dict, eb: Any, cb: Any, ep: Any, cp: Any,
                          vol_b: Any, vol_p: Any, R500: float, dens_kw: dict,
                          mu059_fit: bool, nosf_fd: bool) -> tuple[dict, dict]:
    """:func:`~tngxmm.sim.compute_hse_mass._literature_estimators` from the Barnes and Pearce
    shell sums (the same arithmetic after the binning)."""
    import numpy as np

    density, min_filling = dens_kw["density"], dens_kw["min_filling"]
    out: dict = {}
    fit_rec: dict = {}

    def prof(m, V, tw, w, vol):
        return _profile_from_sums(m, V, tw, w, vol, density, min_filling, True)

    for key in ("all", "nsf", "xcut"):
        name = {"all": "barnes21", "nsf": "barnes21_nosf", "xcut": "barnes21_xcut"}[key]
        rho, Tm = prof(Sb[f"m_{key}"], Sb[f"V_{key}"], Sb[f"Tm_{key}"], Sb[f"m_{key}"], vol_b)
        if name != "barnes21_nosf" or nosf_fd:
            out[H.NOSF_FD_ESTIMATOR if name == "barnes21_nosf" else name] = (
                cb, H._m_nt(cb, rho, Tm))
        if mu059_fit and name == "barnes21_nosf":
            M, info = H._m_fit(cb, rho, Tm, R500)
            out[H.MU059_FIT_ESTIMATOR] = (cb, M)
            fit_rec.update({f"{H.MU059_FIT_ESTIMATOR}_{n}": v for n, v in info.items()})
    rho, Tmu = prof(Sb["m_nsf"], Sb["V_nsf"], Sb["Tmu_nsf"], Sb["m_nsf"], vol_b)
    M, info = H._m_fit(cb, rho, Tmu, R500, mu=1.0)
    out["barnes21_nosf_fit_mu"] = (cb, M)
    fit_rec.update({f"barnes21_nosf_fit_mu_{n}": v for n, v in info.items()})
    rho, Tsl = prof(Sb["m_xcut"], Sb["V_xcut"], Sb["Tsl_xcut"], Sb["wsl_xcut"], vol_b)
    out["barnes21_tsl"] = (cb, H._m_nt(cb, rho, Tsl))

    rho, Tm = prof(Sp["m"], Sp["V"], Sp["Tm"], Sp["m"], vol_p)
    Msh = Sp["m"]
    with np.errstate(invalid="ignore", divide="ignore"):
        sig3 = np.zeros(len(cp))
        for k in range(3):
            mean = Sp[f"mv{k}"] / Msh
            sig3 += Sp[f"mvv{k}"] / Msh - mean ** 2
        Pth = rho * H.KB * Tm / (H.MU_X * H.MP) / 1e10
    out["pearce20_th"] = (cp, H._m_pressure(cp, rho, Pth))
    out["pearce20_thkin"] = (cp, H._m_pressure(cp, rho, Pth + rho * sig3 / 3.0))
    out["pearce20_thkin_sig3d"] = (cp, H._m_pressure(cp, rho, Pth + rho * sig3))

    with np.errstate(invalid="ignore", divide="ignore"):
        rec = {"t_mw_r500c_all_gas_kev": float(sc["tm_num"] / sc["tm_den"]) / H.KEV_K,
               "t_sl_r500c_xcut_kev": float(sc["tsl_num"] / sc["tsl_den"]) / H.KEV_K}
    rec["t_sl_valid"] = bool(rec["t_sl_r500c_xcut_kev"] >= H.T_SL_VALID_KEV)
    rec.update(fit_rec)
    return out, rec


def _mock_streamed(source: Any, fr: dict, edges: Any, cent: Any, vol: Any, eb: Any, cb: Any,
                   vol_b: Any, pe: Any, npe: int, pvol: Any, *, selection: str,
                   radius_ckpc_h: float | None, clip_radius_kpc: float, t_min_k: float,
                   cum_mock: Any, abund_table: str, chunk_rows: int, stats: dict,
                   verbose: bool, density: str = "geometric",
                   min_filling: float | None = None) -> dict:
    """:func:`~tngxmm.sim.compute_hse_mass._mock_phase_profiles` from chunks of the mock's
    cells (the FoF members inside the sphere, ``selection``)."""
    import numpy as np

    from tngxmm.sim import truth_profile as tpm
    from tngxmm.sim.compute_true_profiles import radius_kpc
    from tngxmm.sim.load_halo_gas import emission_masks

    h, a = fr["h"], fr["a"]
    fields = _mock_fields(lambda pt, f: source.has_fields(pt, [f]))
    have_cr, have_metals = "GFM_CoolingRate" in fields, "GFM_Metals" in fields
    have_zmet = "GFM_Metallicity" in fields
    nb, nbb = len(cent), len(cb)
    zsun_t, fesun_t = H.solar_units_of_table(abund_table)
    S: dict[str, Any] = {}
    Sb: dict[str, Any] = {}
    Sq: dict[str, Any] = {}
    pw: dict[str, list] = {k: [] for k in ("Tew", "ew", "Tsl", "sl", "Tmm", "mm", "w_em",
                                           "z_ew", "z_fe_ew")}
    present = {"z_ew": False, "z_fe_ew": False}
    nebuf: list = []
    iabuf: list = []
    ipbuf: list = []
    n_ch = n_rows = 0
    for g in source.iter_particles(0, fields, selection, radius_ckpc_h, chunk_rows):
        xh = (np.asarray(g["GFM_Metals"][:, 0], float) if have_metals
              else np.full(len(g["Masses"]), H.X_H))
        xfe = H.metal_columns(g["GFM_Metals"])[1] if have_metals else None
        zmet = np.asarray(g["GFM_Metallicity"], float) if have_zmet else None
        r = radius_kpc(np.asarray(g["Coordinates"], float), fr)
        m = np.asarray(g["Masses"], float) * 1e10 / h
        rho = np.asarray(g["Density"], float) * 1e10 * h ** 2 / a ** 3
        xe = np.asarray(g["ElectronAbundance"], float)
        mu = 4.0 / (1.0 + 3.0 * xh + 4.0 * xh * xe)
        u_int = np.asarray(g["InternalEnergy"], float)
        T = (2.0 / 3.0) * u_int * 1e10 * mu * H.MP / H.KB
        sfr = np.asarray(g["StarFormationRate"], float)
        cr = np.asarray(g["GFM_CoolingRate"], float) if have_cr else None
        nH = xh * rho * H.MSUN / H.KPC ** 3 / H.MP
        ne = xe * nH
        V = m / rho
        n_rows += len(r)
        n_ch += 1
        phase = (r <= clip_radius_kpc) & emission_masks(T, sfr, cr, t_min_k)[0]
        A = _Idx(r, edges, nb)
        with np.errstate(invalid="ignore", divide="ignore"):
            wsl = ne ** 2 * V * T ** -0.75
            wew = ne ** 2 * V * np.sqrt(T)
            A.acc(S, "wsl", wsl, phase)
            A.acc(S, "Twsl", T * wsl, phase)
            A.acc(S, "m", m, phase)
            A.acc(S, "Tm", T * m, phase)
            A.acc(S, "V", V, phase)
            s5 = phase & (r < fr["r500_kpc"])
            for name, arr in (("Tew", T * wew), ("ew", wew), ("Tsl", T * wsl), ("sl", wsl),
                              ("Tmm", T * m), ("mm", m)):
                pw[name].append(arr[s5])
            wem = ne * nH * V
            zs = zmet / zsun_t if zmet is not None else None
            zf = xfe / fesun_t if xfe is not None else None
            present["z_ew"], present["z_fe_ew"] = zs is not None, zf is not None
            if s5.any():
                pw["w_em"].append(wem[s5])
                for kz, zz in (("z_ew", zs), ("z_fe_ew", zf)):
                    if zz is not None:
                        pw[kz].append((wem * zz)[s5])
            B = _Idx(r, eb, nbb)
            B.acc(Sb, "m", m, phase)
            B.acc(Sb, "V", V, phase)
            B.acc(Sb, "Tm", T * m, phase)
            if pe is not None:
                Q = _Idx(r, pe, npe)
                _phase_sums(Sq, "mock", Q, m, T, ne, V, phase, (H.GAM - 1) * rho * u_int)
                Q.acc(Sq, "zw", wem, phase)
                if zs is not None:
                    Q.acc(Sq, "zz", wem * zs, phase)
                if zf is not None:
                    Q.acc(Sq, "zf", wem * zf, phase)
            ipp = tpm.shell_index(r, pe) if pe is not None else A.idx.astype(np.int16)
            if phase.any():
                nebuf.append(ne[phase])
                iabuf.append(A.idx[phase].astype(np.int16))
                ipbuf.append(ipp[phase])
                if cum_mock is not None:
                    cum_mock.add(r[phase], m[phase])
        del g
    stats["chunks"]["mock"], stats["rows"]["mock"] = n_ch, n_rows
    stats["median_buffer_bytes"] += int(sum(x.nbytes for x in nebuf + iabuf + ipbuf))
    stats["pairwise_buffer_bytes"] += int(sum(x.nbytes for v in pw.values() for x in v))
    ne_all, ia, ip = _cat(nebuf), _cat(iabuf), _cat(ipbuf)
    ne_med_l = _shell_median(ne_all, ia, nb)
    with np.errstate(invalid="ignore", divide="ignore"):
        out = dict(ne_med=ne_med_l,
                   T_sl=S["Twsl"] / S["wsl"] / H.KEV_K,
                   T_mw=S["Tm"] / S["m"] / H.KEV_K)
        tot = {k: _pairwise(pw[k]) for k in ("Tew", "ew", "Tsl", "sl", "Tmm", "mm")}
        out["t_ew_r500c_kev"] = float(tot["Tew"] / tot["ew"]) / H.KEV_K
        out["t_sl_r500c_kev"] = float(tot["Tsl"] / tot["sl"]) / H.KEV_K
        out["t_mw_r500c_kev"] = float(tot["Tmm"] / tot["mm"]) / H.KEV_K
        out["mgas_mock_lt_r500c_msun"] = float(tot["mm"])
        out["metal_mock"] = _metal_summary(pw)
        if min_filling is not None:
            _, _, omit = H.shell_gas_density(S["m"], S["V"], vol, density, min_filling)
            for k in ("ne_med", "T_sl", "T_mw"):
                out[k][omit] = np.nan
    rho_b, T_b = _profile_from_sums(Sb["m"], Sb["V"], Sb["Tm"], Sb["m"], vol_b, density,
                                    min_filling, True)
    out["barnes21_mock"] = (cb, H._m_nt(cb, rho_b, T_b))
    if pe is not None:
        out["tp_mock"] = _phase_from_sums(Sq, "mock", _shell_median(ne_all, ip, npe), pe,
                                          density)
        out["tp_metal_mock"] = _metal_from_sums(Sq, present)
    return out
