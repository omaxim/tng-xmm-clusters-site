Source code for tngxmm.sim.truth_sphere

"""Spherical hydrostatic truth: every particle within a sphere about the halo centre.

Selected by ``sim.truth_selection_hse = 'sphere'``.  Why: the generation computes the intrinsic truth (the HSE masses of
:mod:`tngxmm.sim.compute_hse_mass`, the curves of :mod:`tngxmm.sim.truth_profile`)
from the halo's FoF members.  At z > 0.7 the FoF gas fills only 0.63-0.82 of the
R500c shell, and its members near the group boundary are the denser gas, so the FoF
truth falls ~16 % below the spherical (zoom) truth at R500c (docs/dev/DECISIONS.md,
"Node-pilot-2b fixes").  The truth is therefore recomputed here from ALL particles
(gas, dark matter, stars, black holes) inside a sphere about ``GroupPos``, in every
simulation.  Photons, maps and the ``*_tngref`` columns stay on the FoF gas, and the
``*_mock`` estimators keep the mock's own cells (with the loader 'fof', the FoF members inside the sphere;
with the production loader 'cutout', the whole sphere), which hold every mock cell because the sphere is larger than the mock's 2 R200c
clip).

The stage runs AFTER the generation, per (simulation, snapshot), outside the
generation's memory budget, in three steps:

1. **Select** (once per snapshot; persisted).  For every target halo the global
   snapshot indices of the particles within ``r_cut`` of ``GroupPos``
   (minimum-image distance in the periodic box), per particle type, are written to
   ``<tree>/truth_cutouts/<sim>/snap_<snap:03d>.h5`` (:func:`write_cutouts`):
   sorted int64 per halo and type (delta-encoded), with the centre, radius, box,
   counts and a sha256 per index array.  ``r_cut = max(f R200c, r_max)`` with ``f`` the spec field
   ``sim.truth_sphere_r200c`` (3 in the campaign) and ``r_max = 1.02 max(3.15 R500c, 2 R200c)``
   the outermost radius any truth estimator reads (:func:`truth_rmax_kpc`).

   * Periodic boxes (TNG300/TNG100/TNG50): a snapshot's chunk files are consecutive
     slices of the particle list (FoF order, then the fuzz), not spatial
     sub-volumes, so a sphere draws from many chunks and the selection of every
     chunk must be accumulated before any profile is computed.  Each chunk's
     ``Coordinates`` are read once, wrapped into [0, L) and binned on a voxel grid;
     ONE small ``cKDTree`` of the snapshot's halo centres built with ``boxsize = L``
     (only the full box is periodic) is queried per occupied voxel, so a voxel
     knows every sphere that can reach it (:class:`SphereSelector`); every
     candidate pair is then decided by the exact
     minimum-image test ``|x - c - L round((x - c) / L)| <= r`` (the brute-force
     definition, :func:`sphere_rows_brute`), so a cell may belong to several
     halos' spheres and the result does not depend on how the snapshot is split
     into chunks (:func:`stream_box`, a pool over chunks with a deterministic,
     chunk-ordered merge).
   * TNG-Cluster: the halo's ORIGINAL ZOOM (its FoF range and outer-fuzz range of
     the offsets file, ``loadOriginalZoom``), cut to the sphere
     (:func:`select_zoom`, inside the halo's truth worker: one zoom per process).  Particles of other zooms are never mixed in: each zoom
     is a separate simulation in the parent volume.  The sphere is flagged when it
     reaches low-resolution dark matter (``PartType2`` within the truth radius
     ``r_max``: attribute ``sphere_contaminated``; counts and the nearest distance
     are recorded either way).

2. **Truth** (per halo; resumable).  The fields of the selected rows are read
   (only those rows: block reads of sorted index runs per chunk), wrapped to their
   minimum image about ``GroupPos`` (bit-identical to the generation's
   ``periodic_wrap`` for every particle that needs no wrap) and handed to
   :func:`~tngxmm.sim.compute_hse_mass.compute_hse_truth` through a HaloSource
   (:class:`SphereSource`) with ``selection='sphere'`` and the mock selection
   ``'fof'`` (FoF members inside the sphere).  The result REPLACES the halo's
   ``truth_profile.h5`` (format 3, ``truth_selection = 'sphere'`` and the
   ``sphere_*`` attributes; written atomically).  A halo whose file already holds
   the spherical truth of the same spec hash is skipped (the file is the done
   marker); ``force`` recomputes.

   Truth modes (``truth_mode``, CLI ``--truth-mode``).  ``memory`` holds every particle of
   the sphere (the reference above; 0.25-0.4 GB per million particles).  ``streamed`` reads
   the sphere's rows chunk by chunk from the snapshot and accumulates per-shell sums
   (:mod:`tngxmm.sim.compute_hse_stream`): the same truth (bit-identical except the
   cumulative particle masses, 1e-10; DECISIONS "Streamed spherical truth") with a memory
   that does not grow with the dark matter, ~45 GB for a TNG50 halo-0 sphere (1.1e9
   particles) instead of ~450 GB.  ``auto`` (default) streams a sphere above
   :data:`STREAM_ABOVE_PARTICLES` particles; a streamed sphere is never gathered.  A
   streamed file carries the attribute ``sphere_truth_mode = 'streamed'`` (absent from an
   in-memory file).

   Fields come either from the stream itself (mode ``stream``, read in the same
   pass as the coordinates) or from the persisted cutouts (mode ``cutouts``: the
   snapshot pass is never repeated); both give the same arrays in the same order,
   hence the same truth bit for bit (tests/unit/test_sim_truth_sphere.py).  With
   ``stream_fields=False`` a stream pass only writes the cutouts and the truth
   reads its fields from them: a zoom halo by halo (its rows are two contiguous
   ranges), a box in GATHER passes (:func:`gather_fields`: each chunk read once for
   the union of the rows of a batch of halos whose fields fit ``gather_gb``; a
   sphere's rows are scattered over most chunks of a box, so reading them halo by
   halo would read every chunk once per halo).  The production setting for the
   boxes (memory bounded by ``gather_gb`` instead of the snapshot's whole set of
   spheres).

3. **Apply** (cheap, idempotent): every ``ok`` row of the tree's results CSVs
   (``results_<sim>_snap_<snap>.csv``) and its view's ``obs_meta.json`` get the
   truth columns recomputed from the spherical file
   (:func:`~tngxmm.sim.truth_profile.hse_from_truth_profile`, then
   :func:`~tngxmm.sim.generate_view.view_truth_columns` with the view's z_obs:
   exactly the generation's arithmetic).  Only values change (no column is added,
   so a resumed generation appends aligned rows); the first original CSV is kept
   as ``<csv>.pre_sphere_truth.bak``; ``obs_meta.json`` records
   ``hse_truth_selection = 'sphere'``.

Commands: ``python -m tngxmm.core.runner campaign truth-sphere`` (CLI),
``slurm/truth_sphere.sh`` (node job), the Kedro node ``generate_views`` (after
each run's pool).  Acceptance: campaign check C17.

References
----------
illustristng : TNG300-1/TNG100-1/TNG50-1 snapshots, group catalogues and offsets.
tngcluster : TNG-Cluster original zooms (offsets ``OriginalZooms``).
illustris_python : catalogue reader and the snapshot file layout.
scipy : ``scipy.spatial.cKDTree`` (periodic tree of the halo centres).
h5py, numpy : chunk reads and the cutout files.

def truth_rmax_kpc(r500_kpc: float, r200_kpc: float, margin: float = RMAX_MARGIN) -> float:
    """Outermost radius [physical kpc] any truth estimator reads: the HSE shells (to
    3 R500c, cells read to 1.05 x that) and the mock's 2 R200c clip sphere."""
    return margin * max(HSE_RMAX_R500 * r500_kpc, MOCK_CLIP_R200 * r200_kpc)

def cutout_radius_kpc(r500_kpc: float, r200_kpc: float, r200c_factor: float) -> float:
    """Radius [physical kpc] of the stored cutout and of the truth's particles:

    the origin: ``sphere`` Euclidean distance <= extent, ``box`` the axis-aligned cube
    max |d_i| <= extent (``extent`` the half-side)."""
    import numpy as np

    if shape == "sphere":
        return (d * d).sum(1) <= float(extent) ** 2
    if shape == "box":
        return np.abs(d).max(axis=1) <= float(extent)
    raise ValueError(f"shape must be one of {SHAPES}, not {shape!r}")

def sphere_rows_brute(x: Any, centre: Any, radius: float, box: float,
                      shape: str = "sphere") -> Any:
    """Sorted row indices of ``x`` [code units] within ``radius`` of ``centre`` with
    the minimum-image distance (the reference definition every selection here
    reproduces exactly; the same formula as the snapshot reader's radius cut).
    ``shape='box'``: inside the axis-aligned cube of half-side ``radius`` about ``centre``
    (minimum image per axis)."""
    import numpy as np

    d = np.asarray(x, dtype=np.float64) - np.asarray(centre, dtype=np.float64)
    d -= box * np.round(d / box)
    return np.flatnonzero(inside_shape(d, radius, shape))




def _wrap(x: Any, box: float) -> Any:
    """``x`` mod ``box`` in [0, box) (cKDTree's requirement; a tiny negative value whose
    modulo rounds to ``box`` is folded to 0)."""
    import numpy as np

    w = np.mod(np.asarray(x, dtype=np.float64), box)
    w[w >= box] = 0.0
    return w

class SphereSelector:
    """Rows of a coordinate block inside each of a set of spheres (periodic box).

    One ``cKDTree`` of the wrapped sphere centres with ``boxsize = box`` (the snapshot's
    halo centres; only the full box is periodic).  The rows are binned on a grid of
    cubic voxels (edge about half the largest radius); the tree is queried once per
    OCCUPIED VOXEL (its centre, radius = largest sphere radius + the voxel's half
    diagonal), so every sphere that can reach a voxel is found, however many overlap
    there; then each candidate (row, sphere) pair is decided by the exact test of
    :func:`sphere_rows_brute`.  The result equals the brute-force selection exactly; a
    row may fall in several spheres.  (A query per row instead costs ~1 microsecond per
    row: 30 s for the 25 M gas cells of a dense TNG300 chunk, against a few seconds.)

    ``shape='box'``: the "radii" are the half-sides of axis-aligned cubes; the voxel
    search uses the circumscribed radius (sqrt(3) x the half-side) and the exact test is
    the per-axis minimum-image bound of :func:`sphere_rows_brute`."""

    #: relative inflation of the tree radius (the exact test decides)
    INFLATE = 1e-6
    #: voxel edge in units of the largest sphere radius
    VOXEL_OVER_R = 0.5
    #: at most this many voxels per axis
    MAX_VOXELS = 256

    def __init__(self, centres: Any, radii: Any, box: float, shape: str = "sphere") -> None:
        """Selector of the particles inside the spheres (``shape='sphere'``, radius) or cubes (``shape='box'``,
        half-side) of ``radii`` [same units as the coordinates] about ``centres`` in a periodic box of side ``box``.
        Builds the periodic ``cKDTree`` of the centres and the voxel grid on which each coordinate chunk is binned."""
        import numpy as np
        from scipy.spatial import cKDTree

        if shape not in SHAPES:
            raise ValueError(f"shape must be one of {SHAPES}, not {shape!r}")
        self.shape = shape
        self.centres = np.atleast_2d(np.asarray(centres, dtype=np.float64))
        self.radii = np.atleast_1d(np.asarray(radii, dtype=np.float64))
        # farthest point of each shape from its centre
        self.reach = self.radii * (math.sqrt(3.0) if shape == "box" else 1.0)
        self.box = float(box)
        self.n = len(self.centres)
        rmax = float(self.reach.max()) if self.n else 0.0
        self.tree = cKDTree(_wrap(self.centres, self.box), boxsize=self.box) if self.n else None
        ng = int(max(1, min(self.MAX_VOXELS,
                            math.floor(self.box / max(self.VOXEL_OVER_R * rmax, 1e-30)))))
        self.ng, self.cell = ng, self.box / ng
        # a point may round into a neighbouring voxel: one voxel edge of slack on top of
        # the half diagonal
        self.rq = min((rmax + self.cell * (math.sqrt(3) / 2 + 1)) * (1 + self.INFLATE),
                      self.box * math.sqrt(3) / 2)
        # voxels any sphere can reach (one tree query per voxel of the grid, once): the
        # rows of the other voxels are dropped before any sort
        self.vmask = np.zeros(ng ** 3, bool)
        if self.n:
            step = 1 << 20
            for a in range(0, ng ** 3, step):
                v = np.arange(a, min(a + step, ng ** 3), dtype=np.int64)
                vc = (np.stack([v // (ng * ng), (v // ng) % ng, v % ng], axis=1) + 0.5) * self.cell
                d, _ = self.tree.query(vc, k=1, distance_upper_bound=self.rq)
                self.vmask[a:a + len(v)] = np.isfinite(d)

    def select(self, x: Any) -> list[Any]:
        """Per sphere, the sorted int64 rows of ``x`` [code units] inside it."""
        import numpy as np

        empty = [np.zeros(0, np.int64) for _ in range(self.n)]
        if self.n == 0 or len(x) == 0:
            return empty
        ng = self.ng
        v = np.minimum((_wrap(x, self.box) / self.cell).astype(np.int64), ng - 1)
        key = (v[:, 0] * ng + v[:, 1]) * ng + v[:, 2]
        del v
        cand = np.flatnonzero(self.vmask[key])
        if not len(cand):
            return empty
        key = key[cand]
        idx = np.argsort(key, kind="stable")
        order, ks = cand[idx], key[idx]
        del key, cand, idx
        vox, first = np.unique(ks, return_index=True)
        last = np.append(first[1:], len(ks))
        del ks
        vc = np.stack([vox // (ng * ng), (vox // ng) % ng, vox % ng], axis=1)
        vc = (vc + 0.5) * self.cell
        lists = self.tree.query_ball_point(vc, self.rq)
        hv = [[] for _ in range(self.n)]          # per sphere: its candidate voxels
        for iv, lst in enumerate(lists):
            for h in lst:
                hv[h].append(iv)
        out = []
        for i in range(self.n):
            if not hv[i]:
                out.append(np.zeros(0, np.int64))
                continue
            iv = np.asarray(hv[i], np.int64)
            # a sphere may still miss a candidate voxel: keep those within r_i + the slack
            d = vc[iv] - self.centres[i]
            d -= self.box * np.round(d / self.box)
            iv = iv[np.sqrt((d * d).sum(1)) <= self.reach[i] + (self.rq - self.reach.max())]
            if not len(iv):
                out.append(np.zeros(0, np.int64))
                continue
            r = np.concatenate([order[first[k]:last[k]] for k in iv])
            d3 = np.asarray(x[r], dtype=np.float64) - self.centres[i]
            d3 -= self.box * np.round(d3 / self.box)
            out.append(np.sort(r[inside_shape(d3, self.radii[i], self.shape)]).astype(np.int64))
        return out

def _runs(rows: Any, gap: int = BLOCK_GAP_ROWS) -> list[tuple[int, int, int, int]]:
    """``(a, b, i0, i1)``: contiguous read blocks [a, b) covering ``rows[i0:i1]``
    (sorted), two rows closer than ``gap`` sharing a block."""
    import numpy as np

    if not len(rows):
        return []
    br = np.flatnonzero(np.diff(rows) > gap) + 1
    starts = np.concatenate([[0], br])
    ends = np.concatenate([br, [len(rows)]])
    return [(int(rows[s]), int(rows[e - 1]) + 1, int(s), int(e)) for s, e in zip(starts, ends)]


def _metals_block(ds: Any, a: int, b: int, columns: Any = METALS_COLUMNS) -> Any:
    """Rows [a, b) of a ``GFM_Metals`` dataset, columns :data:`METALS_COLUMNS` (two slice
    reads, not the 9-column block); ``columns=None``: every column (the cutout gas
    loader needs the elements C to Fe of the photon spectra)."""
    import numpy as np

    if columns is None:
        return ds[a:b]
    h, fe = columns
    if ds.shape[1] <= fe:
        return ds[a:b, h:h + 1]
    return np.concatenate([ds[a:b, h:h + 1], ds[a:b, fe:fe + 1]], axis=1)

def read_group_rows(grp: Any, rows: Any, fields: Sequence[str],
                    metals: Any = METALS_COLUMNS) -> dict[str, Any]:
    """``fields`` of the sorted local ``rows`` of an HDF5 ``PartType<N>`` group, native
    dtypes, in row order; absent fields are absent keys; ``GFM_Metals`` as its H and Fe
    columns (:data:`METALS_COLUMNS`), shape (N, 2) (only H, shape (N, 1), for a table with
    fewer than 9 columns).  ``metals=None`` reads every ``GFM_Metals`` column."""
    import numpy as np

    rows = np.asarray(rows, np.int64)
    out: dict[str, Any] = {}
    blocks = _runs(rows)
    for f in fields:
        if f not in grp:
            continue
        ds = grp[f]
        parts = []
        for a, b, i0, i1 in blocks:
            blk = _metals_block(ds, a, b, metals) if f == "GFM_Metals" else ds[a:b]
            parts.append(blk[rows[i0:i1] - a])
        if parts:
            out[f] = np.concatenate(parts) if len(parts) > 1 else parts[0]
        else:
            shape = ((0, 2 if ds.shape[1] > METALS_COLUMNS[1] else 1)
                     if f == "GFM_Metals" and metals is not None else (0, *ds.shape[1:]))
            out[f] = np.zeros(shape, ds.dtype)
    return out

    def __init__(self, base_path: str | Path, snap: int, catalogue: Any = None) -> None:

        import h5py

def _stream_chunk(c: int) -> dict[str, Any]:
    """One chunk: per type the rows inside each sphere (global indices) and, with
    ``fields``, those rows' fields; timings and bytes for the throughput report."""
    import h5py
    import numpy as np

    st = _STREAM
    store, sel, fields_on, ptypes = st["store"], st["selector"], st["fields"], st["ptypes"]
    t0 = time.time()
    res: dict[str, Any] = {"chunk": c, "sel": {}, "bytes": 0, "t_coord": 0.0, "t_select": 0.0,
                           "t_fields": 0.0, "rows": 0}
    with h5py.File(store.chunk_path(c), "r") as f:
        for pt in ptypes:
            n = int(store.chunk_start[c + 1, pt] - store.chunk_start[c, pt])
            if n == 0 or f"PartType{pt}" not in f:
                continue
            g = f[f"PartType{pt}"]
            t1 = time.time()
            x = g["Coordinates"][()]
            t2 = time.time()
            res["bytes"] += x.nbytes
            res["rows"] += len(x)
            local = sel.select(x)
            del x
            t3 = time.time()
            res["t_coord"] += t2 - t1
            res["t_select"] += t3 - t2
            if not any(len(r) for r in local):
                continue
            start = int(store.chunk_start[c, pt])
            data = None
            if fields_on:
                allr = np.unique(np.concatenate([r for r in local if len(r)]))
                data = read_group_rows(g, allr, _fields_for(pt, store.mass_table))
                res["t_fields"] += time.time() - t3
            per = []
            for i, r in enumerate(local):
                if not len(r):
                    continue
                item = {"halo": i, "gidx": r + start}
                if data is not None:
                    pos = np.searchsorted(allr, r)
                    item["fields"] = {k: v[pos] for k, v in data.items()}
                per.append(item)
            res["sel"][pt] = per
    res["seconds"] = time.time() - t0
    return res

@cites("illustristng", "scipy", "h5py")
def stream_box(store: SnapshotStore, spheres: list[HaloSphere], *, workers: int = 1,
               fields: bool = True, chunks: Sequence[int] | None = None,
               echo: Callable[[str], Any] = print, shape: str = "sphere",
               ptypes: Sequence[int] = PTYPES) -> dict[str, Any]:
    """Cut every sphere out of a periodic snapshot in ONE pass over its chunk files.

    Fills ``sphere.gidx`` (sorted global rows per type) and, with ``fields``, returns
    the selected rows' fields per sphere (``{'fields': {halo_id: {ptype: {...}}}``)
    plus the throughput statistics.  ``chunks`` restricts the pass (validation and
    tests only: the result is then the selection of those chunks, flagged incomplete).
    The merge is in chunk order whatever the number of workers.  ``shape='box'``: the
    selections are axis-aligned cubes of half-side ``r_cut_ckpc_h`` (the mock gas,
    :mod:`tngxmm.sim.mock_cutout`); ``ptypes``: the particle types read (the truth reads all
    of :data:`PTYPES`, the mock gas type 0 only: the coordinates of the other types are
    never read)."""
    import numpy as np

    sel = SphereSelector([s.centre for s in spheres], [s.r_cut_ckpc_h for s in spheres],
                         store.box, shape)
    pre = attr_prefix(shape)
    ptypes = tuple(int(p) for p in ptypes)
    todo = list(range(store.n_chunks)) if chunks is None else [int(c) for c in chunks]
    _STREAM.update(store=store, selector=sel, fields=bool(fields), ptypes=ptypes)
    acc: list[dict[int, list]] = [{pt: [] for pt in ptypes} for _ in spheres]
    facc: list[dict[int, dict[str, list]]] = [{pt: {} for pt in ptypes} for _ in spheres]
    stats = {"chunks": len(todo), "bytes": 0, "rows": 0, "t_coord": 0.0, "t_select": 0.0,
             "t_fields": 0.0, "chunk_seconds": []}
    t0 = time.time()

    def take(res: dict) -> None:
        for k in ("bytes", "rows", "t_coord", "t_select", "t_fields"):
            stats[k] += res[k]
        stats["chunk_seconds"].append(round(res["seconds"], 3))
        for pt, items in res["sel"].items():
            for it in items:
                acc[it["halo"]][pt].append(it["gidx"])
                for k, v in it.get("fields", {}).items():
                    facc[it["halo"]][pt].setdefault(k, []).append(v)

    try:
        if workers > 1 and len(todo) > 1:
            with _pool(workers) as pool:
                for i, res in enumerate(pool.map(_stream_chunk, todo)):
                    take(res)
                    if (i + 1) % 50 == 0:
                        echo(f"  {i + 1}/{len(todo)} chunks, {time.time() - t0:.0f} s")
        else:
            for i, c in enumerate(todo):
                take(_stream_chunk(c))
                if (i + 1) % 50 == 0:
                    echo(f"  {i + 1}/{len(todo)} chunks, {time.time() - t0:.0f} s")
    finally:
        _STREAM.clear()
    stats["seconds"] = time.time() - t0
    out_fields: dict[int, dict] = {}
    for s, a, fa in zip(spheres, acc, facc):
        s.gidx = {pt: (np.concatenate(a[pt]) if a[pt] else np.zeros(0, np.int64))
                  for pt in ptypes}
        s.attrs.update({f"{pre}_source": "box-stream", f"{pre}_complete": chunks is None,
                        f"{pre}_truncated": False, f"{pre}_chunks_scanned": len(todo)})
        if fields:
            out_fields[s.halo_id] = {pt: {k: np.concatenate(v) for k, v in fa[pt].items()}
                                     for pt in ptypes if s.gidx[pt].size}
    return {"fields": out_fields if fields else None, "stats": stats}

def memory_batches(spheres: list[HaloSphere], store: Any, gather_gb: float
                   ) -> list[list[HaloSphere]]:
    """``spheres`` in consecutive batches whose gathered fields stay below ``gather_gb``
    (a single sphere larger than that is a batch of its own)."""
    out: list[list[HaloSphere]] = []
    cur: list[HaloSphere] = []
    tot = 0.0
    for s in spheres:
        b = sum(len(s.gidx.get(pt, ())) * BYTES_PER_PARTICLE[pt] for pt in PTYPES) / 1e9
        if cur and tot + b > gather_gb:
            out.append(cur)
            cur, tot = [], 0.0
        cur.append(s)
        tot += b
    if cur:
        out.append(cur)
    return out




_GATHER: dict[str, Any] = {}


def _gather_chunk(c: int) -> dict[str, Any]:
    """One chunk: the fields of the union of the batch's rows in it, read once, then
    split per sphere."""
    import h5py
    import numpy as np

    st = _GATHER
    store, spheres = st["store"], st["spheres"]
    t0 = time.time()
    out: dict[str, Any] = {"chunk": c, "per": {}, "rows": 0}
    lo, hi = store.chunk_start[c], store.chunk_start[c + 1]
    pieces = {}
    for pt in PTYPES:
        part = []
        for i, s in enumerate(spheres):
            g = s.gidx.get(pt)
            if g is None or not len(g):
                continue
            a, b = np.searchsorted(g, [lo[pt], hi[pt]])
            if b > a:
                part.append((i, g[a:b] - lo[pt]))
        if part:
            pieces[pt] = part
    if not pieces:
        out["seconds"] = time.time() - t0
        return out
    with h5py.File(store.chunk_path(c), "r") as f:
        for pt, part in pieces.items():
            allr = np.unique(np.concatenate([r for _, r in part]))
            data = read_group_rows(f[f"PartType{pt}"], allr, _fields_for(pt, store.mass_table))
            out["rows"] += len(allr)
            for i, r in part:
                pos = np.searchsorted(allr, r)
                out["per"].setdefault(i, {})[pt] = {k: v[pos] for k, v in data.items()}
    out["seconds"] = time.time() - t0
    return out

@cites("illustristng", "h5py")
def gather_fields(store: SnapshotStore, spheres: list[HaloSphere], *, workers: int = 1,
                  echo: Callable[[str], Any] = print) -> dict[str, Any]:
    """The truth's fields of the stored rows of ``spheres`` (their ``gidx``), in ONE pass
    over the chunk files that hold any of them: each chunk read once for the union of
    the rows, in chunk order whatever the number of workers.  The arrays equal, bit for
    bit and in order, those of :meth:`SnapshotStore.read` per sphere (the stream's
    fields as well).  Returns ``{'fields': {halo_id: {ptype: {...}}}, 'stats': {...}}``."""
    import numpy as np

    t0 = time.time()
    todo = [c for c in range(store.n_chunks)
            if any(len(s.gidx.get(pt, ())) and np.searchsorted(
                s.gidx[pt], store.chunk_start[c + 1, pt]) > np.searchsorted(
                s.gidx[pt], store.chunk_start[c, pt]) for s in spheres for pt in PTYPES)]
    _GATHER.update(store=store, spheres=spheres)
    acc: list[dict[int, dict[str, list]]] = [{pt: {} for pt in PTYPES} for _ in spheres]
    rows = 0
    try:
        if workers > 1 and len(todo) > 1:
            with _pool(workers) as pool:
                it = list(pool.map(_gather_chunk, todo))
        else:
            it = [_gather_chunk(c) for c in todo]
    finally:
        _GATHER.clear()
    for res in it:
        rows += res["rows"]
        for i, per in res["per"].items():
            for pt, d in per.items():
                for k, v in d.items():
                    acc[i][pt].setdefault(k, []).append(v)
    out = {s.halo_id: {pt: {k: np.concatenate(v) for k, v in a[pt].items()}
                       for pt in PTYPES if a[pt]} for s, a in zip(spheres, acc)}
    stats = {"halos": len(spheres), "chunks": len(todo), "rows": rows,
             "seconds": round(time.time() - t0, 2)}
    echo(f"  gather: {len(spheres)} halos, {len(todo)} chunks, {rows / 1e6:.1f} M rows, "
         f"{stats['seconds']:.0f} s")
    return {"fields": out, "stats": stats}

def select_zoom(store: Any, sphere: HaloSphere, grp: dict, *, fields: bool = True,
                ptypes: Sequence[int] = PTYPES, gas_diagnostics: bool = False
                ) -> dict[int, dict[str, Any]] | None:
    """Cut one halo's sphere (or cube, ``sphere.shape == 'box'``) out of its original zoom
    (TNG-Cluster, or a fixture cutout): fills ``sphere.gidx`` and the contamination
    attributes; with ``fields`` returns the selected rows' fields per type.

    ``ptypes``: the particle types cut (the mock gas: ``(0,)``).  The low-resolution dark
    matter of the zoom (PartType2) is always read for the contamination attributes: the
    nearest distance (Euclidean) and, inside the shape, the count and mass; a sphere also
    counts those within ``rmax_kpc`` (``sphere_contaminated``), a cube those within the
    inscribed ball of radius the half-side (``box_lowres_n_ball``) and flags ``box_contaminated``
    when any lies inside the cube.  ``gas_diagnostics`` (cube only): the coarse-gas census and
    the high-resolution coverage of the cube and of its three projections
    (:func:`tngxmm.sim.mock_cutout.box_gas_diagnostics`)."""
    import numpy as np

    shape = sphere.shape
    pre = attr_prefix(shape)
    rng = store.zoom_ranges(grp)
    gc = store.groupcat_header()
    h, a = float(gc["HubbleParam"]), float(gc["Time"])
    out: dict[int, dict[str, Any]] = {}
    diag = gas_diagnostics and shape == "box"
    allow_ref = diag and "AllowRefinement" in store.fields_present(0)
    for pt in (*[int(p) for p in ptypes], LOWRES):
        keep = []
        rmin, n_cut, n_max, m_cut = math.inf, 0, 0, 0.0
        gd: dict[str, list] = {"off": [], "m": [], "ar": []}
        for start, n in rng.get(pt, []):
            for b0 in range(start, start + n, COORD_BLOCK_ROWS):
                b1 = min(start + n, b0 + COORD_BLOCK_ROWS)
                want = ["Coordinates"] + (["Masses"] if pt == LOWRES or (diag and pt == 0)
                                          else []) + (["AllowRefinement"]
                                                      if allow_ref and pt == 0 else [])
                blk = store.read(pt, np.arange(b0, b1, dtype=np.int64), want)
                if "Coordinates" not in blk or not len(blk["Coordinates"]):
                    continue
                if pt == LOWRES:          # contamination: distances of low-res DM
                    d = np.asarray(blk["Coordinates"], np.float64) - sphere.centre
                    d -= store.box * np.round(d / store.box)
                    r = np.sqrt((d * d).sum(1)) * a / h
                    if len(r):
                        rmin = min(rmin, float(r.min()))
                    if shape == "sphere":
                        inb = r <= sphere.r_cut_kpc
                        n_max += int((r <= sphere.rmax_kpc).sum())
                    else:                 # inside the cube; n_max: inside the inscribed ball
                        inb = inside_shape(d, sphere.r_cut_ckpc_h, "box")
                        n_max += int((r <= sphere.r_cut_kpc).sum())
                    n_cut += int(inb.sum())
                    m_cut += float(np.asarray(blk["Masses"], np.float64)[inb].sum()) * 1e10 / h
                    continue
                rows = sphere_rows_brute(blk["Coordinates"], sphere.centre,
                                         sphere.r_cut_ckpc_h, store.box, shape)
                keep.append(rows + b0)
                if diag and pt == 0 and len(rows):
                    d = np.asarray(blk["Coordinates"][rows], np.float64) - sphere.centre
                    d -= store.box * np.round(d / store.box)
                    gd["off"].append(d.astype(np.float32))
                    gd["m"].append(np.asarray(blk["Masses"][rows], np.float64))
                    if allow_ref:
                        gd["ar"].append(np.asarray(blk["AllowRefinement"][rows]))
        if pt == LOWRES:
            if shape == "sphere":
                sphere.attrs.update(sphere_lowres_rmin_kpc=rmin, sphere_lowres_n_rcut=n_cut,
                                    sphere_lowres_n_rmax=n_max,
                                    sphere_lowres_mass_rcut_msun=m_cut,
                                    sphere_contaminated=bool(n_max > 0))
            else:
                sphere.attrs.update(box_lowres_rmin_kpc=rmin, box_lowres_n_box=n_cut,
                                    box_lowres_n_ball=n_max, box_lowres_mass_box_msun=m_cut,
                                    box_contaminated=bool(n_cut > 0))
            continue
        g = np.sort(np.concatenate(keep)) if keep else np.zeros(0, np.int64)
        sphere.gidx[pt] = g
        if diag and pt == 0:
            from tngxmm.sim.mock_cutout import box_gas_diagnostics

            sphere.attrs.update(box_gas_diagnostics(
                np.concatenate(gd["off"]) if gd["off"] else np.zeros((0, 3), np.float32),
                np.concatenate(gd["m"]) if gd["m"] else np.zeros(0),
                np.concatenate(gd["ar"]) if gd["ar"] else None,
                half_ckpc_h=sphere.r_cut_ckpc_h))
        if fields and len(g):
            out[pt] = store.read(pt, g, _fields_for(pt, store.mass_table))
    # a fixture cutout is a ball of radius ``radius_ckpc_h``: a cube needs its corners inside
    reach = sphere.r_cut_ckpc_h * (math.sqrt(3.0) if shape == "box" else 1.0)
    trunc = isinstance(store, CutoutStore) and reach > store.radius_ckpc_h
    sphere.attrs.update({f"{pre}_source": "zoom" if store.kind == "snapshot" else "cutout",
                         f"{pre}_complete": True, f"{pre}_truncated": bool(trunc)})
    if trunc:
        sphere.attrs[f"{pre}_truncated_at_kpc"] = store.radius_ckpc_h * a / h
    return out if fields else None

def write_cutouts(path: str | Path, store: Any, sim: str, spheres: list[HaloSphere],
                  *, r200c_factor: float = 0.0, shape: str = "sphere",
                  ptypes: Sequence[int] = PTYPES, box_r500: float | None = None,

    ``shape='box'``: the cube files of the mock gas
    (``<tree>/mock_cutouts/<sim>/snap_<snap:03d>.h5``, format :data:`MOCK_CUTOUT_FORMAT`):
    per halo the half-side (``half_side_kpc``, ``half_side_ckpc_h``, ``half_side_r500c``),
    the corner distance and the index arrays of ``ptypes``; ``box_r500`` the half-side in
    R500c.  ``copy_existing``: the halos already in the file are copied group by group
    (no decompression, no checksum) instead of read back and re-encoded."""

    import h5py
    import numpy as np

    path = Path(path)
    path.parent.mkdir(parents=True, exist_ok=True)

    keep: dict[int, HaloSphere] = {}
    kept_ids: list[int] = []

        if copy_existing:
            with h5py.File(path, "r") as f:
                kept_ids = [int(f[n].attrs["halo_id"]) for n in f
                            if int(f[n].attrs["halo_id"]) not in new_ids]
        else:
            keep = read_cutouts(path)
    for s in spheres:
        keep[s.halo_id] = s
    gc = store.groupcat_header()
    tmp = path.with_name(f".{path.name}.{os.getpid()}.tmp")
    with h5py.File(tmp, "w") as f:
        at = dict(
            format=MOCK_CUTOUT_FORMAT if shape == "box" else CUTOUT_FORMAT,
            stage_version=STAGE_VERSION, sim=str(sim),
            snap=int(store.snap), source=store.describe(),
            selection="box" if shape == "box" else SELECTION,
            box_ckpc_h=float(store.box), h=float(gc["HubbleParam"]), a=float(gc["Time"]),
            z=float(gc["Redshift"]), n_chunks=int(store.n_chunks),
            index_definition="global snapshot index per particle type (offsets "
                             "FileOffsets/SnapByType; a fixture cutout: its row), stored as "
                             "PartType<N>/gidx_delta: gidx = cumsum(gidx_delta)",
            created_utc=dt.datetime.now(dt.timezone.utc).strftime("%Y-%m-%dT%H:%M:%SZ"))
        if shape == "box":
            at.update(mock_box_r500=float(box_r500 if box_r500 is not None else float("nan")),
                      ptypes=np.asarray(ptypes, np.int64),
                      r_cut_definition="axis-aligned cube about GroupPos, half-side mock_box_r500 "
                                       "x R500c, per-axis minimum-image bound |x - c| <= half-side")
        else:
            at.update(
                r_cut_definition=(f"max({r200c_factor:g} R200c, {RMAX_MARGIN} x max("
                                  f"{HSE_RMAX_R500} R500c, {MOCK_CLIP_R200} R200c)) about "
                                  "GroupPos, minimum-image distance"),
                truth_sphere_r200c=float(r200c_factor))
        f.attrs.update(at)
        if copy_existing and kept_ids:
            with h5py.File(path, "r") as src:
                for name in src:
                    if int(src[name].attrs["halo_id"]) in kept_ids:
                        src.copy(name, f)
        for hid in sorted(keep):
            s = keep[hid]
            g = f.create_group(f"halo_{hid}")
            if shape == "box":
                g.attrs.update(dict(
                    halo_id=int(hid), centre_ckpc_h=np.asarray(s.centre, float), shape="box",
                    half_side_ckpc_h=float(s.r_cut_ckpc_h), half_side_kpc=float(s.r_cut_kpc),
                    half_side_r500c=float(s.r_cut_kpc / s.r500_kpc), corner_kpc=float(s.rmax_kpc),
                    r500c_kpc=float(s.r500_kpc), r200c_kpc=float(s.r200_kpc), selection="box"))
            else:
                g.attrs.update(dict(halo_id=int(hid), centre_ckpc_h=np.asarray(s.centre, float),
                                    r_cut_ckpc_h=float(s.r_cut_ckpc_h),
                                    r_cut_kpc=float(s.r_cut_kpc), rmax_kpc=float(s.rmax_kpc),
                                    r500c_kpc=float(s.r500_kpc), r200c_kpc=float(s.r200_kpc),
                                    selection=SELECTION))
            for k, v in s.attrs.items():
                g.attrs[k] = v
            for pt in ptypes:
                arr = np.asarray(s.gidx.get(pt, np.zeros(0, np.int64)), np.int64)
                # delta-encoded (first index, then the gaps): sorted indices become small
                # numbers that gzip packs ~20x better than the indices themselves

                d.attrs["sha256"] = _sha(arr)
                d.attrs["encoding"] = "gidx = cumsum(gidx_delta)"
    os.replace(tmp, path)
    return path

def read_cutouts(path: str | Path, halo_ids: Sequence[int] | None = None,
                 verify: bool = True, ptypes: Sequence[int] | None = None
                 ) -> dict[int, HaloSphere]:

    or ``halo_ids``); ``verify`` checks every index array against its sha256.  ``ptypes``:

    import numpy as np

    with h5py.File(path, "r") as f:
        fmt = f.attrs.get("format")
        if fmt not in (CUTOUT_FORMAT, MOCK_CUTOUT_FORMAT):
            raise ValueError(f"{path}: format {fmt!r}")
        for name in f:
            g = f[name]
            hid = int(g.attrs["halo_id"])

                continue

    def particles(self, ptype: int, fields: Sequence[str], selection: str = SELECTION,
                  radius_ckpc_h: float | None = None, halo_id: int | None = None
                  ) -> dict[str, Any]:
        """The particles of type ``ptype``: ``selection='sphere'`` all of the sphere, ``'fof'`` the FoF members;
        ``radius_ckpc_h`` further clips about ``GroupPos`` (comoving ckpc/h).  ``{'count': 0}`` for an empty type;
        ``KeyError`` for a field the snapshot lacks, ``ValueError`` for another selection."""
        import numpy as np

            d = np.asarray(p["Coordinates"], np.float64) - np.asarray(self._grp["GroupPos"],
                                                                     np.float64)
            r_ok = (d * d).sum(1) <= float(radius_ckpc_h) ** 2
            m = r_ok if m is None else (m & r_ok)
        out = {f: (p[f] if m is None else p[f][m]) for f in fields}
        out["count"] = int(len(p["Coordinates"]) if m is None else m.sum())
        return out

class StreamedSphereSource(SphereSource):
    """HaloSource of one halo's sphere whose particles are read chunk by chunk from the
    store (:meth:`iter_particles`), never held together: the source of
    :func:`~tngxmm.sim.compute_hse_stream.compute_hse_truth_streamed`.  The chunks are
    consecutive slices of the sphere's sorted global rows, so a chunk touches one or two
    snapshot files; the arrays of a chunk equal the corresponding slice of what
    :func:`sphere_parts` reads (same reader, same minimum image), so a streamed truth sees
    the same cells in the same order as the in-memory one."""

    def __init__(self, store: Any, sphere: HaloSphere, *, snap: int, halo_id: int,
                 header: dict, groupcat_header: dict, group: dict, description: str,
                 read_workers: int = 1) -> None:
        """``store``: the snapshot store; ``sphere``: the halo's :class:`HaloSphere` (sorted global row indices per
        type); the other arguments as :class:`SphereSource`; ``read_workers``: forked processes that read chunks."""
        super().__init__({}, snap=snap, halo_id=halo_id, header=header,
                         groupcat_header=groupcat_header, group=group, description=description)
        self._store, self._sphere = store, sphere
        self.read_workers = max(int(read_workers), 1)

    def _readable(self, ptype: int) -> set[str]:
        st = self._store
        return set(_fields_for(int(ptype), st.mass_table)) & set(st.fields_present(int(ptype)))

    def read_slice(self, ptype: int, i0: int, i1: int, fields: Sequence[str],
                   selection: str, radius_ckpc_h: float | None) -> dict[str, Any] | None:
        """The selected rows of ``sphere.gidx[ptype][i0:i1]`` (one chunk): the fields, the
        coordinates at their minimum image about GroupPos, the FoF members only for
        ``selection='fof'`` (decided from the indices, before any read) and those inside
        ``radius_ckpc_h`` if given; ``None`` if no row is selected."""
        import numpy as np

        from tngxmm.sim.read_halo_source import minimum_image

        st, sph = self._store, self._sphere
        gi = sph.gidx[int(ptype)][i0:i1]
        if selection == "fof":
            gi = gi[np.asarray(st.in_fof(int(ptype), gi, self._grp, sph.halo_id), bool)]
            if not len(gi):
                return None
        want = tuple(dict.fromkeys(["Coordinates", *fields]))
        d = st.read(int(ptype), gi, want)
        if len(d.get("Coordinates", ())) != len(gi):
            raise RuntimeError(f"halo {sph.halo_id} PartType{ptype}: {len(gi)} rows "
                               f"selected, {len(d.get('Coordinates', ()))} read")
        d["Coordinates"] = minimum_image(d["Coordinates"], sph.centre, st.box)
        keep = None
        if radius_ckpc_h is not None:
            dd = np.asarray(d["Coordinates"], np.float64) - np.asarray(self._grp["GroupPos"],
                                                                       np.float64)
            keep = (dd * dd).sum(1) <= float(radius_ckpc_h) ** 2
        out = {f: (d[f] if keep is None else d[f][keep]) for f in fields}
        out["count"] = len(out[fields[0]])
        return out if out["count"] else None

    def iter_particles(self, ptype: int, fields: Sequence[str], selection: str = SELECTION,
                       radius_ckpc_h: float | None = None, chunk_rows: int = 4_000_000
                       ) -> Iterator[dict[str, Any]]:
        """The chunks, in sphere order.  With ``read_workers`` > 1 the chunks are read by
        forked processes ``read_workers`` + 2 slices ahead of the consumer (the order and the
        arrays are those of the serial read; a TNG50 sphere's rows are scattered over the whole
        snapshot, and one reader is latency bound at ~30 000 rows/s on a cold file system)."""
        if selection not in (SELECTION, "fof"):
            raise ValueError(f"a sphere source serves 'sphere' and 'fof', not {selection!r}")
        lack = [f for f in fields if f not in self._readable(ptype)]
        if lack:
            raise KeyError(f"fields {lack} absent from the snapshot")
        g = self._sphere.gidx.get(int(ptype))
        if g is None:
            return
        step = max(int(chunk_rows), 1)
        slices = [(i, min(i + step, len(g))) for i in range(0, len(g), step)]
        if self.read_workers <= 1 or len(slices) < 2:
            for i0, i1 in slices:
                out = self.read_slice(ptype, i0, i1, fields, selection, radius_ckpc_h)
                if out is not None:
                    yield out
            return
        from collections import deque

        _READ.update(src=self, ptype=int(ptype), fields=list(fields), selection=selection,
                     radius=radius_ckpc_h)
        try:
            with _pool(min(self.read_workers, len(slices))) as pool:
                todo, window = iter(slices), deque()
                for sl in todo:
                    window.append(pool.submit(_read_task, sl))
                    if len(window) >= self.read_workers + 2:
                        break
                while window:
                    out = window.popleft().result()
                    nxt = next(todo, None)
                    if nxt is not None:
                        window.append(pool.submit(_read_task, nxt))
                    if out is not None:
                        yield out
        finally:
            _READ.clear()

_READ: dict[str, Any] = {}

    st = _READ
    return st["src"].read_slice(st["ptype"], sl[0], sl[1], st["fields"], st["selection"],
                                st["radius"])

def sphere_parts(store: Any, sphere: HaloSphere, grp: dict,
                 fields: dict[int, dict[str, Any]] | None = None) -> dict[int, dict[str, Any]]:
    """The particles of a sphere per type (fields of the selected rows: given, from a
    stream, or read now from the store), with ``in_fof`` and ``Coordinates`` at their
    minimum image about GroupPos."""
    import numpy as np

    from tngxmm.sim.read_halo_source import minimum_image

    out: dict[int, dict[str, Any]] = {}
    for pt in PTYPES:
        g = sphere.gidx.get(pt)
        if g is None or not len(g):
            continue
        want = tuple(f for f in _fields_for(pt, store.mass_table)
                     if f in store.fields_present(pt))
        d = dict(fields[pt]) if fields is not None and pt in fields else store.read(pt, g, want)
        if len(d.get("Coordinates", ())) != len(g):
            raise RuntimeError(f"halo {sphere.halo_id} PartType{pt}: {len(g)} rows selected, "
                               f"{len(d.get('Coordinates', ()))} read")
        d["Coordinates"] = minimum_image(d["Coordinates"], sphere.centre, store.box)
        d["in_fof"] = np.asarray(store.in_fof(pt, g, grp, sphere.halo_id), bool)
        out[pt] = d
    return out

def selection_text(store: Any, sphere: HaloSphere, mock_selection: str = "fof") -> str:
    """The sentence recorded in the truth file that says which particles the sphere holds (the original zoom or the
    periodic box, within ``r_cut`` of GroupPos) and which cells the mock phase uses: with ``mock_selection`` ``'fof'``
    the FoF members inside the sphere, with ``'cutout'`` (the production loader) every gas cell of the sphere, FoF
    member or not, and otherwise the named selection.  Files written before release 1.1.2 carry the 'FoF members'
    wording whatever the loader was; they are not rewritten."""
    what = ("every particle of the halo's original zoom (loadOriginalZoom ranges)"
            if store.kind != "snapshot" or sphere.attrs.get("sphere_source") == "zoom"
            else "every particle of the periodic box (all FoF groups and fuzz)")
    if mock_selection == "fof":
        mock = "the FoF members inside the sphere"
    elif mock_selection == "cutout":
        mock = "every gas cell of the sphere (the cutout loader; FoF members or not)"
    else:
        mock = f"the gas of selection {mock_selection!r} inside the sphere"
    return (f"sphere: {what} within r_cut = {sphere.r_cut_kpc:.1f} kpc of GroupPos "
            f"(minimum-image distance); mock phase: {mock}")

def compute_sphere_truth(store: Any, sphere: HaloSphere, grp: dict, opts: Any, *,
                         fields: dict[int, dict[str, Any]] | None = None,
                         verbose: bool = False, truth_mode: str = "memory",
                         chunk_rows: dict[int, int] | int | None = None,
                         read_workers: int = 1) -> dict:
    """The truth of one sphere with the campaign's keywords
    (``generate_view.hse_truth_kwargs``), ``selection='sphere'`` and the truth profile on.

    ``truth_mode``: ``memory`` (default; every particle in memory,
    :func:`~tngxmm.sim.compute_hse_mass.compute_hse_truth`, the reference) or ``streamed``
    (:func:`~tngxmm.sim.compute_hse_stream.compute_hse_truth_streamed`: with ``fields`` None
    the particles are read chunk by chunk from ``store``, else the given fields are
    iterated in chunks; the result has the reference's layout plus ``hse['stream_stats']``;
    ``read_workers`` processes read the chunks ahead).  ``auto`` is resolved by the caller
    (:func:`resolve_truth_mode`)."""
    from tngxmm.sim.generate_view import hse_truth_kwargs

    if truth_mode not in ("memory", "streamed"):
        raise ValueError(f"truth_mode must be memory or streamed here, not {truth_mode!r}")
    gc = store.groupcat_header()
    h, a = float(gc["HubbleParam"]), float(gc["Time"])
    kw = hse_truth_kwargs(opts, grp, a, h, float(grp["Group_R_Crit200"]) * a / h)
    loader = str(kw["mock_selection"])
    # the mock's cells inside the sphere: the cutout loader's gas (the cube, within the shells the
    # estimators read) is all the gas of the sphere there
    kw.update(selection=SELECTION, profile=True,
              mock_selection=SELECTION if kw["mock_selection"] == "cutout" else kw["mock_selection"])
    common = dict(snap=store.snap, halo_id=sphere.halo_id, header=store.header(),
                  groupcat_header=gc, group=grp, description=selection_text(store, sphere, loader))
    if truth_mode == "streamed":
        from tngxmm.sim.compute_hse_stream import compute_hse_truth_streamed

        src = (StreamedSphereSource(store, sphere, read_workers=read_workers, **common)
               if fields is None else
               SphereSource(sphere_parts(store, sphere, grp, fields), **common))
        stats: dict = {}
        hse = compute_hse_truth_streamed(src, verbose=verbose, chunk_rows=chunk_rows,
                                         stats=stats, **kw)
        hse["stream_stats"] = stats
        return hse
    from tngxmm.sim.compute_hse_mass import compute_hse_truth

    src = SphereSource(sphere_parts(store, sphere, grp, fields), **common)
    return compute_hse_truth(src, verbose=verbose, **kw)

def fill_at_r500(hse: dict, phase: str = "nonsf") -> float:
    """Shell filling factor of a phase at R500c (log interpolation over the common grid)."""
    import numpy as np

    tp = hse["truth_profile"]
    r = np.asarray(tp["r_kpc"], float) / float(hse["summary"]["R500c"])
    fill = np.asarray(tp["gas"][phase]["fill"], float)
    ok = np.isfinite(fill)
    return float(np.interp(0.0, np.log(r[ok]), fill[ok])) if ok.sum() > 1 else float("nan")

def _done(tree: Path, sim: str, snap: int, hid: int, spec_hash: str) -> bool:
    """A halo is done when its truth-profile file holds the spherical truth of this

    from tngxmm.sim.truth_profile import FORMAT, path_for

    p = path_for(halo_dir_of(tree, sim, snap, hid))

        return False

    except OSError:

            and str(at.get("spec_hash")) == str(spec_hash))


# per-halo truth pool: shared state (forked workers)
_TRUTH: dict[str, Any] = {}


def _truth_pool(spheres: list[HaloSphere], fields: dict | None, workers: int,
                common: dict[str, Any], label: str = "cutouts") -> list[dict[str, Any]]:
    """:func:`_truth_task` over ``spheres`` (forked pool; results in input order);
    ``label``: where ``fields`` came from (``stream`` or ``cutouts``)."""
    _TRUTH.update(common, spheres=spheres, fields=fields, label=label)
    try:
        if workers > 1 and len(spheres) > 1:
            with _pool(min(workers, len(spheres))) as pool:
                return list(pool.map(_truth_task, range(len(spheres))))
        return [_truth_task(i) for i in range(len(spheres))]
    finally:
        _TRUTH.clear()


def _truth_task(i: int) -> dict[str, Any]:
    import resource

    from tngxmm.sim.generate_view import snapshot_info, write_halo_truth_profile

    st = _TRUTH
    s, store, opts = st["spheres"][i], st["store"], st["opts"]
    grp = st["rows"][s.halo_id]
    t0 = time.time()
    selected = None
    try:
        if s.halo_id in st["select_here"]:     # a zoom: its selection runs in this worker
            select_zoom(store, s, grp, fields=False)
            selected = {"gidx": s.gidx, "attrs": dict(s.attrs),
                        "seconds": round(time.time() - t0, 2)}
            tmode = resolve_truth_mode(st["truth_mode"], s)
            # in memory: the fields of the selected rows now (the selection's own read);
            # streamed: read chunk by chunk by the truth
            fields = zoom_fields(store, s) if tmode == "memory" and st["stream_fields"] else None
            label = "stream"
        else:
            tmode = resolve_truth_mode(st["truth_mode"], s)
            fields = None if st["fields"] is None else st["fields"].get(s.halo_id)
            label = st["label"]
        hse = compute_sphere_truth(store, s, grp, opts, fields=fields, truth_mode=tmode,
                                   read_workers=st["read_workers"])
        sstats = hse.pop("stream_stats", None)
        # 'stream': the fields were read in the selection pass; 'cutouts': read from the
        # persisted cutout rows (by this worker, or by a gather pass)
        extra = sphere_attrs(s, hse, st["cutouts"], st["tree"], opts.truth_sphere_r200c,
                             label if fields is not None else "cutouts", tmode)
        p = write_halo_truth_profile(hse, st["tree"], st["sim"], opts,
                                     runtime_s=time.time() - t0,
                                     snap_info=snapshot_info(int(store.snap)), extra_attrs=extra)
        s_ = hse["summary"]
        return {"halo_id": s.halo_id, "status": "ok", "path": str(p), "selected": selected,
                "seconds": round(time.time() - t0, 2),
                "fill_nonsf_r500c": extra["sphere_fill_nonsf_r500c"],
                "hse_atR500c": float(s_.get("barnes21_nosf_fit_mu_atR500c", math.nan)),
                "hse_M500self": float(s_.get("barnes21_nosf_fit_mu_M500self", math.nan)),
                "contaminated": bool(s.attrs.get("sphere_contaminated", False)),
                "counts": {pt: int(len(s.gidx.get(pt, ()))) for pt in PTYPES},
                "truth_mode": tmode, "stream": sstats,
                "maxrss_gb": resource.getrusage(resource.RUSAGE_SELF).ru_maxrss / 1e6}
    except Exception as e:                     # one halo never stops the snapshot
        return {"halo_id": s.halo_id, "status": f"error: {e!r}"[:300], "selected": selected,
                "seconds": round(time.time() - t0, 2)}

                 gather_gb: float = GATHER_GB, store: Any = None, truth_mode: str = "auto",
                 read_workers: int = 1, echo: Callable[[str], Any] = print) -> dict[str, Any]:
    """Spherical truth of the halos ``halo_ids`` of one snapshot of a campaign tree.

    ``mode``: ``stream`` (select from the snapshot, write the cutouts), ``cutouts``
    (read the persisted cutouts only; an absent halo is an error) or ``auto``
    (cutouts where stored, the snapshot pass for the others).  ``stream_fields``:
    read the fields in the stream pass (else the truth reads them from the cutouts
    afterwards: a zoom halo by halo, a box in snapshot-wide gather passes of at most
    ``gather_gb`` of fields each, :func:`gather_fields`).  ``workers``: truth processes;
    ``chunk_workers``: stream / gather processes.  ``chunks``: restrict a box pass
    (validation only).  ``truth_mode``: ``memory`` / ``streamed`` / ``auto`` per sphere
    (:func:`resolve_truth_mode`); a streamed sphere is never gathered: its truth process
    reads its rows chunk by chunk (memory independent of the sphere's size), with
    ``read_workers`` forked reader processes ahead of it (a box sphere's rows are scattered
    over the whole snapshot; one reader is latency bound).
    Returns the stage report (also written next to the cutout file)."""
    import resource

    from tngxmm.sim.generate_view import SimOptions

    if mode not in ("auto", "stream", "cutouts"):
        raise ValueError(f"mode must be auto, stream or cutouts, not {mode!r}")
    if truth_mode not in TRUTH_MODES:
        raise ValueError(f"truth_mode must be one of {TRUTH_MODES}, not {truth_mode!r}")
    opts = SimOptions.from_spec(spec)
    if opts.truth_selection_hse != SELECTION:
        raise click.ClickException(f"preset {spec.name}: sim.truth_selection_hse is "
                                   f"{opts.truth_selection_hse!r}, not 'sphere'")
    sim = str(spec.sim.sim_name)
    tree = Path(tree)
    store = store or open_store(source or spec.sim.base_path, int(snap))
    t0 = time.time()
    ids = sorted({int(h) for h in halo_ids})
    todo = [h for h in ids if force or not _done(tree, sim, int(snap), h, opts.spec_hash)]
    rep: dict[str, Any] = {"sim": sim, "snap": int(snap), "preset": spec.name,
                           "spec_hash": opts.spec_hash, "halos": len(ids),
                           "already_done": len(ids) - len(todo), "mode": mode,
                           "stream_fields": bool(stream_fields), "workers": int(workers),
                           "chunk_workers": int(chunk_workers), "truth_mode": truth_mode,
                           "read_workers": int(read_workers),
                           "store": store.describe()}
    echo(f"truth-sphere {spec.name} {sim} snap {snap}: {len(ids)} halos, "
         f"{len(todo)} to do ({store.describe()})")
    if not todo:
        return rep
    cpath = cutouts_path(tree, sim, int(snap))
    spheres, rows = halo_spheres(store, todo, opts.truth_sphere_r200c)
    stored = {}
    if mode in ("auto", "cutouts") and cpath.exists():
        stored = read_cutouts(cpath, todo)
        # a stored cutout serves only the sphere this run would select (a reused tree, REUSE_CUTOUTS_FROM of
        # slurm/truth_sphere.sh): another centre or radius is selected again
        want = {s.halo_id: s for s in spheres}
        stale = [h for h, c in stored.items() if h in want and not _same_sphere(c, want[h])]
        for h in stale:
            del stored[h]
        if stale:
            echo(f"  {len(stale)} stored cutouts with another centre or radius: selected again")
    missing = [s for s in spheres if s.halo_id not in stored]
    if mode == "cutouts" and missing:
        raise click.ClickException(f"{cpath}: no cutout of halos "
                                   f"{[s.halo_id for s in missing][:8]}")
    if mode == "stream":
        missing = spheres
    fields_by_halo: dict[int, Any] | None = None
    t_sel = time.time()
    # a zoom (TNG-Cluster, fixture cutout) is selected inside its truth worker (each
    # halo reads its own zoom ranges: parallel over halos); a periodic box in one
    # chunk-parallel pass for all its halos, before the truth
    zoom = [s for s in missing if store.is_zoom(rows[s.halo_id])]
    box = [s for s in missing if not store.is_zoom(rows[s.halo_id])]
    if box:
        r = stream_box(store, box, workers=chunk_workers, fields=stream_fields,
                       chunks=chunks, echo=echo)
        fields_by_halo = r["fields"] if stream_fields else None
        st = r["stats"]
        rep["stream"] = {k: v for k, v in st.items() if k != "chunk_seconds"}
        cs = st["chunk_seconds"]
        rep["stream"]["chunk_seconds_median"] = (sorted(cs)[len(cs) // 2] if cs else None)
        rep["stream"]["gb_per_chunk"] = st["bytes"] / max(st["chunks"], 1) / 1e9
        echo(f"  stream: {st['chunks']} chunks, {st['bytes'] / 1e9:.1f} GB coordinates, "
             f"{st['seconds']:.0f} s")
        write_cutouts(cpath, store, sim, box, r200c_factor=opts.truth_sphere_r200c)
    rep["select_seconds"] = round(time.time() - t_sel, 2)
    rep["cutouts"] = str(cpath)
    by_id = {**stored, **{s.halo_id: s for s in missing}}
    order = [by_id[h] for h in todo]
    zoom_all = [s for s in order if store.is_zoom(rows[s.halo_id])]
    box_all = [s for s in order if not store.is_zoom(rows[s.halo_id])]
    t_tr = time.time()
    common = dict(store=store, opts=opts, rows=rows, tree=tree, sim=sim, cutouts=cpath,
                  stream_fields=bool(stream_fields), select_here={s.halo_id for s in zoom},
                  truth_mode=truth_mode, read_workers=int(read_workers))
    res_by: dict[int, dict] = {}
    # zooms: each worker reads its own halo's rows (contiguous zoom ranges)
    if zoom_all:
        for r in _truth_pool(zoom_all, None, workers, common):
            res_by[r["halo_id"]] = r
    # boxes: the fields of the selected rows, from the stream when read there, else
    # gathered in snapshot-wide passes over the chunks (each chunk read once per batch
    # for the union of the batch's rows), batches bounded by ``gather_gb``
    big = [s for s in box_all if resolve_truth_mode(truth_mode, s) == "streamed"]
    big_ids = {s.halo_id for s in big}
    box_mem = [s for s in box_all if s.halo_id not in big_ids]
    if big:     # streamed: no gather, each truth process reads its own sphere chunk by chunk
        held = fields_by_halo is not None and all(s.halo_id in fields_by_halo for s in big)
        for r in _truth_pool(big, fields_by_halo if held else None, workers, common,
                             "stream" if held else "cutouts"):
            res_by[r["halo_id"]] = r
    if box_mem:
        if fields_by_halo is not None and all(s.halo_id in fields_by_halo for s in box_mem):
            for r in _truth_pool(box_mem, fields_by_halo, workers, common, "stream"):
                res_by[r["halo_id"]] = r
        else:
            rep["gather"] = []
            for batch in memory_batches(box_mem, store, gather_gb):
                g = gather_fields(store, batch, workers=chunk_workers, echo=echo)
                rep["gather"].append(g["stats"])
                for r in _truth_pool(batch, g["fields"], workers, common):
                    res_by[r["halo_id"]] = r
                del g
    res = [res_by[s.halo_id] for s in order]
    zoom_ids = {s.halo_id for s in zoom}
    if zoom:                                  # the zoom selections, back from the workers
        for s, r in zip(order, res):
            if s.halo_id in zoom_ids and r.get("selected"):
                s.gidx, s.attrs = r["selected"]["gidx"], r["selected"]["attrs"]
        done = [s for s in zoom if s.gidx]
        if done:
            write_cutouts(cpath, store, sim, done, r200c_factor=opts.truth_sphere_r200c)
    rep["cutouts_bytes"] = cpath.stat().st_size if cpath.exists() else 0
    for r in res:
        sel = r.pop("selected", None)
        if sel:
            r["select_seconds"] = sel["seconds"]
        echo(f"  halo {r['halo_id']:8d} {r['status']} {r['seconds']} s"
             + (f" fill(R500c) {r['fill_nonsf_r500c']:.3f} Mhse(<R500c)/M500c "
                f"{r['hse_atR500c']:.3f}" if r["status"] == "ok" else ""))
    rep.update(truth_seconds=round(time.time() - t_tr, 2), seconds=round(time.time() - t0, 2),
               n_ok=sum(r["status"] == "ok" for r in res), results=res,
               maxrss_self_gb=resource.getrusage(resource.RUSAGE_SELF).ru_maxrss / 1e6,
               maxrss_children_gb=resource.getrusage(resource.RUSAGE_CHILDREN).ru_maxrss / 1e6)
    rp = cpath.with_suffix(".report.json")
    rp.parent.mkdir(parents=True, exist_ok=True)
    rp.write_text(json.dumps(rep, indent=1, default=str) + "\n")
    return rep

def _csv_str(v: Any) -> str:
    """A value as the campaign's results writer prints it (``csv`` module, floats by
    ``repr``)."""
    import numpy as np

    if isinstance(v, (bool, np.bool_)):
        return str(bool(v))
    if isinstance(v, (float, np.floating)):
        return repr(float(v))
    if isinstance(v, (int, np.integer)):
        return str(int(v))
    return "" if v is None else str(v)

def apply_sphere_truth(tree: str | Path, spec: Any, *, snaps: Sequence[int] | None = None,
                       echo: Callable[[str], Any] = print) -> dict[str, Any]:
    """Write the spherical truth into the results CSVs and ``obs_meta.json`` of a tree.

    For every ``ok`` row whose halo has a spherical truth file, the truth columns
    (:data:`~tngxmm.sim.compute_hse_mass.TRUTH_COLUMNS`) are recomputed from the file
    with the row's z_obs and written as the generation's writer prints them; every
    other cell is left byte-identical.  Idempotent.  Returns per CSV the number of
    rows updated and the halos still without a spherical truth."""
    import pandas as pd

    from tngxmm.sim.compute_hse_mass import TRUTH_COLUMNS
    from tngxmm.sim.generate_view import SimOptions, halo_dir_of, view_dir_of, view_truth_columns
    from tngxmm.sim.truth_profile import hse_from_truth_profile, is_sphere_truth, path_for

    opts = SimOptions.from_spec(spec)
    sim = str(spec.sim.sim_name)
    tree = Path(tree)
    out: dict[str, Any] = {}
    for csv_path in sorted(tree.glob(f"results_{sim}_snap_*.csv")):
        snap = int(csv_path.stem.rsplit("_", 1)[1])
        if snaps is not None and snap not in {int(s) for s in snaps}:
            continue
        df = pd.read_csv(csv_path, dtype=str, keep_default_na=False)
        cols = [c for c in TRUTH_COLUMNS if c in df.columns]
        cache: dict[int, Any] = {}
        n_upd, lacking = 0, set()
        for i, r in df.iterrows():
            if not str(r.get("status", "")).startswith("ok"):
                continue
            hid = int(r["halo_id"])
            if hid not in cache:
                p = path_for(halo_dir_of(tree, sim, snap, hid))
                cache[hid] = hse_from_truth_profile(p) if is_sphere_truth(p) else None
            hse = cache[hid]
            if hse is None:
                lacking.add(hid)
                continue
            tc = view_truth_columns(hse, float(r["z_obs"]), opts)
            for c in cols:
                df.at[i, c] = _csv_str(tc[c])
            n_upd += 1
            mp_ = view_dir_of(tree, sim, snap, hid, int(r["view"])) / "obs_meta.json"
            if mp_.exists():
                m = json.loads(mp_.read_text())
                m.update({c: (float(tc[c]) if isinstance(tc[c], float) else tc[c])
                          for c in TRUTH_COLUMNS if c in m})
                m["hse_truth_selection"] = SELECTION
                m["hse_truth_spec_hash"] = hse["attrs"].get("spec_hash", "")
                tmp = mp_.with_name(f".{mp_.name}.tmp")
                tmp.write_text(json.dumps(m))
                os.replace(tmp, mp_)
        bak = csv_path.with_name(csv_path.name + BACKUP_SUFFIX)
        if n_upd and not bak.exists():
            bak.write_bytes(csv_path.read_bytes())
        if n_upd:
            tmp = csv_path.with_name(f".{csv_path.name}.tmp")
            # the campaign's writer (csv module) ends lines with CRLF
            df.to_csv(tmp, index=False, lineterminator="\r\n")
            os.replace(tmp, csv_path)
        out[csv_path.name] = {"rows_updated": n_upd, "halos_without_sphere": sorted(lacking)}
        echo(f"  {csv_path.name}: {n_upd} rows with the spherical truth"
             + (f"; {len(lacking)} halos without it" if lacking else ""))
    return out

def targets_halos(targets_csv: str | Path, sim: str, snap: int | None = None,
                  exclude: dict[str, str] | None = None) -> dict[int, list[int]]:
    """``{snap: [halo_id, ...]}`` of the unique (sim, snap, halo_id) of a targets table.  ``exclude``
    (:func:`tngxmm.core.pool.excluded_donors`): the views of these donors are not counted, so a halo
    whose every view is excluded is not in the plan."""
    import pandas as pd

    from tngxmm.core.pool import split_excluded

    t = pd.read_csv(targets_csv, dtype={"donor_id": str})
    t = t[t["sim"] == sim]
    t, _ = split_excluded(t, exclude)
    if snap is not None:
        t = t[t["snap"] == int(snap)]
    return {int(s): sorted({int(h) for h in g["halo_id"]}) for s, g in t.groupby("snap")}




def _chunk_list(text: str | None) -> list[int] | None:
    if not text:
        return None
    out: list[int] = []
    for part in text.split(","):
        a, _, b = part.partition("-")
        out += list(range(int(a), int(b) + 1)) if b else [int(a)]
    return out
