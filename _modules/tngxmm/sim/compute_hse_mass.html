Source code for tngxmm.sim.compute_hse_mass

"""Intrinsic hydrostatic masses of a halo from its gas cells, and the particle M500 at any z.

The hydrostatic mass the simulated gas itself implies, from the TRUE 3-D
profiles with no instrument and no fit, so that the bias of the mock fits
splits into a physical part (M_HSE / M500c: non-thermal support, multiphase gas
seen by X-rays) and a method part (M_fit / M_HSE).

:func:`compute_hse_truth` reads the snapshot through a HaloSource, so the
fixture cutouts work too.  Per halo, 48 log shells from 0.05 to 3 R500c
about GroupPos (periodic):

* ``true``      M_true(<r): gas + DM + stars + BH of the original zoom;
* ``th_vw``     thermal HSE, -r^2/(G rho_gas) dP_th/dr, P_th = (gamma-1) rho u,
                volume-weighted shell mean over all non-star-forming gas (no mu,
                no T needed);
* ``th_med``    the same with the shell MEDIAN of P and rho (clump-robust);
* ``th+kin``    P_th + rho sigma_r^2 plus the Jeans anisotropy term -(r/G) 2
                beta sigma_r^2, velocities about the shell's mean radial flow
                and the halo bulk velocity, Hubble flow added (closure test);
* ``X_Tsl_nemed``, ``X_Tmw_nemed``, ``X_Tsl_nevw``, ``X_Tsl_nemed_mu0.641``
                "X-ray-like" -(kT r/(G mu m_p)) (dln n_e/dln r + dln T/dln r)
                of the hot gas (T > 5.5 MK, non-SF): n_e shell median or
                volume-weighted mean, T spectroscopic-like (n^2 T^-0.75 V,
                Mazzotta et al. 2004) or mass-weighted, mu = 0.59 or
                mbproj2d's 0.6409;
* ``X_Tsl_nemed_mock``, ``X_Tmw_nemed_mock`` (the
                truth with the mock's own gas selection and floor) the same
                estimator on the cells the mock emits from: the mock's loader
                selection, T > t_min_k, non-SF, net cooling, inside the clip
                sphere, with the mock's per-cell X_H.

The literature definitions, each its own column
(:func:`_literature_estimators`; mu = 0.59; log-slopes by finite differences
over the shell centres):

* ``barnes21``  Barnes et al. (2021, MNRAS 506, 2533; secs. 2.1.5,
                2.4): 3-D mass-weighted T and gas density in 50 LINEAR shells
                over 0-1.5 r500, thermal pressure only, NO gas cut (Barnes's
                cuts belong to its synthetic images);
* ``barnes21_nosf`` (:data:`NOSF_FD_ESTIMATOR`)  the same without star-forming cells
                (their temperature is the effective EOS value, not a physical one);
                finite-difference slopes, mu = 0.59.  NOT EMITTED (too easily
                mistaken for the headline ``barnes21_nosf_fit_mu``): no
                results column, no truth-profile dataset, not a selectable headline; computed
                only on request (``nosf_fd=True`` of :func:`compute_hse_truth`) for the unit
                tests that compare it with the fitted headline;
* ``barnes21_nosf_fit_mu``  THE fitted Barnes truth and the headline:
  Barnes et al. (2021) sec. 2.4 -- 50 linear shells over 0-1.5 r500c, the
  shell mass-weighted quantities and the shell gas density fitted with the Vikhlinin
  (2006) forms and differentiated analytically (see :func:`_m_fit`), gas without
  star-forming cells (their temperature is the effective equation-of-state value of the
  TNG star-formation model) -- but with the thermal pressure of each cell as simulated:
  the shell mass-weighted ``<T/mu>`` with each cell's own mu
  (``4 / (1 + 3 X_H + 4 X_H x_e)``, X_H of the cell from ``GFM_Metals`` where present)
  replaces the temperature and the fixed mu = 0.59:
  ``M = -(k r / (G m_p)) <T/mu> (dln rho/dln r + dln <T/mu>/dln r)``, ``<T/mu>`` fitted
  with the Vikhlinin T form.  Since T = (gamma-1) u mu m_p / k, ``T/mu`` is the internal
  energy per unit mass in temperature units: the estimator is the pressure-based thermal
  HSE mass with fitted slopes (``mu_hse_barnes21_nosf_fit_mu`` is NaN: no single value).
  ``hse_fit_ok_barnes21_nosf_fit_mu`` flags a converged pair of fits.
* ``barnes21_nosf_fit`` (:data:`MU059_FIT_ESTIMATOR`)  the same fit with T and the assumed
  mu = 0.59.  NOT EMITTED (no results column, no truth-profile dataset, not a
  selectable headline): it is computed only on request (``mu059_fit=True`` of
  :func:`compute_hse_truth`), kept for the unit test that shows it differs from the
  headline only through the cells' departure of mu from 0.59.
* ``barnes21_fit_mu``, ``barnes21_fit`` (:data:`S8_ESTIMATORS`)  the headline's fit over every cell (star-forming
  cells kept), with the own mu and with mu = 0.59 (the latter is Barnes's estimator as published).  NOT EMITTED:
  computed only on request (``s8_variants=True``) for ledger test S8, which sizes the two deviations of the headline
  from Barnes et al. one at a time.
* ``barnes21_mock``  the same on the mock's own cells, with the mock's own
                selection (``load_halo_gas.emission_masks``: drop T < t_min_k,
                SFR > 0 and heated cells, GFM_CoolingRate >= 0; loader cells
                inside the clip sphere);
* ``barnes21_xcut``  with Barnes's X-ray-image cuts (sec. 2.2.3: drop T < 1e6 K,
                SFR > 0, and cells whose net cooling rate is positive, i.e.
                heated): the same ``emission_masks`` rule with a 1e6 K floor.
                GFM_CoolingRate is negative for net cooling and positive for
                net heating; heated cells (>= 0) are dropped, net-cooling
                cells (< 0) kept;
* ``barnes21_tsl``  the xcut cells with the spectroscopic-like T (Mazzotta et
                al. 2004, w = n^2 T^-0.75 V; valid above ~2-3 keV: the halo's
                T_sl inside R500c and ``t_sl_valid`` are recorded);
* ``pearce20_th``, ``pearce20_thkin``, ``pearce20_thkin_sig3d``  Pearce et
                al. (2020, MNRAS 491, 1622; sec. 3.6): 50 log shells over
                0.05-2 r500 without T < 1e5 K or n_H >= 0.1 cm^-3 cells;
                thermal only, + rho sigma_1D^2 (sigma_3D^2 / 3 of the peculiar
                velocities about the shell's mean velocity), + rho sigma_3D^2.

For each estimator: the ratio to M500c at R500c (``*_atR500c``), the
self-consistent M500 at 500 rho_c(z_snap) beyond 0.4 R500c (``*_M500self``,
``*_R500self``: the INNERMOST downward crossing of 500 rho_c by M_HSE(<r)/(4/3 pi
r^3), log-interpolated between the two shells; ``*_ncross`` counts the downward
crossings, NaN M500self when there is none) and the median ratio to M_true over
0.8-1.2 R500c.  The headline's count becomes the ``hse_crossing`` column
(``none`` / ``single`` / ``multiple``).

Shell density (``sim.hse_shell_density``, :func:`shell_gas_density`): every estimator
that pairs a shell gas density with a cell-averaged T or P uses either the selected
gas mass over the geometric shell volume (``geometric``, the definitions as written,
which assume the selected cells fill the shell) or over the selected cells' summed
volume (``filling``).  With a FoF-member selection the outer shells of high-z groups
are only partly filled by FoF members (the campaign computes its truth from all particles in
a sphere, ``sim.truth_selection_hse = 'sphere'``, which fills them, and keeps the filling
rule); the geometric density then falls while the cell-averaged P and T do not, and the HSE
mass comes out high.  ``filling`` gives the
density of the gas present; shells filled below ``sim.hse_min_filling`` (0.1 in the campaign)
are omitted from the profiles.  The cumulative particle masses are unaffected.

The headline intrinsic mass ``m500c_hse_msun`` is the estimator the preset's
method fields select (``sim.hse_pressure``, ``hse_gas_phase_cut``,
``hse_shell_binning``, ``t_weighting``; :func:`variant_for`).  The campaign's
choice (one methodological line) is ``barnes21_nosf_fit_mu``: Barnes et al.
(2021) secs. 2.1.5 and 2.4 (Vikhlinin fits, analytic slopes, 50 linear shells to 1.5 R500c),
with one deviation of ours: Barnes states no gas cut for the 3-D profiles, we drop the
star-forming cells, whose temperature is the effective
equation-of-state value of the TNG star-formation model, not a physical one (TNG
data specifications; the same exclusion as the mock's gas selection,
Chatzigiannakis et al. 2025), with each cell's own thermal pressure (its own mu).
Every other estimator stays its own column, classified headline or diagnostic in the
truth-column table of docs/dev/INTERFACES.md (:func:`truth_columns`).

:func:`m500_at_z` gives M500 at 500 rho_c(z) (any z, e.g. the view's z_obs,
the fitter's convention) from the halo's particle mass profile; at z_snap it
reproduces the catalogue Group_M_Crit500.

References
----------
Hydrostatic equilibrium mass (Sarazin 1988); hydrostatic bias in simulated
clusters (Rasia et al. 2006); spectroscopic-like temperature (Mazzotta et al.
2004); IllustrisTNG / TNG-Cluster particle data.
"""

def shell_gas_density(msum, vsum, vol, density: str = "geometric",
                  min_filling: float | None = None):
    """``(rho, fill, omit)`` of a set of shells from the selected cells' summed mass
    ``msum`` [Msun], summed cell volume ``vsum`` and geometric volume ``vol`` [kpc^3].

    ``fill = vsum / vol`` is the shell filling factor of the selected cells;
    ``rho = msum / vol`` (``geometric``) or ``msum / vsum`` (``filling``, the density
    of the gas present, consistent with a T or P averaged over the same cells);
    ``omit`` marks the shells with ``fill < min_filling`` (none when ``None``): a
    FoF group at high z holds a few filaments or clumps in its outer shells, whose
    gradient says nothing about the hydrostatic state of the shell.  The campaign
    threshold 0.1 (:data:`MIN_FILLING`) keeps every shell of the zoom gas (fill ~ 1 for the
    non-star-forming gas) and every FoF shell inside R500c."""
    import numpy as np

    if density not in SHELL_DENSITIES:
        raise ValueError(f"shell density must be one of {SHELL_DENSITIES}, not {density!r}")
    with np.errstate(invalid='ignore', divide='ignore'):
        fill = vsum / vol
        rho = msum / vol if density == "geometric" else msum / vsum
    omit = (np.zeros(len(fill), bool) if min_filling is None
            else ~(fill >= float(min_filling)))
    return rho, fill, omit

def variant_for(pressure: Any, gas_phase_cut: Any, shell_binning: Any,
                t_weighting: Any) -> str | None:
    """The estimator that fills ``m500c_hse_msun`` for the preset's method fields;
    ``None`` while any field it needs is unset (``None``)."""
    undecided = (None,)
    if pressure in undecided or gas_phase_cut in undecided or shell_binning in undecided:
        return None
    for t in (t_weighting, None):
        if (pressure, gas_phase_cut, shell_binning, t) in HSE_VARIANTS:
            return HSE_VARIANTS[(pressure, gas_phase_cut, shell_binning, t)]
    if t_weighting in undecided and any(k[:3] == (pressure, gas_phase_cut, shell_binning)
                                        for k in HSE_VARIANTS):
        return None
    raise ValueError(f"no HSE estimator for "
                     f"{(pressure, gas_phase_cut, shell_binning, t_weighting)}; "
                     f"known: {sorted(HSE_VARIANTS, key=str)}")

def _dln(y, cent, w=3):
    """Local log-slope of ``y(cent)`` (quadratic fit over +-w shells
    when >= 6 finite points, linear when 4-5)."""
    import numpy as np

    nb = len(cent)
    with np.errstate(divide="ignore", invalid="ignore"):
        ly, lx = np.log(y), np.log(cent)
    out = np.full(nb, np.nan)
    for i in range(nb):
        a0, b0 = max(0, i - w), min(nb, i + w + 1)
        ok = np.isfinite(ly[a0:b0])
        n = int(ok.sum())
        if n >= 6:
            c = np.polyfit(lx[a0:b0][ok], ly[a0:b0][ok], 2)
            out[i] = c[1] + 2 * c[0] * lx[i]
        elif n >= 4:
            out[i] = np.polyfit(lx[a0:b0][ok], ly[a0:b0][ok], 1)[0]
    return out


def _shell_tools(idx, nb):
    """Binned sum and median over shells."""
    import numpy as np

    inb = (idx >= 0) & (idx < nb)

    def bs(w, s):
        return np.bincount(idx[s & inb], weights=w[s & inb], minlength=nb)

    def bmed(x, s):
        out = np.full(nb, np.nan)
        ii = idx[s & inb]
        xx = x[s & inb]
        o = np.argsort(ii, kind='stable')
        ii, xx = ii[o], xx[o]
        cuts = np.searchsorted(ii, np.arange(nb + 1))
        for k in range(nb):
            if cuts[k + 1] - cuts[k] > 10:
                out[k] = np.median(xx[cuts[k]:cuts[k + 1]])
        return out

    return bs, bmed

def _summaries(key: str, M, cent, R500: float, M500: float, rho_c: float,
               Mtrue_c) -> dict[str, float]:
    """at R500c, self-consistent M500 (beyond 0.4 R500c) and 0.8-1.2 R500c average
    of one estimator."""
    import numpy as np

    res: dict[str, float] = {}
    good = np.isfinite(M) & (M > 0)
    at = (float(np.exp(np.interp(np.log(R500), np.log(cent[good]), np.log(M[good]))))
          if good.sum() > 5 else np.nan)
    res[f'{key}_atR500c'] = at / M500
    dens = M / (4 / 3 * np.pi * cent ** 3) - 500 * rho_c
    j = np.where((dens[:-1] > 0) & (dens[1:] <= 0) & (cent[:-1] > 0.4 * R500)
                 & good[:-1] & good[1:])[0]
    # number of downward crossings (the self-consistent M500 takes the innermost)
    res[f'{key}_ncross'] = int(len(j))
    if len(j):
        j = j[0]
        t = dens[j] / (dens[j] - dens[j + 1])
        Rs = np.exp(np.log(cent[j]) + t * np.log(cent[j + 1] / cent[j]))
        Ms = np.exp(np.log(M[j]) + t * np.log(M[j + 1] / M[j]))
        res[f'{key}_M500self'] = Ms / M500
        res[f'{key}_R500self'] = Rs / R500
    else:
        res[f'{key}_M500self'] = np.nan
        res[f'{key}_R500self'] = np.nan
    w = (cent > 0.8 * R500) & (cent < 1.2 * R500) & good
    res[f'{key}_avg0.8-1.2'] = float(np.median(M[w] / Mtrue_c[w])) if w.any() else np.nan
    return res


def _bin_profile(r, m, T, mask, edges, w=None, *, V=None, density: str = 'geometric',
                 min_filling: float | None = None):
    """Shell gas density [Msun/kpc^3] and weighted T [K] (default mass-weighted) of the
    cells in ``mask``; NaN in empty shells.  The density is the phase mass over the
    shell volume (``density='geometric'``) or over the summed cell volume ``V``
    (``'filling'``, :func:`shell_gas_density`); shells with a filling factor below
    ``min_filling`` are NaN in both (needs ``V``)."""
    import numpy as np

    nb = len(edges) - 1
    idx = np.digitize(r, edges) - 1
    s = mask & (idx >= 0) & (idx < nb)
    w = m if w is None else w
    vol = 4.0 / 3.0 * np.pi * np.diff(edges ** 3)
    with np.errstate(invalid='ignore', divide='ignore'):
        msum = np.bincount(idx[s], weights=m[s], minlength=nb)
        if density == 'geometric' and min_filling is None:
            rho = msum / vol
            omit = None
        else:
            if V is None:
                raise ValueError("the filling-consistent density needs the cell volumes V")
            vsum = np.bincount(idx[s], weights=V[s], minlength=nb)
            rho, _, omit = shell_gas_density(msum, vsum, vol, density, min_filling)
        T = (np.bincount(idx[s], weights=(T * w)[s], minlength=nb)
             / np.bincount(idx[s], weights=w[s], minlength=nb))
    rho[rho <= 0] = np.nan
    if omit is not None:
        rho[omit] = np.nan
        T[omit] = np.nan
    return rho, T


def _m_nt(cent, rho, T_K, mu=MU_X):
    """M(<r) = -(k T r / (G mu m_p)) (dln rho/dln r + dln T/dln r) [Msun]; the
    log-slopes by second-order finite differences over the shell centres
    (``numpy.gradient``)."""
    import numpy as np

    with np.errstate(invalid='ignore', divide='ignore'):
        lr = np.log(cent)
        slope = np.gradient(np.log(rho), lr) + np.gradient(np.log(T_K), lr)
        return -(KB * T_K / (mu * MP) / 1e10) * cent * slope / GK


# --- Vikhlinin (2006) fits, Barnes et al. (2021) sec. 2.4 -------------------------------
#: the fits run on r / R500c; at least this many finite shells are required (> parameters)
FIT_MIN_SHELLS = 15
#: gamma of Vikhlinin's density break, fixed as in Barnes (eq. 8)
VIK_GAMMA = 3.0


def _vik_rho2(x, p):
    """ln(n_e n_H) [arbitrary amplitude] and its log slope for Vikhlinin (2006) eq. 8,
    single component: ``p = (ln A, r_c, alpha, beta, r_s, xi)``, gamma = 3, x = r / R500c.
    n_e n_H = A (x/r_c)^-alpha / (1 + x^2/r_c^2)^(3 beta - alpha/2) / (1 + (x/r_s)^g)^(xi/g)."""
    import numpy as np

    lnA, rc, al, be, rs, xi = p
    u2 = (x / rc) ** 2
    q = (x / rs) ** VIK_GAMMA
    lnf = (lnA - al * np.log(x / rc) - (3 * be - al / 2) * np.log1p(u2)
           - xi / VIK_GAMMA * np.log1p(q))
    slope = -al - (3 * be - al / 2) * 2 * u2 / (1 + u2) - xi * q / (1 + q)
    return lnf, slope


def _vik_temp(x, p):
    """ln T and its log slope for Vikhlinin (2006) eq. 6 / Barnes eq. 10,
    T = T0 t_cool(x) t(x): ``p = (ln T0, r_cool, a_cool, tau, r_t, a, b, c)`` with
    t_cool = (y + tau)/(y + 1), y = (x/r_cool)^a_cool, tau = T_min/T0 (Barnes prints
    T_min T0, a typo for Vikhlinin's ratio) and
    t = (x/r_t)^-a / (1 + (x/r_t)^b)^(c/b).  Barnes prints +1 as the exponent of the
    first factor of t: the a = -1 member of this family, here a free parameter in [-1, 1]."""
    import numpy as np

    lnT0, rcool, acool, tau, rt, a, b, c = p
    y = (x / rcool) ** acool
    w = (x / rt) ** b
    lnT = (lnT0 + np.log((y + tau) / (y + 1)) - a * np.log(x / rt)
           - c / b * np.log1p(w))
    slope = acool * y * (1 / (y + tau) - 1 / (y + 1)) - a - c * w / (1 + w)
    return lnT, slope

def _vik_fit(model, x, y, starts, bounds, lead):
    """Least-squares fit of ``y = model(x, p)[0]`` (log space, robust ``soft_l1`` loss)
    from several starts; the lead parameter (log amplitude) starts at the mean offset.
    Returns ``(p, ok, rms)``; ``ok`` = converged and finite (``p`` NaN otherwise)."""
    import numpy as np
    from scipy.optimize import least_squares

    lo, hi = np.asarray(bounds[0], float), np.asarray(bounds[1], float)
    best = None
    for st in starts:
        p0 = np.clip(np.concatenate([[0.0], st]), lo + 1e-9, hi - 1e-9)
        p0[0] = float(np.clip(lead + np.mean(y - model(x, p0)[0]), lo[0] + 1e-9, hi[0] - 1e-9))
        try:
            r = least_squares(lambda p: model(x, p)[0] - y, p0, bounds=(lo, hi),
                              loss='soft_l1', f_scale=0.1, x_scale='jac', max_nfev=3000,
                              xtol=1e-10, ftol=1e-10, gtol=1e-10)
        except (ValueError, FloatingPointError):
            continue
        if np.isfinite(r.cost) and (best is None or r.cost < best.cost):
            best = r
    if best is None or not best.success:
        return np.full(len(lo), np.nan), False, float('nan')
    rms = float(np.sqrt(np.mean((model(x, best.x)[0] - y) ** 2)))
    return best.x, True, rms


def _m_fit(cent, rho, T_K, R500, mu=MU_X):
    """Barnes et al. (2021, sec. 2.4) mass profile: the shell density (fitted as
    n_e n_H, i.e. rho^2 up to a constant; the slope of rho is half the fitted slope) with
    the Vikhlinin (2006) modified beta model (:func:`_vik_rho2`; eq. 8, gamma = 3,
    xi < 5, ONE component) and the temperature with :func:`_vik_temp` (eq. 10), both in
    log space with robust bounds; M(<r) is eq. 12, ``-(k T r / (G mu m_p)) (dln rho/dln r
    + dln T/dln r)``, with the FITTED T(r) and the ANALYTIC slopes of the fitted
    functions, at the shell centres where the data exist (NaN where the shell was empty
    or omitted).  Returns ``(M, info)``; ``info``: ``rho_ok``, ``T_ok``, ``ok`` (both
    converged on >= FIT_MIN_SHELLS shells), the rms log residuals and the shell count."""
    import numpy as np

    x = np.asarray(cent, float) / R500
    good = np.isfinite(rho) & (rho > 0) & np.isfinite(T_K) & (T_K > 0)
    info = dict(rho_ok=False, T_ok=False, ok=False, rho_rms=float('nan'),
                T_rms=float('nan'), n_shells=int(good.sum()))
    M = np.full(len(x), np.nan)
    if good.sum() < FIT_MIN_SHELLS:
        return M, info
    y_rho = 2.0 * np.log(rho[good])
    pr, info['rho_ok'], info['rho_rms'] = _vik_fit(
        _vik_rho2, x[good], y_rho, _VIK_RHO_STARTS, _VIK_RHO_BOUNDS, float(y_rho.max()))
    y_T = np.log(T_K[good])
    pt, info['T_ok'], info['T_rms'] = _vik_fit(
        _vik_temp, x[good], y_T, _VIK_T_STARTS, _VIK_T_BOUNDS, float(np.median(y_T)))
    info['ok'] = bool(info['rho_ok'] and info['T_ok'])
    if not info['ok']:
        return M, info
    with np.errstate(invalid='ignore', divide='ignore', over='ignore'):
        lnT, sT = _vik_temp(x, pt)
        sr = 0.5 * _vik_rho2(x, pr)[1]
        Mf = -(KB * np.exp(lnT) / (mu * MP) / 1e10) * np.asarray(cent, float) * (sr + sT) / GK
    M[good] = Mf[good]
    M[~np.isfinite(M)] = np.nan
    return M, info

        return -(cent / GK) * (P / rho) * np.gradient(np.log(P), np.log(cent))

def metallicity_summary(w, zsol, zfe, mask) -> dict:
    """Emission-weighted mean metallicity of the cells in ``mask`` (weights ``w`` = n_e n_H V):
    ``{'z_ew': sum w Z / sum w, 'z_fe_ew': the same for iron}`` in solar units of the
    abundance table (``zsol`` = GFM_Metallicity / Z_sun, ``zfe`` = X_Fe / X_Fe,sun); NaN
    where the field is absent or no cell has weight."""
    import numpy as np

    out = {'z_ew': math.nan, 'z_fe_ew': math.nan}
    ws = float(np.sum(w[mask])) if mask.any() else 0.0
    if ws > 0:
        for k, z in (('z_ew', zsol), ('z_fe_ew', zfe)):
            if z is not None:
                out[k] = float(np.sum((w * z)[mask]) / ws)
    return out

def _literature_estimators(r, m, rho_cell, T, ne, V, sfr, cr, v_pec, R500, *,
                           density: str = 'geometric',
                           min_filling: float | None = None,
                           tmu: Any = None, mu059_fit: bool = False,
                           nosf_fd: bool = False, s8_variants: bool = False) -> tuple[dict, dict]:
    """The literature HSE definitions on the zoom gas.

    Barnes et al. (2021, secs. 2.1.5 and 2.4): mass-weighted T and gas density in
    50 linear shells over 0-1.5 r500, thermal pressure only, mu = 0.59:
    ``barnes21`` no gas cut (as written), ``barnes21_xcut`` with Barnes's X-ray-image cuts (the mock's
    ``emission_masks`` rule with a 1e6 K floor: drop T < 1e6 K, SFR > 0 and
    heated cells, GFM_CoolingRate >= 0), ``barnes21_tsl`` the same cells with the
    spectroscopic-like T (n^2 T^-0.75 V; Mazzotta et al. 2004).
    Pearce et al. (2020, sec. 3.6): 50 shells over 0.05-2 r500, cells with
    T < 1e5 K or n_H >= 0.1 cm^-3 dropped, P_th = rho k T_mw / (mu m_p),
    ``pearce20_th`` thermal only, ``pearce20_thkin`` + rho sigma^2 with sigma^2 the
    one-dimensional dispersion (sigma_3D^2 / 3) of the peculiar velocities about
    the shell's mass-weighted mean velocity, ``pearce20_thkin_sig3d`` + rho
    sigma_3D^2 (the literal reading of "sigma^2 the 3D dispersion").

    ``density`` / ``min_filling``: the shell density of every estimator
    (:func:`shell_gas_density`; ``geometric`` and ``None`` are the definitions as written).

    ``tmu`` (per cell, K): T / mu with each cell's OWN mean molecular weight
    (``mu = 4 / (1 + 3 X_H + 4 X_H x_e)``, X_H of the cell).  With it,
    ``barnes21_nosf_fit_mu`` is added: the ``barnes21_nosf`` cells and density, Vikhlinin
    fits (as Barnes sec. 2.4), but the fitted quantity is the shell mass-weighted ``<T/mu>`` and the
    mass is ``-(k r / (G m_p)) <T/mu> (dln rho/dln r + dln <T/mu>/dln r)``, i.e. the
    composition enters through each cell, not through one mu = 0.59.  ``mu059_fit``
    additionally returns the fit with T and mu = 0.59 (:data:`MU059_FIT_ESTIMATOR`, not
    emitted).  ``nosf_fd`` additionally returns the finite-difference mu = 0.59
    estimator without star-forming cells (:data:`NOSF_FD_ESTIMATOR`, not emitted);
    the binned non-SF profile itself is always computed (the fitted estimators use it).
    ``s8_variants`` additionally returns the fits of :data:`S8_ESTIMATORS` (every cell, with the own mu and with
    mu = 0.59; needs ``tmu``; not emitted).

    Returns ``({key: (cent, M(<r))}, {temperature records})``."""
    import numpy as np

    from tngxmm.sim.load_halo_gas import emission_masks

    out: dict = {}
    dkw = dict(V=V, density=density, min_filling=min_filling)
    eb, cb = barnes_edges(R500)
    allc = np.ones(len(r), bool)
    nsf = sfr <= 0
    xcut = emission_masks(T, sfr, cr, BARNES_XCUT_T_K)[0]   # the mock's rule, 1e6 K floor
    fit_rec: dict = {}
    for key, mask in (("barnes21", allc), ("barnes21_nosf", nsf), ("barnes21_xcut", xcut)):
        rho, Tm = _bin_profile(r, m, T, mask, eb, **dkw)
        if key != "barnes21_nosf" or nosf_fd:        # non-SF FD mass: on request only
            out[NOSF_FD_ESTIMATOR if key == "barnes21_nosf" else key] = (cb, _m_nt(cb, rho, Tm))
        if mu059_fit and key == "barnes21_nosf":     # the mu = 0.59 fit: on request only
            M, info = _m_fit(cb, rho, Tm, R500)
            out[MU059_FIT_ESTIMATOR] = (cb, M)
            fit_rec.update({f"{MU059_FIT_ESTIMATOR}_{n}": v for n, v in info.items()})
        if s8_variants and key == "barnes21":        # Barnes as published: every cell, mu = 0.59, fitted
            M, info = _m_fit(cb, rho, Tm, R500)
            out["barnes21_fit"] = (cb, M)
            fit_rec.update({f"barnes21_fit_{n}": v for n, v in info.items()})
    if tmu is not None:
        rho, Tmu = _bin_profile(r, m, tmu, nsf, eb, **dkw)
        M, info = _m_fit(cb, rho, Tmu, R500, mu=1.0)         # <T/mu> fitted, mu folded in
        out["barnes21_nosf_fit_mu"] = (cb, M)
        fit_rec.update({f"barnes21_nosf_fit_mu_{n}": v for n, v in info.items()})
        if s8_variants:                                      # the headline with the star-forming cells kept
            rho, Tmu = _bin_profile(r, m, tmu, allc, eb, **dkw)
            M, info = _m_fit(cb, rho, Tmu, R500, mu=1.0)
            out["barnes21_fit_mu"] = (cb, M)
            fit_rec.update({f"barnes21_fit_mu_{n}": v for n, v in info.items()})
    elif s8_variants:
        raise ValueError("s8_variants needs each cell's T / mu (tmu)")
    with np.errstate(invalid='ignore', divide='ignore'):
        wsl = ne ** 2 * V * T ** -0.75
    rho, Tsl = _bin_profile(r, m, T, xcut, eb, w=wsl, **dkw)
    out["barnes21_tsl"] = (cb, _m_nt(cb, rho, Tsl))

    ep, cp = pearce_edges(R500)
    nH = X_H * np.asarray(rho_cell, np.float64) * MSUN / KPC ** 3 / MP   # float32 would overflow
    keep = (T >= PEARCE_T_MIN_K) & (nH < PEARCE_NH_MAX)
    rho, Tm = _bin_profile(r, m, T, keep, ep, **dkw)
    nb = len(cp)
    idx = np.digitize(r, ep) - 1
    s = keep & (idx >= 0) & (idx < nb)
    with np.errstate(invalid='ignore', divide='ignore'):
        Msh = np.bincount(idx[s], weights=m[s], minlength=nb)
        sig3 = np.zeros(nb)
        for k in range(3):
            vk = v_pec[:, k]
            mean = np.bincount(idx[s], weights=(m * vk)[s], minlength=nb) / Msh
            sig3 += np.bincount(idx[s], weights=(m * vk * vk)[s], minlength=nb) / Msh - mean ** 2
        Pth = rho * KB * Tm / (MU_X * MP) / 1e10
    out["pearce20_th"] = (cp, _m_pressure(cp, rho, Pth))
    out["pearce20_thkin"] = (cp, _m_pressure(cp, rho, Pth + rho * sig3 / 3.0))
    out["pearce20_thkin_sig3d"] = (cp, _m_pressure(cp, rho, Pth + rho * sig3))

    s5 = r < R500
    x5 = xcut & s5
    with np.errstate(invalid='ignore', divide='ignore'):
        rec = {"t_mw_r500c_all_gas_kev": float((T[s5] * m[s5]).sum() / m[s5].sum()) / KEV_K,
               "t_sl_r500c_xcut_kev": float((T[x5] * wsl[x5]).sum() / wsl[x5].sum()) / KEV_K}
    rec["t_sl_valid"] = bool(rec["t_sl_r500c_xcut_kev"] >= T_SL_VALID_KEV)
    rec.update(fit_rec)
    return out, rec

    from tngxmm.sim.compute_true_profiles import radius_kpc

    try:                                   # + GFM_Metallicity (emission-weighted metallicity)

        wew = ne ** 2 * V * np.sqrt(T)
        out = dict(ne_med=bmed(ne, phase),
                   T_sl=bs(T * wsl, phase) / bs(wsl, phase) / KEV_K,
                   T_mw=bs(T * m, phase) / bs(m, phase) / KEV_K)
        s5 = phase & (r < fr['r500_kpc'])
        out['t_ew_r500c_kev'] = float((T[s5] * wew[s5]).sum() / wew[s5].sum()) / KEV_K
        out['t_sl_r500c_kev'] = float((T[s5] * wsl[s5]).sum() / wsl[s5].sum()) / KEV_K
        out['t_mw_r500c_kev'] = float((T[s5] * m[s5]).sum() / m[s5].sum()) / KEV_K
        out['mgas_mock_lt_r500c_msun'] = float(m[s5].sum())
        zsun_t, fesun_t = solar_units_of_table(abund_table)
        wem = ne * nH * V                                  # emission measure n_e n_H V
        zs = zmet / zsun_t if zmet is not None else None
        zf = xfe / fesun_t if xfe is not None else None
        out['metal_mock'] = metallicity_summary(wem, zs, zf, s5)
        if min_filling is not None:
            _, _, omit = shell_gas_density(bs(m, phase), bs(V, phase),
                                       4 / 3 * np.pi * np.diff(edges ** 3), density,
                                       min_filling)
            for k in ('ne_med', 'T_sl', 'T_mw'):
                out[k][omit] = np.nan
    eb, cb = barnes_edges(fr['r500_kpc'])
    rho_b, T_b = _bin_profile(r, m, T, phase, eb, V=V, density=density,
                              min_filling=min_filling)

    if profile_acc is not None:        # sim.truth_profiles: the same cells on the common grid
        from tngxmm.sim.truth_profile import phase_profiles, shell_index

        pe = profile_acc.edges
        from tngxmm.sim.truth_profile import metallicity_profiles

        out['tp_mock'] = phase_profiles(shell_index(r, pe), pe, m, T, ne, V, phase,
                                        P=(GAM - 1) * rho * u_int, density=density)
        out['tp_metal_mock'] = metallicity_profiles(shell_index(r, pe), len(pe) - 1, wem, zs, zf,
                                                    phase)
        profile_acc.add('gas_mock', r[phase], m[phase])
    return out

              f'R500c={R500:.0f}  gas {int(sel.sum()):,}', flush=True)

    with np.errstate(invalid='ignore', divide='ignore'):
        rho_gas = bs(m, nsf) / vol                            # all non-SF gas
        P_vw = bs(P * V, nsf) / bs(V, nsf)
        P_med = bmed(P, nsf)
        rho_med = bmed(rho, nsf)
        ne_med = bmed(ne, hot)
        ne_vw = bs(ne * V, hot) / bs(V, hot)
        T_mw = bs(T * m, hot) / bs(m, hot) / KEV_K
        wsl = ne ** 2 * V * T ** -0.75
        T_sl = bs(T * wsl, hot) / bs(wsl, hot) / KEV_K
        mu_mw = bs(mu * m, hot) / bs(m, hot)
        rhat = d / r[:, None]
        vr = (v * rhat).sum(1)
        vt2 = (v ** 2).sum(1) - vr ** 2
        Mg = bs(m, nsf)
        vr_mean = bs(m * vr, nsf) / Mg
        sr2 = bs(m * vr ** 2, nsf) / Mg - vr_mean ** 2
        st2 = bs(m * vt2, nsf) / Mg                            # 2 tangential components
        beta = 1 - st2 / (2 * sr2)
    fills = {}
    if shell_density != 'geometric' or min_filling is not None:
        # the density of the non-SF gas present (consistent with P_vw) and the shells
        # each phase fills too little for a gradient (shell_gas_density)
        rho_gas, fills['nonsf'], omit = shell_gas_density(Mg, bs(V, nsf), vol, **dens_kw)
        _, fills['hot'], omit_hot = shell_gas_density(bs(m, hot), bs(V, hot), vol, **dens_kw)
        for arr in (rho_gas, P_vw, P_med, rho_med):
            arr[omit] = np.nan
        for arr in (ne_med, ne_vw, T_mw, T_sl):
            arr[omit_hot] = np.nan

    lit, lit_rec = _literature_estimators(r, m, rho, T, ne, V, sfr, cr, v_pec, R500,
                                          tmu=tmu, mu059_fit=mu059_fit,
                                          nosf_fd=nosf_fd, s8_variants=s8_variants, **dens_kw)
    del v_pec, cr, tmu, mu_c
    # emission-weighted metallicity (weights n_e n_H V, per-cell X_H) of the non-SF gas, in
    # solar units of the fit's abundance table
    zsun_t, fesun_t = solar_units_of_table(abund_table)
    nH_c = xh_c * rho * MSUN / KPC ** 3 / MP
    w_em = xe * nH_c * nH_c * V
    z_sol = zmet_c / zsun_t if zmet_c is not None else None
    z_fe = xfe_c / fesun_t if xfe_c is not None else None
    metal_nsf = metallicity_summary(w_em, z_sol, z_fe, nsf & (r < R500))
    tp = None
    if macc is not None:              # the zoom-gas part of the truth profile
        tp = _truth_profile_gas(macc.edges, macc.cent, r, m, T, ne, V, P, nsf, hot, vr, vt2,
                                metal=(w_em, z_sol, z_fe), **dens_kw)
    del w_em, nH_c, z_sol, z_fe, xh_c, xfe_c, zmet_c

    # total mass
    mtot_shell = bs(m, np.ones_like(m, bool))
    m_in = m[r < edges[0]].sum()
    del d, v, rhat, vr, vt2
    for pt, pn in (('dm', 1), ('stars', 4), ('bh', 5)):
        flds = ['Coordinates'] if (pt == 'dm' and mt[pn] > 0) else ['Coordinates', 'Masses']
        try:
            p = source.particles(pn, flds, selection=selection)
        except Exception as e:                                # noqa: BLE001
            if verbose:
                print('  !', pt, e)
            continue
        if p.get('count', 0) == 0:
            continue
        rr = np.sqrt((rel(p['Coordinates']) ** 2).sum(1))
        # native dtype (float32 masses): same sums to the last bit
        mm = p['Masses'] * 1e10 / h if 'Masses' in p else np.full(len(rr), mt[pn] * 1e10 / h)
        ii = np.digitize(rr, edges) - 1
        s = (ii >= 0) & (ii < nb)
        mtot_shell += np.bincount(ii[s], weights=mm[s], minlength=nb)
        m_in += mm[rr < edges[0]].sum()
        add_grid(rr, mm, pt)
        del p, rr, mm
    Mtrue = np.cumsum(mtot_shell) + m_in                       # at outer edges
    Mtrue_c = np.exp(np.interp(np.log(cent), np.log(edges[1:]), np.log(Mtrue)))

    with np.errstate(invalid='ignore', divide='ignore'):
        M_th = -cent * P_vw * _dln(P_vw, cent) / (GK * rho_gas)
        M_th_med = -cent * P_med * _dln(P_med, cent) / (GK * rho_med)
        Ptot = P_vw + rho_gas * sr2
        M_thkin = -cent * Ptot * _dln(Ptot, cent) / (GK * rho_gas) - 2 * beta * sr2 * cent / GK
        est = {'true': Mtrue_c, 'th_vw': M_th, 'th_med': M_th_med, 'th+kin': M_thkin,
               'X_Tsl_nemed': _mx(T_sl, ne_med, cent), 'X_Tmw_nemed': _mx(T_mw, ne_med, cent),
               'X_Tsl_nevw': _mx(T_sl, ne_vw, cent),
               'X_Tsl_nemed_mu0.641': _mx(T_sl, ne_med, cent, MU_MBPROJ2D)}

    res: dict[str, Any] = dict(
        snap=int(source.snap), halo=int(source.halo_id), z=z, M500c=M500, R500c=R500,
        R200c=R200,
        mu_hot_R500=float(np.interp(R500, cent, mu_mw)),
        beta_R500=float(np.interp(R500, cent, beta)),
        sigr_R500_kms=float(np.sqrt(np.interp(R500, cent, sr2))),
        Tsl_R500=float(np.interp(R500, cent, T_sl)),
        Tmw_R500=float(np.interp(R500, cent, T_mw)))
    for k, M in est.items():
        with np.errstate(invalid='ignore', divide='ignore'):
            res.update(_summaries(k, M, cent, R500, M500, rho_c, Mtrue_c))

    def mtrue_at(c):
        return np.exp(np.interp(np.log(np.maximum(c, r_grid[0])), np.log(r_grid),
                                np.log(np.maximum(m_grid, 1e-30))))

    for k, (c, M) in lit.items():
        with np.errstate(invalid='ignore', divide='ignore'):
            res.update(_summaries(k, M, c, R500, M500, rho_c, mtrue_at(c)))
    res.update(lit_rec)
    res.update({'z_ew_r500c_nonsf': metal_nsf['z_ew'], 'z_fe_ew_r500c_nonsf': metal_nsf['z_fe_ew'],
                'z_ew_r500c_mock': math.nan, 'z_fe_ew_r500c_mock': math.nan,
                'metal_abund_table': str(abund_table)})

    profiles = dict(r=cent, edges=edges, P_vw=P_vw, P_med=P_med, rho_gas=rho_gas,
                    ne_med=ne_med, ne_vw=ne_vw, T_mw=T_mw, T_sl=T_sl, mu=mu_mw, sr2=sr2,
                    st2=st2, vr_mean=vr_mean, **{f'M_{k}': M for k, M in est.items()},
                    M500c=M500, R500c=R500, z=z)
    profiles.update({f'fill_{k}': v for k, v in fills.items()})

    if mock_selection is not None:
        clip = 2.0 * R200 if mock_clip_radius_kpc is None else float(mock_clip_radius_kpc)
        mp = _mock_phase_profiles(source, fr, edges, cent, selection=mock_selection,
                                  radius_ckpc_h=mock_radius_ckpc_h, clip_radius_kpc=clip,
                                  t_min_k=mock_t_min_k, profile_acc=macc,
                                  abund_table=abund_table, **dens_kw)
        with np.errstate(invalid='ignore', divide='ignore'):
            mock_est = {'X_Tsl_nemed_mock': _mx(mp['T_sl'], mp['ne_med'], cent),
                        'X_Tmw_nemed_mock': _mx(mp['T_mw'], mp['ne_med'], cent)}
            for k, M in mock_est.items():
                res.update(_summaries(k, M, cent, R500, M500, rho_c, Mtrue_c))
        res.update({k: mp[k] for k in ('t_ew_r500c_kev', 't_sl_r500c_kev', 't_mw_r500c_kev',
                                       'mgas_mock_lt_r500c_msun')})
        res['z_ew_r500c_mock'] = mp['metal_mock']['z_ew']
        res['z_fe_ew_r500c_mock'] = mp['metal_mock']['z_fe_ew']
        res['mock_selection'] = mock_selection
        res['mock_t_min_k'] = float(mock_t_min_k)
        res['mock_clip_radius_kpc'] = clip
        c, M = mp['barnes21_mock']
        with np.errstate(invalid='ignore', divide='ignore'):
            res.update(_summaries('barnes21_mock', M, c, R500, M500, rho_c, mtrue_at(c)))
        profiles['M_barnes21_mock'] = M
        profiles.update({'ne_med_mock': mp['ne_med'], 'T_sl_mock': mp['T_sl'],
                         'T_mw_mock': mp['T_mw'], **{f'M_{k}': M for k, M in mock_est.items()}})
    res['m500c_particles_msun'] = m500_at_z((r_grid, m_grid), z, h, om0)[0]
    for k, (c, M) in lit.items():
        profiles[f'M_{k}'] = M
        profiles[f'r_{k}'] = c
    out = {'summary': res, 'profiles': profiles, 'mass_profile': (r_grid, m_grid),
           'h': h, 'om0': om0}
    res['truth_selection'] = str(selection)
    res['hse_shell_density'] = str(shell_density)
    res['hse_min_filling'] = float('nan') if min_filling is None else float(min_filling)
    if tp is not None:
        native = {k: (cent, M) for k, M in est.items()}
        native.update({k: v for k, v in lit.items()
                       if k not in (MU059_FIT_ESTIMATOR, NOSF_FD_ESTIMATOR, *S8_ESTIMATORS)})
        if mock_selection is not None:
            native.update({k: (cent, profiles[f'M_{k}']) for k in MOCK_ESTIMATORS})
            native['barnes21_mock'] = mp['barnes21_mock']
        out['truth_profile'] = _truth_profile_finish(
            tp, macc, mp.get('tp_mock') if mock_selection is not None else None, native,
            metal_mock=mp.get('tp_metal_mock') if mock_selection is not None else None,
            abund_table=abund_table,
            source=source, fr=fr, box=box, mock_selection=mock_selection, selection=selection,
            mock_t_min_k=mock_t_min_k,
            mock_clip=res.get('mock_clip_radius_kpc', float('nan')), **dens_kw)
    return out




def _truth_profile_gas(pe, pc, r, m, T, ne, V, P, nsf, hot, vr, vt2, *,
                       density: str = 'geometric', min_filling: float | None = None,
                       metal: Any = None) -> dict:
    """The zoom-gas arrays of the truth profile on the common grid ``pe``: phases
    ``nonsf`` and ``hot``, the kinetic terms and the thermal / thermal+kinetic HSE
    masses of the non-SF gas (the formulas of ``th_vw`` / ``th+kin``; the shell
    density and the omitted shells by :func:`shell_gas_density`)."""
    import numpy as np

    from tngxmm.sim import truth_profile as tpm

    idx = tpm.shell_index(r, pe)
    order = tpm.shell_order(idx)
    gas = {'nonsf': tpm.phase_profiles(idx, pe, m, T, ne, V, nsf, P, order, density=density),
           'hot': tpm.phase_profiles(idx, pe, m, T, ne, V, hot, P, order, density=density)}
    del order
    bs, _ = _shell_tools(idx, len(pc))
    vol = 4 / 3 * np.pi * np.diff(pe ** 3)
    with np.errstate(invalid='ignore', divide='ignore'):
        Mg = bs(m, nsf)
        rho_gas, _, omit = shell_gas_density(Mg, bs(V, nsf), vol, density, min_filling)
        vr_mean = bs(m * vr, nsf) / Mg
        sr2 = bs(m * vr ** 2, nsf) / Mg - vr_mean ** 2
        st2 = bs(m * vt2, nsf) / Mg
        beta = 1 - st2 / (2 * sr2)
        P_vw = bs(P * V, nsf) / bs(V, nsf)
        rho_h = np.where(omit, np.nan, rho_gas)        # the HSE masses skip omitted shells
        P_h = np.where(omit, np.nan, P_vw)
        M_th = -pc * P_h * _dln(P_h, pc) / (GK * rho_h)
        Ptot = P_h + rho_h * sr2
        M_thkin = -pc * Ptot * _dln(Ptot, pc) / (GK * rho_h) - 2 * beta * sr2 * pc / GK
    kin = dict(sigma_r2=sr2, sigma_t2=st2, beta=beta, vr_mean=vr_mean,
               P_kin=rho_gas * sr2 * tpm.P_TO_KEV_CM3)
    out = dict(gas=gas, kinetic=kin, hse={'M_th_nonsf': M_th, 'M_thkin_nonsf': M_thkin})
    if metal is not None:       # (weights n_e n_H V, Z / Z_sun, X_Fe / X_Fe,sun) of the cells
        out['metallicity'] = tpm.metallicity_profiles(idx, len(pc), *metal, nsf)
    return out


def _truth_profile_finish(tp: dict, macc: Any, tp_mock: dict | None, native: dict, *,
                          source: Any, fr: dict, box: float, mock_selection: str | None,
                          mock_t_min_k: float, mock_clip: float, selection: str = 'zoom',
                          density: str = 'geometric', min_filling: float | None = None,
                          metal_mock: dict | None = None, abund_table: str = 'angr') -> dict:
    """Assemble the truth-profile arrays and attributes (:mod:`tngxmm.sim.truth_profile`)."""
    import numpy as np

    from tngxmm.sim import truth_profile as tpm

    nb = len(macc.cent)
    gas = dict(tp['gas'])
    gas['mock'] = (tp_mock if tp_mock is not None else
                   {k: np.full(nb, np.nan) for k in tpm.GAS_FIELDS})
    hse = dict(tp['hse'])
    for p in tpm.PHASES:
        for t, M in tpm.hse_from_phase(macc.cent, gas[p], min_filling=min_filling).items():
            hse[f'M_{p}_{t}'] = M
    kind = type(getattr(source, 'wrapped_source', source)).__name__
    attrs = dict(
        centre_ckpc_h=np.asarray(fr['pos0'], float), centre_kpc=np.asarray(fr['pos0'], float)
        * fr['a'] / fr['h'], centre_definition='GroupPos (FoF group potential minimum)',
        periodic=f'minimum-image distances about GroupPos, BoxSize {box:g} ckpc/h',
        particle_selection=(
            str(source.selection_description) if selection == 'sphere'
            and hasattr(source, 'selection_description') else
            'fof: every particle of the FoF group (loadHalo / fixture InFoF == 1); beyond '
            '~R200c the profiles hold FoF members only' if selection == 'fof' else
            'zoom: every particle of the periodic sphere cutout'
            if kind == 'CutoutDirectorySource' else
            'zoom: the original zoom (loadOriginalZoom) / fixture cutout'),
        truth_selection=str(selection),
        source_type=kind,
        mock_selection=str(mock_selection) if mock_selection is not None else 'none',
        mock_t_min_k=float(mock_t_min_k), mock_clip_radius_kpc=float(mock_clip),
        hse_shell_density=str(density),
        hse_min_filling=float('nan') if min_filling is None else float(min_filling),
        metallicity_abund_table=str(abund_table),
        metallicity_z_sun=solar_units_of_table(abund_table)[0],
        metallicity_xfe_sun=solar_units_of_table(abund_table)[1])
    defs = {'nonsf': f'{selection} gas, StarFormationRate == 0 (no temperature cut)',
            'hot': f'{selection} gas, StarFormationRate == 0 and T > {T_HOT_K:g} K (X_H = 0.76)',
            'mock': (f"the mock's emitting cells: selection {mock_selection}, "
                     f"T >= {mock_t_min_k:g} K (per-cell X_H), SFR == 0, GFM_CoolingRate < 0, "
                     f"r <= {mock_clip:g} kpc")}
    nanb = {k: np.full(nb, np.nan) for k in tpm.METAL_FIELDS}
    metallicity = {'nonsf': tp.get('metallicity', nanb),
                   'mock': metal_mock if metal_mock is not None else nanb}
    return dict(r_kpc=macc.cent, r_edges_kpc=macc.edges, mass=macc.result(), gas=gas,
                kinetic=tp['kinetic'], hse=hse, native=native, phase_definitions=defs,
                attrs=attrs, M200c_msun=fr['m200'], metallicity=metallicity)

def m500_at_z(mass_profile: tuple, z: float, h: float, om0: float = OM0,
              delta: float = 500.0) -> tuple[float, float]:
    """``(M, R)`` [Msun, kpc] where the mean enclosed density of the particle profile
    falls to ``delta`` rho_c(z): the outermost crossing, log-interpolated
    between grid radii (NaN if the profile never crosses on its grid)."""
    import numpy as np

    r, M = (np.asarray(x, float) for x in mass_profile)
    dens = M / (4.0 / 3.0 * np.pi * r ** 3) - delta * rho_crit_msun_kpc3(z, h, om0)
    above = np.flatnonzero(dens[:-1] >= 0)
    if not len(above) or above[-1] + 1 >= len(r):
        return float('nan'), float('nan')
    j = int(above[-1])
    if dens[j + 1] >= 0:
        return float('nan'), float('nan')
    t = dens[j] / (dens[j] - dens[j + 1])
    R = float(np.exp(np.log(r[j]) + t * np.log(r[j + 1] / r[j])))
    Mx = float(np.exp(np.log(M[j]) + t * np.log(M[j + 1] / M[j])))
    return Mx, R

def crossing_flag(ncross: Any) -> str:
    """``hse_crossing`` of a crossing count: ``'none'`` (M_HSE(<r) never falls through
    500 rho_c(z) beyond 0.4 R500c: ``m500c_hse_msun`` is NaN, a valid outcome, e.g. a
    halo whose HSE mass profile stays above the threshold out to the end of its grid),
    ``'single'`` or ``'multiple'`` (the headline is then the INNERMOST downward crossing
    beyond 0.4 R500c, :func:`_summaries`; a flag, not a cut)."""
    if ncross is None or (isinstance(ncross, float) and ncross != ncross):
        return 'none'
    n = int(ncross)
    return 'none' if n <= 0 else 'single' if n == 1 else 'multiple'

def truth_columns(hse: dict, variant: str | None = None) -> dict[str, Any]:
    """Per-halo view-table columns of a :func:`compute_hse_truth` result.

    For every estimator (:data:`COLUMN_ESTIMATORS`): ``m500_hse_<slug>_msun``
    (self-consistent M500 at 500 rho_c(z_snap)), ``mhse_<slug>_r500c_over_m500c``
    (M_HSE(<R500c) / M500c) and ``mu_hse_<slug>`` (the mean molecular weight it
    used; NaN where none enters).  Plus ``m500c_hse_msun`` (the ``variant`` chosen
    by the preset, the headline; NaN while undecided) and ``hse_headline`` (its
    key), ``hse_crossing`` (:func:`crossing_flag` of the headline: ``none`` /
    ``single`` / ``multiple``, or ``fit-failed`` when the headline fit failed, or empty without a variant;
    ``m500c_hse_msun`` is NaN for ``none`` and ``fit-failed``),
    ``m500c_particles_msun``, ``hse_fit_ok_<key>`` (both Vikhlinin fits of a
    ``*_fit`` estimator converged), the temperatures inside R500c (``t_ew_kev``,
    ``t_sl_r500c_kev``, ``t_mw_r500c_kev``: the mock's cells; ``t_mw_r500c_all_gas_kev``;
    ``t_sl_r500c_xcut_kev`` and ``t_sl_valid`` = T_sl >= 2 keV, the validity of the
    spectroscopic-like weighting) and the diagnostics at R500c."""
    s = hse['summary']
    M500 = float(s['M500c'])
    nan = math.nan
    out: dict[str, Any] = {}
    for k in COLUMN_ESTIMATORS:
        slug = SLUGS[k]
        have = f'{k}_M500self' in s
        out[f'm500_hse_{slug}_msun'] = float(s[f'{k}_M500self']) * M500 if have else nan
        out[f'mhse_{slug}_r500c_over_m500c'] = float(s[f'{k}_atR500c']) if have else nan
        out[f'mu_hse_{slug}'] = MU_OF[k]
    out['m500c_hse_msun'] = (out.get(f'm500_hse_{SLUGS[variant]}_msun', nan)
                             if variant else nan)
    for k in FIT_ESTIMATORS:
        out[f'hse_fit_ok_{k}'] = bool(s.get(f'{k}_ok', False))
    out['hse_headline'] = variant or ''
    out['hse_crossing'] = crossing_flag(s.get(f'{variant}_ncross')) if variant else ''
    if variant in FIT_ESTIMATORS and not s.get(f'{variant}_ok', False):
        out['hse_crossing'] = 'fit-failed'     # NaN headline: no fit, not "no crossing"
    out['m500c_particles_msun'] = float(s['m500c_particles_msun'])
    out['t_ew_kev'] = float(s.get('t_ew_r500c_kev', nan))
    out['t_sl_r500c_kev'] = float(s.get('t_sl_r500c_kev', nan))
    out['t_mw_r500c_kev'] = float(s.get('t_mw_r500c_kev', nan))
    out['t_mw_r500c_all_gas_kev'] = float(s.get('t_mw_r500c_all_gas_kev', nan))
    out['t_sl_r500c_xcut_kev'] = float(s.get('t_sl_r500c_xcut_kev', nan))
    out['t_sl_valid'] = bool(s.get('t_sl_valid', False))
    out['mu_hot_r500c'] = float(s['mu_hot_R500'])
    out['beta_r500c'] = float(s['beta_R500'])
    out['sigma_r_r500c_km_s'] = float(s['sigr_R500_kms'])
    return out

def write_hse_truth(hse: dict, out_dir: Any) -> Any:
    """``hse_<snap:03d>_<halo>.{npz,json}`` (the npz holds ``hse['profiles']`` plus the
    mass-profile grid ``mprof_r_kpc`` / ``mprof_m_msun``; the json holds ``hse['summary']``); returns the json path."""
    import json
    from pathlib import Path

    import numpy as np

    out = Path(out_dir)
    out.mkdir(parents=True, exist_ok=True)
    s = hse['summary']
    stem = f"hse_{int(s['snap']):03d}_{int(s['halo'])}"
    r_grid, m_grid = hse['mass_profile']
    np.savez(out / f'{stem}.npz', **hse['profiles'], mprof_r_kpc=r_grid, mprof_m_msun=m_grid)
    with open(out / f'{stem}.json', 'w') as f:
        json.dump({k: (float(v) if isinstance(v, (float, np.floating)) else v)
                   for k, v in s.items()}, f, indent=1)
    return out / f'{stem}.json'
