Source code for tngxmm.sim.truth_profile

"""Per-halo TRUTH PROFILE file: the intrinsic 3-D profiles behind the truth columns.

Written when ``sim.truth_profiles = 'on'``.  The truth columns
(:func:`tngxmm.sim.compute_hse_mass.truth_columns`) are scalars; this module
writes the radial profiles they come from, once per halo-snapshot, so a fit
of any of the halo's views can be compared with the truth radius by radius
(``massfit.render_fit_v4``).  The arrays are filled inside
:func:`~tngxmm.sim.compute_hse_mass.compute_hse_truth` from the cells it has
already loaded (no extra snapshot read; the mock-phase part from the second,
mock-selection read the HSE truth already makes); this module holds the
binning, the file schema, the writer, the reader and the check.

File ``<out_root>/<sim>/<snap:03d>/<halo:07d>/truth_profile.h5`` (next to the
``view<k>/`` directories; one per halo-snapshot, shared by its views).

Common grid: :data:`N_SHELLS` log-spaced shells from :data:`RMIN_R500` to
:data:`RMAX_R500` x R500c (catalogue) about ``GroupPos``, physical kpc,
minimum-image (periodic) distances.  Groups:

``mass/``     cumulative masses at the shell centres AND outer edges (exact
              particle sums, no interpolation): ``M_tot`` (gas + DM + stars +
              BH of the original zoom; sphere cutout for a box run), ``M_gas``,
              ``M_dm``, ``M_stars``, ``M_bh``, and ``M_gas_mock`` (the mock's
              emitting cells);
``gas/<phase>/``  per shell, for each gas phase (:data:`PHASES`): ``rho_gas``
              (phase mass / shell volume under ``hse_shell_density = 'geometric'``,
              phase mass / summed phase-cell volume under ``'filling'``),
              ``fill`` (shell filling factor sum V_cell / V_shell; the HSE masses
              below omit the shells with ``fill < hse_min_filling``),
              ``ne_vw`` (volume-weighted),
              ``ne_med`` (shell median, >10 cells), ``ne_rms``
              (sqrt <n_e^2>_V, what an emission measure sees), ``T_mw``,
              ``T_sl`` (spectroscopic-like, w = n_e^2 V T^-0.75; Mazzotta et al.
              2004), ``T_ew`` (emission-weighted, w = n_e^2 V T^0.5),
              ``K_mw`` / ``K_sl`` (k T n_e,vw^-2/3), ``P_th`` (volume-weighted
              (gamma-1) rho u), ``n_cells``;
``kinetic/``  non-star-forming gas (the headline's cells): ``sigma_r2``,
              ``sigma_t2`` (both tangential components), ``beta``, ``vr_mean``
              (peculiar + Hubble flow about the halo bulk velocity, as the HSE
              truth's ``th+kin``), ``P_kin`` = rho_gas sigma_r^2;
``hse/``      M_HSE(<r) on the common grid: ``M_<phase>_<T>`` =
              -(k T r / (G mu m_p)) (dln rho_gas/dln r + dln T/dln r), mu = 0.59
              (Barnes et al. 2021 sec. 2.4, eq. 12, with the phase's gas density),
              T in {mw, sl, ew}; ``M_th_nonsf`` (-r^2 / (G rho) dP_th/dr, P_th
              from the internal energy, no mu) and ``M_thkin_nonsf`` (+ rho
              sigma_r^2 and the Jeans anisotropy term); log-slopes by the HSE
              truth's local quadratic fit over +-3 shells (``_dln``);
``metallicity/<phase>/``  (additive, format 3; phases ``nonsf`` and ``mock``)
              emission-weighted metallicity per shell, weights n_e n_H V (the cell's own
              X_H): ``Z_ew`` = GFM_Metallicity / Z_sun and ``Z_fe_ew`` = X_Fe / X_Fe,sun in
              solar units of the fit's abundance table (``metallicity_abund_table`` root
              attribute, e.g. ``lodd``; the solar values are the attributes
              ``metallicity_z_sun`` and ``metallicity_xfe_sun``); NaN on a snapshot without
              ``GFM_Metals`` (Fe) or without the field.  The scalar Z_ew(<R500c) of both
              phases is in the summary (``z_ew_r500c_<phase>``, ``z_fe_ew_r500c_<phase>``);
``mass_grid/``  (format 3) ``r_kpc``, ``M_msun``: the particle mass profile M(<r) on
              the fine log grid 0.05-5 R500c behind ``m500c_particles_msun`` and the
              per-view ``m500c_zobs_msun`` / ``r500c_zobs_kpc``
              (:func:`~tngxmm.sim.compute_hse_mass.m500_at_z`);
``native/<key>/`` every estimator of the truth columns on its OWN grid (Barnes
              et al. 2021: 50 linear shells over 0-1.5 R500c, Pearce et al.
              2020: 50 log shells over 0.05-2 R500c, 48 log shells over
              0.05-3 R500c): ``r_kpc``, ``M_msun``; the headline
              (``barnes21_nosf_fit_mu``) is the exact curve behind
              ``m500c_hse_msun``.

Phases: ``nonsf`` all zoom gas with SFR == 0 (the headline's cells, no
temperature cut); ``hot`` non-SF and T > 5.5e6 K (X-ray-like
cells); ``mock`` the cells the mock emits from (the mock's loader selection,
T >= t_min_k with per-cell X_H, SFR == 0, net cooling, inside the clip
sphere).  Root attributes carry the catalogue values, the centre, the grid,
the selections and the provenance (spec_hash, git, package version); from format
3 also ``summary_json`` (the scalar summary of the truth computation, from which
:func:`hse_from_truth_profile` rebuilds every truth column of any view of the
halo exactly) and ``truth_selection`` (``fof`` / ``zoom`` from the generation,
``sphere`` from the spherical truth stage, :mod:`tngxmm.sim.truth_sphere`, which
adds its own ``sphere_*`` attributes: cutout radius, particle counts, the shell
filling factor at R500c as a sanity check, the low-resolution contamination of
a TNG-Cluster zoom).

References
----------
Barnes et al. 2021 (HSE definitions); Pearce et al. 2020; Mazzotta et al.
2004 (T_sl); IllustrisTNG / TNG-Cluster particle data.
"""

from __future__ import annotations

import functools
import math
import os
from pathlib import Path
from typing import Any

from tngxmm.cites import cites, collect_cites

FILENAME = "truth_profile.h5"
#: format 2: ``gas/<phase>/fill`` added; ``rho_gas`` and the HSE masses
#: follow ``hse_shell_density`` (root attribute) and omit the shells filled below
#: ``hse_min_filling``.  Format 3 (spherical truth): ``mass_grid/`` and the
#: root attributes ``summary_json`` and ``truth_selection`` added (a file of either
#: selection; the spherical stage marks its own with ``truth_selection = 'sphere'``)
FORMAT = "tngxmm-truth-profile-3"
#: formats :func:`check_truth_profile_file` accepts (older trees keep format 2)
READABLE_FORMATS = ("tngxmm-truth-profile-2", FORMAT)
MODES = ("off", "on")

RMIN_R500, RMAX_R500, N_SHELLS = 0.01, 3.0, 60
PHASES = ("nonsf", "hot", "mock")
T_WEIGHTS = ("mw", "sl", "ew")

MSUN_G = 1.98841e33
KPC_CM = 3.0856775814913674e21
KEV_ERG = 1.602176634e-9
#: (gamma-1) rho u in Msun/kpc^3 (km/s)^2 -> keV cm^-3
P_TO_KEV_CM3 = MSUN_G * 1e10 / KPC_CM ** 3 / KEV_ERG

#: dataset -> (unit, definition); the writer puts both in the dataset attributes
GAS_FIELDS = {
    "rho_gas": ("Msun kpc^-3", "phase gas mass in the shell / shell volume (hse_shell_density "
                "'geometric') or / summed phase-cell volume ('filling': the density of the "
                "gas present)"),
    "fill": ("", "shell filling factor of the phase cells, sum V_cell / V_shell "
             "(V_cell = m / rho)"),
    "ne_vw": ("cm^-3", "volume-weighted mean n_e of the phase cells"),
    "ne_med": ("cm^-3", "median n_e of the phase cells (NaN with <= 10 cells)"),
    "ne_rms": ("cm^-3", "sqrt(sum n_e^2 V / sum V) of the phase cells"),
    "T_mw": ("keV", "mass-weighted temperature"),
    "T_sl": ("keV", "spectroscopic-like temperature, w = n_e^2 V T^-0.75 (Mazzotta+04)"),
    "T_ew": ("keV", "emission-weighted temperature, w = n_e^2 V T^0.5"),
    "K_mw": ("keV cm^2", "entropy T_mw ne_vw^(-2/3)"),
    "K_sl": ("keV cm^2", "entropy T_sl ne_vw^(-2/3)"),
    "P_th": ("keV cm^-3", "volume-weighted thermal pressure (gamma-1) rho u"),
    "n_cells": ("", "number of phase cells in the shell"),
}
KIN_FIELDS = {
    "sigma_r2": ("km^2 s^-2", "mass-weighted radial velocity dispersion about the shell mean"),
    "sigma_t2": ("km^2 s^-2", "mass-weighted mean tangential v^2 (two components)"),
    "beta": ("", "velocity anisotropy 1 - sigma_t2 / (2 sigma_r2)"),
    "vr_mean": ("km s^-1", "mass-weighted mean radial velocity (peculiar + Hubble flow)"),
    "P_kin": ("keV cm^-3", "rho_gas sigma_r2 (non-thermal radial pressure)"),
}
#: datasets of the optional ``metallicity/<phase>/`` groups (phases below)
METAL_FIELDS = {
    "Z_ew": ("Z_sun(table)", "emission-weighted (n_e n_H V) GFM_Metallicity / Z_sun of the "
             "abundance table"),
    "Z_fe_ew": ("X_Fe,sun(table)", "emission-weighted (n_e n_H V) iron mass fraction "
                "GFM_Metals[Fe] / solar iron mass fraction of the abundance table"),
}
METAL_PHASES = ("nonsf", "mock")
MASS_KEYS = ("M_tot", "M_gas", "M_dm", "M_stars", "M_bh", "M_gas_mock")
HSE_KEYS = tuple(f"M_{p}_{t}" for p in PHASES for t in T_WEIGHTS) + ("M_th_nonsf",
                                                                      "M_thkin_nonsf")
#: datasets the campaign check requires
REQUIRED = (("r_kpc", "r_edges_kpc")
            + tuple(f"mass/{k}" for k in MASS_KEYS)
            + tuple(f"mass/{k}_edges" for k in MASS_KEYS)
            + tuple(f"gas/{p}/{k}" for p in PHASES for k in GAS_FIELDS)
            + tuple(f"kinetic/{k}" for k in KIN_FIELDS)
            + tuple(f"hse/{k}" for k in HSE_KEYS))
REQUIRED_ATTRS = ("format", "snap", "halo_id", "sim", "z_snap", "h", "R500c_kpc", "M500c_msun",
                  "R200c_kpc", "M200c_msun", "centre_ckpc_h", "centre_kpc", "centre_definition",
                  "grid", "rmin_r500c", "rmax_r500c", "n_shells", "mu_hse", "periodic",
                  "particle_selection", "mock_selection", "mock_t_min_k",
                  "mock_clip_radius_kpc", "spec_hash", "git_hash", "package_version",
                  "created_utc", "hse_headline", "m500c_particles_msun",
                  "hse_shell_density", "hse_min_filling")
#: added in format 3
REQUIRED_FORMAT3 = ("mass_grid/r_kpc", "mass_grid/M_msun")
REQUIRED_ATTRS_FORMAT3 = ("summary_json", "truth_selection")

    """The truth-profile file of a halo directory (``<root>/<sim>/<snap>/<halo>/``)."""

class MassAccumulator:
    """Exact cumulative masses M(<r) at fixed radii (shell centres and edges), per kind."""

    def __init__(self, edges, cent) -> None:
        """Accumulator of cumulative masses [Msun] at the shell edges ``edges`` and the shell centres ``cent`` [kpc] of
        the truth profile."""
        import numpy as np

        self.edges, self.cent = edges, cent
        self.radii = np.concatenate([cent, edges])
        self.m: dict[str, Any] = {}



[docs]
    def add(self, kind: str, r, m) -> None:
        """Add the masses ``m`` [Msun] of particles at radii ``r`` [kpc] of species ``kind`` (``gas``, ``dm``,
        ``stars``, ``bh`` or ``gas_mock``) to the cumulative mass at every radius."""
        import numpy as np

        r = np.asarray(r)
        o = np.argsort(r, kind="stable")
        self.add_sorted(kind, r[o],
                        np.concatenate([[0.0], np.cumsum(np.asarray(m, np.float64)[o])]))





[docs]
    def add_sorted(self, kind: str, r_sorted, cumsum0) -> None:
        """Add from radii already sorted and their cumulative masses with a leading 0."""
        import numpy as np

        got = cumsum0[np.searchsorted(r_sorted, self.radii, side="right")]
        self.m[kind] = self.m.get(kind, 0.0) + got

    def result(self) -> dict:
        """The cumulative masses per species at the centres (``M_<kind>``) and edges (``M_<kind>_edges``), and the total
        of gas, dark matter, stars and black holes (``M_tot``)."""
        import numpy as np

        nc = len(self.cent)
        zero = np.zeros(len(self.radii))
        out = {}
        for k in ("gas", "dm", "stars", "bh", "gas_mock"):
            v = np.asarray(self.m.get(k, zero), float)
            out[f"M_{k}"], out[f"M_{k}_edges"] = v[:nc], v[nc:]
        tot = sum(np.asarray(self.m.get(k, zero), float) for k in ("gas", "dm", "stars", "bh"))
        out["M_tot"], out["M_tot_edges"] = tot[:nc], tot[nc:]
        return out

def shell_index(r, edges):
    """Shell of each radius (-1 / n outside), int16 (numpy's stable sort is a radix sort)."""
    import numpy as np

    if len(edges) > 30000:
        raise ValueError("too many shells for int16 shell indices")
    return (np.searchsorted(edges, r, side="right") - 1).astype(np.int16)

def shell_order(idx):
    """Stable argsort of the shell indices (shared by every median of one cell set)."""
    import numpy as np

    return np.argsort(idx, kind="stable")

def shell_median(x, mask, idx, order, nb: int):
    """Median of ``x`` over the ``mask`` cells of each shell, NaN with <= 10 cells (the
    HSE truth's ``bmed`` rule, with one shared sort instead of one per call)."""
    import numpy as np

    o = order[mask[order]]
    ii = idx[o]
    xx = x[o]
    cuts = np.searchsorted(ii, np.arange(nb + 1))
    out = np.full(nb, np.nan)
    for k in range(nb):
        if cuts[k + 1] - cuts[k] > 10:
            out[k] = np.median(xx[cuts[k]:cuts[k + 1]])
    return out

def phase_profiles(idx, edges, m, T_K, ne, V, mask, P=None, order=None,
                   density: str = "geometric") -> dict:
    """The ``gas/<phase>`` arrays of the cells in ``mask`` (``idx``: :func:`shell_index`,
    ``order``: its :func:`shell_order`; ``m`` Msun, ``T_K`` K, ``ne`` cm^-3, ``V`` kpc^3,
    ``P`` Msun/kpc^3 (km/s)^2; ``density``: ``rho_gas`` by
    :func:`~tngxmm.sim.compute_hse_mass.shell_gas_density`)."""
    import numpy as np

    from tngxmm.sim.compute_hse_mass import KEV_K, _shell_tools, shell_gas_density

    nb = len(edges) - 1
    vol = 4.0 / 3.0 * np.pi * np.diff(edges ** 3)
    bs, _ = _shell_tools(idx, nb)
    order = shell_order(idx) if order is None else order
    with np.errstate(invalid="ignore", divide="ignore"):
        Vs = bs(V, mask)
        Ms = bs(m, mask)
        rho, fill, _ = shell_gas_density(Ms, Vs, vol, density)
        wsl = ne ** 2 * V * T_K ** -0.75
        wew = ne ** 2 * V * np.sqrt(T_K)
        out = dict(rho_gas=rho, fill=fill,
                   ne_vw=bs(ne * V, mask) / Vs,
                   ne_med=shell_median(ne, mask, idx, order, nb),
                   ne_rms=np.sqrt(bs(ne ** 2 * V, mask) / Vs),
                   T_mw=bs(T_K * m, mask) / Ms / KEV_K,
                   T_sl=bs(T_K * wsl, mask) / bs(wsl, mask) / KEV_K,
                   T_ew=bs(T_K * wew, mask) / bs(wew, mask) / KEV_K,
                   P_th=(bs(P * V, mask) / Vs * P_TO_KEV_CM3) if P is not None
                   else np.full(nb, np.nan),
                   n_cells=bs(np.ones(len(m)), mask))
        out["K_mw"] = out["T_mw"] * out["ne_vw"] ** (-2.0 / 3.0)
        out["K_sl"] = out["T_sl"] * out["ne_vw"] ** (-2.0 / 3.0)
    out["rho_gas"][out["rho_gas"] <= 0] = np.nan
    return out

def metallicity_profiles(idx, nb: int, w, zsol, zfe, mask) -> dict:
    """``{'Z_ew', 'Z_fe_ew'}`` per shell: the emission-weighted (``w`` = n_e n_H V) mean of
    ``zsol`` (total metallicity, solar units) and ``zfe`` (iron, solar units) of the cells in
    ``mask`` (``idx``: :func:`shell_index`); NaN in shells without weight and for a field that
    is ``None`` (absent from the snapshot)."""
    import numpy as np

    from tngxmm.sim.compute_hse_mass import _shell_tools

    bs, _ = _shell_tools(idx, nb)
    out = {}
    with np.errstate(invalid="ignore", divide="ignore"):
        ws = bs(w, mask)
        for name, z in (("Z_ew", zsol), ("Z_fe_ew", zfe)):
            out[name] = (np.full(nb, np.nan) if z is None
                         else np.where(ws > 0, bs(w * z, mask) / ws, np.nan))
    return out

def hse_from_phase(cent, prof: dict, min_filling: float | None = None) -> dict:
    """``{T: M_HSE(<r)}`` [Msun] of one phase for T in :data:`T_WEIGHTS`
    (gas density slope + T slope, mu = 0.59, the HSE truth's smoothed log-slopes);
    shells with ``fill < min_filling`` are left out of the slopes (NaN)."""
    import numpy as np

    from tngxmm.sim.compute_hse_mass import _mx

    rho = np.asarray(prof["rho_gas"], float)
    omit = (np.zeros(len(rho), bool) if min_filling is None or "fill" not in prof
            else ~(np.asarray(prof["fill"], float) >= float(min_filling)))
    rho = np.where(omit, np.nan, rho)
    with np.errstate(invalid="ignore", divide="ignore"):
        return {t: _mx(np.where(omit, np.nan, prof[f"T_{t}"]), rho, cent) for t in T_WEIGHTS}

def summary_json(summary: dict) -> str:
    """The scalar summary of a truth computation as JSON (floats by ``repr``, so the
    round trip is exact; NaN as ``NaN``)."""
    import json

    import numpy as np

    def plain(v: Any) -> Any:
        if isinstance(v, (bool, np.bool_)):
            return bool(v)
        if isinstance(v, (int, np.integer)):
            return int(v)
        if isinstance(v, (float, np.floating)):
            return float(v)
        return v if isinstance(v, str) else str(v)

    return json.dumps({k: plain(v) for k, v in summary.items()}, sort_keys=True)

def hse_from_truth_profile(path: str | Path) -> dict:
    """The parts of a :func:`~tngxmm.sim.compute_hse_mass.compute_hse_truth` result the
    truth columns need (``summary``, ``mass_profile``, ``attrs``, ``h``, ``om0``; ``ValueError`` when the file has no ``summary_json``), read back from a
    format-3 file: :func:`tngxmm.sim.generate_view.view_truth_columns` of the result
    equals, bit for bit, the columns computed when the file was written."""
    import json

    import h5py
    import numpy as np

    with h5py.File(path, "r") as f:
        if "summary_json" not in f.attrs:
            raise ValueError(f"{path}: format {f.attrs.get('format')!r} has no summary_json")
        sj = f.attrs["summary_json"]
        s = json.loads(sj.decode() if isinstance(sj, bytes) else sj)
        mp = (np.asarray(f["mass_grid/r_kpc"][()]), np.asarray(f["mass_grid/M_msun"][()]))
        attrs = {k: (v.decode() if isinstance(v, bytes) else v) for k, v in f.attrs.items()}
        return {"summary": s, "mass_profile": mp, "h": float(f.attrs["h"]),
                "om0": float(f.attrs["om0"]), "attrs": attrs}

def write_truth_profile(hse: dict, path: str | Path, *, sim: str, spec_hash: str = "",
                        campaign: str = "", **extra: Any) -> Path:
    """Write the truth-profile file of a :func:`compute_hse_truth` result computed with
    ``profile=True`` (atomic: temporary file in the same directory, then rename)."""
    import h5py
    import numpy as np

    if "truth_profile" not in hse:
        raise ValueError("compute_hse_truth was run without profile=True")
    tp = hse["truth_profile"]
    path = Path(path)
    path.parent.mkdir(parents=True, exist_ok=True)
    tmp = path.with_name(f".{path.name}.{os.getpid()}.tmp")

    def put(grp, name, arr, unit, definition):
        d = grp.create_dataset(name, data=np.asarray(arr, np.float64))
        d.attrs["unit"] = unit
        d.attrs["definition"] = definition

    with h5py.File(tmp, "w") as f:
        for k, v in _attrs_of(hse, sim=sim, spec_hash=spec_hash, campaign=campaign,
                              extra=extra).items():
            f.attrs[k] = np.asarray(v) if isinstance(v, (list, tuple, np.ndarray)) else v
        put(f, "r_kpc", tp["r_kpc"], "kpc", "geometric shell centres (physical)")
        put(f, "r_edges_kpc", tp["r_edges_kpc"], "kpc", "shell edges (physical)")
        g = f.create_group("mass")
        for k in MASS_KEYS:
            what = {"M_tot": "gas + DM + stars + BH", "M_gas": "all gas",
                    "M_dm": "dark matter", "M_stars": "stars and wind particles",
                    "M_bh": "black holes",
                    "M_gas_mock": "gas of the mock's emitting cells"}[k]
            put(g, k, tp["mass"][k], "Msun", f"M(<r) at r_kpc, exact particle sum: {what}")
            put(g, f"{k}_edges", tp["mass"][f"{k}_edges"], "Msun",
                f"M(<r) at r_edges_kpc, exact particle sum: {what}")
        for p in PHASES:
            g = f.create_group(f"gas/{p}")
            g.attrs["selection"] = tp["phase_definitions"][p]
            for k, (u, dfn) in GAS_FIELDS.items():
                put(g, k, tp["gas"][p][k], u, dfn)
        if tp.get("metallicity"):          # additive: older readers ignore the group
            for p in METAL_PHASES:
                g = f.create_group(f"metallicity/{p}")
                g.attrs["selection"] = tp["phase_definitions"][p]
                for k, (u, dfn) in METAL_FIELDS.items():
                    put(g, k, tp["metallicity"][p][k], u, dfn)
        g = f.create_group("kinetic")
        g.attrs["selection"] = tp["phase_definitions"]["nonsf"]
        for k, (u, dfn) in KIN_FIELDS.items():
            put(g, k, tp["kinetic"][k], u, dfn)
        g = f.create_group("hse")
        for k in HSE_KEYS:
            if k == "M_th_nonsf":
                dfn = "-r^2/(G rho_gas) dP_th/dr, P_th volume-weighted (gamma-1) rho u, no mu"
            elif k == "M_thkin_nonsf":
                dfn = ("-r/(G rho_gas) d(P_th + rho_gas sigma_r2)/dln r - 2 beta sigma_r2 r / G "
                       "(Jeans, non-SF gas)")
            else:
                _, p, t = k.split("_")
                dfn = (f"-(k T_{t} r/(G mu m_p)) (dln rho_gas/dln r + dln T_{t}/dln r), "
                       f"phase {p}, mu = 0.59")
            put(g, k, tp["hse"][k], "Msun", dfn)
        g = f.create_group("mass_grid")
        r_grid, m_grid = hse["mass_profile"]
        put(g, "r_kpc", r_grid, "kpc", "fine log grid 0.05-5 R500c (physical)")

            "(gas + DM + stars + BH of the truth selection)")

                           "(compute_hse_mass); Barnes+21 linear 0-1.5 R500c, Pearce+20 "
                           "log 0.05-2 R500c, audit 48 log shells 0.05-3 R500c")

    os.replace(tmp, path)
    return path

def read_truth_profile(path: str | Path) -> dict:
    """``{'attrs': {...}, '<group>/<name>': array, ...}`` (native curves as
    ``native/<key>/r_kpc`` and ``native/<key>/M_msun``)."""
    import h5py
    import numpy as np

    out: dict[str, Any] = {}
    with h5py.File(path, "r") as f:
        out["attrs"] = {k: (v.decode() if isinstance(v, bytes) else
                            v.tolist() if isinstance(v, np.ndarray) else v)
                        for k, v in f.attrs.items()}

        def visit(name, obj):
            if isinstance(obj, h5py.Dataset):
                out[name] = obj[()]
        f.visititems(visit)
    return out

def check_truth_profile_file(path: str | Path, *, snap: int | None = None,
                             halo_id: int | None = None) -> list[str]:
    """Problems of one truth-profile file (campaign check C2); empty when complete:
    format, required datasets and attributes, shapes, the halo, M_tot monotonic and
    M_tot(<R500c) within 5 % of the catalogue M500c."""
    import numpy as np

    p = Path(path)
    if not p.exists():
        return [f"{p.name} missing"]
    try:
        d = read_truth_profile(p)
    except Exception as e:
        return [f"{p.name}: {e!r}"[:200]]
    a = d["attrs"]
    prob: list[str] = []
    if a.get("format") not in READABLE_FORMATS:
        prob.append(f"format {a.get('format')!r}")
    f3 = a.get("format") == FORMAT
    lack_a = [k for k in REQUIRED_ATTRS + (REQUIRED_ATTRS_FORMAT3 if f3 else ()) if k not in a]
    lack_d = [k for k in REQUIRED + (REQUIRED_FORMAT3 if f3 else ()) if k not in d]
    if lack_a:
        prob.append(f"attrs lack {lack_a[:4]}")
    if lack_d:
        prob.append(f"datasets lack {lack_d[:4]}")
    if prob:
        return prob
    n = int(a["n_shells"])
    bad = [k for k in REQUIRED if k != "r_edges_kpc" and not k.endswith("_edges")
           and np.shape(d[k]) != (n,)]
    if bad or np.shape(d["r_edges_kpc"]) != (n + 1,):
        prob.append(f"shape mismatch {bad[:3]}")
    if snap is not None and int(a["snap"]) != int(snap):
        prob.append(f"snap {a['snap']} != {snap}")
    if halo_id is not None and int(a["halo_id"]) != int(halo_id):
        prob.append(f"halo {a['halo_id']} != {halo_id}")
    mt = np.asarray(d["mass/M_tot_edges"])
    if not (np.all(np.isfinite(mt)) and np.all(np.diff(mt) >= 0)):
        prob.append("M_tot(<r) not finite and monotonic")
