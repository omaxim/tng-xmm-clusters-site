# Reference ledger: claims to verify by hand

State on 2026-11-12: 43 rows are `open`, i.e. not yet checked by hand against the original (row 35 was checked against the arXiv PDF on 2026-11-12). This is a separate check
from the page proofs of the assumption ledger (`tngxmm ledger proofs`, which locate each quoted text on its arXiv PDF
page). Until a row is checked, the value it carries is as read, with the reading mode stated below.

Every claim that a decision, a line of code or a sentence of the paper rests on,
with the source we took it from and how we read it. The author checks each row
against the original (PDF or journal page, not a summary) and fills in the last
two columns. This ledger is about CONTENT; the bibliographic metadata of each key
(authors, journal, DOI) is tracked separately by `verify:` in `citations/*.yml`.

How we read the sources: **primary** = the paper's own text (journal or arXiv);
**rendered** = an HTML rendering of the arXiv source (ar5iv / arxiv.org/html),
read through an automatic summariser, so equations and numbers can be garbled;
**secondary** = another paper or a search result quoting it; **code** = read in
the installed source; **internal** = our own reports.

Every numeric literature value the code uses (the published cluster masses of
`reference_masses.csv` and the constants: cosmology, c(M), abundances, truth definitions,
priors, instrument facts) is tabulated, with its table/equation, arXiv page and code
location, in the public `inputs/literature_values.csv` (see `inputs/README.md`); its
`verified` column follows the verdicts of this ledger. The paper sources themselves live in
the private references area, outside git.

Status: `open` (not checked), `ok` (checked, as stated), `fix` (checked, wrong:
correct the text/code), `drop` (do not use).
