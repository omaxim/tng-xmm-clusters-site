tngxmm.ingest.swift¶

Ingest of the SWIFT family: FLAMINGO snapshots and SOAP halo catalogues.

Runs in an environment whose HDF5 reads the lossy-compressed SWIFT and SOAP datasets (HDF5 1.10; the embed stack on Vera, descriptor halos.reader_note) and imports only numpy, h5py and the canonical-format modules.

  • soap_halos(): the halo table of a snapshot from SOAP (SO/500_crit, SO/200_crit, VR/CentreOfPotential, field halos VR/HostHaloID == -1);

  • read_cube(): every particle of the requested kinds inside the axis-aligned cube about a centre (per-axis minimum image), read through the snapshot’s top-level cell index (Cells/) so that only the cells overlapping the cube are read (the reading follows internal/ledger_tests/lx_gas_explore/xsim/flamingo_particles.py);

  • canonical_gas_arrays(): SWIFT gas fields -> canonical gas arrays (the conversions of the descriptor flamingo);

  • ingest_snapshot(): the canonical cubes of a list of halos, with a manifest.

Rules (descriptor flamingo): star forming StarFormationRates > 0; no wind, no net-heating flag (SWIFT writes no cooling rate); temperature and electron density as stored; the element fractions smoothed (the only ones written), the total metallicity smoothed with the particle value beside it (Z_particle); u derived from T for the truth. Neutrinos (PartType6) are not stored (their mass inside R500c is a few 1e-3 of the total; the truth’s mass profile leaves them out).

References

flamingo, flamingo_dr (simulation and data release); swift (snapshot format, cell metadata); soap, velociraptor (halo catalogue); ploeckinger2020 (the cooling tables behind the stored temperatures and electron densities).
