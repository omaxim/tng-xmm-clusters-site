tngxmm.sim.read_halo_source¶

Read snapshot chunks and public-API cutouts through one HaloSource interface.

The illustris_python import helper and the snapshot units (cosmo_units()), for the simulation output and for the TNG public-API cutout layout of the test fixtures (tests/fixtures/README.md, format_version = "tngxmm-fixture-1").

Two backends implement tngxmm.schemas.signatures.HaloSource (header(), group(halo_id), gas(halo_id, fields), dark_matter(halo_id, fields)) plus subhalo, particles, groupcat_header (cosmo_units(source) is a module-level function):

  • SnapshotHaloSource illustris_python on the simulation output (loadHalo for selection='fof', loadOriginalZoom + a periodic radius cut for 'zoom', every chunk + a radius cut for 'spatial');

  • CutoutHaloSource one fixture HDF5 (InFoF == 1 for 'fof', every particle + the same radius cut for 'zoom' and 'spatial').

Both return the particles in snapshot order with native dtypes, so the gas loader gives bit-identical arrays from either (for loader='fof').

References

illustris_python (snapshot and group-catalogue readers); TNG-Cluster data release (Nelson et al. 2024; Nelson et al. 2019, the public-API cutout layout).
