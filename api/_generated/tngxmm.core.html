tngxmm.core¶

Shared core: the one cosmology, RNG seeding, roots and site paths, provenance stamping, logging and units, the campaign pool, runner and checks, the memory budget, the node queue, the data bundle and the Kedro datasets. Stages import from here and never re-implement these. Sub-modules import their scientific dependencies lazily.

Modules

bundle

Frozen input tables of the data package, and the local data bundle.

campaign_checks

compare_tables

Does a rebuilt table hold the rows of an earlier one unchanged?

cosmology

The one cosmology of the pipeline and the TNG h-convention helpers.

datasets

Kedro datasets of the project (used by conf/*/catalog/*.yml only).

diskguard

Writes that survive a full disk: atomic files, completeness tests, the disk-full stop.

fetch

Download what a machine away from the cluster needs, from the release files of the repository.

freeze

hashing

File digests for provenance records (the one copy of the chunked-read helpers).

logging

Logging for every stage: one format, configured once.

membudget

Node-wide memory budget of the campaign workers: one token pool (GB) shared by every worker of every pool on the node, the per-halo memory estimate, peak-RSS reporting.

node_queue

paths

pool

Campaign process pool: one task per halo, the gas-load semaphore, the resumable results CSV.

provenance

Provenance stamping: package version, git hash (+ dirty flag), CampaignSpec hash.

rng

runner

One-node SLURM runner: the per-user guard, one sbatch per explicit go, provenance.

site

Site configuration: the one place where machine-specific paths enter the package.

units

Physical constants and the unit-suffix convention for column names.
