tngxmm.core.bundle¶

Frozen input tables of the data package, and the local data bundle.

Two things live here:

  • Frozen input tables (FROZEN_LEGACY_FILES). The real fits and the image bank read a few small tables (fit target lists, the ECF and APEC reference tables, the catalogue snapshot, …). Byte-identical copies live in the data package under $TNGXMM_DATA/legacy_v3/ and legacy_v2/ at the same relative path, each asset with a SHA256SUMS; tngxmm.core.paths.frozen_legacy() reads them first, so no module needs the source trees. tngxmm data freeze-legacy (re)creates the copies from the source trees and tngxmm data verify checks every SHA256SUMS.

  • The local bundle (bundle.yml next to this module): what a laptop needs to run the analysis stages from stored products (photometry on stored views, massfit renders from the shipped rate cache, bank, embed, ml, viz), where each item comes from on the producing machine and where it goes in the bundle. tngxmm data bundle --list reports the items with their sizes, --make <dir> copies them (SHA256SUMS and bundle.json written). See docs/LOCAL.md.
