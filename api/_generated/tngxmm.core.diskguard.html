tngxmm.core.diskguard¶

Writes that survive a full disk: atomic files, completeness tests, the disk-full stop.

A production run can hit the quota in the middle of any write. Three rules keep such a run resumable, and every stage driver (generation pool, SAS queue, fit batch) follows them through this module:

  • a product is written under a temporary name in its own directory (.<name>.<pid>.tmp), synced and renamed (atomic_path(), atomic_open(), write_text(), write_json()), so a file with its final name is complete. An item with several files gets its done-marker last, after the files were synced (sync_tree()), and loses the marker first when it is made again;

  • a failure caused by the disk (ENOSPC / EDQUOT, or the message an external tool leaves: is_disk_error(), and failure_status(), which also asks the disk itself with a probe write) is not a failure of the item: its status is interrupted: disk (INTERRUPTED), it is recorded nowhere and the next run makes it again;

  • after the first such item the driver takes no new item (request_stop(), seen by the forked workers through stop_requested()), lets the running ones end and exits with EXIT_DISK after one line starting with DISK FULL: (disk_message()).

The guard (check_space(), SpaceGuard) runs before the first item and every few minutes. os.statvfs gives the free space of the file system, not of a user’s quota, so the guard also writes and removes a few MB in the output root (probe_write()): that write fails when the quota’s hard limit is reached. Neither sees how much room is left under the quota.

Settings (environment; the defaults need no tuning): TNGXMM_DISK_PROBE_MB (8; 0 = no probe write), TNGXMM_DISK_MIN_FREE_GB (1, file-system free space) and TNGXMM_DISK_CHECK_S (120, the least time between two checks of a running driver).

The futures as they end (as concurrent.futures.as_completed), and None whenever interval_s passes without one ending: the driver checks the disk on a tick, so a disk that fills while every worker is busy for hours is noticed without waiting for the next item to end.
