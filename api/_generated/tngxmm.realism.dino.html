tngxmm.realism.dino¶

DINOv3 embeddings of the renders of real donors and mock views, and the C2ST on them.

The image the network sees is made by one code path for both populations: the 0.5-2 keV counts summed over the cameras of the per-camera products, rendered by tngxmm.bank.render_bank.render_rgb() (99th-percentile core top, background minus 0.25 dex floor, inferno colour map, 640 x 640 native-pixel crop), scaled to [0, 1] and normalised with the ImageNet mean and standard deviation; no resize. The embedding is the CLS token of the last layer of facebook/dinov3-vitl16-pretrain-lvd1689m (1024 numbers).

The weights are read from the local Hugging Face cache only ($HF_HUB_CACHE / $HF_HOME): the node never contacts the hub. The classifier on the embeddings is the grouped C2ST of tngxmm.realism.c2st on the first k principal components (fitted inside every training fold) with a strongly regularised logistic regression.

The embedding table has one row per image: key (the donor obsid, or the view id), kind (real | mock), donor_id and the numbers e0000 … e1023.
