tngxmm.instrument.donor_tables¶

The per-donor tables of the data package that the instrument stage reads.

Every table has one row (or a few) per real observation, keyed by its ten-digit obsid, and is BUILT by a node of the donor_tables Kedro pipeline (tngxmm.donor_tables) into $TNGXMM_DATA/tables/. The instrument options name the tables only to override the package copy (a study, a test); an empty name means the package table. Nothing here knows a machine path: $TNGXMM_DATA comes from the site file (tngxmm.core.paths.data_root()).

Six tables depend on where each donor’s cluster is (CENTRE_TABLES). The core offsets (donor_core_offsets.csv) are the cluster’s place on the detector, computed from the guarded centres; the anomalous-CCD table, the IN/OUT soft-proton table and the in-field background table (donor_background.csv) are measured outside a circle about those centres; the corner QPB table is measured for the donors of the same catalogue (the centre and seed tables); the condition table copies the core offsets and the background levels. The other files of the data package a view is made from that a builder of this package writes (BUILT_TABLES: the total column, the RASS sky, the active CCDs and the CCD maps, the source thresholds, the catalogue positions; the list of a preset is tngxmm.sim.data_inputs.stage_files()) are checked the same way. The package copy of each is read only when the provenance sidecar written with it (<table>.provenance.json) describes its bytes, says it was built from a committed, clean tree (git_dirty false), names the current versions of the files it was built from by their sha256 (current_inputs(): the centre and seed tables for the tables measured about the cluster, for the core offsets the centre table and observations.csv, for the two corner tables also the anomalous-CCD table, for the condition table also the core-offset and background tables, and so on), and, for the tables whose measurement is versioned, records the current measurement version and FWC reference rule (measurement_record(); check_table()). The inputs that lie outside the package are compared too: the published catalogue files of the catalogue positions through their pins, the PPS source lists of the source thresholds with the local PPS cache where it holds them. An input of the data package with a sidecar of its own must have been built from a clean tree too, and the package’s centre table must itself be current: copied from the current seed table, which is current for the production preset (tngxmm.photometry.build_obs_centres_guarded.check_centres_table(), the check the real fits make). A table named explicitly (an override) is the caller’s and is read as given.

Module Attributes

TABLE_FILES

logical name -> file of the data package tables asset

STAGE_FILES

further files of the data package tables asset that the generation of a view reads, each with a builder in this package (tngxmm.sim.data_inputs): logical name -> file

CENTRE_TABLES

tables that depend on the donors' cluster centres (module docstring) -> the command that rebuilds the package copy

BUILT_TABLES

the other files with a builder in this package that a view is made from (module docstring) -> the command that rebuilds the package copy

CHECKED_TABLES

every file checked by its provenance sidecar (check_table())

Functions

check_donor_tables(donors, spec[, image_root])

Fail fast, before any view is generated, when a donor of the campaign is absent from a donor table the preset reads (missing_donors()), except the donors the preset excludes from the generation (runtime.exclude_donors, tngxmm.core.pool.excluded_donors()): raises DonorTablesError with the list per table.

check_inputs(path, current, rebuild[, expect])

The provenance record of the table path when its sidecar (<table>.provenance.json, written by tngxmm.core.provenance.write_table_provenance()) describes the table's bytes (table_sha256), says the table was built from a committed, clean tree (git_dirty false: the recorded commit is the code that built it), records every value of expect (the measurement version and FWC rule of measurement_record()) and, for every name of current, the sha256 of that file as it is now (inputs.<name>.sha256), and when those inputs are clean and current themselves (_upstream()); else StaleTableError naming what differs and rebuild, the command that builds the table again.

check_table(name[, path])

check_inputs() of name (default its package copy) against current_inputs() and measurement_record(); returns the provenance record.

core_offset_gaps(donors)

The donors (obsids) without a usable row in the data package's core-offset table (read through its check against the current centres, read_table()): under the conditions rule donor the instrument places their clusters at those offsets, and would stop at the first view of such a donor.

current_inputs(name)

The files the package copy of name (one of CHECKED_TABLES) must have been built from, as they are now: the guarded centre table for the tables measured about the cluster; the observation table for the core offsets (the pointings), the total column, the RASS sky, the active CCDs and the CCD maps (the observations they cover); the seed table for the measured tables (R500, hence the radius of their regions, and the condition table's theta500); for the two corner tables the anomalous-CCD table (the CCDs their scales leave out); for the condition table also the core-offset and background tables (it copies their values) and the observation table (the donors it holds beside those of the target lists); the reddening table for the total column (with the reddening of the observations added to the bank, a package input), the total column for the sky, the CCD maps for the active CCDs, the core offsets for the anomalous CCDs (their pointings), the active CCDs for the condition table (the observation dates of the solar angle).

donor_rows(table, obsid, what)

The rows of one donor (the obsid is zero-padded to ten digits on both sides); KeyError naming what when the donor is absent.

is_package_copy(name, path)

Whether path is the data package's copy of table name (however it is spelled).

measurement_record(name)

The provenance values the package copy of table name must record to hold the current measurement: the measurement version of its builder (measure_version) and, for the two corner tables, whose scales are referred to the filter-wheel-closed data, the rule of that reference (fwc_rule, tngxmm.instrument.fwc_state.FWC_REFERENCE_RULE); for the catalogue positions also the file name and sha256 of the three published files outside the package it is built from (PSZ2, ACT DR6, the counterpart table: tngxmm.photometry.catalogue_positions.INPUT_PINS).

missing_donors(donors, opt[, conditions, ...])

{table: sorted donors it lacks} for the donors (obsids) of a campaign: every table of required_tables(), under detector_footprint != 'mask' the PPS exposure maps ('exposure_maps': no map of any camera in image_root) and under responses != 'packaged' the per-observation responses ('obs_responses': tngxmm.instrument.obs_responses.missing_responses()).

observations_csv()

The packaged observation table (tngxmm/obs/catalogue/observations.csv), whose pointings the core offsets are measured from.

pps_cache()

The local cache of the PPS source lists P<obsid>_OBSMLI.FTZ: $TNGXMM_PPS_CACHE, else the default cache of tngxmm.massfit.mask_point_sources (the one the real fits read).

pps_cache_mismatch(path[, cache])

What differs between the source-threshold table path and the PPS source lists of the local cache (default pps_cache()): a row's list (pps_file) present in the cache with another sha256 than the row records (pps_sha256), and a row flagged no_pps_list whose observation now has a list there.

qpb_unit_gaps(donors[, table])

{obsid: cameras} of the donors that have a camera with an exposure but no corner unit factor (tngxmm.instrument.donor_corner_qpb.donor_unit_factors(): no corner count in any CCD or quadrant, as for a pn exposure in a window mode).

read_table(name[, override])

Table name as a DataFrame with a string obsid (further column dtypes by keyword).

required_tables(opt[, conditions])

The donor tables the instrument stage reads for opt (InstrumentOptions): {logical name: override path or ''}.

soft_proton_gaps(donors, opt[, spec])

'<obsid> <camera>' of the donors (obsids) whose soft-proton rate the instrument could not set under opt (soft_protons on): a camera without a measured rate under sp_rate_unmeasured = 'refuse', or without a substitute under 'nearest-in-fold' (tngxmm.sim.generate_view.view_soft_protons(), the lookup of the stage).

table_path(name[, override])

The file of table name (of TABLE_FILES or STAGE_FILES): override when given, else the data package's.

Exceptions

DonorTablesError

Donors of a campaign that a donor table the preset reads does not hold.

StaleTableError

A table whose provenance does not name the current version of a file it was built from (for the donor tables of CENTRE_TABLES, the guarded centre table), or that has no provenance.

tngxmm.instrument.donor_tables.measurement_record(name)[source]¶

The provenance values the package copy of table name must record to hold the current measurement: the measurement version of its builder (measure_version) and, for the two corner tables, whose scales are referred to the filter-wheel-closed data, the rule of that reference (fwc_rule, tngxmm.instrument.fwc_state.FWC_REFERENCE_RULE); for the catalogue positions also the file name and sha256 of the three published files outside the package it is built from (PSZ2, ACT DR6, the counterpart table: tngxmm.photometry.catalogue_positions.INPUT_PINS). Empty for a table without a versioned measurement.

A table whose provenance does not name the current version of a file it was built from (for the donor tables of CENTRE_TABLES, the guarded centre table), or that has no provenance.

tngxmm.instrument.donor_tables.check_inputs(path, current, rebuild, expect=None)[source]¶

The provenance record of the table path when its sidecar (<table>.provenance.json, written by tngxmm.core.provenance.write_table_provenance()) describes the table’s bytes (table_sha256), says the table was built from a committed, clean tree (git_dirty false: the recorded commit is the code that built it), records every value of expect (the measurement version and FWC rule of measurement_record()) and, for every name of current, the sha256 of that file as it is now (inputs.<name>.sha256), and when those inputs are clean and current themselves (_upstream()); else StaleTableError naming what differs and rebuild, the command that builds the table again. A check that passed is remembered until a file or a sidecar changes (modification time and size).

tngxmm.instrument.donor_tables.observations_csv()[source]¶

The packaged observation table (tngxmm/obs/catalogue/observations.csv), whose pointings the core offsets are measured from.

tngxmm.instrument.donor_tables.current_inputs(name)[source]¶

The files the package copy of name (one of CHECKED_TABLES) must have been built from, as they are now: the guarded centre table for the tables measured about the cluster; the observation table for the core offsets (the pointings), the total column, the RASS sky, the active CCDs and the CCD maps (the observations they cover); the seed table for the measured tables (R500, hence the radius of their regions, and the condition table’s theta500); for the two corner tables the anomalous-CCD table (the CCDs their scales leave out); for the condition table also the core-offset and background tables (it copies their values) and the observation table (the donors it holds beside those of the target lists); the reddening table for the total column (with the reddening of the observations added to the bank, a package input), the total column for the sky, the CCD maps for the active CCDs, the core offsets for the anomalous CCDs (their pointings), the active CCDs for the condition table (the observation dates of the solar angle). The source thresholds and the catalogue positions take the observation table (the observations they cover); the rest of their inputs lies outside the package: the catalogue positions’ published files are compared through their pins (measurement_record()), the source thresholds’ PPS source lists with the local PPS cache where it holds them (pps_cache_mismatch()).

The local cache of the PPS source lists P<obsid>_OBSMLI.FTZ: $TNGXMM_PPS_CACHE, else the default cache of tngxmm.massfit.mask_point_sources (the one the real fits read).

tngxmm.instrument.donor_tables.pps_cache_mismatch(path, cache=None)[source]¶

What differs between the source-threshold table path and the PPS source lists of the local cache (default pps_cache()): a row’s list (pps_file) present in the cache with another sha256 than the row records (pps_sha256), and a row flagged no_pps_list whose observation now has a list there. A list the cache does not hold is not compared (the cache of a machine may be partial, or absent: then nothing is compared). Remembered until the table or the cache directory changes.

The donor tables the instrument stage reads for opt (InstrumentOptions): {logical name: override path or ''}. tngxmm.instrument.donor_tables.qpb_unit_gaps(donors, table=None)[source]¶

{obsid: cameras} of the donors that have a camera with an exposure but no corner unit factor (tngxmm.instrument.donor_corner_qpb.donor_unit_factors(): no corner count in any CCD or quadrant, as for a pn exposure in a window mode). Under qpb_units = 'corners' such a donor cannot lend its conditions: the particle background of that camera has no measured level per unit. table: the corner table (default: the data package’s).

tngxmm.instrument.donor_tables.missing_donors(donors, opt, conditions=None, image_root=None)[source]¶

{table: sorted donors it lacks} for the donors (obsids) of a campaign: every table of required_tables(), under detector_footprint != 'mask' the PPS exposure maps ('exposure_maps': no map of any camera in image_root) and under responses != 'packaged' the per-observation responses ('obs_responses': tngxmm.instrument.obs_responses.missing_responses()). Under the rule ‘nn’ the usable conditions donors (rows of the condition table with pool) are held to the same tables, since a view is observed with the tables’ rows of the donor it draws. Empty values are left out.

tngxmm.instrument.donor_tables.core_offset_gaps(donors)[source]¶

The donors (obsids) without a usable row in the data package’s core-offset table (read through its check against the current centres, read_table()): under the conditions rule donor the instrument places their clusters at those offsets, and would stop at the first view of such a donor.

tngxmm.instrument.donor_tables.soft_proton_gaps(donors, opt, spec=None)[source]¶

'<obsid> <camera>' of the donors (obsids) whose soft-proton rate the instrument could not set under opt (soft_protons on): a camera without a measured rate under sp_rate_unmeasured = 'refuse', or without a substitute under 'nearest-in-fold' (tngxmm.sim.generate_view.view_soft_protons(), the lookup of the stage). Empty with the soft protons off.

tngxmm.instrument.donor_tables.check_donor_tables(donors, spec, image_root=None)[source]¶

Fail fast, before any view is generated, when a donor of the campaign is absent from a donor table the preset reads (missing_donors()), except the donors the preset excludes from the generation (runtime.exclude_donors, tngxmm.core.pool.excluded_donors()): raises DonorTablesError with the list per table. Under the conditions rule donor with the placement donor-offset every donor needs a usable core offset (core_offset_gaps()); with the soft protons on every donor that can lend its conditions (the pool under nn) needs a rate for every camera, measured or substituted (soft_proton_gaps()). First, every data-package file a view of the preset is made from must be current (tngxmm.sim.data_inputs.check_stage_inputs()). Called by sim.plan_campaign (all targets) and by campaign run (the snapshot’s).
