tngxmm.sim.pipeline¶

Kedro pipeline of stage sim: the campaign that turns target views into mock observations.

What runs here is EXACTLY what production runs. The cluster job (slurm/campaign.sh, slurm/campaign_all.sh) calls python -m tngxmm.core.runner campaign run per snapshot, i.e. tngxmm.core.pool.run_campaign(); the node generate_views calls the same function with the same arguments, so the view tree, the results CSVs and every product are the same bytes (tests/e2e/test_kedro_fixtures.py compares a Kedro run with a campaign run of the same fixture views). Per view that function draws nothing itself: tngxmm.sim.generate_view.run_halo_task() seeds the view’s streams (core.rng.ViewStreams), loads the halo’s gas once, and for every view writes photons, absorbed events, the instrument products, the photometry, the hydrostatic truth and the temet-exact reference map. Under sim.truth_selection_hse = 'sphere' each run’s pool is followed by the spherical truth stage (tngxmm.sim.truth_sphere, campaign truth-sphere: the truth from every particle in a sphere about the halo centre replaces the generation’s FoF truth in the truth-profile files, the results CSV and obs_meta.json) before the run’s rows are read. With sim.loader = 'cutout' and sim.mock_cutout_shape = 'box' (the production gas) the mock emits from the cube about each halo that the mock-cutout stage has stored (tngxmm.sim.mock_cutout); that stage is a node of its own that runs before the generation. Four nodes:

targets ─plan_campaign─> campaign_plan                  (one run per snapshot)
campaign_plan ─cut_mock_gas─> mock_cutouts              (the cubes of the mock gas)
campaign_plan + mock_cutouts ─generate_views─> views, view_meta, truth_profiles, tngref_maps
campaign_plan + views ─check_campaign─> campaign_check  (C1-C17)
plan_campaign the runs: one campaign run per snapshot of the preset

(params:sim.snaps, default the preset’s snapshots; for a periodic-box preset only the snapshots with targets of its simulation), with the targets FILE, the source (the simulation output; the presets’ default loader 'cutout' reads the stored mock cube or truth sphere of each halo, the FoF members at their periodic minimum image for the 'fof' loader) and the output tree <params:sim.out_root>/<preset>.

cut_mock_gas the box cutouts of the mock gas of each run’s halos

(tngxmm.sim.mock_cutout.run_snapshot(), params:sim.mock_cutout: TNG-Cluster zoom workers, chunk-stream processes for the boxes; the cluster job is slurm/mock_cutout.sh); resumable, a halo already stored is skipped, nothing is cut for a preset whose gas is not the box.

generate_views tngxmm.core.pool.run_campaign() per run (forked pool

of params:sim.workers processes, the gas-load semaphore, resumable results CSV), then the spherical truth of the run’s halos (tngxmm.sim.truth_sphere.run_snapshot() and apply_sphere_truth(), params:sim.truth_sphere: workers, chunk workers, stream fields); returns the view table (the results CSV rows + preset, view_dir), the per-view donor package and seed (view_meta, from obs_meta.json) and two declared indices of the side products: truth_profiles (one truth_profile.h5 per halo-snapshot: the intrinsic 3-D profiles behind the truth columns, sim/truth_profile.py) and tngref_maps (one tngref_sb_map.fits per view: temet-exact surface brightness, sim/project_tngref_map.py).

check_campaign the acceptance checks C1-C17 on each tree

(tngxmm.core.campaign_checks.run_checks(), the campaign check command the job runs at its end); the report also goes to <tree>/checks/.

Targets: params:sim.targets picks the table: replica (donors.targets, campaigns/v4/targets_v4.csv: the replica campaign) or max (donors.max_targets, campaigns/v4_max/targets_v4_max.csv: the maximal campaign, both simulations; the runner keeps the rows of the preset’s simulation, the sim column). Seeds, drop_events, VIEW_ID and the view-schema columns are the runner’s (they come from the targets rows and the preset), never re-derived here.

tngxmm.sim.pipeline.plan_campaign(targets, max_targets, preset, options)[source]¶

The runs of generate_views: campaign runs (one per snapshot, the arguments of campaign run) or, in the fixtures environment, the explicit params:sim.runs (campaign runs on fixture cutouts).

A campaign run: preset, snap, out_root (<sim.out_root>/<preset>), targets_csv (the targets FILE: the runner reads it with its own dtypes), source (null = the preset’s sim.base_path), excluded (the views of the snapshot whose donor the preset excludes, runtime.exclude_donors: they are not generated and are recorded with status excluded: <reason>).

tngxmm.sim.pipeline.cut_mock_gas(campaign_plan, options)[source]¶

The mock-cutout stage of every planned run: [{preset, snap, report}] (the report of tngxmm.sim.mock_cutout.run_snapshot() without its per-halo results; None where the preset’s gas is not the box). A halo that failed to cut stops the node: the generation would refuse it.

tngxmm.sim.pipeline.generate_views(campaign_plan, mock_cutouts, options)[source]¶

Run every planned run; returns views, view_meta, truth_profiles, tngref_maps. mock_cutouts (the output of cut_mock_gas()) is a declared input only: it orders the stages.

views: one row per view of the plan (the results CSV columns, plus preset, view_dir, generation = campaign, instrument_replay = False). view_meta: per view directory, the donor package, the seed (_seed), the generation exposure [s] and the exact dither cap [arcmin] (dict-valued, so JSON).

tngxmm.sim.pipeline.check_campaign(campaign_plan, views, options)[source]¶

campaign check <tree> --preset P --targets T: C1-C17 per campaign tree.

The markdown and CSV reports go to <tree>/checks/ (as the CLI); the node returns the verdicts. options: sample (per-view checks on this many random views, 0 = all), reference_root, fail (raise when a check fails, as the CLI’s exit 1).
