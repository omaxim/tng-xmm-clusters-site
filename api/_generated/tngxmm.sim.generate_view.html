tngxmm.sim.generate_view¶

Generate the mock views of one halo: seeding, gas, photons, absorption, hand-off.

The per-view generation and seeding of the campaign (the process pool, the gas-load semaphore and the job layer belong to the orchestration stage). For each view, in this order:

  1. seed the view’s streams (tngxmm.core.rng.ViewStreams: the global numpy stream, then the view Generator); supplement views not listed in z_obs_fixed are skipped BEFORE seeding; cached views make no draw;

  2. load the gas once per halo (load_halo_gas through a HaloSource);

  3. intrinsic rest-frame 0.5-2 keV luminosities in cylinders (R500c, 1, 1.5 Mpc);

  4. z_obs: fixed, from the targets table (z_obs_fixed);

  5. donor observing conditions (a replica view takes its donor from rec['donor_packages']; otherwise deps.draw_donor when a caller binds one, stream donor; default_dependencies binds none) and the roll angle (posangle);

  6. photons for the longest camera time (generate_photons), then Galactic absorption (apply_absorption); only the absorbed list is kept;

  7. the pointing-dither cap;

  8. the instrument stage and the measured photometry, through deps (owned by the instrument and photometry stages; skipped when not given);

  9. obs_meta.json.

Cross-stage callables are injected through ViewDependencies so this stage never imports another stage’s internals; default_dependencies() binds the package implementations.

References

TNG-Cluster (Nelson et al. 2024); the emission and photon models cited by the called modules.

Module Attributes

measured columns and catalogue columns of the results row

cells of the *_tngref columns and maps (sim.lx_reference_gas)

TRUTH_SELECTIONS

particles of the truth (sim.truth_selection)

TRUTH_SELECTIONS_HSE

computed by the generation with sim.truth_selection, or by the spherical truth stage (tngxmm.sim.truth_sphere) after the generation

BOX_CYLINDER_MARGIN

the gas of the cube lies inside it by construction)

MOCK_GAS_REGIONS

parts of the stored cube that emit (sim.mock_gas_region) and the production one

TNGREF_COLS

intrinsic Lx in the TNG official convention (sim.lx_reference='temet-exact': temet's own table and per-cell treatment, rest band / (1+z_snap), no gas cut) temet-exact reference luminosities in temet's convention: the REST-FRAME 0.5-2 keV luminosity divided by (1 + z_snap) (sim/temet_xray.py), so lx_intr_* / lx_*_tngref = (1 + z_snap) for equal emission; compare after multiplying by (1 + z)

SNAPSHOT_COLS

snapshot kind of a row (snapshot_info())

VIEW_PRODUCT_FILES

SAS_MARKER

the done-marker of the SAS detection of a view (tngxmm.instrument.sas_detect), removed when the view is made again

Functions

cached_position_current(stored, opts)

True when the obs_meta.json record stored of a view on disk carries the catalogue position of the current rule of its physics donor (tngxmm.photometry.catalogue_positions.position_rule() with the preset's X-ray smoothing, every key and the version): a resumed campaign keeps only such views and makes the others again.

campaign_ccf_dir([spec])

Calibration directory of a run: spec.runtime.ccf_path, else $CCF_PATH, else the site's TNGXMM_SITE_CCF (the order of tngxmm.massfit.prepare_images.ccf_dir()); "" when none is set, which the instrument stage refuses.

campaign_source(source, opts[, cutout_tree, sim])

The source every read of the generation goes through (CampaignHaloSource): the gas-load slot of the campaign pool held for each RAW read only (mock gas, *_tngref cells, truth particles; the per-cell arithmetic and the HSE / profile computation run outside it), and with sim.periodic_wrap the coordinates moved to their minimum image about GroupPos.

catalogue_position_record(rule, evt_file)

The catalogue_position record of obs_meta.json: the position rule of the physics donor's catalogue entry (tngxmm.photometry.catalogue_positions.position_rule(): kind, catalogue, estimator, filter scale and beam (and the entry's S/N), or the X-ray smoothing, and the rule's version) and what the photon file evt_file holds of it: the position in the frame of xsky/ysky [deg], the map pixel [arcmin], the flag (ok, or global-elsewhere, merged, off-halo, edge), the distance from the position to the highest point of the map [arcsec], the fraction of the kernel about the position beyond the cylinder (edge_weight) and the truncation test of the edge flag (edge_shift_arcsec, None when the kernel stays inside the cylinder or no detection is left in the smaller one, and edge_tolerance_arcsec) (tngxmm.sim.catalogue_centre.catalogue_position()).

default_dependencies(spec)

Bind the package implementations of the donors, instrument and photometry stages.

draw_observing_conditions(opts, pkg, nh, ...)

What the instrument stage of one view will be given, drawn BEFORE the photons so the photon list is sized for it: the physics donor's own conditions (donors.observing_conditions unset or {rule: donor}: pkg, nh and posangle unchanged), or those of a conditions donor drawn from the view's conditions stream (rule nn): its package, its N_H, the rolled position angle and the jittered live times.

ensure_truth_profile(source, out_root, sim, ...)

Write the halo's truth-profile file if it is missing (or overwrite): compute_hse_truth() with the campaign's keywords (hse_truth_kwargs()) (the gas-load slot held for the raw reads only, campaign_source()).

generate_halo_views(rec, source, out_root, deps)

All views of one halo; returns one row per view.

generate_view(spec, source, view, out_root)

Generate ONE view of the halo held by source under preset spec.

halo_dir_of(out_root, sim, snap, halo_id)

<root>/<sim>/<snap:03d>/<halo:07d>/ (the parent of the view directories).

hse_truth_kwargs(opts, grp, a, h, r200c_kpc)

Keywords of compute_hse_truth() for one halo under opts: the mock's selection, sphere radius, clip sphere and floor (and profile when sim.truth_profiles is on).

instrument_stage(spec)

run_instrument for ViewDependencies: the call with ccf_dir= mapped onto run_xmm_simulator(options=...), with the instrument options of spec.

instrument_view_kwargs(spec, opt, info, ...)

Per-view keywords of the instrument stage that depend on the donor (the same calls as the instrument Kedro node): the mock obsid, the donor's filters, PN mode, per-camera submodes (SUBMODE headers, readout windows), the header context, the donor core offset and the donor's active CCDs.

load_tngref_cells(source, halo_id, grp, sub, ...)

The lx_reference_gas='zoom' read of one halo: (ref, ref_map) with ref = (p_kpc, lum) the *_tngref cells (clip reference_clip_kpc()) and ref_map the MapCells of the per-view maps (sim.tngref_map='on'; else None), from ONE snapshot read.

observation_columns(pkg, run_pkg, ...)

The observation a view was made under, for its results row and obs_meta.json.

opts_sim(spec)

Simulation name of a spec (sim.sim_name).

package_soft_protons(spec, pkg)

view_soft_protons() of the observation of a donor package (the conditions donor's under the rule nn) under the preset's instrument options: what the generation records for the view (soft_protons of obs_meta.json and of the conditions record).

photon_switches(opts, r500c_kpc[, ...])

The keyword arguments of generate_photons set by the options: the temperature sampling, the APEC version and the abundance table, and with los_depth_r500 the emitting cylinder (half-depth los_depth_r500 R500c, radius gas_radius_r500 R500c; r500c_kpc physical).

physics_real_times(pkg)

The physics donor's REAL per-camera live times [s]: cameras_real_s of the package (the observation's own times; a replica package's cameras_s are its JITTERED ones), else cameras_s of a package that is not jittered.

provenance_fields(opts)

obs_meta.json fields of the simulation switches.

recorded_provenance(opts)

provenance_fields() for the record of a made view (obs_meta.json, the closure truth.json): RuntimeError when the view was made with the per-observation responses and their set has no digest (no manifest), since the record would then not name the responses the photons saw.

reference_clip_kpc(meta)

Clip sphere [physical kpc, about GroupPos] of the lx_reference_gas='zoom' cells: just covers the widest intrinsic-Lx cylinder (radius max(R500c, 1.5 Mpc), half-depth R200c), so every cylinder holds ALL zoom gas, as the maps.

result_columns(spec)

Columns of the campaign results CSV for spec: the base columns (tngxmm.core.pool.RESULT_COLUMNS), plus the Lx flag and signed columns, the *_tngref intrinsic luminosities when sim.lx_reference is not 'none', the truth columns when sim.truth_columns is on, and the snapshot kind (core.pool.run_pool(columns=...)).

run_halo_task(task)

Campaign task function (tngxmm.core.pool.run_pool): all views of one halo.

sim_label(campaign)

Simulation of a preset name, for headers (v1_tng300 -> TNG300-1).

snapshot_info(snap[, source])

{'snap_is_mini': bool, 'snap_absent_fields': [...]} of a TNG snapshot (tngxmm.sim.snapshots; mini snapshots lack per-cell metals and cooling rates, so the per-cell fallbacks of the gas loader apply).

stage_observing_conditions(ob, nh, evt_abs, ...)

The second half of draw_observing_conditions(), once the absorbed photon list evt_abs exists: under the rule nn the list thinned and retargeted to the conditions donor's N_H (tngxmm.instrument.conditions_donor.stage_events()), the record written to <view_dir>/conditions.json.

view_complete(view_dir, stored)

True when the products of a view with the done-marker stored (its obs_meta.json) are whole: the merged image reads to its end and every file of the marker's products is there with its size.

view_dir_of(out_root, sim, snap, halo_id, view)

Campaign layout <root>/<sim>/<snap:03d>/<halo:07d>/view<view>/.

view_products(sizes)

The entries of sizes ({relative path: bytes} of a view directory, tngxmm.core.diskguard.sync_tree()) that are products of the view (VIEW_PRODUCT_FILES, VIEW_PRODUCT_DIRS).

view_soft_protons(spec, opt, obsid[, table])

The residual soft protons of the observation obsid (the view's conditions donor) under the instrument options opt: camera -> {'sp_rate', 'source', 'substitute', 'distance'} (tngxmm.instrument.donor_inout_sp.donor_soft_protons()), None under soft_protons = 'off'.

view_truth_columns(hse, z_obs, opts)

Truth columns of one view: the per-halo HSE columns (truth_columns(), the preset's variant in m500c_hse_msun) and M500 / R500 at 500 rho_c(z_obs) from the particles.

warm_campaign_caches(spec)

Pre-build the APEC tables of photon generation and the camera responses in the PARENT, before the pool forks, so the workers share them copy-on-write.

write_halo_truth_profile(hse, out_root, sim, ...)

truth_profile.h5 of one halo-snapshot (tngxmm.sim.truth_profile) in its halo directory, stamped with the preset's spec hash and HSE headline (extra_attrs: further root attributes, e.g. the spherical stage's).

write_tngref_view_map(view_dir, halo_ctx, ...)

The view's temet-exact surface-brightness map (sim.tngref_map='on'): tngxmm.sim.project_tngref_map.write_view_map() on the halo's map cells, VIEW_ID the replica's (donor package) or the canonical one.

A view is finished when its obs_meta.json exists: the file is written last, atomically, after the view’s files were flushed to the disk, and is removed first when the view is made again (tngxmm.core.diskguard). A view that fails because the disk is full gets the status interrupted: disk, the views after it are not started, and the next run makes them.

rec: a select_halos() record plus the task keys z_obs_fixed ({view: z}), z_donor ({view: obsid}), drop_events, and optionally donor_packages (replica views), seed_offset, no_dither_cap, tvir_frac. stop_after='posangle' stops each view after the roll angle draw (photon lists without the instrument stage).

tngxmm.sim.generate_view.generate_view(spec, source, view, out_root, deps=None, *, rec=None, **kwargs)[source]¶

Generate ONE view of the halo held by source under preset spec.

rec defaults to the halo’s select_halos() record (for a cutout, its one halo; for a snapshot, source.halo_id); that record carries no z_obs_fixed, so a caller must pass a rec that does (the view otherwise fails with ‘no z_obs in the targets’). kwargs go to generate_halo_views() (raise_errors, stop_after, verbose). Returns the view’s row.

tngxmm.sim.generate_view.run_halo_task(task)[source]¶

Campaign task function (tngxmm.core.pool.run_pool): all views of one halo.

task is a make_halo_tasks() dict: the halo’s select_halos() record, the task keys (z_obs_fixed, z_donor, seed_offset, no_dither_cap, tvir_frac, drop_events) and preset, out_root, source (simulation output directory or fixture cutout). Opens the source, binds the dependencies (default_dependencies()) and options of the preset and runs generate_halo_views(); views go to the campaign layout under out_root. Rows carry no private keys (dicts would not fit the results CSV).

tngxmm.sim.generate_view.warm_campaign_caches(spec)[source]¶

Pre-build the APEC tables of photon generation and the camera responses in the PARENT, before the pool forks, so the workers share them copy-on-write. Same cache keys as the per-view calls (generate_photons); the camera responses depend on the donor (per-donor filters, CCF pattern tables) and are built by the workers on first use.
