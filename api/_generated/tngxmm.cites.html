tngxmm.cites¶

Citations as code: the @cites decorator is the single source of truth.

Every function (or class) that implements, calls or reproduces published work declares it:

from tngxmm.cites import cites, collect_cites

@cites("mbproj2d", "sanders2018_bgprior")
def fit_hydrostatic(...): ...

__cites__ = collect_cites(__name__)      # last line of the module

From the decorator three things are generated, never written by hand :

  • obj.__cites__ on the function and the module-level __cites__ union (collect_cites()); a module without citations declares __cites__: list[str] = [] explicitly, and lint_package() fails on a module that declares nothing or under-declares;

  • Kedro node tags cite.<key> (cite_tags(), stage_node()) for the scientific references, data, instrument documents and scientific codes of a node; the general-purpose libraries of GENERIC_SOFTWARE are credited by tngxmm cite and the documentation but carry no tag; Kedro accepts only tags matching [\w.-]+, so cite:<key> is invalid;

  • the bibliography and CREDITS.md via tngxmm cite (keys resolved in citations/<stage>.yml; catalogue keys are the catalogue: true entries of citations/obs.yml).

Keys: lower case, [a-z0-9][a-z0-9_.-]* (Kedro-tag safe).

Module Attributes

KEDRO_TAG_RE

Kedro's own node-tag rule (kedro/pipeline/node.py, 0.19 and 1.0)

GENERIC_SOFTWARE

general-purpose libraries (arrays, tables, files, plotting, generic machine learning, optimisers used as libraries): credited in the bibliography and CREDITS.md through tngxmm cite and listed on the node pages of the documentation, but not turned into Kedro node tags, so that the tag filter of Kedro-Viz lists the scientific references, data sets, instrument documents and scientific codes of each node

REGISTRY

"<module>.<qualname>" -> keys, filled at import time by the decorator

CREDITED_STATUSES

statuses whose entries are credited (the others are listed separately)

adapts(*wrapped)

Give a node adapter the citations of the functions it calls.

Sorted union of every key used in the package.

(fragment, key, entry) of every citations/*.yml entry, in file then key order.

citations/ of the checkout, else of the installed package.

Keys recorded on obj by cites() (empty tuple if none).

cite_tags(obj)

Kedro-safe node tags cite.<key> for obj: every key of cite_keys() except the general-purpose libraries of GENERIC_SOFTWARE.

cites(*keys)

Record citation keys on a function or class (stackable, idempotent).

iter_modules([package])

Import and return every module of package (sorted by name).

known_keys([citations_dir])

Keys defined in citations/*.yml (the checkout's, else the copy shipped in the installed package, tngxmm.core.paths.repo_file()).

lint_package([package, citations_dir])

Problems: missing __cites__, under-declaration, invalid or unknown keys.

module_cites([package])

module name -> declared __cites__ for every module of the package.

render_credits([citations_dir])

The text of CREDITS.md (deterministic).

A Kedro node whose tags carry the function's cite.<key> tags.

stage_pipeline(nodes, namespace)

Kedro pipeline of one stage with namespace namespace.

Exceptions

CitationError

Invalid citation key or declaration.

tngxmm.cites.adapts(*wrapped)[source]¶

Give a node adapter the citations of the functions it calls.

A Kedro node sometimes needs a thin I/O adapter around a stage function (unpack a dict, write side products under a root). The adapter does no science of its own; its cite.<key> tags are the union of the wrapped functions’ keys, so the flowchart and tngxmm cite still see them.

tngxmm.cites.stage_pipeline(nodes, namespace)[source]¶

Kedro pipeline of one stage with namespace namespace.

Datasets the stage owns are written without prefix in its nodes and become <namespace>.<name>; datasets of another stage are written with their full name (obs.observations) and parameters as params:<stage>.<key> or params:preset; neither is prefixed again.
