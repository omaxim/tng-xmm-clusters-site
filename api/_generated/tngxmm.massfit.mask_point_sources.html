tngxmm.massfit.mask_point_sources¶

Point-source masks for the hydrostatic fit, the same on mocks and real data.

The readers make the masking usable on both sides (CampaignSpec.massfit.source_masking).

The mask zeroes the exposure map within mask_rad_as of each point source, so the masked pixels drop out of the image, the background and the coverage at once; sources within protect_core_as of the cluster centre are never masked, and no pixel within that radius is masked (the BCG / cool core survives). prepare_images.preprocess_one applies it per image on the native grid.

Source lists:

  • real observations: the XMM PPS source list P<obsid>EPX000OBSMLI0000.FTZ (emldetect), point-like sources only (EP_EXTENT == 0, the cluster itself is extended) above a detection likelihood EP_DET_ML > det_ml_min;

  • mocks: a source table with sky positions (RA/DEC columns, FITS or a whitespace table with a # header). A box-frame table carries RA = Dec = 0 (positions only in the simulator box frame), so mock_point_sources() refuses it; legacy_v3_mock_sources() projects its box positions onto the per-camera grid with the instrument stage’s own transform, and mock_sources_for_view() picks the right reader. The instrument stage writes sky positions. With massfit.mock_source_min_flux_cgs = "per-donor-density" a mock masks its sources above the flux at which the mock logN-logS has the PPS point-source density of the view’s DONOR observation, one threshold per donor in the data-package table of tngxmm.massfit.build_source_thresholds.

sources_for_target() applies these rules to one fit target and returns what it did (recorded by the fit in result.json, provenance.json and the fit_results table).

References

xmm_ccf_sas (PPS source lists, emldetect), xmm_mission (XSA/HEASARC archive).

tngxmm.massfit.mask_point_sources.legacy_v3_mock_sources(path, image_header, posangle_deg, min_flux_cgs=None, npix=648, pix_arcsec=4.0)[source]¶

[(ra, dec, flux)] of a pts_sources.fits box-frame text table.

The table carries RA = Dec = 0; the box position (X, Y) maps to the per-camera image grid exactly as the instrument stage projects the AGN (detector frame, rotated by the position angle, not dithered): offset = (X - 256, Y - 256) x 30’/512, rotated, then 0-indexed pixel 323.5 + offset / 4”. The sky position uses the per-camera image WCS (image_header), so source_mask() maps it back to the same pixel. On the fixture view the 60 brightest sources stack to 100 counts per 5x5 px against 10 at random offsets (tests/unit/test_massfit_switches.py).

tngxmm.massfit.mask_point_sources.sas_list_candidates(kind, obsid, *, image_path=None, data_root=None)[source]¶

Where the SAS edetect_chain source list of one fit target lives (first existing wins).

  • mock: <view>/sas_detect/sources.csv, written next to the view’s products by tngxmm instrument sas-detect --view-dir <view>; <view> is the directory of the view’s pts_sources.fits / image_merged.fits (found from the fit image image_path);
