tngxmm.sim.truth_profile¶

Per-halo TRUTH PROFILE file: the intrinsic 3-D profiles behind the truth columns.

Written when sim.truth_profiles = 'on'. The truth columns (tngxmm.sim.compute_hse_mass.truth_columns()) are scalars; this module writes the radial profiles they come from, once per halo-snapshot, so a fit of any of the halo’s views can be compared with the truth radius by radius (massfit.render_fit_v4). The arrays are filled inside compute_hse_truth() from the cells it has already loaded (no extra snapshot read; the mock-phase part from the second, mock-selection read the HSE truth already makes); this module holds the binning, the file schema, the writer, the reader and the check.

File <out_root>/<sim>/<snap:03d>/<halo:07d>/truth_profile.h5 (next to the view<k>/ directories; one per halo-snapshot, shared by its views).

Common grid: N_SHELLS log-spaced shells from RMIN_R500 to RMAX_R500 x R500c (catalogue) about GroupPos, physical kpc, minimum-image (periodic) distances. Groups:

mass/ cumulative masses at the shell centres AND outer edges (exact

particle sums, no interpolation): M_tot (gas + DM + stars + BH of the original zoom; sphere cutout for a box run), M_gas, M_dm, M_stars, M_bh, and M_gas_mock (the mock’s emitting cells);

gas/<phase>/ per shell, for each gas phase (PHASES): rho_gas

(phase mass / shell volume under hse_shell_density = 'geometric', phase mass / summed phase-cell volume under 'filling'), fill (shell filling factor sum V_cell / V_shell; the HSE masses below omit the shells with fill < hse_min_filling), ne_vw (volume-weighted), ne_med (shell median, >10 cells), ne_rms (sqrt <n_e^2>_V, what an emission measure sees), T_mw, T_sl (spectroscopic-like, w = n_e^2 V T^-0.75; Mazzotta et al. 2004), T_ew (emission-weighted, w = n_e^2 V T^0.5), K_mw / K_sl (k T n_e,vw^-2/3), P_th (volume-weighted (gamma-1) rho u), n_cells;

kinetic/ non-star-forming gas (the headline’s cells): sigma_r2,

sigma_t2 (both tangential components), beta, vr_mean (peculiar + Hubble flow about the halo bulk velocity, as the HSE truth’s th+kin), P_kin = rho_gas sigma_r^2;

hse/ M_HSE(<r) on the common grid: M_<phase>_<T> =

-(k T r / (G mu m_p)) (dln rho_gas/dln r + dln T/dln r), mu = 0.59 (Barnes et al. 2021 sec. 2.4, eq. 12, with the phase’s gas density), T in {mw, sl, ew}; M_th_nonsf (-r^2 / (G rho) dP_th/dr, P_th from the internal energy, no mu) and M_thkin_nonsf (+ rho sigma_r^2 and the Jeans anisotropy term); log-slopes by the HSE truth’s local quadratic fit over +-3 shells (_dln);

metallicity/<phase>/ (additive, format 3; phases nonsf and mock)

emission-weighted metallicity per shell, weights n_e n_H V (the cell’s own X_H): Z_ew = GFM_Metallicity / Z_sun and Z_fe_ew = X_Fe / X_Fe,sun in solar units of the fit’s abundance table (metallicity_abund_table root attribute, e.g. lodd; the solar values are the attributes metallicity_z_sun and metallicity_xfe_sun); NaN on a snapshot without GFM_Metals (Fe) or without the field. The scalar Z_ew(<R500c) of both phases is in the summary (z_ew_r500c_<phase>, z_fe_ew_r500c_<phase>);

mass_grid/ (format 3) r_kpc, M_msun: the particle mass profile M(<r) on

the fine log grid 0.05-5 R500c behind m500c_particles_msun and the per-view m500c_zobs_msun / r500c_zobs_kpc (m500_at_z());

native/<key>/ every estimator of the truth columns on its OWN grid (Barnes

et al. 2021: 50 linear shells over 0-1.5 R500c, Pearce et al. 2020: 50 log shells over 0.05-2 R500c, 48 log shells over 0.05-3 R500c): r_kpc, M_msun; the headline (barnes21_nosf_fit_mu) is the exact curve behind m500c_hse_msun.

Phases: nonsf all zoom gas with SFR == 0 (the headline’s cells, no temperature cut); hot non-SF and T > 5.5e6 K (X-ray-like cells); mock the cells the mock emits from (the mock’s loader selection, T >= t_min_k with per-cell X_H, SFR == 0, net cooling, inside the clip sphere). Root attributes carry the catalogue values, the centre, the grid, the selections and the provenance (spec_hash, git, package version); from format 3 also summary_json (the scalar summary of the truth computation, from which hse_from_truth_profile() rebuilds every truth column of any view of the halo exactly) and truth_selection (fof / zoom from the generation, sphere from the spherical truth stage, tngxmm.sim.truth_sphere, which adds its own sphere_* attributes: cutout radius, particle counts, the shell filling factor at R500c as a sanity check, the low-resolution contamination of a TNG-Cluster zoom).

References

Barnes et al. 2021 (HSE definitions); Pearce et al. 2020; Mazzotta et al. 2004 (T_sl); IllustrisTNG / TNG-Cluster particle data.

Module Attributes

FORMAT

Functions

check_truth_profile_file(path, *[, snap, ...])

Problems of one truth-profile file (campaign check C2); empty when complete: format, required datasets and attributes, shapes, the halo, M_tot monotonic and M_tot(<R500c) within 5 % of the catalogue M500c.

grid_edges(r500_kpc[, rmin_r500, rmax_r500, n])

(edges, geometric centres) of the common grid [physical kpc].

hse_from_phase(cent, prof[, min_filling])

{T: M_HSE(<r)} [Msun] of one phase for T in T_WEIGHTS (gas density slope + T slope, mu = 0.59, the HSE truth's smoothed log-slopes); shells with fill < min_filling are left out of the slopes (NaN).

hse_from_truth_profile(path)

The parts of a compute_hse_truth() result the truth columns need (summary, mass_profile, attrs, h, om0; ValueError when the file has no summary_json), read back from a format-3 file: tngxmm.sim.generate_view.view_truth_columns() of the result equals, bit for bit, the columns computed when the file was written.

is_sphere_truth(path)

True when path exists and was written by the spherical truth stage.

metallicity_profiles(idx, nb, w, zsol, zfe, mask)

{'Z_ew', 'Z_fe_ew'} per shell: the emission-weighted (w = n_e n_H V) mean of zsol (total metallicity, solar units) and zfe (iron, solar units) of the cells in mask (idx: shell_index()); NaN in shells without weight and for a field that is None (absent from the snapshot).

path_for(halo_dir)

The truth-profile file of a halo directory (<root>/<sim>/<snap>/<halo>/).

phase_profiles(idx, edges, m, T_K, ne, V, mask)

The gas/<phase> arrays of the cells in mask (idx: shell_index(), order: its shell_order(); m Msun, T_K K, ne cm^-3, V kpc^3, P Msun/kpc^3 (km/s)^2; density: rho_gas by shell_gas_density()).

read_truth_profile(path)

{'attrs': {...}, '<group>/<name>': array, ...} (native curves as native/<key>/r_kpc and native/<key>/M_msun).

shell_index(r, edges)

Shell of each radius (-1 / n outside), int16 (numpy's stable sort is a radix sort).

shell_median(x, mask, idx, order, nb)

Median of x over the mask cells of each shell, NaN with <= 10 cells (the HSE truth's bmed rule, with one shared sort instead of one per call).

shell_order(idx)

Stable argsort of the shell indices (shared by every median of one cell set).

summary_json(summary)

The scalar summary of a truth computation as JSON (floats by repr, so the round trip is exact; NaN as NaN).

write_truth_profile(hse, path, *, sim[, ...])

Write the truth-profile file of a compute_hse_truth() result computed with profile=True (atomic: temporary file in the same directory, then rename).
