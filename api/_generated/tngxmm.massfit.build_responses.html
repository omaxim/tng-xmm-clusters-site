tngxmm.massfit.build_responses¶

Per-camera and per-filter RMF/ARF.

Builds on-axis EPIC ARFs (one per camera x filter) and stages the RMFs for mbproj2d / XSPEC.

Why on-axis: the PPS EXPMAP products are effective-exposure maps that already carry the vignetting, so the spatial response must NOT be applied twice. The ARF handed to XSPEC is therefore the theta=0 curve and the exposure map supplies vig(theta, E) * t_exp per pixel:

counts(x, y) = rate[apec, rmf, arf_onaxis] * expmap(x, y)

The ARF model reproduces xmm_simulator.utils.calc_arf at theta=0 (where the CCF vignetting factor is exactly 1.0), so the mocks and the observations are fit through the same response model:

ARF(E) = A_mirror(E) * corr(E) * T_filter(E) * QE(E) * [areacorr(E) if MOS]

calc_arf itself cannot be reused: it calls scipy.interp2d (removed in SciPy >= 1.14) and hardcodes the Medium filter, whereas the real observations use Thin1 and Medium.

Outputs must land under a prefix the HEASoft container binds unchanged (TNGXMM_SITE_CONTAINER_BINDS, environment/sites/<site>.env): a path under $HOME would not resolve inside the container, and XSPEC is the process that opens these files.

The output directory is an explicit argument (never the production response directory); the CCF and RMF source directories are parameters whose defaults are site paths (tngxmm.core.site: the XMM CCF TNGXMM_SITE_CCF and the RMFs shipped with xmm_simulator). The ARF header ORIGIN string is fixed, so the files are byte-identical from run to run.

Which CCF file of each type an ARF reads (rule, the fit’s massfit.ccf_selection): 'highest-issue' (the default) takes the highest number in the file name, the scan of xmm_simulator; 'valid-at-date' takes the constituent SAS cifbuild selects for the observation date (tngxmm.instrument.ccf_select). The selection then changes with the epoch, so build_responses(rule='valid-at-date') writes one ARF set per interval of constant selection, ccf_<start>/<camera>_<filter>.arf, next to the RMFs, and the index ccf_selection.json (ccf_epoch_dir() finds the set of an image’s DATE-OBS).
